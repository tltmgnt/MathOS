# MathOS beginner bridge: four weeks to evidence-aware mathematics

**Audience:** first-time learners with arithmetic, basic algebra and no proof assistant experience. **Time:** 3–5 hours per week. **Software:** none required; optional Python 3.11+. **Outcome:** a human-reviewed portfolio of claims, arguments and negative controls. This is not a course completion certificate generated by CI.

## Week 1 — Statements, examples, and quantifiers

**Learn:** Sets, variables, "for all" and "there exists." An example illustrates a statement; it need not prove it.

**Hand exercise:** Assess "Every integer is even." Supply a counterexample. Then write "The sum of any two even integers is even" with integer quantifiers, and prove it by writing \(a=2m,b=2n\). 

**Check:** A reviewer must confirm you identified the domain and did not confuse a finite check with universal proof.

## Week 2 — Counterexamples and assumptions

**Learn:** Logical implication, assumptions and how one counterexample refutes a universal claim.

**Hand exercise:** Someone proposes "Every prime is odd." Test 2 and revise to "Every prime greater than 2 is odd." Explain why checking 3, 5 and 7 is still not a proof. Stretch: prove the revised claim by noting an even integer greater than 2 has divisor 2.

**Check:** Submit the original false claim, counterexample, revised statement, proof and limitations.

## Week 3 — Reproducible computation versus mathematical truth

**Learn:** Inputs, outputs, environments, finite test bounds, independent oracles.

**No-code exercise:** Evaluate \(f(n)=n^2+n\) for \(n=0,1,2,3\). Prove \(f(n)\) is even for every integer \(n\) by writing it as \(n(n+1)\). Explain why the algebra proves more than the table.

**Optional code route:**

```python
for n in range(-10, 11):
    assert (n*n + n) % 2 == 0
```

**Check:** State what the 21 tests establish and what the parity argument establishes. Note that a successful program tests the chosen implementation under its execution assumptions.

## Week 4 — Explain and transfer

**Learn:** MathOS TOPO-406's proof, explanation and transfer distinctions.

**Capstone:** Assess this claim: "Testing 100 inputs proves an algorithm correct for all integers." Create a one-page record with precise proposition, assumptions, attempted counterexample, observed outcome, revised conclusion, and transfer boundary. Use [TOPO-406 acceptance tests](../TOPO-406-acceptance-tests.md).

**Review rubric (20 points):** proposition precision 0–4; correct proof/counterexample 0–4; assumptions 0–4; explicit evidence boundary 0–4; clarity and reproducibility 0–4. At least 16/20 **and** no unsupported universal proof claim are recommended for a human instructor's progression decision. No automated certification is issued.
