Overview

MathOS v0.1.0 is the initial research release of the MathOS experimental framework.

This milestone consolidates 22 experiments investigating arithmetic behavior, model sensitivity, neural activation observations, and methods for evaluating mathematical competence.

The release emphasizes reproducible experimentation, transparent reporting, and evidence-based conclusions.

Key Research Findings

1. Arithmetic Understanding Was Not Demonstrated

The experiments did not establish reliable arithmetic competence in either evaluated model.

2. Constant Baselines Were Competitive

Experiment 020 found that tiny-GPT2 matched a constant-answer baseline on the original arithmetic benchmark.

3. Generalization Evaluation Produced No Correct Answers

Experiment 021 evaluated 25 addition problems outside the earlier operand grid.

Neither model produced a correct answer under the tested generation method.

4. Prompt Changes Did Not Improve Accuracy

Experiment 022 evaluated four prompt formats.

Neither model produced a correct answer on any of the 25 problems under any tested format.

DistilGPT2 generated numerical-looking outputs when given worked examples, but those outputs were mathematically incorrect.

Interpretation

The results support observations about model behavior, prompt sensitivity, and evaluation methodology.

They do not demonstrate internal mathematical reasoning.

The findings should not be generalized to all language models, prompts, or arithmetic tasks.

Known Limitations

* Small arithmetic evaluation sets
* Limited model selection
* In-sample baseline selection
* No independent held-out prompt-validation set
* No fine-tuning
* Greedy generation
* Dependency version ranges rather than a complete lockfile
* Exact model revisions not recorded in the experiment reports

Verification

The TOPO-406 GitHub Actions workflow successfully executed the research experiments, including Experiments 021 and 022, and uploaded their artifacts.

Release readiness requires a successful workflow run on the final release commit.

Release Scope

MathOS v0.1.0 is a research milestone.

It is not a demonstration of general mathematical intelligence, reliable arithmetic reasoning, or production-ready mathematical verification.

Next Steps

Future development may explore stronger arithmetic baselines, independently held-out evaluation sets, instruction-tuned models, and more rigorous causal analyses.

Such work is outside the scope of the v0.1.0 release.
