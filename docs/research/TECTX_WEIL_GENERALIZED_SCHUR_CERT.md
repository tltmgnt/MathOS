# ResearchOS / TECT-X — Verified generalized Weil eigenvalues and nested Schur extensions

**Scientific status:** a fixed, finite-dimensional, *function-norm-relative* positivity certificate for the **actual** arithmetic Weil form, plus a rigorous finite-block extension mechanism. **No** dimension-independent natural-function-norm constant for growing arbitrary spans, global Weil positivity, complete Weil Hilbert space, fixed self-adjoint zeta operator, or RH proof is asserted.

## 1. Exactly which two quadratic forms?

On the fixed space generated by

```text
q_c(t)=exp(-t²/100)*cos(c*t),  c in {0,1/5,1/2},
```

let `G_ij=W(q_(c_i) q_(c_j))` be the *actual* Weil arithmetic form. The previously validated matrix integration includes the poles, completed-zeta gamma/digamma terms and full von Mangoldt prime-power series, using certified interval error bounds (PR #78). No zeta-zero data are inputs.

Let `L_ij=<q_(c_i),q_(c_j)>_(L²(R))` be the ordinary positive Gaussian comparison Gram,

```text
L_ij = (sqrt(pi/a)/2) *
   [exp(-(c_i-c_j)²/(4a)) + exp(-(c_i+c_j)²/(4a))],
a=1/50.
```

The Gaussian L² Gram is **not** the Weil form; it supplies an independent meaningful function norm against which to measure positivity of the Weil form.

## 2. Certified generalized eigenvalue interval

The module imports the *already proven and interval-enclosed* `G` from `riemann_weil_certified_gram3.py`; it evaluates `L` with pinned outward interval arithmetic. It checks that all three pivots of `L` are positive and all three pivots of

```text
G - (1/50,000,000) L
```

are strictly positive. Since `L` is positive definite on the fixed span, this proves

```text
lambda_min(L^-1/2 G L^-1/2) > 1/50,000,000
```

or equivalently for every nonzero function `q_v=sum_j v_j q_(c_j)` in the fixed span,

```text
W(q_v²) > (1/50,000,000) * ||q_v||_(L²(R))².
```

This is an **intrinsic L²-relative inequality** for the selected finite space, not a coordinate-norm claim.

An independently specified **integer Rayleigh vector**

```text
v=(1000,1466,557)
```

passes the interval test `vᵀ [G-(1/1,000,000)L] v < 0`. Consequently, the exact smallest generalized eigenvalue also satisfies

```text
1/50,000,000 < lambda_min(G,L) < 1/1,000,000.
```

The upper bound is a direct witness, not the result of trusting a floating-point eigensolver or zero table. These bounds intentionally leave substantial room for the true value, approximately `5.18*10^-7`, and make only finite-dimensional claims.

## 3. Verified nested extensions: dimension 1 to 2 to 3

For a **verified** block matrix

```text
M = G - kappa*L = [ A  B ]
                  [ Bᵀ C ],  kappa=1/50,000,000,
```

suppose the old block `A` is proved positive. Its exact `LDLᵀ` decomposition `A=P D Pᵀ` gives

```text
S = C - Bᵀ A^-1 B
  = C - Yᵀ D^-1 Y,    P Y = B.
```

The block-Schur theorem says `M>0` **if and only if** `A>0` and `S>0`. The implementation performs all operations with outward interval enclosures, including the triangular solve, reciprocals and the final new-block LDL. A pivot interval including or touching zero **fails closed**.

The test runs this for **actual arithmetic blocks** from the fixed certified `3×3` matrix:

- `span(q_0)`;
- `span(q_0,q_(1/5))`, adding the verified 1×1 Schur complement;
- `span(q_0,q_(1/5),q_(1/2))`, adding a second verified 1×1 Schur complement.

This proves a stable **fixed** lower generalized bound along this particular finite nested chain. It is not an infinite-dimensional induction: the next Weil and L² cross blocks for a fourth function are *not* bounded or supplied. A synthetic fourth block in tests checks Schur algebra only and is **never** reported as an actual additional arithmetic Weil test.

## 4. Exact rational certificate and error budget

The complete report stores:
- outward rational intervals of all entries of `G` and `L`;
- verified `L` pivots and `G-kappa L` pivots;
- old-block and new-block Schur pivot enclosures for both actual finite extensions;
- the negative rational-vector witness `vᵀ(G-10^-6L)v`;
- inherited analytic error components: bounded composite Simpson quadrature, Binet digamma remainder, archimedean Gaussian tail, and all omitted prime powers.

Rational endpoints are rounded **outward** for portable checking. The mathematical remainder bounds are derived in [the certified 3D Weil Gram study](TECTX_WEIL_CERTIFIED_GRAM3.md). As in its prerequisite, actual directed rounding is entrusted to pinned `mpmath.iv==1.3.0`; the report is **not** a Lean or independently reviewed proof certificate.

## 5. What is genuinely still missing for infinite-dimensional completion

To extend beyond three directions, a legitimate proof must independently construct **validated** Weil and reference (L²) cross-block intervals for each new test family, with derivative and infinite-prime bounds that remain useful as centers coalesce. It then must prove that the Schur lower bound is positive for **every** new block in an explicitly specified increasing dense sequence or, better, derive a direct global form inequality.

A uniform **coefficient-Euclidean** bound across arbitrary centers is impossible because almost identical basis functions create nearly null coordinate directions, as documented in [the growing-span stability study](TECTX_WEIL_GROWING_SPAN_STABILITY.md). That obstruction is a representation issue; it does not preclude a bound relative to a true function norm.

Even a verified positive increasing sequence with dense union requires a rigorous argument connecting the test-function topology, Weil continuity/closability and the limits of the quadratic form. The standard null-quotient Hilbert completion is **conditional on positive semidefiniteness for the full admissible test space**, an RH-equivalent unsolved requirement. There is no unconditional Weil-positive Hilbert completion or self-adjoint zeta-zero operator in this implementation.
