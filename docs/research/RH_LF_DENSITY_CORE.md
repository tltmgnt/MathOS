# G1 auxiliary theorem — rational bump spans in the usual LF space

**Classification:** Mathematical analysis of an **auxiliary test-function space**,
with a bounded numerical illustration. **Not** a proof of the G1 theorem for
the RH-equivalent Weil criterion; the exact Weil admissible space/topology
remains to be specified. The mathematical derivation below is not currently
kernel-formalized or independently peer-reviewed.

## Exactly specified topological space

Let `D(R)=C_c^∞(R;C)`. For every positive integer `R`, let
`D_R={f∈D(R):supp(f)⊆[-R,R]}` have the Fréchet topology generated by
`p_m(f)=sup_{x∈R}|f^(m)(x)|` (all nonnegative integers `m`).
Take the usual **strict LF inductive-limit topology** on
`D(R)=colim_R D_R`. In particular, a sequence supported in one fixed
`[-R,R]` whose every derivative converges uniformly converges in
`D(R)`. No claim is made that the Weil test domain has this same
topology or can be replaced by it.

Define the even positive mollifier

```
b(x) = exp(-1/(1-x^2))   if |x|<1, else 0,
I = integral_R b(x) dx,
phi(x) = b(x)/I,
phi_e(x) = phi(x/e)/e.
```

Let `B_Q` be the complex linear span of all `phi_e(·-q)` for
`e∈Q, 0<e≤1` and `q∈Q`. For a real test space, take its real span.

## Auxiliary density statement

**Proposition.** `B_Q` is dense in `D(R)` in its usual strict LF
topology. The even subspace of `B_Q` is dense in the space of even
test functions with the induced topology. The same construction handles
odd functions via antisymmetrization.

**Constructive proof (standard mollification and Riemann sums).** Fix
`f∈D(R)` with support in `[-R,R]`. Choose positive rational `e,h` and
set

```
S_(e,h)f(x) = h * sum_{k∈Z} f(kh) phi_e(x-kh).
```

The sum is finite: `f(kh)=0` for `|kh|>R`, so every term uses
**rational center `kh`** and rational scale `e`. For `e≤1`,
`supp(S_(e,h)f)⊆[-R-1,R+1]`, independent of `h`.

Write `A_m=integral_R |phi^(m)(x)| dx`, a finite constant. For every
derivative order `m≥0`, standard convolution/mollifier estimates give

```
|| (f * phi_e)^(m) - f^(m) ||∞ <= e ||f^(m+1)||∞.
```

Apply the elementary rectangle-sum estimate

```
|h sum_k g(kh) - integral g| <= h integral |g'(y)|dy
```

to `g(y)=f(y)phi_e^(m)(x-y)` for each `x`. Since
`||phi_e^(m)||_1=e^(-m)A_m`, the resulting uniform estimate is

```
|| (S_(e,h)f)^(m) - f^(m) ||∞
 <= e ||f^(m+1)||∞
  + h (||f'||∞ e^(-m) A_m + ||f||∞ e^(-m-1) A_(m+1)).
```

Choose **rational** `e_n=1/n` and `h_n=2^(-n²)` for integers `n≥2`.
For each fixed `m`, the RHS tends to zero because `A_m,A_(m+1)`
are finite constants and the factor `2^(-n²)` dominates every fixed
power of `n`. All approximants lie in the same `D_(R+1)`; thus
`S_(e_n,h_n)f→f` in the LF topology.

For even `f`, evenness of `phi` and `f(kh)=f(-kh)` implies
`S_(e,h)f` is even. This proves the even version as well.

### One conditional explicit zeroth-derivative bound

With `M0≥||f||∞` and `M1≥||f'||∞` externally established:

```
||S_(e,h)f-f||∞ <= e*M1 + h*(M1+3*M0/e).
```

Indeed, `A0=1`, and `A1=2*phi(0)` because `phi` is even and
decreases on the positive half-axis. Over `[-1/2,1/2]`, the
unnormalized bump is at least `exp(-4/3)`; consequently
`I≥exp(-4/3)` and `A1≤2 exp(1/3)<3`.

This **analytic inequality** assumes the exact normalized mollifier,
true support bounds, exact coefficients/integrals and certified `M0,M1`.
The Python evaluator uses Simpson quadrature and floats; it is NOT an
outward-rounded certificate for the inequality.

## What this does NOT prove (RH boundary)

1. The classical Weil criterion's full admissible space need not equal
   `D(R)`; the involution, support conditions and normalization
   must be specified and verified under the RH criterion.
2. Density in one LF topology **does not entail** density or continuity
   in the topology required by the arithmetic Weil functional.
3. Density does not establish **G5P**: nonnegative Weil form on every
   member of this dense span. A finite Gram matrix cannot imply it.
4. The quadrature program does not verify arbitrary derivatives,
   arithmetic prime-power tail control, exact positivity or RH.
5. A fixed **support window** is demonstrably insufficient to
   approximate arbitrary translations; do not confuse that fact with
   a blanket assertion about every fixed-width translating lattice.

**G1 remains OPEN** in the repository's RH obligation registry.
