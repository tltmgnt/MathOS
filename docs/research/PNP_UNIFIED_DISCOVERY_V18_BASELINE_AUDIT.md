## Static mathematical and evidence audit

Checked proof-template logic: resolution derives a consequence of its parents. The compact checker reconstructs clauses, requires backward references, correct signed pivot, an empty root and no unused records. Under a signed injection, a satisfying target assignment pulls back to a satisfying template assignment if every mapped premise is present. More generally a target subclause of each mapped premise entails that premise. Thus a valid refutation transfers under either witness relation. Exact width multiplicities and active-variable counts are necessary filters for exact inclusion of normalized nonduplicate axioms, not for strengthening. Never infer SAT from a failed lookup or a timeout. A bounded search need not discover all embeddings. Verify template and witness before credit; no raw learned clause transfer.

Evidence gaps: verify_query checks reported work/candidate counters against ranges and reconstructs sums, not the search itself. Adjusting a valid counter inside its allowed range and recomputing aggregate work can preserve audit acceptance; this is a source-level observation, not an executed tampering test. A self-consistent content digest is not independent provenance. Per-template fresh budgets do not enforce a shared end-to-end resource ceiling. Normalization, index construction and replay also consume resources. Strengthening currently requires a supplied signed injection; no automatic strengthening matcher. Fresh data use a public fixed seed and a seed inequality, not a verified semantic split. Need independent reference solver, checker tests, independent reruns and hard process limits. None of these observations invalidates an actual successfully replayed contradiction.

## Restricted-family results (paper proofs, not Lean-checked here)

For each integer n >= 1 let F_n = (x_1) AND conjunction over i=1..n-1 of (NOT x_i OR x_(i+1)) AND (NOT x_n). Unit propagation from x_1 forces every x_i true, contradicting the last clause. Delete the first clause and all-false satisfies; delete the last and all-true satisfies; delete the i-th implication and assign x_j true iff j <= i. Thus F_n is minimally UNSAT for every n. Replacing the last negative unit by a positive unit gives a SAT neighbor with the same variable count, width multiset and unsigned incidence graph. The two signed endpoint patterns distinguish these neighbors; those unsigned features alone cannot classify SAT/UNSAT. On the explicitly indexed path family with either endpoint sign, propagation decides in O(n) literal operations and O(n) space; a resolution refutation of F_n uses n steps (derive units successively, then empty clause). This is an elementary restricted result, not a new general SAT algorithm.

For any fixed finite set of contradictory templates whose active variable counts are at most k, no exact or strengthened signed embedding can refute F_n for n>k: the target clauses used as premise witnesses already form an UNSAT subset, by pullback and premise implication. Minimality forces that subset to be the whole formula, which uses all n variables. Each witness uses only variables in the image of the injection, at most k, a contradiction. Therefore a fixed bounded-support library cannot alone cover all UNSAT instances, even on these easy Horn chains. The result does not preclude adaptive synthesis, parameterized templates, resolution or other proof routes.

For a fixed finite library, exhaustive signed-injective matching is polynomial in explicit target input length: for active variable count v, at most (2v)^k maps per template; test each by scanning the input for each constant-size premise (exact or strengthening). This recognizes the template-covered subclass in polynomial time and certifies UNSAT there. It is not a complete SAT decision procedure; variable k or growing library invalidates the fixed-constant bound. The current bounded matcher is not this exhaustive algorithm.

## v18 architecture contract (proposed, not implemented)

Canonical original CNF + immutable digest -> structural feature extraction -> frozen adaptive route policy and verified-template candidate retrieval -> budgeted candidate SAT assignment / UNSAT certificate search -> independent replay on the original input -> SAT, UNSAT or UNKNOWN. Failed candidates go to counterexample search and obligation ledger, never to the theorem store. Verified refutations may be abstracted and admitted only after source replay and template replay; duplicate coverage requires an explicit checked witness. Abstraction is separate from the online holdout run. Preserve an immutable evaluation library and quarantine all discoveries from held-out cases until scoring is complete. Static audit now includes both implementations and their workflows. Adaptive v16 performs bounded DPLL-like branching with immediate unit conflict leaves; the iterative verifier checks all leaves against the input and both branches for each unassigned variable. By induction on the finite tree, a closed subtree excludes every extension of its path assignment. SAT models are directly checked. Failed-assumption learning appends a consequence only after replay; retry on the augmented formula is sound conditional on the existing resolution and lemma checkers. These soundness arguments do not establish code refinement or worst-case polynomial time. The depth cap and heuristic scheduling are incomplete. Resource borrowing from earlier phases is not dominance over a full-budget v12 run. verify_report accepts partial unknown attempt prefixes and range-checked counters, not proof of authentic search or exhaustion. A shared hard process envelope including final report replay remains required; the adaptive solve calls final report replay after timing the solver. The branch's CI gate explicitly requires the original benchmark coverage, zero v12/v14 per-case misses and strict fresh coverage improvement. Preserve that gate even if it fails. Source: mathos/research/pnp_adaptive_decision.py and docs/research/PNP_ADAPTIVE_DECISION_V16.md at pinned adaptive commit.

v17 extracts guarded nonempty and empty conclusions, supports signed clause-driven matching with subclause premises, checks each addition via RUP and replays the flattened sequence against the original CNF. RUP is sound because unit propagation from the current premises plus the negated proposed clause can derive conflict only if that conjunction is unsatisfiable. Induction over the checked additions proves the final empty clause is a contradiction. Guards are conditional; index hits are not proof. The small canonicalization enumerates signed permutations only up to four variables; large keys are labelled. Fragment and transfer caps and matcher limits prevent completeness. Premise countermodels certify necessity relative to the tested guard; a replay failure is not a countermodel. The earlier fixed bounded-support library impossibility proof applies to direct whole-contradiction retrieval, not arbitrary fragment composition: compositions can accumulate information across more variables. The v17 experiment compares an expanded training library and a new matcher with the old library, confounding causes; isolate each on the same frozen library. Its public seeded holdout rejects exact normalized duplicate inputs but not signed isomorphs. Its workflow runs tests and an experiment with replay inside reuse, but no separate report audit command; require independent full artifact replay, reconstruction of library/provenance, row manifests, and aggregates before admission. The v17 proposed target of at least one verified held-out match is not a mathematical requirement of correctness. Source: mathos/research/pnp_proof_library.py, docs/research/PNP_PROOF_LIBRARY_V17.md, and .github/workflows/pnp-proof-library.yml at pinned v17 commit.
