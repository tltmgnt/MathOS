## 1. Main result

In the full nine-group distributed normalized family (n=19m-7, L=Theta(m^3)), if the primal support graph has a tree decomposition with bag size at most eight and adhesion at most four, there exists a fixed original three-symbol single-tape witness program with time

    O(m^(44/5) polylog(m+2)) = O(L^(44/15) polylog(L+2)).

In particular every graph that can be disconnected into two nonempty parts by deleting at most four groups satisfies the promise: use the two bags consisting of the separator plus one part each. The condition can be detected from the actual selector, without advice. The resulting program eventually fits the exact cubic allocation uniformly on SAT inputs meeting the promise, including unique SAT. This advances the previous five-group bag / three-group adhesion theorem. A four-coordinate message can have m^4 entries; the previous whole-span simulation applied to eight-group bag enumeration would cost m^12. Here finite-depth domain tiling reduces the charged exponent to 8.8 in m, even when separator messages are dense. No message of width exceeding four or expanded m^6 supergroup tensor is necessary.

## 2. Message problem and base routine

Generalize the parent separator computation to a stand-alone local task with a bag G of a<=8 group indices and a requested output subset S of size <=4. Each group has domain [0,m). A fixed bounded number of input relations of width at most four are represented by lists of distinct tuples and a flag specifying allowed-list or forbidden-list semantics. An empty list and an empty support are permitted with their exact Boolean semantics. Unary restrictions are allowed. Given these relations, output a list containing exactly one record (key on S, representative full bag tuple) per extendible key. The key is empty if S is empty. No witness is returned if there are no passing assignments. The representatives need not be lexicographically minimal; correctness only requires that each satisfies the local relations and agrees with the key. This is a message computation, not a witness-only algorithm.

For fixed a and the relation count, the raw input and output streams have at most O(m^4) records of O(log(m+2)) bits with self-delimiting lengths and finite tags. A fixed multitape bit implementation enumerates all m^a assignments in reusable buffers of C=m^4 records (or fewer when a<4). For each relation, sort projection queries with local IDs and merge with its sorted input relation to mark passing/failing IDs, respecting its allowed/forbidden flag. Sort flags by ID and combine them. Sort survivors by S-key, deduplicate, and merge into a running output of at most m^4 records, retaining one valid representative per key. There are a fixed number of relations. Time O((m^4+m^a) polylog m), per-tape visited span O(m^4 polylog m); no m^a table need be stored. The fixed-track three-symbol simulation (raw input expansion, constant-width binary-coded finite product alphabet and head markers, sweep overhead linear in span) yields a local physical-tape routine with

    time O(m^12 polylog m), span O(m^4 polylog m),

uniformly for all a<=8. The base exponent is an upper bound, not necessarily tight for smaller a. Emit the record stream in a contiguous raw region with a marked length or terminator and halt at its start. Copying out O(m^4 polylog m) raw bits by shuttling within the used interval costs O(m^8 polylog m), already included. This task uses the same three physical tape symbols but its raw message input/output is an internal subroutine format, not a changed external U or verifier.

## 3. One level of message-preserving tiling

Suppose a fixed local routine for the above task has time O(m^e polylog m) and visited span O(m^4 polylog m) for all a<=8, with e>=8. Choose an integer 2<=b<=m and divide each group domain into consecutive intervals of b digits (last possibly short). There are at most ceil(m/b)^a=O((m/b)^8) tiles. Process tiles in an order that first fixes the block index of EVERY group in S, then enumerates all block indices of the remaining groups, so all tiles for a given separator block are consecutive.

For a tile with offset vector o, scan the input relations. Discard records with any digit outside its coordinate's tile and subtract the offset from every retained digit. Retain each relation's flag and support, even when its restricted list is empty. For each group add a forbidden unary relation on padded digits u with o_g+u>=m. This prevents bogus representatives in the short last blocks. On the uniform local domain [0,b), the local conjunction is exactly the original conjunction restricted to that tile, under the coordinate translation. In particular this holds for allowed child-message lists as well as forbidden original clauses. The number of relations stays fixed: padding restrictions can be consolidated into an existing unary allowed/forbidden restriction or stored as one additional per-group forbidden list at each FIXED depth. No input-dependent relation-count expansion is needed.

Call the previous local MESSAGE routine on this smaller instance, with the same requested subset S. Translate each returned representative and key back to original coordinates. For a fixed separator block, maintain a union of all successful keys over the remaining group blocks, with one valid representative for each key. This union never exceeds b^|S|<=b^4 records. When that separator block finishes, append the accumulated records to the output stream and clear the accumulator. Different separator blocks have disjoint keys, so no global sorting/deduplication of a large output is needed, and each extendible original key is returned exactly once. For S empty there is one block, and the accumulator stores at most one representative; early stopping is optional. Proof: every original satisfying assignment lies in exactly one tile, and its key appears in that tile's message; conversely every translated representative is an original satisfying assignment. Keeping a different representative for the same key cannot affect this existential relation. This is an exact recurrence for messages, not merely for the root SAT bit.

## 4. Physical cost of extraction, local execution and append

Keep the outer raw record input, and a growing output stream, on stationary track components encoded in constant-width blocks over the physical three-symbol tape. Their total span is O(m^4 polylog m). Initial conversion costs O(m^8 polylog m). Delimit the streams and mark the current append end. Keep O(log m)-bit block counters and a mobile workspace containing the restricted tile records and current separator-block accumulator, of size O(b^4 polylog m). As in the earlier mobile-projection and recursive-tiling notes, use a one-block carry shift of the mobile component (preserving stationary symbols) in O(workspace length) moves, and adjacent-record query propagation with polylog overhead. To scan the outer records, shift the work component with the stationary scan head; parse support/digit fields, compare with tile offsets and append translated records. A fixed number of width<=4 relations can each contribute only O(b^4) distinct records; the accumulator also fits. Rewinds or travel to the marked append end cost at most the same full-span-times-workspace bound. This charges O(m^4 b^4 polylog m) physical moves per tile, including counters, reading the stationary input, and transport of local data. Output already written is stationary; no search through all previously emitted keys is required.

Near the append end, allocate a local-machine component in which the tile input is a contiguous raw record stream, using local digits and the local header b. Construct it from the restricted list with sequential scans/copies in O(b^8 polylog m) moves. Leave the accumulator and outer markers on separate components. Simulate the fixed previous local routine by encoding each of its physical cells as a component of the outer product alphabet; each local physical transition takes only a constant number of outer physical transitions, following the local head without going back to a global header. Mark visited cells as the local head traverses them. Its visited span is O(b^4 polylog m), its runtime O(b^e polylog m). Reading/decoding the returned stream, translating keys and merging the local output with the accumulator can be done even by pairwise sequential record scans in O(b^8 polylog m) moves; reset the local component over its marked used interval. These costs are dominated because e>=8. When a separator block is finished, append its accumulator to the stationary output in O(b^8 polylog m) local work, updating the append marker; the buffer can be transported over the outer interval if necessary within the extraction bound. The output span is O(m^4 polylog m) at all times because blocks have disjoint keys. The local component is reused and has span <=O(m^4 polylog m). The actual three-symbol alphabet is unchanged: each level uses finitely many product components in fixed-width binary block codes with all-2 blank blocks. Composition at a FIXED number of levels increases only constants and fixed description length. Logarithmic field widths at a local scale b=Theta(m^alpha) with fixed alpha>0 are comparable to outer logarithmic widths; all costs can absorb those factors. No input-dependent recursive depth, random-access lookups, extra physical heads, or uncharged large message scans are used.

After all separator blocks, copy the entire accumulated output stream from its stationary encoded component to a contiguous raw self-delimiting record stream in a fresh region, leaving the head at the first bit. The stream has O(m^4 polylog m) bits and the used span has the same bound, so even a shuttle per bit costs O(m^8 polylog m). This restores exactly the same local subroutine interface used by the base routine, including an empty-list header if there is no extendible key. This cost is included below.

The resulting new physical time and span are

    T_new(m)=O((m^8+(m/b)^8*(m^4*b^4+b^e)) polylog m)
            =O((m^8+m^12/b^4+m^8*b^(e-8)) polylog m),
    S_new(m)=O(m^4 polylog m).

This bound is for the complete message list including representatives, even if all m^4 separator keys survive.

## 5. Four fixed levels cross the cubic boundary

For e>8 choose b=Theta(m^(4/(e-4))) by the least integer >=2 satisfying the appropriate integer-power inequality, capped by m. For a rational constant exponent this can be computed by binary counters and arithmetic, even by trying all b<=m, within the time bound. The two tile terms balance, giving

    e_new = 8 + 4(e-8)/(e-4).

Writing delta=e-8, the recurrence is delta_new=4delta/(4+delta), equivalently 1/delta_new=1/delta+1/4. Starting at e=12, after depth h the bound is e_h=8+4/(h+1). In particular the four fixed levels have outer block exponents 1/2, 2/3, 3/4, 4/5 respectively (outermost uses 4/5 in the depth-four algorithm). The exponent sequence in m is

    12, 10, 28/3, 9, 44/5.

Thus the fourth level is strictly below nine; three levels would not establish exact cubic inclusion because logarithms and the description penalty still matter. More generally every fixed epsilon>0 admits a fixed-depth complete message routine with time O(m^(8+epsilon) polylog m), span O(m^4 polylog m). This is not a uniform increasing-depth bound or O(m^8) claim.

## 6. Application to the actual normalized nine-group selector

Use the inherited primal graph, containing an edge whenever two groups co-occur in a selected negative cross clause. Parse the actual input sequentially, preserving pins and selected support records. Find a tree decomposition with bags <=8 and adhesion <=4 if one exists, using finite enumeration as in the parent: contract contained adjacent bags (running intersection ensures adhesion is preserved), then every nonroot bag introduces at least one new group, so at most nine bags are needed. Check support coverage explicitly, assign each selected support and its forbidden records to one containing bag, and root the tree. This search is a fixed finite calculation independent of m. If the promise fails, the program may halt on blank.

Each bag's owned constraints have width <=3. Each child message has width <=4 and is used as an allowed-list relation on its separator (ignore its representative payload during tests). Process bags bottom-up with the complete depth-four routine. Keep already computed messages with their representatives on stationary components for later retrieval. There are at most nine, hence the total stationary span O(m^4 polylog m). Copy a bag's owned constraints and child keys to its local raw stream by sequential scans and shuttles; even a simple per-bit copy over the whole used span costs O(m^8 polylog m) per bag. Run the fixed local message routine on its own physical-tape component with constant per-local-transition overhead, preserve all saved data, and copy the message back at the same O(m^8 polylog m) cost. Cleanup is bounded by the marked visited span. The total O(m^(44/5) polylog m) over a constant number of bags holds. The parent's exact subtree message induction proves that root key present iff SAT. Reconstruct a global tuple by reading representatives top-down at matching separator keys; running intersection guarantees agreement. Reconstruct the inherited full n-bit one-hot/OR/pin/guard witness using the actual pins; output contiguously with the final head on its first bit. O(m^5 polylog m) output copying suffices and is dominated. On no root key halt on a blank. No new external syntax or verifier is used. Input parsing and raw block conversion O(L^2 polylog L) are also dominated. The fixed original description length ell is independent of m and of masks/pins.

At j=ceil(log2 L), the actual clock is 2^(3j-ell)>=L^3/2^ell once eligible. Since 44/15<3, it eventually dominates the time uniformly on the promise. In particular a separator of <=4 groups dividing the graph into two nonempty parts gives bags <=8 and adhesion <=4. An unbounded sequence of actual cubic misses in this family must eventually have no such separator (in addition to the earlier necessary structural conditions). There is no claim that graphs without such separators are hard.

## 7. Strict separation control: K8 plus a four-neighbor vertex

For every m>=3 use bags G={0,...,7} and H={4,...,8}, joined on {4,5,6,7}. For EVERY pair within either bag forbid the single digit pair (1,1). Also use the parent's four parity triples on {0,1,2,3} and the five cyclic consecutive triples on {4,5,6,7,8}: permit exactly even parity of nonzero indicators, and when there are two nonzero digits require them distinct. The added binary clauses are redundant on each such constrained triple and do not change its local relation. No other cross clauses are selected. All these are actual original negative clause positions.

As in the parent, the parity equations force every nonzero indicator to be zero, so the unique global tuple is all zero, allowed also by the extra binary constraints. Every digit has support in every closed local table: constrained triples use all-zero or two distinct nonzero digits plus zero; other triples and pairs choose all other digits zero. Each group is in a constrained triple and its signatures are pairwise incomparable by the same contexts (a nonzero and zero to distinguish nonzero digits; all-zero and another nonzero context to distinguish zero). Thus both static and contextual widths are m. In every direction of every closed local relation, maximum fanout is >=m-2 (constrained triples have a key with one nonzero and one zero, otherwise choose all parent digits zero); hence W>=(m-2)^9. The primal graph is K8 with the ninth vertex adjacent to exactly four of its vertices: no separator of size <=3 can disconnect it, since the remaining clique is connected and the ninth vertex, if present, has a remaining neighbor. Removing its four neighbors disconnects it. Any tree decomposition contains a bag of at least eight by the clique/subtree Helly argument. Therefore neither the previous bag-size-five condition nor any nontrivial adhesion-three decomposition applies; the latter would give a separator of size <=3 after contraction of contained bags. A single nine-group bag in the previous message-fanout theorem still has W>=(m-2)^9. The new theorem covers this family; it is a strict separation of sufficient conditions, not a hardness example (the all-zero solution is cheap).

## 9. Disposition

The new construction shows four-coordinate messages can be handled even in eight-group bags without storing all bag assignments or losing the physical-tape cubic slack. Remaining targets: separators of size five or larger, dense highly connected support graphs, and tighter resource accounting for general nine-group SAT.
