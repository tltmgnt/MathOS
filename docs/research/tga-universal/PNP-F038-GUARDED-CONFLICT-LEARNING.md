## Persistent query database

The previous relational pruning summaries are tied to a fixed predicate configuration. Reusing an UNSAT conclusion after changing a leaf predicate can be unsound. Instead construct one immutable ordinary CNF database B with a truth indicator e_i for each original clause C_i:

  (not e_i OR C_i) AND AND_{l in C_i}(e_i OR not l).

Every assignment to original variables extends uniquely to the indicators, which equal the original clause truth values. A query is a consistent list of literal assumptions A. Pin e_i positively to require its clause, negatively to complement it, or leave it unpinned to omit the requirement. Additional variable pins constrain projections. This directly serves the ordinary-coordinate version of the earlier semantic projection compiler, including different candidate clauses. For affine boundary queries one can instead use fixed Tseitin parity circuits to define queried direction bits and fixed truth-table predicate indicators on their signatures; the same proof lifting applies to that extended immutable database. The executable here implements ordinary CNF indicators and coordinate pins, not the full affine separator query adapter. Original width-three clauses give indicator clauses of width at most four; this is an internal proof database, not a claim of a normalized 3-CNF source encoding.

## Guarded RUP lifting theorem

Let D be B with any previously checked globally implied learned clauses. Write G_A for the disjunction of the negations of all assumptions in A. Suppose C_1,...,C_s is a RUP derivation from D plus the unit assumptions A, where a RUP addition C is checked by unit propagation of not C to contradiction. For each C_j add C_j OR G_A to the persistent database, removing duplicate literals and omitting tautologies.

For a nontautological lifted clause, negating it sets all assumptions A and all negated literals of C_j. Earlier lifted clauses reduce under A to the corresponding old clauses, except clauses satisfied by A (including tautological lifts), which are irrelevant to unit propagation. Consequently the original propagation conflict is reproduced in the lifted database. Each lifted addition is itself RUP from the persistent database, without treating any query assumption as a permanent axiom. Induction proves validity of the entire persistent proof. If the original derivation ends with the empty clause, its lifted final clause is G_A, a globally implied conflict explanation. If the scoped solver returns a model, its intermediate RUP additions may still be lifted and retained.

Any future query A' containing the negations of every literal of a learned clause is immediately refuted by that clause, regardless of changes to other query bits. More generally all persistent learned clauses may participate in unit propagation on any query. A failed query can shrink its explanation by dropping one assumption at a time whenever unit propagation on the current persistent database still contradicts the remaining assumptions. Each newly added shorter clause is RUP. This greedy deletion procedure gives an inclusion-minimal UP-conflicting assumption subset relative to the database used for minimization (not a globally minimum semantic core). No assumption can be reintroduced by the monotonicity of unit propagation in consistent assumptions; the code minimizes before adding the shorter clause. It does not try to find a minimum core over all proofs.

Soundness is independent of query order. For a fixed sequence, the verifier checks every new RUP addition in its actual order from B, checks each positive assignment against B and assumptions, and for each negative answer checks a referenced persistent clause whose negation is contained in the assumptions. No negative answer is accepted from a scoped trace alone. Learned clauses from different immutable bases cannot be shared by this rule without a new implication certificate. The code uses the previously verified adaptive decision-clause RUP solver under scoped assumptions, not an implementation of unrestricted CDCL, and independently replays the persistent stream.

## Cost and proof-system boundary

For t assumptions and s scoped RUP additions, lifting creates at most s clauses of width at most n_total, with at most O(st) additional literal occurrences before deduplication. With an explicit persistent database, unit propagation is polynomial in its length. Core minimization takes at most t additional UP calls (one deletion pass). Total production and verification are polynomial in the actual scoped search/proof work, cumulative learned length, and query length; no universal polynomial bound on those quantities is supplied. Direct subsumption of an earlier conflict explanation by a later assumption set saves an entire scoped search. This is conditional reuse, not a bound on the number of different necessary conflicts.

Resolution derives a resolvent by a RUP check: under negation of the resolvent the two parent clauses force opposite pivot values, or an immediate contradiction. Conversely, as established in the earlier F038 resolution certificate analysis, a nontautological RUP addition on a fixed variable set can be simulated by polynomially many resolution steps with weakening (reverse propagation reasons), and weakening can be eliminated for refutations by maintaining subclauses. Thus these proof formats are polynomially equivalent for ordinary CNF refutations, without claiming that the implemented search finds shortest proofs.

For an UNSAT query requiring all indicators true, restrict a persistent RUP proof ending in a clause falsified by those assumptions to the assignment e_i=1. Its axioms restrict to the original source clauses (other indicator clauses disappear). A RUP addition satisfied by the restriction disappears; otherwise the restricted addition remains RUP: a UP contradiction under negation of the original clause persists after fixing additional variables, and satisfied clauses are irrelevant. The referenced final guard becomes empty. This gives a RUP refutation of the original CNF with no more additions than the persistent prefix, even if earlier queries supplied many learned clauses. Any prior resolution size lower bound for the source therefore transfers, up to the polynomial simulation overhead, to the cumulative persistent proof length. In particular the earlier odd-charge bounded-degree Tseitin family (before affine extraction) supplies exponential-in-a-sublinear-power size lower bounds for this ordinary fixed-variable RUP architecture, even with arbitrary query scheduling and guard minimization. This does not constrain the full MathOS portfolio, which can solve pure affine Tseitin systems by Gaussian elimination; arbitrary parity extensions, preprocessing and stronger proof systems are not covered.

A universal polynomial bound on the total ordinary persistent negative certificates, already for the all-positive query, would imply NP=coNP, by checking polynomial-size certificates of arbitrary 3-CNF unsatisfiability. A uniform polynomial-time complete query algorithm would imply P=NP. Neither follows from finite reuse examples.
