## 1. Scope and prior result

PNP-B006 gives a polynomial decision method for disjoint Boolean AND blocks with affine output equations. PNP-F001 proved the projection and lifting equivalence for arbitrary finite disjoint blocks. Its corrected Lean replay (run 45385881661) passed the strict empty-axiom check on all five audited theorems. We now formalize the linear algebra step. This is a reconstruction of elementary known GF(2) mathematics, not a literature novelty claim or a general SAT proof. The original Python solver uses integer bitmasks and highest-bit pivots; this formal model uses coefficient lists and eliminates the first coordinate. A correspondence with that implementation remains to be established.

## 2. Exact row representation

A row is a finite coefficient list a of Booleans and a right-hand-side bit b. Assignment x is a finite Boolean list. Dot(a,x) is the XOR of the pairwise Boolean products, using zero padding (missing coordinates contribute zero). The row holds iff Dot(a,x)=b. Define addition of coefficient lists by pointwise XOR, padding either input with zeros; add right sides by XOR as well.

Theorem: Dot(a XOR c,x)=Dot(a,x) XOR Dot(c,x) for all finite lists. Proof: induction on a; cases on c and x; the cons case uses the five-Boolean distributive identity checked by cases. This includes unequal lengths and empty lists.

Consequently, given pivot p, replacing row r by p+r while retaining p preserves precisely the satisfying assignments. Forward follows by linearity; reverse follows by XOR cancellation. The formal theorem is ProctorGF2.row_replace.

## 3. Contradiction certificate soundness

Let sel be any finite list of rows each belonging to the original row list orig. Define sumRows by repeated row addition starting at the zero row. If x satisfies every original row, induction on sel proves it satisfies sumRows(sel). If the summed coefficient list is entirely false and the summed right side is true, the resulting equation is 0=1. Such x cannot exist.

This formalizes soundness of a supplied XOR certificate; repeated rows are permitted and cancel in pairs, so ordinary subset certificates are included. It does not prove that the Python solver always constructs a valid certificate, nor that every inconsistent system has a certificate generated by the currently implemented algorithm. Those require iteration/provenance arguments.

## 4. Complete one-column elimination theorem

Let p be a pivot with first coefficient true, and R the list of other rows. Clear every row r whose first coefficient is true by replacing it with p+r; leave other rows unchanged. Every resulting first coefficient is false. Drop that coordinate from the cleared rows to obtain reduced(p,R).

For every finite tail assignment x,

(there exists b in GF(2) with p and every r in R satisfied by b::x)
if and only if
(every row of reduced(p,R) is satisfied by x).

Forward: row replacement preserves satisfaction given the pivot; each cleared first coefficient is zero, so dropping it does not affect the equation. Reverse: define b as p.rhs XOR Dot(tail(p.coeff),x). This makes the pivot equation true by XOR cancellation. Insert b in front of x; each reduced row lifts to a satisfied cleared row, and row replacement recovers all original rows. The theorem ProctorGF2.elimination_step covers every finite row list and tail, not merely finite test instances. It supplies a deterministic back-substitution formula.
