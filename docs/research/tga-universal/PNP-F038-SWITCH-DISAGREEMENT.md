## Constructive switch theorem

Let F_1(x,y_1),...,F_k(x,y_k) be explicit CNF alternatives over common declared parameters x (absent variables allowed), with existential witnesses private to each alternative or renamed privately. The projected union is C(x)=OR_i exists y_i F_i(x,y_i). A witness consists of an index i and a satisfying assignment for its alternative. This is equivalent to an existential switch; the proof does not rely on representing a switch by one particular CNF.

Let D be the parameter variables occurring with both signs across the entire list of clauses of all alternatives, and d=|D|. Outside D all occurrences have a common sign, so choose a common worst value (zero for positive-only, one for negative-only, arbitrary for absent). For each of the 2^d assignments a to D form w(a) by filling in these worst values. Test the alternatives at w(a) until a satisfying witness is found or all fail. If a seed fails then w(a) is an uncovered parameter assignment. If one succeeds, keep its index and its existential witness. Changing any parameters outside D cannot falsify a literal previously true in that chosen formula; hence the SAME witness and index work for every x agreeing with a. This proves

forall x C(x) iff forall a in {0,1}^d C(w(a)).

With supplied valid local decompositions of maximum bag size b_i, use the verified fixed-input interface DP to construct each seed. The total time is bounded by 2^d sum_i 2^O(b_i) poly(L_i), plus polynomial preprocessing and output cost, where L_i is the explicit size including the decomposition and declared variables. Thus d+max_i b_i=O(log L) suffices for uniform polynomial time, even when k is not fixed. The kernel is found by scanning literal signs, not by semantic polarity recognition. If all seeds succeed, a lookup on the d bits yields a witness circuit of size O((q+log(k+1)+1)2^d), plus routing, where q is a common padded witness length. The switch index can be chosen once per slice. The result also applies to projected functions with a promised common monotone orientation outside D for decision only; semantic monotonicity does not guarantee reuse of actual existential witnesses.

This is a sufficient structural class. A local unate variable may have a different sign in another alternative, forcing it into D. Arbitrary mixtures of conjunctions with independent existential scopes may be certified separately using the preceding theorem, but nested existential switches need not preserve the same small D. The explicit list cost is charged.

## Black-box point-probe lower bound

Let d>=2 and r=floor(d/2). For x in {0,1}^d, let A(x)=[weight(x)>=r] and B(x)=[weight(x)<r]. The union is total. For every s of weight r define A_s=A with precisely the point s removed. This remains increasing, since s is minimal in A; explicitly A_s(x)=A(x) AND (OR_{i:s_i=0} x_i). B remains decreasing. Thus (A_s,B) has exactly one uncovered parameter s.

Consider a deterministic adaptive membership-query algorithm told that its input pair is either (A,B) or some (A_s,B), with the orientations known but no access to an explicit representation. Even a query that returns both memberships can only distinguish a hole pair from the baseline at x=s. On the baseline, every s must be queried: otherwise the same transcript and answer occur on a non-total pair. Therefore worst-case point probes >= binom(d,r)=Theta(2^d/sqrt(d)). This uses the standard central-binomial estimate (e.g. Stirling's formula).

For a randomized algorithm with worst-case at most Q point probes and error at most epsilon<1/2 on every promised pair, couple executions on the baseline and on a uniformly random hole using the same random coins. Before the hole is queried they have identical transcripts. For each baseline execution, at most Q of the binom(d,r) possible holes are visited, so the probability of any difference is at most Q/binom(d,r). The acceptance probability difference between the baseline and the random hole is at least 1-2 epsilon. Hence Q >= (1-2 epsilon) binom(d,r). The same reasoning permits repeated queries and adaptive order. This matches the upper bound's exponential scale up to a polynomial factor in the membership-only model. Witness-returning oracles with additional information are not covered.

## Explicit syntactically pure 3-CNF realizability

The threshold function has a monotone DAG of O(d^2) binary gates: use prefix thresholds T(i,j)=T(i-1,j) OR (x_i AND T(i-1,j-1)), with T(i,0)=true and T(0,j>0)=false. For B apply a threshold of d-r+1 to negative literals. For A_s append the displayed extra disjunction. For each monotone AND gate g with inputs a,b add (not g OR a), (not g OR b); for OR add (not g OR a OR b). Inputs may be original signed literals or fresh gate variables; force the output true, force a false constant false, and leave a true constant unconstrained. If a satisfying extension sets a gate true, induction forces its actual Boolean value true. Conversely the actual gate values satisfy all implications whenever the output evaluates true. Thus existential projection equals the function. All original input occurrences have only the specified sign, width is at most three, and size is polynomial in d. This is a one-direction gate encoding sufficient for existential feasibility, not a unique-extension encoding.

The explicit encoding demonstrates that the black-box functions are within the syntactic universe. It does NOT give a lower bound on algorithms that inspect their clauses or gates: the hole can be read from the explicit construction. It does not claim bounded width for these threshold encodings, nor an exponential SAT running-time lower bound. The unrestricted opposite-orientation union certification hardness of the preceding branch remains a separate complexity result.
