## Forward theorem: guarded degree-two elimination

For a normalized CNF with a variable u appearing positively in exactly one current clause A OR u and negatively in exactly one current clause B OR not u, replace those occurrences by the resolvent A OR B (omit it if tautological). All other clauses are unchanged. For each assignment of the other variables the existential projection is exact: if both A,B false neither u works, otherwise choose u=1 if A is false, and u=0 if A is true. This choice restores the removed variable. The statement includes empty and tautological resolvents. A deterministic algorithm repeatedly takes the least eligible variable whose nontautological resolvent has width <=3. Each step removes two occurrences and adds at most one, so at most min(n,m) steps and at most 2m clause records are needed. The implementation scans occurrences; all operations and certificate replay are polynomial in the explicit input length (with variable indices renumbered densely or n given explicitly). It does not eliminate a variable whose removal would exceed the width cap. No completeness of this elimination policy is asserted.

Attach a source-support set to each clause occurrence. Original clauses have singleton supports; the resolvent's support is the union of both parent supports. In the immutable truth-indicator database, all positive indicators in that union imply the resolvent, even if other source clauses are disabled. A verifier replays the two active occurrence IDs, variable incidence, width cap, resolvent and union, and final active list. An equation extracted from a full forbidden parity class among the retained clauses is conditionally valid under the union of their source supports. Retain both original extracted equations and recovered equations, deduplicating identical (mask,rhs,guard) triples. The guarded conflict checker activates only equations whose complete positive guard is among the actual negated learned-clause pins. Thus the prior hybrid proof theorem applies without changing its proof rules or assuming all original clauses are true. Recovery is a preprocessing method producing conditional axioms with replayable provenance, not an arbitrary oracle for implied equations.

When all original clause indicators are pinned true, the remaining formula is entirely extracted affine equations, and no eliminated variable is pinned, a particular Gaussian solution on the retained variables can be extended in reverse elimination order. Check the restored assignment against the immutable database and all pins. A consistent reduced system therefore yields a polynomial-time positive witness on this restricted domain. For a contradictory system the prior guarded hybrid propagator can derive a global conflict. For other modes or non-affine residuals fall back to the exact previously verified search, which may be exponential. The implementation checks original witnesses, not just projected ones.

## TECT-X adversarial controls and complexity barrier

A stronger hiding gadget uses three fresh private bits u_1,u_2,u_3 for each original clause C=A OR l. Require A OR u_j and not u_j OR l for each j, together with the three cyclic implications not u_j OR u_(j+1) (indices modulo three). For every assignment to the original variables the gadget has an extension iff C holds (set every u_j to the truth of l for the forward direction). Each private variable occurs twice positively and twice negatively; the original parity variables have even larger incidence counts. Each exact scope occurs singly, so the complete-class extraction finds no rows. No degree-two elimination is eligible on the constructed split-cube sources. Substituting all three private variables by the literal l maps each gadget to the original clause (possibly duplicated) and tautologies. The preceding ordinary RUP-to-resolution and literal-substitution simulation therefore transfers the earlier resolution size lower bound to this fixed guarded engine on these encodings when all indicators are true and the root pin is wrong. There are no active XOR rows in any query, and previously learned clauses do not change the static recovery table. This is not a lower bound on the full portfolio or on algorithms allowed to recover larger blocks, perform general resolution closure or change encoding.

There is also a representation-independent limitation to *complete* implied-affine discovery: deciding whether an arbitrary satisfiable normalized 3-CNF entails even one designated unit equation is coNP-complete (under the promise that the source is satisfiable). Given arbitrary 3-CNF D(x), form AND_i(z OR D_i) with a fresh z, splitting width-four clauses by private variables as in the earlier universal-boundary theorem. This formula is always satisfiable at z=1, and has a z=0 model iff D is satisfiable. Thus entailment z=1 holds iff D is UNSAT. A countermodel is an NP certificate, so the entailment problem is coNP-complete. A uniform polynomial-time procedure that recovers every implied width-one affine equation (with exact semantics and total polynomial costs), even on satisfiable formulas, would imply P=NP. A sound incomplete extractor avoids this requirement. This does not prohibit specialized polynomial recovery or imply that discovering only a sufficient subset of equations is hard on every input.
