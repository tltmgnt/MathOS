## Query rather than compile

Fix the provenance-checked affine parametrization and a supplied binary clause tree. Each leaf has an allowed predicate on its direction space W. For node v and a specified boundary functional z on S_v, ask only whether z extends to a satisfying functional on W_v. At a leaf enumerate the extensions of z to W_v and stop at the first permitted local signature. At an internal node with children a,b, set K=S_a+S_b. By the earlier gluing theorem S_v is contained in K. Extend the supplied basis of S_v to a basis of K by independent rows. Enumerate the 2^(dim K-dim S_v) extensions of z to K, using only these additional functional bits. Each determines a compatible child signature pair. Recursively ask whether both children admit extensions. Stop at the first successful pair. Distinct extensions give distinct pairs because the child spaces span K. Every compatible pair with parent signature z occurs exactly once, so the algorithm is sound and complete. Memoize (node,signature) answers for a fixed predicate configuration only; do not reuse across changed leaf predicates.

A positive query reconstructs a functional by following its chosen child pair to leaves, solving the collected local equations together. The full-space gluing theorem guarantees consistency, and the result is checked against the requested signature and all leaves in that subtree. A negative query certificate lists exact memoized answers, and for each queried state the number of candidates tried in the fixed enumeration order. The independent checker recomputes the fiber and checks all preceding failed candidates (a negative child suffices) and the final successful pair, if any; a negative state must exhaust the fiber. Each dependency is checked earlier in postorder. A leaf is checked by direct membership of its local signatures. Unfinished searches are not certificates. This is a deterministic replay certificate, not a new polynomially bounded proof system.

If V is the set of visited states and q_v(z) the number of candidates inspected at each, the computation and replay cost are poly(L)(1+|V|+sum q_v(z)), with bounded leaf rank for normalized 3-CNF. Over all signatures at one join, the total fiber size equals 2^dim K, at most 2^(2b), rather than multiplying a worst-case fiber by all parent rows. Thus the worst-case guarantee matches the earlier explicit table exponent; the improvement is demand sensitivity, not a better worst-case complexity class. The implementation caps inspected candidates per query, including leaf trials; this is not a cap on physical wall-clock or memory, or on an entire multi-query repair procedure. A cap returns UNKNOWN without a certificate, not a negative answer.

## Exact semantic repair with root-only projection queries

For each designated residual clause C, complement its leaf predicate to form the bad relation. For each leaf i and each possible local signature z (at most 2^ell), intersect that leaf predicate with the singleton z and query the empty root signature. A positive query means z occurs in a global bad model; negative certificates establish absence. Compile Q_i={h:R_i XOR h subset P_i} exactly as before. One final root query using Q_i as the leaf predicates decides translation existence and reconstructs a direction. There are at most 1+sum_i 2^dim W_i root queries per candidate. A checker regenerates every pinned predicate configuration, verifies each query certificate and then the final translation query. It never needs to construct the entire reusable boundary relation. No full message compilation, nonuniform advice, or arbitrary truth-table equivalence test is assumed.

The procedure gives exact decisions for all finite inputs, but a universal polynomial bound would still imply P=NP via the prior semantic repair existence reduction. A positive individual boundary query is in NP (a satisfying extension is a polynomial-size witness), and universal polynomial-time decision of a single query is equivalent to P=NP by the fixed universal presence-bit family. A universal polynomial-time witness finder on all feasible queries, even with no requirement to halt on infeasible ones, also implies P=NP by imposing its polynomial clock and verifying output. These conclusions concern uniform guarantees, not all algorithms' runtime or nonuniform circuit lower bounds. Lazy queries avoid the requirement to materialize polynomial-size reusable descriptions, so the earlier NP subset P/poly equivalence is not an additional independent obligation for query-only computation.

## Exact separation between easy and adversarial search order

Let m shared bits x_i occur in a left half consisting of pairs (l_i OR u_i),(l_i OR not u_i), where l_i=x_i for the positive family and l_i=not x_i for the negative family. The right half consists of anchors (x_i OR v_i). All u_i,v_i are private. The specified affine extraction leaves every clause residual, since the two clauses on a left pair have different falsifying parities and each anchor scope occurs once. Arrange each left pair as siblings, join groups in a balanced tree; right anchors are balanced separately. The root cut has shared space of rank m. Its right message has all 2^m signatures (set v_i=1 as necessary), and its left message has exactly one signature, all zeros in the negative-literal family and all ones in the positive-literal family. The root enumerates the fiber in increasing packed binary order. For the all-zero case the first pair succeeds and every queried descendant needs only a constant number of trials per node (the left group has at most one private direction). Thus the demand-driven computation and replay use polynomial time despite an exponential explicit right message. For the all-one case the root must inspect exactly 2^m candidates before success; this is an unconditional lower bound for this fixed lazy enumeration policy, not for arbitrary query algorithms, different search orders, symbolic message engines, or SAT runtime. The opposite signs demonstrate why lazy evaluation alone cannot establish universal polynomial coverage.
