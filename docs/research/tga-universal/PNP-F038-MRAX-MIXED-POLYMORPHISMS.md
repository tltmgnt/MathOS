## Constructive track: supplied mixed typing theorem

An instance is a conjunction of explicit Boolean tables on variable scopes (distinct coordinates in each scope), with a supplied type for each variable: ternary AND, ternary OR, majority, or ternary XOR (minority). Require each table to be closed under the coordinatewise typed ternary operation f, using the same variable type across every occurrence. This is checked by every ordered triple of rows. Empty tables are handled as immediate contradictions. Complement OR coordinates once, turning their operation into AND; this coordinate change is invertible. Let H be all AND coordinates after complementation, M majority coordinates and A minority coordinates. Projection and fixing constants preserve closure because the operations are idempotent.

First project each local relation onto H. These projections are meet-closed, since f(x,x,y) on H is binary meet. Compute their common least solution via monotonically raising H bits from zero: for each local projected table retain rows componentwise >= the current local restriction. If empty, no global H solution exists (every global H solution is >= the current vector, inductively). Otherwise raise the restriction to the meet of all retained rows. That meet belongs to the projection and is >= the old vector. At a fixed point the restriction lies in every local projection. At most |H| strict bit increases and one final sweep, polynomial in table size. Denote the least solution by h*.

The term g(x,y)=f(x,x,f(y,y,x)) acts as x meet y on H, and as x on M and A. If an original global solution exists, its H part dominates h*. In each local relation choose any row y whose H part equals h* (it exists by construction), and apply g to the original solution's local restriction x and y. The resulting row has exactly the local h* part and all original non-H bits. Thus pinning H to h* preserves satisfiability and even preserves the set of globally attainable non-H restrictions. This does NOT say an arbitrary locally feasible H assignment extends globally.

After fixing H=h*, f(x,x,y) acts as x on M and y on A. Each nonempty residual local table is therefore exactly the Cartesian product of its projections onto M and A. This eliminates cross-class dependencies at the chosen pin. The M projection is majority-closed. Such a nonempty relation is determined by all unary/binary coordinate projections: any candidate agreeing locally extends to every k-coordinate subset by induction, using three size-(k-1) witnesses each missing a distinct coordinate and taking their majority. Encode missing unary and binary patterns as clauses, solve the resulting 2-CNF by the existing verified algorithm. The A projection is affine: choose a base row a; differences form a linear subspace because x XOR y XOR a stays in the relation. Compute its annihilator and right-hand sides, then solve all combined equations by Gaussian elimination. Combine the two independent witnesses with h*, undo complementation, and verify every original table. Empty projections, an inconsistent 2-CNF, or an inconsistent affine system are exact negative decisions on the supplied typed class.

All work including closure checks, least-model computation, projections, 2SAT, Gaussian elimination, and witness checking is polynomial in explicit table length and n. For private-component scope bound h in the earlier theorem, table construction and checking take 2^O(h) poly(L), so h=O(log L) suffices, even if the interface has linear size. The certificate is deterministic replay of the typed procedure and original witness verification, not a general SAT proof system. It is not a uniform polynomial guarantee without a compatible typing and an efficiently obtainable bounded-block representation.

## Alternative track: discover compatible types and connect to source CNF

For each table of arity d enumerate its at most 4^d local type tuples and test closure. These allowed tuples define an exact four-valued compatibility CSP on the interface variables. Repeatedly intersect each type domain with supports in every incident local type table, deleting unsupported labels; at most 4n deletions. Empty domains certify no typing. If a variables remain ambiguous, enumerate their at most 4^a assignments and check all type tables; this is exact when allowed to finish. The implementation has a caller-supplied cap on ambiguity: above it return UNKNOWN rather than an unverified decision. Exact NO_TYPING is not UNSAT. Variables absent from tables may use a default type; the implementation includes them in the ambiguity count, a conservative bound. Discovery plus solving costs 2^O(h) poly(L)(1+4^a) on bounded block sources; a=O(log L) and h=O(log L) give polynomial time. No general polynomial discovery guarantee.

For exact block tables from a supplied interface, intersect all projected relations with identical boundary scope; this is exact because their private variables are disjoint, and may expose closure that individual clause projections lack. Solve the resulting typed interface and lift local witnesses with the prior block checker. A global negative typed result certifies absence of a global source witness; NO_TYPING and UNKNOWN do not. The code checks the source table reconstruction on a genuinely mixed fixture encoded as width-three CNF with private splitting variables. The full mixed fixture includes guarded parity and majority constraints, signed Horn constraints and both pin signs. It does not have a common untyped Schaefer operation: one ungated (or pinned-active) ternary parity relation is not closed under any coordinatewise signed meet or majority, and the active OR relation is not minority-closed; an active three-literal Horn clause is not majority-closed either. Pins rule out the trivial constant-zero/one witnesses in the exhibited satisfiable combination. The proof of typed tractability is constructive rather than a claim that arbitrary individually tractable constraints compose.

## TECT-X counterexample and gap boundaries

Even the two clauses x OR y OR z and not x OR not y OR not z, each Horn or dual Horn, admit no common typing from these four operations. For the positive clause closure requires either at least two OR types, or exactly one OR with two majority types. Reason: under a zero output OR permits no true input, majority permits at most one, AND and minority permit up to two. If the capacities sum to at least three, distribute one true bit to each of three input rows within capacities (for minority used once, use a second true input to make its parity zero), obtaining satisfying inputs with zero output. The negative clause has the symmetric requirement with AND and OR exchanged. The requirements are disjoint. The exact NAE triple relation also has no such typing, as the finite exhaustive check of all 64 tuples demonstrates; this latter assertion is a fixed finite fact, not an inference from closure of the separate clauses. NAE is nevertheless satisfiable. This demonstrates a concrete limit of the compatibility criterion, not hardness of recognizing a typing. General mixtures of individually Horn/dual-Horn width-three clauses include arbitrary 3-CNF, so an unconditional polynomial solver for all such mixtures would imply P=NP. Neither absence of a typing nor hardness of generic mixtures rules out other tractable mechanisms.

Topological analysis is exact local-to-global gluing on shared coordinates. The term g synchronizes the semilattice coordinates without changing the other restrictions of an existing global solution; after that pin the local product factorization eliminates cross-class compatibility. This is a precise algebraic compatibility result, not a homology characterization of arbitrary SAT.
