## 1. Main result and scope

Let M(p) be the number of satisfying assignments of an arbitrary original selector p on n variables. For fixed integer d>=1, write B_K^{<=d}(n)={p in B_K(n): M(p)<=n^d}. For every fixed k,d>=1 there exists a fixed K>=k such that, for every n>=1,

    |B_k^uniq(h)| >= sum_{p in B_K^{<=d}(n)} M(p) [Q-(n-1)(M(p)-1)],

where r=max(1,bit_length(2(n-1)(n^d-1))), Q=2^r, and h=n+r(n+2). In particular the right-hand side is at least (Q/2) sum M(p). The actual original U and its exact weighted stages are used. No assumption such as NP!=RP is needed for this transfer inequality. It is NOT an assertion that there exist unbounded few-model residuals, even under P!=NP. The exponent K is an absorbed fixed polynomial exponent, not necessarily k. The target complete selector is polynomial in the original complete length, and h=O_d(n log(n+2)).

## 2. Deterministic bounded-ambiguity isolation

Work over a field GF(Q) using r-bit polynomial coordinates over GF(2). Choose the first monic irreducible degree-r polynomial in increasing binary integer order. This can be constructed deterministically by enumerating all 2^r candidate polynomials and trial-dividing by all monic polynomials of degrees 1..floor(r/2). A reducible monic polynomial has such a factor. Existence follows from the usual elementary finite-field argument: the roots of X^(2^r)-X in a splitting field are distinct and form a field of size 2^r by closure under sum, product and inversion. Proper subfields have degrees e properly dividing r, so for r>1 the union of elements in proper subfields has size at most sum_{e=1}^{floor(r/2)} 2^e <2^r. (Each subfield of order 2^e is the root set of X^(2^e)-X.) Some element therefore has minimal polynomial of degree r. Degree one is immediate. All candidate enumeration and polynomial division costs are polynomial in Q and r; Q=O(n^{d+1}) for fixed d. No exponentially long advice, random bits or unknown witness is used.

For each assignment x=(x_1,...,x_n) define f_x(X)=sum_{j=1}^n x_j X^(j-1). For each alpha,beta in GF(Q), restrict the formula by f_x(alpha)=beta. For any two distinct assignments x,y, the difference polynomial is nonzero of degree <=n-1 and has at most n-1 roots, by repeated linear factor division. Fix a satisfying assignment x of a formula with M models. At most (n-1)(M-1) values of alpha collide with any other model. Thus at least Q-(n-1)(M-1) values of alpha isolate x in its own bucket beta=f_x(alpha). If 1<=M<=n^d, Q>2(n-1)(n^d-1), and the number is at least Q/2. The pair (alpha,beta) for a uniquely occupied bucket cannot correspond to two different models. Thus there are at least M[Q-(n-1)(M-1)] distinct uniquely occupied buckets. The algorithm need not know M, or choose a particular witness: enumerate all Q^2 pairs. For inputs with more models, the isolation count may be useless, but any projected verified model is still correct.

## 3. Exact normalized CNF encoding

For fixed n,d, allocate h=n+r(n+2) variables: the original n bits, r accumulator rows of n+1 bits each, then r tag bits. For row i (0<=i<r), write y_{i,j}, 0<=j<=n. Let c_{ij} be bit i of alpha^(j-1), 1<=j<=n. Force y_{i,0}=beta_i by a unit; impose y_{i,j}=y_{i,j-1} XOR (c_{ij} AND x_j); force y_{i,n}=0 by a unit. If c=0 use two binary equality clauses. If c=1 use the four ternary clauses enforcing XOR on the three distinct variables. Tag bits are forced by units to the r bits of alpha. There are O(nr) extra selected clauses, but the constructed input is the COMPLETE original h-variable selector of length L(h), not a compact list. Keep every source clause on its original variables. Every source assignment has exactly one extension satisfying the accumulator recurrences, initial units and tag bits, and satisfies final zero units iff f_x(alpha)=beta. Therefore the target model count is exactly the bucket count, with no auxiliary multiplicity. Projection reads the first n bits. For fixed n,d, the map (p,alpha,beta)->target selector is injective, including empty and unsatisfiable source formulas: recover the source bits from clauses on source variables only; recover alpha from tag units and beta from initial units. The tag is necessary in cases where different alpha give the same evaluation map, e.g. n=1. No external uniqueness promise is required to verify a projected assignment.

The complete selector constructor enumerates the actual normalized clause pool and marks selected clauses (one may sequentially sort clause index records); all integer widths and field operations are polynomial. With h=O_d(n log(n+2)), L(h)=O_d(L(n) log^3(n+2)). Field construction and Q^2 query enumeration are polynomial in L(n) for fixed d. All target stage calls are polynomial in their explicit length for fixed k, using the previously proved actual U simulation bound. No free execution of a target solver is assumed.

## 4. Deterministic residual transfer and a conditional asymptotic dichotomy

On arbitrary source input p, use a single fixed deterministic algorithm that constructs every bucket selector, runs the exact target stage k ceil(log2 L(h)) on each, and projects and verifies the first successful witness. If none succeeds, return FAIL (not a general UNSAT assertion). Its total time is polynomial in L(n) for fixed k,d, including field construction, selector generation, every stage call, and verification. Compile mathematically to a fixed general U tape description by the previously used polynomial-overhead simulation with original output positioning. Its fixed description length and polynomial clock fit some integer K>=k in the original stage K ceil(log2 L(n)) on every valid input, enlarging K for finite exceptions. No concrete compiled description or numerical K is supplied.

If p in B_K(n), none of its bucket selectors can be solved by stage k. Every uniquely occupied bucket is thus in B_k^uniq(h). Injectivity across p and bucket pairs proves the stated sum bound. The source restriction to few models is only used to get the isolation lower bound, not to define or run the wrapper.

In particular, if a fixed stage eventually succeeds on every uniquely satisfiable selector, then for every fixed d there is a polynomial stage K that eventually succeeds on every satisfiable selector with at most n^d models. Equivalently the same fixed deterministic bucket search decides the promise "unsatisfiable or 1..n^d models" in polynomial time (finite exceptions can be hardcoded). More strongly, under the unique-success assumption, enumerate all buckets, retain every verified projected witness and deduplicate: each individual model is isolated by at least Q/2 evaluations and recovered, so all models on the promised inputs can be listed in polynomial time. This is a promise-search conclusion; it is not an implication from the language-class statement P=UP without a promise-solving hypothesis. The all-model enumerator's output size is polynomial on the promise (and at most Q^2 distinct projections in its fixed number of calls even outside it).

Consequently under P!=NP, either every fixed k has unbounded unique residuals, or for each d there exists K such that all sufficiently large residuals of stage K have more than n^d models, and that stage still has unbounded residuals by the established unrestricted equivalence. This dichotomy does not prove either alternative. The earlier randomized isolation theorem under NP!=RP covers arbitrary multiplicities; the new transfer is deterministic but its guarantee needs bounded ambiguity. It does not give a deterministic isolation of arbitrary SAT and cannot convert the finite cubic interval into an unbounded result. Further work must address hard formulas with many witnesses or prove unbounded hard few-model inputs without assuming the desired separation.
