## Constructive theorem: global difference representation

Input is monotone NAE-3SAT on distinct variables in each triple. Choose any one pivot a for each atom NAE(a,b,c). Form the simple graph G with edges ab,ac for every atom, sharing equal edges globally. For each edge e=uv define d_e=x_u XOR x_v. Then the atom is equivalent to d_ab OR d_ac. For an arbitrary proposed difference vector d, there exists x inducing it iff the sum of d along every cycle is zero modulo two. Necessity follows from cancellation at vertices; sufficiency follows by choosing one vertex bit per connected component and extending along a spanning forest. The fundamental cycles of the nonforest edges suffice, since after forest lifting each corresponding equation is exactly the consistency condition for that edge. Denote the matrix of fundamental cycle incidences by H; it has r=|E|-|V|+components independent rows, since the nonforest columns form an identity matrix. Build H and lift in polynomial time. Thus the complete source is equivalent, with explicit witness map, to

    H d = 0 over GF(2), AND_{atoms}(d_ab OR d_ac).

Every satisfying difference vector lifts to exactly 2^components source assignments (including isolated variables). This is exact global gluing, expressed in the graph cut space, or equivalently orthogonality to the cycle space. The coordinates are not disjoint encodings of individual source variables. For independent NAE triples G is a forest, so no parity equations remain, the difference constraints are positive 2-CNF, and free component-root bits recover every source solution. This bypasses the section obstruction on that family without listing exponentially many charts.

### Exact typing test for the natural representation

Consider the relations consisting of each complete fundamental-cycle even parity relation and each binary OR relation. A parity relation of length >=3 forces XOR on every coordinate in any compatible four-operation typing: fix all but an arbitrary triple of coordinates to zero (idempotence preserves the pin). For even parity on three bits, write a_i,b_i for outputs on weights 1,2. Taking two zero rows and a weight-two row forces all a_i equal. Taking a zero row and two distinct weight-two rows forces b_i=0. Taking two identical weight-two rows and a distinct weight-two row forces a_i=1, using parity and the common all-one coordinate. Thus all operations are XOR. Every nonbridge belongs to a fundamental cycle (otherwise its column in H is zero and its edge unit vector would be a cut vector, impossible for a nonbridge). Every bridge has zero column. OR is not preserved by XOR on both coordinates, witnessed by 01,10,11. With at least one OR-typed coordinate and the other XOR or OR it is preserved: if the OR-coordinate output is zero all three inputs on it are zero, so the other coordinate is one in all three inputs. Hence the natural representation admits a common typing iff every atom's two-edge pair contains at least one bridge. The sufficiency typing is OR on bridges, XOR elsewhere. This test uses compact cycle descriptions and does not materialize exponential parity tables. It is specific to the stated natural constraints, not a claim about all equivalent representations.

## Alternative track: exact completion fixed-parameter in cycle rank

Set every bridge bit to one; it affects no cycle equation and can only improve positive clauses. Remove the bridges for the following degree count. Let G' be the nonbridge graph, omitting isolated vertices; its minimum degree is two, its cycle rank is still r, and with c' components sum_v(deg(v)-2)=2(r-c'). Let B be the set of edges incident to vertices of degree >=3 in G'. Since deg(v)<=3(deg(v)-2) for such vertices, |B|<=6(r-c')<=6r.

Enumerate the at most 2^|B| assignments to B. Reject a branch if a positive clause on fixed edges is false. Each remaining clause either disappears, becomes a positive unit, or is a positive binary clause. The graph of the remaining binary clauses on edge variables has maximum degree two: an unassigned edge has both endpoints of degree two in G', and its potential binary-clause neighbors are incident at one of its endpoints. Hence this graph is a disjoint union of paths, cycles and isolated vertices.

For each such component enumerate a dynamic program along its path/cycle order. Store the last bit, first bit (for cycles) and r-bit partial syndrome H d; retain one actual edge assignment for each feasible state. Test positive units and adjacent OR clauses, including wraparound for a cycle. Local work O(2^r poly(L)). Combine component syndrome sets by XOR convolution, retaining witnesses; at most 4^r pairs per merge. Include the fixed edges' syndrome; accept iff the total is zero. Lift and check the original NAE assignment. Exhausting all branches is exact negative evidence. The prototype's deterministic replay checks the answer and counts, not a general polynomial-size refutation. No physical resource meter.

Total time is 2^O(r) poly(L), including preprocessing, every branch, state transitions, witness storage and replay. In particular logarithmic cycle rank suffices for polynomial time without a bound on component size, interface cardinality or global ambiguity. Long cycles have r=1. The algorithm is not a polynomial worst-case algorithm on arbitrary instances (r can grow linearly in input length). The choice of pivot per atom is supplied or deterministic; no optimal pivot selection claim.

## TECT-X: mixed global compatibility is NP-complete

The exact difference representation does not eliminate general SAT hardness. For self-contained hardness, start from 3SAT with three distinct variable indices per clause (the standard restricted NP-complete form). Add a shared reference s. A clause of signed literals a,b,c is equivalent to NAE(a,b,c,s) when s=0; without pinning s, global complementation of all variables including s preserves every signed NAE atom, so a satisfying NAE assignment can be normalized to s=0. Split each NAE4 into NAE(a,b,u) AND NAE(not u,c,s) using fresh u. If a=b, u must be the opposite bit and the second atom precisely excludes the constant forbidden case; if a!=b choose u to satisfy the second atom. Replace every negated variable by a separate complement variable and enforce inequality between each required pair p,q by the four monotone atoms NAE(p,q,i), NAE(p,q,j), NAE(p,q,k), NAE(i,j,k), with fresh distinct i,j,k. If p=q the private triple is forced constant, impossible; if p!=q choose a nonconstant private triple. This is a polynomial monotone distinct-triple reduction. Applying the difference transform gives NP-completeness of the graph-derived combination of homogeneous cycle constraints and positive incident-edge binary clauses, even though either subsystem alone is tractable. Membership in NP by the difference vector and cycle checks. This is not an unconditional superpolynomial lower bound or a proof of P!=NP.

For arbitrary input there is no guaranteed small cycle rank. Complete triples on five vertices are already unsatisfiable, by pigeonhole: among two colors one has at least three vertices. The graph construction can also yield untypable but satisfiable instances, so an untypable result is not UNSAT. These are boundaries of this representation, not lower bounds on other transformations.
