## Adaptive certified search

Maintain an original CNF and a global learned-clause database. At a recursive node with decision literals p, perform unit propagation (UP) under p. If contradiction occurs, add the clause negating p. This is reverse unit propagation (RUP): the negation of the proposed clause yields contradiction by UP in the current database. Otherwise, if all clauses have a true literal, extend remaining unassigned variables arbitrarily and verify the original CNF. Else choose an unassigned variable of maximum occurrence count in unresolved clauses, breaking ties by variable index; try false first and true second. Counts are recomputed after propagation from the current database. There is no fixed prefix order.

When both recursive children fail they have learned the two clauses negating p together with the two opposite branch literals. Under p these become complementary units, so the parent clause negating p is RUP and can be added. This is sound even when the second branch is immediately contradictory because of the first learned clause. Induction gives completeness, and depth is at most n because each branch adds a previously unassigned variable. All learned clauses are consequences of the original CNF, so a returned witness satisfies the original and every learned clause. If the root fails, the final learned clause is empty, a checkable UNSAT proof. No clause deletion, restarts or first-UIP analysis are implemented; this is adaptive decision-clause learning, not a general modern CDCL solver.

On the previous prefix clock obstruction with m independent opposite-bit pairs and a four-clause guarded contradiction, the adaptive solver chooses z (occurrence four, tied with u,v, lowest index), then u or v in the wrong branch (occurrence four versus two for pair variables). Two conflicts yield the learned unit z after the parent return. On the correct branch, the unit z and one decision per pair suffice. Thus exactly m+5 recursive nodes and three learned clauses suffice (m>=1); the fixture verifies this. This removes that specific exponential obstruction, not arbitrary SAT obstructions.

The implementation keeps all clauses. A node costs polynomial time in the original input length, n and number/total size of prior learned clauses. Each node learns at most one clause of width <=n. Thus an upper bound polynomial in the input length on visited nodes would suffice for polynomial total runtime; one cannot assume a constant cost per node.

## Actual bounded trace verifier compiler

For a fixed explicit input template with presence bits, n variables, and T proposed learned clauses, use 2n membership bits per learned clause (positive and negative membership for every variable). Reject tautological proposals. The verifier checks each addition against all earlier clauses, using the two-sign synchronous UP circuit from the preceding prefix compiler, generalized to variable clause membership: negation of the candidate initializes the positive and negative assignment flags. For each clause and proposed unit literal require that the clause is enabled, that the literal belongs to it, and that every other member is false. Repeat n rounds and check contradictory signs or a completely false enabled clause. An empty clause is treated correctly. Conjoin all RUP checks and all normalization checks. A second output also requires the last learned clause to be empty (for T>=1). All source/trace bits are free inputs. Each gate has a definitional width-three Tseitin encoding, so the asserted second output is satisfiable exactly for source selections and proposed traces giving a valid T-addition RUP refutation. Duplicate clauses, including duplicate empty clauses, may pad a shorter valid refutation. Complexity is polynomial in explicit template length, n and T, including database growth. This is a compiler for certificate verification, not a bounded transition compiler for the heuristic's deterministic execution or a solver for the resulting CNF.

## Resolution simulation barrier

For a normalized RUP addition C, suppose UP on the prior database under the assumptions negating C finds contradiction. Record reason clauses for forced literals in order, and the final falsified clause. Resolve the latter backwards against reason clauses for propagated literals, eliminating them in reverse assignment order. Every introduced non-assumption literal was false at an earlier time, so this process yields a clause containing only literals of C, using at most n resolution steps. If contradiction was already present at the assumptions the same argument starts with its falsified clause; no propagated literals are needed. Weaken the result to C. The assumption set is consistent since C is normalized and non-tautological. Empty C yields a refutation directly. Thus a T-addition RUP proof of contradiction on n variables converts to an ordinary resolution proof with weakening of O((n+1)T+input clause count) lines. Weakening does not evade a resolution lower bound: it can be eliminated by tracking subclauses of each derived clause, resolving if both pivots occur and otherwise reusing a subclause of a parent; the final subclause of the empty clause is empty.

Apply the earlier explicit degree-three split-hypercube Tseitin width and size result (F038 resolution-certificate-barrier). For n edge variables the wrong branch requires exp(Omega(n/log^4 n)) ordinary resolution lines. Thus even arbitrary adaptive RUP clause selection requires exp(Omega(n/log^4 n)) additions to refute this branch (dividing by a polynomial does not change that asymptotic bound). This also applies to the UNSAT branch CNF itself; no adaptive heuristic or schedule removes the bound while required to output only RUP additions on the original variables. The proof does not assert that a solver of the satisfiable guarded instance must visit the wrong branch, or that stronger proof systems, new extension variables, preprocessing with stronger certificates or arbitrary explicit-input algorithms have this lower bound. The Tseitin family has short algebraic contradiction certificates. The result is a transfer of an established restricted lower bound, not an unrestricted complexity separation.
