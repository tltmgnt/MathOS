## Scope and acceptance

Require dimension checking from the raw tensor grammar, two distinct factor bits at each complete candidate, same-tape pair-message storage and backtracking, full physical checkpoints, independent predicate/reference checks, and charged resources. This is standard sliding-bag dynamic programming with explicit tables; no separate agent ensemble, general bounded-width solver or independent formal certification is claimed.

## Input/output contract
Variables x_0,...,x_(g+1), positive finite rank cardinalities d_i. Initial relation M_0(a,b) is encoded in groups indexed by b, each with d_0 membership bits indexed by a. Tokens are three raw bits: 000/001 data 0/1, 010 group open, 011 pair open, 100 pair end, 101 group end, 110 stage end. Initial stage is one or more groups (010, nonempty data sequence, 101), then 110. Each subsequent stage is one or more destination groups (rank c in ascending order), each containing one or more pairs (rank b in ascending order): 011, nonempty sequence of two data bits per candidate a (factor R and S), 100. End each group by 101, stage by 110. No external dimension counts, tuple IDs, predecessor flags or topology pointers. All initial groups must have the same positive length. In stage i each group must have exactly d_(i+1) pairs and each pair exactly d_i candidates; the number of groups determines d_(i+2). Grammar is checked physically, including dimensions at infeasible prefixes. No zero-size domains, arbitrary integer labels, general bag topology or original F038 selector encoding.

Success output is initial pair one-hot in b-major, a-minor order, followed by one-hot vectors for x_2,...,x_(g+1). The initial pair output is deliberately joint, not two independent one-hot vectors. With the input dimensions it decodes uniquely. Output length H=d_0*d_1+sum_(i=2..g+1)d_i. Valid UNSAT and malformed strings halt on blank, not distinguishable from output alone; rejecting scratch need not be erased.

## Semantic invariant
M_(i+1)(b,c)=OR_a [M_i(a,b) AND R_i(a,b,c) AND S_i(a,b,c)].
M_i describes precisely the prefix's feasible frontier pairs. A positive term extends a valid prefix with c, and every satisfying extension produces such a term. The middle coordinate b is the same rank before and after the transition; it is not existentially independent. The least compatible a is recorded as a provenance mark in the pair's candidate payload. This gives a unique chosen predecessor for every positive outgoing entry. Choosing the least feasible final c then b, followed by least compatible predecessors, recovers the reverse-coordinate lexicographically least satisfying assignment. This is proved by induction on prefixes and then by induction backward over stages.

## Fixed tape construction
Reuse six-cell REX block compiler. Parse all raw tokens into a contiguous tagged region, with two Z padding cells per token, L/R sentinels and A active stage delimiter. Initial cells M0/M1 preserve original relation bits, IG indicates initial group; later G group, P pair header, F0/F1 and E0/E1 factor bits. J group end, V pair end, D inactive stage end. Before processing any triple, compare lengths of adjacent initial groups using two unique value cursors, reject if one reaches J before the other. By transitivity all initial groups have common positive size.

In the forward phase A separates source and destination stages. For a destination group (U marker), align its pair headers Q with source group cursor B (BI/BG variants). For each pair, align each F/E candidate with one source message entry C, by scans bounded by L/R. Source entries are M0/M1 for initial grid, T0/T1 at prior pair headers otherwise. Hold a first-factor bit, source feasibility bit and hit flag in finite control. Read the second factor at the same candidate, mark the first fully compatible E1 as EP, preserve both original factor bits. Advance the source entry and candidate together, requiring simultaneous termination at group and pair end. Write T0/T1 at Q according to hit. Advance source group and destination pair together; require their simultaneous exhaustion. Repeat from the first source group for each destination group, then shift A to next stage. Thus all candidate and group dimensions are checked, even if a source message is zero. Every output table is a rectangular joint pair grid with c-major, b-minor order, exactly the layout needed for the next stage. Each source rank is identified by cursor order, not a host integer or arbitrary supplied compatibility table.

At final A, search the latest stage in ascending c then b order for first positive message; reject if none. For initial-only input mark the selected M1 as MW. Otherwise mark the chosen group W and chosen pair TW. Move A left one stage. Backward aligns the selected destination group with source groups and their entries, as in forward mode, until the selected pair and its EP are reached. Mark corresponding source group W (or IG for initial) and source message TW (or MW for initial). Restore the destination pair to T1, original EP, and group W; skipped unselected pairs retain their original T0/T1, including T1 entries not selected. Repeat moving A left until initial stage; no host reset. Final snapshot preserves all original raw factor bits, computed feasibility and provenance, apart from selected output marks that imply the original positive bit. Serializer emits MW and W as 1, M0/M1 and G as 0, skips other tags, erases scratch and returns contiguous output. No computed messages supplied by host. All loops progress through tokens, candidates, pairs, groups or stages, each scan is sentinel-bounded on valid grammar, and mismatched dimensions reject on blank.

## Charged resource ledger
N=3*[d_1(d_0+2)+1+sum_(i=0..g-1)(d_(i+2)*(2+d_(i+1)*(2+2*d_i))+1)]. All loops over explicit data. Initial adjacent group comparison touches O(N) entries; each costs O(N) bounded sweeps. Forward processes each candidate, pair and group once with constant-many region scans per item. Backward processes at most the selected group of each stage, and only up to selected predecessor; no stage is traversed as a destination twice. Therefore logical work O(N^2). Six-cell compiler charges 16 transitions per move and 11 per stay; preparation P=7N^2+17N+3. Serializer exact cost 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, w=6, e_i=1 at initial membership cells and later group headers, c_i=sum_(j>i)e_j. H<=N. Successful final head -6N-H-2. Total valid time Theta(N^2) (preparation supplies lower bound for this implementation), visited span O(N), no growing scratch. Uniform m with g>=1: N=Theta((g+1)m^3), time O((g+1)^2 m^6). This counts explicit tensor input, not original normalized F038 input or its construction. No unrestricted polynomial SAT or original universal-stage admission.
