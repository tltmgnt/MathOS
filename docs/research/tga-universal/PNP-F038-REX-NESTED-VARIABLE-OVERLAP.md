## Semantic invariant
For row i of v define F_v(i)=u_v(i) AND AND_(c child) OR_j [F_c(j) AND pi_c(row_v(i))=(row_c(j)[0],row_c(j)[1])]. Induction on completed subtrees proves F_v(i) represents exactly the existence of a compatible assignment for all descendant introduced variables with that specific parent row. Necessity by restricting a model; sufficiency by combining child extensions, since their introduced variables are disjoint conditional on the parent. Duplicate rows with distinct local flags remain distinct. At the root pick first feasible row, then recursively pick first feasible compatible child. The same invariant ensures each choice can extend, and child independence yields lexicographically least row-index vector. No unary marginal substitution.

## Fixed physical construction
Reuse six-cell REX compiler. Parse interleaved with forward processing, tag openings A(code), preserve code bits and row digit/flag tracks, delimit rows and tables. On close mark unique X and find nearest A (child) -> H, nearest earlier A (parent) -> B. For each positive completed CHILD row (pivot Q), activate all not-yet-supported parent row headers P -> K. Broadcast each digit of its first two fields in turn to parent rows, using finite-control map k to choose retained parent fields. Mark used digits in Q and matching K rows. End broadcast checks equal lengths. Mismatch rewinds only to that row's K, drops it to P, then skips rest of row. Already supported S rows skipped. Each broadcast traverses parent table with constant number of visits per cell. After two fields, K denotes exactly full joint matches among unsupported parent rows. Collect K -> S, restore all used digits and Q -> P. On completing child table, conjoin parent T(raw,old) with header support bit S/P, restore headers P. Thus each parent row stores exact conjunction from processed children; all child masks and accumulated feasibility remain on tape. Restore B->A, H->F and X->C and continue parsing. Empty child table gives zero support, and parsing continues even when earlier messages are zero. Root close installs R only if immediately followed by blank.

Backward scan selects first root T11 (row W, active opening V), then at each child F mark H, find nearest active V parent -> B4. Repeat child-pivot broadcasts, activating ONLY selected parent W->K; mismatch drops to S, collect restores either K or S to W and retains hit bit. First feasible child pivot with hit becomes W. Restore parent and child openings V, proceed to child descendants. At close pop nearest V->G using Y cursor, restore C and continue. No parent-rank host transfer, no external counters, no all-parent predecessor table required; recomputation charges each child row at most once. Original factor masks and conditional bits remain recoverable at ready checkpoint. Serializer projects W=1, P=0, all other tags omitted; erase input and history. Successful output exactly the row-index certificate specified above.

## Charged resource proof
The former parent-pivot method could repeat a large parent's label lengths once per child. Here every nonroot row is a pivot at most once forward and once backward. The sum of retained child label lengths plus row count is O(N), including arbitrary depth and degree. Each digit broadcast (including end-of-field, pivot lookup, and return) costs O(N): bounded global scans to unique B/Q, then monotonic sweep with mismatch rewinds confined to the current parent row. Activation, collection and restoration cost O(N) per pivot. Per-edge finalization and stack transitions O(N) each, O(N) edges; root row selection O(N) per row, and parser/cleanup O(N) aside from these charged operations. Thus total logical time O(N^2), including all edges, even when both parent size and degree grow. Every loop advances a digit, row, edge or token, and bounded searches reach their invariant target for valid input. Six-cell compiler charges 16 transitions per moving logical transition and 11 per stay. Preparation P=7N^2+17N+3. Serializer exact 2wN+2w+2+sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, w=6, e_i=1 at row header positions, c_i=sum_(j>i)e_j, H=row count. Output head -6N-H-2. Both codecs O(N^2); preparation yields Theta(N^2) lower bound for this specific implementation, also on valid UNSAT. Visited tape span O(N). No universal lower bound. For a fixed number of dense triple tables with m labels encoded in O(log m) bits, N=O(m^3 log m), accounted nested computation O(m^6 log^2 m). This excludes original input conversion, arbitrary bag widths/planning, and original witness translation. It is not an original selector-stage admission proof or unrestricted SAT bound.
