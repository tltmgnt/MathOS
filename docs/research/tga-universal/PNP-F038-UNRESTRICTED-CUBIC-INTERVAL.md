## Objective and result

Keep the exact U, input encoding, description syntax, output convention, verifier and stage clocks of the preceding cycles. Return from conditional randomized isolation to unconditional cubic-stage failures, including uniquely satisfiable ones. We establish:
- B_3(n) is empty for every n=1,...,51 (the actual exhaustive built-in is active).

These are finite-length theorems, not an unbounded-length cubic lower bound. The count applies to selectors on the existing universal pool, not arbitrary input encodings. The stage cutoff remains s=3 ceil(log2 L). MRA-X roles are locally authored records, not independent agents. No novelty claim.

## 1. One-running-state prefix theorem

Consider the actual one-running-state general interpreter, with symbols 0,1,blank, a separate halting state, head initially zero, and finite binary tape input beginning with n ones then zero, n>=3. Outside the input all cells are blank. The returned proposal is the n consecutive cells beginning at the final head after the halt transition, and is malformed if any are blank. For every clock t, the optional well-formed proposal depends only on the first 2n+1 cells, provided the input has at least that many cells. In particular adding or changing arbitrary binary suffix bits beyond those cells does not change this optional proposal. This statement is about the concrete interpreter and includes timeout/malformed outputs, not a decision-complexity lower bound.

Proof. If the transition on 1 halts, the first step halts and the result is prefix-local. Otherwise if the transition on 0 halts, any access to the initial zero at cell n halts; before halt no head can pass that cell. The entire computation up to halt or timeout stays on this common region and its blank left side. After halt the head is at most n+1, so even the final output read ends at most at index 2n. If none of the three transitions halts there is no proposal.

The only remaining case is halt exclusively on blank. For each input symbol 0,1, compress local stay transitions into a macro: it either halts at the cell (possibly with its final move), loops there forever, or writes some symbol and exits left/right without halting. This is exact for each symbol because the running state is fixed and at most three different symbols can be visited while staying at one cell. The macro describes a trajectory; it does not give a machine free simulated steps.

If the macro on 1 stays forever, halts, or exits left, the initial behavior terminates, loops, or visits the exterior blank at -1, independently of any suffix. Otherwise the 1 macro exits right, writing c, so the machine scans the initial n ones and reaches the first zero. If the zero macro halts or stays forever, the behavior is prefix-local. If both macros exit right, every binary input cell is traversed monotonically, until the blank at the right exterior (unless the clock expires). The halt on that exterior blank can leave the head no earlier than the last input cell. Only that last cell and the formerly blank cell just after it can possibly be nonblank in the output window. Since n>=3, the output is malformed.

It remains that the zero macro exits left, writing d. After the first zero, if c=blank, the machine halts at cell n-1. If c=0, the retreat traverses the entire formerly-one prefix as zeros, moving left to the exterior blank; all such behavior is prefix-local. If c=1, the next 1 macro returns to the first zero. For d=blank the machine halts there; for d=0 the two-cell configuration repeats; for d=1 this converts the first zero to one and sweeps forward. In the last case an invariant is that all previously processed input cells are ones, and the head is on the next cell to process. An encountered one advances directly; a zero writes one, retreats to the preceding one, and advances twice. There are no blanks in the processed region. Thus the machine reaches the right exterior and has a malformed output, or times out. This handles every transition table.

In all prefix-local cases the actual transitions, output cells and elapsed times coincide on inputs sharing the prefix. In the sweep cases no clock yields a well-formed proposal. A macro proof therefore preserves the optional proposal at every original clock, including a cutoff inside a macro. QED.

## 2. Simultaneous same-U elimination for n=52,...,92

For n source variables, write N=2n+4 binom(n,2)+8 binom(n,3), L=n+1+N and s=3 ceil(log2 L). Direct integer calculation gives s=54 on n=52..58, s=57 on n=59..73, and s=60 on n=74..92. The actual description lengths for one, two and three running states are 20,42,61, respectively, and increase with state count. Thus exactly 18^3+27^6=387426321 valid general descriptions are eligible. Their clocks are 2^(s-20) and 2^(s-42). The exhaustive built-in is inactive because s-3<n at every one of these 41 sizes. Every other built-in either emits no well-formed assignment or an integer <=3. For n=1..51, direct integer calculation instead gives s>=n+3, so the exhaustive built-in accepts every satisfiable input and no residual exists. Hence n=52 is the first possible cubic failure size. At n=93, L=1055520 and s=63, activating three-state descriptions; the present proof stops at 92.

Fix the last 31 source variables as 29 data pins followed by two guards. Force all earlier variables and both guards to zero with fixed ternary clauses: for each earlier variable i select the four lifts (not x_i OR +/-x_(n-1) OR +/-x_n), and force each guard to zero by four corresponding lifts using x_1,x_2 as guards. For each 29-bit a, force its data bits by four ternary lifts per pin using the final two guards. Distinct supports and sign choices yield exactly 4n clauses. Every variable is pinned by the conjunction, so the unique assignment w_a has exactly a on the data block and zeros elsewhere. Conversely w_a satisfies all fixed clauses, for either sign pattern of the guard literals. This is a simple exact model construction, not a SAT solver.

The ternary clauses supported entirely on the last 31 variables form a final selector suffix of 8 binom(31,3)=35960 bits, in the actual lexicographic support/sign ordering. The variable data-pin clauses and any further clauses confined to this suffix can differ between candidates, but every other selector bit is fixed. All unit and binary selectors are zero. Put P=L-35960 and R=P-n. The complete tapes share their first P cells, including the unary header and fixed early pin constraints. At all 41 sizes, P>=2n+1 and 2^(s-42)<=R; these inequalities are checked for each size, not inferred merely from representative endpoints. A two-state program under its original clock cannot read cell P or beyond: the maximum head index is t and its final output window ends at t+n-1<=P-1. All its possible well-formed proposals are independent of the varying suffix. The theorem in section 1 gives the same independence for all one-state programs regardless of their much longer clocks.

For any one fixed input of the family, collect the projections onto the 29 data bits of every well-formed proposal of the eligible general descriptions at their original clocks. There are at most 387426321 distinct projections. This set is the same for all candidate inputs, by the two independence results. Add the all-zero projection to cover all short built-ins, since these data bits lie above the first two source bits. At least

    2^29 - 387426321 - 1 = 149444590

patterns remain. For any such a, the selector has unique model w_a but no eligible program returns it. Invalid descriptions, which are also visited by U, never produce a model. Thus S_s(p)=0 exactly for this unchanged U; the counting proof need not execute all of the enormous literal stage loop.

For any chosen missing pattern, exactly seven of the eight signed ternary clauses on each triple of the last 31 variables are true under w_a. Of those 7 binom(31,3)=31465 clauses, 116 are the already selected data-pin clauses. The fixed guard pin clauses and earlier pin clauses are outside this suffix. Any subset of the remaining 31349 true clauses may be independently added. These additions preserve the unique satisfying assignment and common-prefix condition, so every such distinct selector is also a cubic failure. Different missing patterns cannot give the same selector because their unique assignments differ. Therefore

    |B_3^uniq(n)| >= 149444590 * 2^31349,   52<=n<=92.

This is an unconditional finite census by counting, not an explicit enumeration of the missing patterns at each size. A finite brute-force procedure could find them by enumerating the eligible descriptions and their original clocks on the common prefix and using the one-state theorem. Its actual costs are charged; no efficient asymptotic discovery claim is made. The proof uses actual complete input sizes, not a compressed clause list for the machine's clock.

## 3. Explicit stronger family at n=52

The prior CI-verified cubic fixture fixes x_1,...,x_50 to a=0x123456789abcd via 200 ternary clauses and leaves x_51,x_52 free. It certifies that no scheduled general or built-in program returns any of its four models. At n=52, the unary header and all unit/binary selector bits occupy P0=5461 cells, so t_two=4096 and t_two+52<=P0. Consequently every possible ternary-only selector has the same two-state proposals; the one-state prefix theorem likewise applies to every ternary-only selector. Both facts preserve the actual stage 54. All valid short built-in outputs are unchanged (first two selector bits zero and exhaustive built-in inactive).

For each g in {0,1,2,3}, add eight ternary clauses fixing the last two variables to the bits of g, using x_1,x_2 as guards. The new formula has exactly one model, w=a+2^50 g. It is one of the four original models, so the prior verified rejection plus the proven proposal invariance implies cubic-stage failure. This is a same-length transformation; no padding, change to U, or assumption that success monotonicity holds under adding clauses.

There are 7 binom(52,3)=154700 true ternary clauses under w. The 208 fixed clauses are among these. Every subset of the remaining 154492 can be added, retaining a unique model and the same all-zero unit/binary prefix. Hence there are at least 4 * 2^154492=2^154494 distinct explicit uniquely satisfiable selectors in B_3(52). This count follows exactly from independent subset choices and disjointness of different unique models. The parent cubic fixture was a single counterexample; this proves a large family rather than merely a conditional census.

## 4. Barrier and next direct obligation

This finite interval does not extend to arbitrarily large sizes by the argument above. At n=93 the description-length gap disappears, and at sufficiently large n the two-state clock is no longer prefix-local. The proof of one-state prefix dependence remains valid at every length, but by itself cannot defeat all other algorithms. In particular the fixed pin formula family is easy to solve in polynomial time given the explicit clause selectors, so some program in U eventually handles that family within some polynomial exponent. It is not an all-exponent obstruction. We do not assert the actual worst-case cubic behavior at n>=93 in either direction.

The next goal remains unconditional B_3 nonemptiness at unbounded n (or a universal polynomial cutoff), requiring control of newly active descriptions and computations that inspect and transform the full input. Merely enlarging the pin family or counting additional syntactic redundant clauses does not resolve that obstruction. No universal obligation closes. Independent mathematical review, Lean formalization and new exact-head CI remain outstanding.
