## Constructive theorem: exact witness elimination by a supplied frontier layout

Fix a deterministic verifier with h Boolean witness coordinates and r passes; each pass visits each witness coordinate once, in a supplied permutation. Its state belongs to [W]={0,...,W-1}. At stage j reading witness variable v_j it changes state by a supplied function delta_j(x,state,bit), where x denotes ordinary inputs. The transition predicates for each fixed state pair and bit must be uniformly constructible Boolean circuits of polynomial size in the explicit description L, with no existential oracle. Initial state and accepting state set are fixed. The accepted language is f(x)=exists w such that the full run ends in an accepting state. All passes read the SAME witness, not independently chosen copies.

Identify the two or more occurrences of each witness coordinate as a single vertex of a directed multigraph. For consecutive stages j,j+1 add an edge e_j from v_j to v_(j+1), carrying the intermediate state. Edges keep distinct IDs even when parallel; self-loops are allowed. The initial and final state constraints are local to the first and last stage (the initial state fixed, final state existential among accepting states). For each vertex v form a local Boolean predicate on its incident state variables and x: there exists one bit b such that all stage transitions at occurrences of v hold, with the common b. At a last stage the predicate tests whether delta lands in the accepting set. At a first stage the initial state is substituted. The local existential over b is an OR of two explicit ANDs. Self-loop state variables must be identical at both incidences. The conjunction over vertices, existentially quantified over edge states, is exactly f(x): any actual run supplies a state assignment, and conversely the local predicates choose a single bit per vertex and constrain consecutive states to agree, so determinism yields the actual run.

Let sigma be a supplied permutation of the h witness vertices. Its frontier at a cut contains edges with precisely one endpoint processed; let c be the maximum cardinality, counting parallel edges separately. Maintain a table indexed by assignments of states to frontier edges. Each entry is a Boolean circuit on x expressing existence of all already processed witness bits and all internal edge states compatible with that boundary. Initially the empty assignment has predicate true. For the next vertex, enumerate old frontier assignments and states on its not-yet-assigned incident edges (including self-loops), evaluate the local predicate and AND with the old entry. Forget edges becoming internal and OR all contributions with the same new boundary. Unchanged frontier states are carried across unchanged. Induction on processed vertices proves exactness of the invariant. The final empty-boundary entry computes f(x). A concrete accepting witness can be reconstructed by choosing a true predecessor and local bit at every reverse step with x fixed, then replaying the original run. Alternatively evaluate a Boolean table with backpointers on fixed x. No assumption of unique witnesses.

Each vertex has at most 2r incident stage-edge positions. There are at most W^c old boundary assignments and W^(2r) new incident assignments per update. Thus a deterministic circuit and a uniform compiler (and evaluation/backtracking) have bound

    h * W^(c+2r) * poly(L)

including state indices, transition predicates, OR/AND gates, and explicit bit encodings. This is polynomial for fixed r,c and explicit W<=poly(L), and may also be polynomial when (c+2r) log W=O(log L). A supplied layout can be checked for its actual c in polynomial time; finding an optimal layout is not assumed free. For all passes in the same order use that order as layout: each pass contributes at most one interior crossing and each interpass join at most one, so c<=2r-1. In particular constant-pass common-order polynomial-width verifiers have uniformly polynomial deterministic circuits. This is stronger than simply enumerating every witness or treating per-pass witnesses as independent. For h=0 the verifier is a fixed initial/accept test in this model.

## Alternative track: two different orders already encode arbitrary CNF SAT

Given a CNF with nonempty clauses, assign a fresh witness bit to every literal occurrence. In pass 1 visit occurrences clause by clause. Maintain three states: 0 (current clause not yet satisfied), 1 (current clause satisfied), 2 (permanent reject). Update the satisfaction flag by OR with the signed literal evaluated on its occurrence bit. At the last occurrence of a clause, go to state 0 if satisfied and to 2 otherwise. State 2 is absorbing. In pass 2 visit the same occurrence bits grouped by original variable (fixed order within group). On the first occurrence of a group store the bit (state 0 or 1); on subsequent occurrences stay in that state if equal, else enter 2. Accept states 0 and 1. Empty input CNF is handled as true; an empty clause can be handled separately by an always-reject instance. The reduction uses explicit stage transition tables, no ordinary input required, and O(total literal occurrences) stages with width exactly three available states.

An accepting witness exists iff the original CNF is satisfiable: pass 1 ensures each clause has a true occurrence, pass 2 enforces one common value per original variable. Conversely any satisfying source assignment gives the unique occurrence assignment on the used variables; unused source variables are irrelevant. Projection decision for explicit two-pass, width-three programs with arbitrary different orders is NP-complete (membership by an occurrence-bit witness). This applies already to nonempty width-three source clauses via the standard NP-completeness of 3SAT. Thus simply bounding pass count and width without controlling the cross-order interaction does not give polynomial deterministic witness elimination unless P=NP. It is not a circuit lower bound for general SAT or a proof that the given frontier parameter must be large on every hard instance.

In particular, if a uniform polynomial-time procedure produced polynomial-size deterministic circuits for every explicit verifier of this two-order width-three form, it would solve SAT by evaluating the compiled circuit at a fixed ordinary input. Mere existence of a small circuit for each fixed formula is trivial (it is a constant function); the uniform compiler cost is the relevant issue in this reduction. To derive a nonuniform lower-bound transfer would instead require an input-dependent verifier family representing all formulas of a given length and a justified structural guarantee for that same family. No such theorem is supplied here.

## Topological and adversarial analysis

The common witness induces local constraints on a multigraph of intermediate computation states. The frontier measures exactly which state information must remain shared between processed and unprocessed witness groups in this contraction scheme. In the reduction, clause-local feasibility and variable-local consistency are individually simple but their differing orders carry global SAT interactions. This is a graph-cut DP, not an unrestricted topological invariant. Replacing repeated witness occurrences by independent bits would be unsound; the constructed reduction explicitly demonstrates why. No general graph-layout discovery bound, proof-system completeness, or unrestricted deterministic lower bound follows.
