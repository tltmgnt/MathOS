## Constructive theorem: a uniform universal two-order witness family

For n>=1, let U_n be the ordered pool of all distinct nonempty, non-tautological clauses of width at most three on n indexed variables, ordered deterministically. Each clause occurs once; repeated variables and tautologies in source formulas can be normalized, duplicate clauses removed, and an empty clause handled separately as UNSAT. The pool contains N=sum_{j=1}^min(n,3) 2^j binom(n,j)=O(n^3) selector bits p_C. A single Boolean function F_n(p) asks if the selected formula is satisfiable. This is a fixed function at each n, not one constant function per formula.

Give each literal occurrence in the FULL pool its own witness coordinate. Let h=sum_C |C|=O(n^3). Read all coordinates once in clause order, and a second time grouped by variable with occurrences within each group in first-pass order. Use three states: 0 and 1 track current clause satisfaction, 2 is an absorbing failure. In pass one, treat a literal as true if its selector p_C=0, otherwise evaluate the signed literal on the occurrence bit. At the end of a clause reset to 0 if satisfied, otherwise enter 2. In pass two the first occurrence of each variable group stores its bit, all others check equality, and 2 stays absorbing. Accept 0 or 1. Only a single ordinary selector bit is needed per transition in pass one; none is needed in pass two. Both passes, graph and transition templates are independent of p.

For each source assignment x the occurrence assignment is its repetition across the full pool. Every accepting occurrence assignment is consistent on each variable group, and every selected clause has a true literal. The full pool includes all variables, so the accepting occurrence assignments are in bijection with the satisfying source assignments, including assignments to variables absent from selected clauses. For a smaller pool missing some variables the multiplicity is 2^(number missing). This proves exact decision and witness preservation for one explicit, uniformly constructible family of width-three two-pass programs.

Any uniform polynomial-time compiler that converts every such family member to an ordinary deterministic Boolean circuit of polynomial size, in the explicit program length, would imply P=NP: normalize an arbitrary 3-CNF, produce its selector vector, construct the program/circuit for n and evaluate. The variable count n is bounded by input length after renaming. Conversely if P=NP the fixed function F_n has uniformly constructible polynomial circuits by bounded deterministic machine simulation with hardwired n and fixed input length N; this converse concerns this family, not every verifier formalism. Nonuniformly, polynomial-size deterministic circuits for F_n for every n (one common polynomial bound) are equivalent to NP subset P/poly. In the forward direction, normalize source input by polynomial circuits; since n may vary among source inputs of length l, either use a pool on l variables or multiplex polynomially many lengths, and handle empty clauses separately. In the reverse direction the padded pool language is in NP, and its circuit family specializes to F_n. This repairs the previous fixed-formula quantifier defect. Neither equivalence asserts that these circuits exist.

## TECT-X: linear lower bound on the frontier for every layout of this family

Build the occurrence multigraph of the previous frontier theorem: consecutive visits carry intermediate-state edges; parallel edges have distinct IDs. Each variable's occurrences form a connected path via the within-variable second-pass edges. The first-pass edges inside clauses provide an edge between the occurrence groups of every pair of distinct variables, since the pool includes all two-literal clauses. No appeal to an optimal-layout oracle is necessary.

For n>=2 take any permutation of all h occurrence vertices as a contraction layout. Inspect the cut immediately before the first occurrence of the last variable group to be touched. All n-1 other groups have at least one processed vertex; the last group has none. Each other group is either active (some but not all processed) or completed. An active group contributes a distinct crossing edge on its within-variable path, since the path is connected. A completed group contributes a distinct first-pass edge from a two-variable clause connecting it to the untouched group. The two classes of edges have different stage IDs, even if endpoints coincide. Hence this single cut has at least n-1 crossing edges. The argument works for every vertex permutation and any clause ordering and within-group order that preserve these paths and clause adjacency.

Conversely, the first-pass occurrence order is a layout with at most 2n+1 crossings: at most one first-pass edge, one interpass join, at most one within-group second-pass edge per variable (the within-group order follows first-pass order), and at most n-1 joins between variable groups. Therefore the minimum frontier lies between n-1 and 2n+1, i.e. Theta(n). The same bounds apply to the positive pair-only pool for n>=2, which illustrates the graph bound independently of SAT hardness.

The prior full-state frontier enumeration for W=3 therefore has a worst-cut index domain of at least 3^(n-1) entries on this universal family; the domain is not an assertion that all these entries are reachable, distinct Boolean functions, or actually stored by a sparse compiler. Its supplied-layout bound is exponential in n (and superpolynomial as a bound in the polynomial-size description). No better ordering of these same occurrence vertices makes c=O(log n). This is a structural obstruction to the particular explicit-domain compilation guarantee, not a lower bound for every circuit, a compressed table, a reformulated verifier or actual execution time. It does not show P!=NP.

For small instances one can compute exact minimum cutwidth by subset DP: d(empty)=0, d(S)=max(|delta(S)|,min_{v in S} d(S minus v)). Each layout of S has a last vertex; the earlier cuts are precisely those in its preceding prefix. Boundary edges are always measured against the full graph. Store last vertices to reconstruct an optimal permutation and check its frontier. This costs O(2^h poly(h+edges)) time and memory and is only used for finite regression, not claimed efficient at general h.

## Alternative track: exponential residual width in a specified selector order

Consider deterministic ordered branching programs reading the selector bits exactly once in a fixed order with all unit-clause selectors before every binary or ternary selector. For each assignment x choose the prefix that selects exactly the n units forcing x and leaves the opposite units off. The remaining function on later selectors is satisfiable iff each selected remaining clause is true at x. For distinct x,y and n>=2, choose a differing coordinate i and any j!=i. The two-literal clause whose literals are false at x on i,j is true at y (because i differs). Selecting just this clause among the remaining selectors distinguishes the two residual functions. Thus there are 2^n pairwise different residuals after the units, requiring at least 2^n different states at that layer of any deterministic read-once branching program with that input order. Equivalently, a standard ordered decision diagram allowing skipped variables must have at least 2^n-1 nonconstant residual nodes (at most one residual could be constant true; in fact none are constant in this full binary pool). This is a genuine deterministic model lower bound for the same input-dependent family, not a lower bound for arbitrary selector orders, repeated reads, general branching programs or Boolean circuits. Each unit prefix can be encoded as n-bit x; the witness argument is independent of how the branching program computes internally before the cut.

Topology: the variable occurrence paths and pair-clause links impose a frontier in every layout, whereas the residual argument measures distinguishable future computation under one selector order. The measures are different; no theorem is claimed transferring the residual bound to all circuits. The full pool is structurally large even if the particular input selects only an easy subformula; an input-dependent preprocessing step could remove inactive occurrences and change the graph.
