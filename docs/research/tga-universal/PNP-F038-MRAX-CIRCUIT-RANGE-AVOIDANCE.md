## Constructive track: sparse-prefix circuit avoidance

Fix n>=1 inputs, free constants 0,1, and at most s>=0 gates from the 16 possible binary Boolean truth functions. A gate references two ordered preceding wires (repetitions allowed); the output references any wire. This basis covers general bounded-fan-in Boolean circuits with constant overhead for any fixed finite gate basis. Count syntactic encodings: for each gate there are at most 16(n+s+2)^2 choices. Including all possible lengths and outputs, the number is at most

 B(n,s)=(s+1)(n+s+2)[16(n+s+2)^2]^s.

Let b=ceil(log2(n+s+2)), m=ceil(log2(s+1))+(2s+1)b+4s+1. Then B(n,s)<2^m. Whenever m<=2^n, evaluate each circuit on the first m inputs in binary numeric order. At least one m-bit word is missing from the range. Let h(n,s) be the smallest missing word in numeric order (the output on input i is bit i). Define the n-input function H_{n,s} to equal those m bits on the prefix and zero elsewhere. Every circuit of size <=s disagrees on the prefix. Thus H_{n,s} has circuit complexity >s, without storing a full 2^n-bit truth table. When m>2^n the asymptotic construction below instead uses the zero function on that length; the theorem does not claim a missing word at these exceptional lengths.

An explicit deterministic algorithm enumerates all circuits, evaluating each on the m points, and finds the first missing word. Its bit time and memory are at most 2^{O((s+1)log(n+s+2))} poly(n+s+m) (including enumeration and range storage). A missing word can instead be found by testing candidate words one at a time with exhaustive circuits, using polynomial space in n+s+m and still 2^{O(m)} poly(n+s+m) time. Neither enumeration is polynomial in n for growing s=n^k.

An exact alternative is a prefix-completion oracle: given unary n,s, explicit m and a fixed string prefix u (from most significant bit toward least), decide

 EXISTS y in {0,1}^m extending u, FOR ALL valid <=s-gate circuit encodings C, eval_prefix(C)!=y.

Invalid encodings are ignored; pad encodings to a polynomial bound with canonical parsing. This is a Sigma_2^P predicate in the explicit input length (m also unary or bounded by the input length). Circuit evaluation is polynomial in n+s+m. A greedy binary search of m oracle calls chooses zero at the next position if a missing extension exists, otherwise one. Given a guaranteed absent word initially this yields exactly the least missing word, without exhaustive range storage. The universal circuit quantifier is essential to this argument; the finite checker below uses explicit enumeration rather than calling an actual Sigma_2^P oracle.

For every fixed integer k>=1 put s=n^k. Then m=O(n^k log n)<=2^n eventually. The language L_k whose length-n characteristic function is H_{n,s} belongs to P^{Sigma_2^P} (polynomial-time Turing access to a Sigma_2^P predicate), and its circuit complexity is >n^k for all sufficiently large n. This is an explicit fixed-exponent lower bound for a language in a higher complexity class, not a lower bound for SAT. Under P=NP, the polynomial hierarchy collapses to P, so every L_k individually is in P; this does not contradict any theorem, since the polynomial runtime and circuit exponent can depend on k. In particular the assertion FOR EVERY k EXISTS L_k is not EXISTS L in NP FOR EVERY k. Even proving the former with L_k in NP would not by itself prove P!=NP.

## Alternative track: one language, all polynomial exponents, with charged resource growth

Set s(n)=n^{ceil(log2 n)} for n>=2. Then s eventually exceeds every fixed polynomial bound, while m=2^{O(log^2 n)} is eventually smaller than 2^n. Use the same uniform algorithm on each length to define one language L*. This gives an unconditional explicit language outside P/poly, computable in time 2^{2^{O(log^2 n)}} and space 2^{O(log^2 n)} using the candidate-by-candidate algorithm. The bound does not place L* in NP, P, or even EXP; it is an upper bound, not a runtime lower bound for this particular language. Under the hypothesis P=NP, the oracle implementation would yield a quasipolynomial-time L* (polynomial in the quasipolynomial query size and m calls). This is also consistent with P=NP: quasipolynomial time is not polynomial time. No claim of NP membership, even with a compact description of the input length. Charging s or m as if unary quasi-polynomial lengths were polynomial in n is invalid.

For comparison, a uniform bounded diagonal can defeat all polynomial deterministic programs directly. Fix a self-delimiting encoding of deterministic machines, followed by arbitrary padding. On length n input x with decoded M, simulate M(x) for n^{ceil(log2 n)} steps and output the complement of its bounded acceptance bit; invalid codes give zero. Standard universal simulation has polynomial overhead in explicit machine description, input and simulated clock, so this defines a deterministic quasipolynomial-time language D. Every polynomial-time decider M would disagree on sufficiently long padded encodings of itself, since the clock eventually covers its polynomial runtime. Thus D is outside P, without assuming any proof production. This is a standard diagonal/time-hierarchy argument, not a claim D is outside P/poly or in NP. The circuit avoidance language is stronger in its nonuniform lower bound but has a more expensive known unconditional construction. Neither language is known here to be in NP; the theorem is not an assertion that either is outside NP.

### Quantitative transfer audit

If some L_k has a polynomial-time reduction to a padded SAT encoding of a fixed output length N(n)<=O(n^d), with Boolean reduction circuits of size O(n^e), and SAT on that encoding has circuits of size O(N^c), then composing the reduction and SAT circuits gives L_k circuits of size O(n^e+n^{dc}). The lower bound >n^k for all large n excludes the simultaneous strict inequalities e<k and dc<k. If the output length is variable one must charge length selection/padding overhead separately; the theorem only uses fixed output length. The reduction and its exponents may depend on k and the language; the hard-prefix construction establishes no reduction from L_k to SAT unless a further membership/collapse theorem is available. Even under P=NP, reducing each L_k to SAT need not yield a fixed d or e independent of k. This is a concrete transfer requirement, not a universal circuit lower bound.

P/poly contains P by standard machine-to-circuit simulation. A single NP language with superpolynomial circuit complexity would therefore imply P!=NP, and if such a language were established, NP-completeness gives the usual polynomial circuit transfer to SAT (with explicit encoding overhead). The reverse implication P!=NP => NP not subset P/poly is not known. Likewise a lower bound for all uniform polynomial programs does not automatically imply one for nonuniform circuits. The missing premise here is a resource theorem placing one hard language in NP or transferring its lower bound to a fixed NP-complete language with adequate quantitative control.
