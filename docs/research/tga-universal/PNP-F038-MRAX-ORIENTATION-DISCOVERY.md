## Constructive track: orientation compatibility is bijunctive with fixed families

Use the prior four ternary operations AND, OR, majority, minority (XOR). Fix a family map F assigning every coordinate either H (AND or OR), M (majority), or A (minority). For an explicit local Boolean relation R, let O_F(R) be the set of semilattice sign vectors for which the coordinatewise typed ternary operation preserves R. On H coordinates sign 0 means AND and sign 1 means OR. M/A coordinates have no orientation choice.

**Theorem.** O_F(R) is majority-closed. For any three compatible sign vectors p,q,r, let f_p,f_q,f_r be their respective typed operations. The ternary term
  t(x,y,z)=f_p(f_q(x,y,z), f_r(x,y,z), f_r(x,y,z))
preserves R by composition. At a semilattice coordinate, if x=y=z, every operation returns that value. Otherwise each inner value equals its own orientation (AND=0, OR=1). If q=r the term returns q; otherwise the outer AND/OR returns p. This is exactly majority(p,q,r). At M/A coordinates all three operations coincide, so their inner results coincide and idempotence yields the same operation. Thus t is exactly the typed operation with coordinatewise majority orientation, proving closure. Empty sets cause no exception.

As proved in the earlier majority-projection argument, a nonempty Boolean majority-closed relation is determined by its unary and binary projections. Hence O_F(R) has an exact 2-CNF representation (empty relation gives contradiction). Use missing unary/binary patterns to compile each local orientation table, sharing orientation variables across scopes. The conjunction is an exact compatibility formula. Solve it with 2SAT, reconstruct the complete four-type tuple, and check closure again. This replaces global exponential orientation enumeration by polynomial work in the local type tables and variable count, with at most O(sum_i |scope_i|^2) clauses. It does not assume each possible family assignment works.

For explicit source blocks of maximum scope h, local type tables can be built in 2^O(h) poly(L) time, including checking every ordered triple of allowed Boolean rows for every local type tuple. This local enumeration is counted: no polynomial bound in arbitrary sparse high-arity table length is asserted. After local enumeration, fixed-family orientation discovery is polynomial in explicit local typing-table size. For h=O(log L) the entire fixed-family pipeline, including the previous typed solver and original witness reconstruction, is polynomial even when there are linearly many unknown orientations.

## Alternative track: componentwise family discovery

Map allowed local type tuples to the three family labels. Perform domain consistency on these projected family tables, deleting a family label without local support, retaining the full original type tables for the final exact orientation check. This propagation is necessary, not sufficient. Build the connected components of the local constraint scope graph, including singleton unused variables. They have disjoint variable sets, hence family choices and orientation CNFs can be solved independently. For component j let b_j be the number of remaining variables with more than one family label. Enumerate at most 3^b_j family assignments and solve the exact orientation CNF for each. Stop on the first verified typing for that component. Combine component witnesses. Optional supplied family-domain restrictions are part of the discovery input and must not be confused with unrestricted recognition. The implementation uses a per-component ambiguity cap, returns UNKNOWN if a component exceeds it, and returns NO_TYPING only after a local domain contradiction or complete failure of a component within the cap. Neither status is source UNSAT.

Total cost is 2^O(h) poly(L)(1+sum_j 3^b_j) for a supplied bounded-block interface, with deterministic replay as certificate verification. If max_j b_j=O(log L) and h=O(log L), this is polynomial even if the global number of ambiguous labels is linear. In a connected chain of equality tables with H families fixed, there are two global orientations and all n individual orientations are ambiguous; one 2SAT call replaces an enumeration upper bound 2^n. On disjoint equality/disequality pairs, all n variables initially have all three families available, yet b_j=2 and each component has a typing on its first family trial. These are demonstrations of parameter separation, not lower bounds on every possible previous search order or runtime.

Topology: the connected-component decomposition is exact because local scopes do not cross components. Within a component the orientation term provides an algebraic local-to-global compatibility criterion via an implication graph. An odd cycle of disequality-type conditions in H can have all unary orientation domains supported locally but no common orientation. The 2SAT compilation detects it globally. This is not a topological invariant for arbitrary SAT.

## TECT-X adversarial analysis and selector relevance

NAE remains a nonempty relation with no compatible typing among these four operations; the prior exhaustive test covers every type. Thus even exact family discovery does not establish universal existence. For a 2-coordinate equality relation the H orientations must coincide; for disequality they must differ, while MAJ and XOR each preserve both relations. Three H variables constrained by equality on two edges and disequality on the third have every local orientation domain nonempty but no global H orientation. Choosing all M instead gives a compatible typing, although that Boolean source is unsatisfiable. This separates algebraic compatibility from satisfiability in both directions. The executable checks the distinction, the cap, and corruption rejection.

For a supplied or efficiently found bounded-block interface and a compatible typing, the earlier polynomial typed decision and witness reconstruction algorithm solves the original CNF exactly. A branch selector on that promised class can take the chosen variable's value from the reconstructed original witness; if no witness exists either branch is allowed. If discovery returns UNKNOWN or NO_TYPING, the selector may abstain; replacing abstention by an arbitrary bit would not prove preservation. Pinning a typed table coordinate preserves closure by idempotence; arbitrary pins on eliminated private variables need not preserve the projected interface's typing, so a self-reduction using new projections must recheck its hypotheses. A verified full witness avoids that issue for the original instance. No claim of total polynomial selector coverage on arbitrary CNF. Neither P=NP nor P!=NP follows.
