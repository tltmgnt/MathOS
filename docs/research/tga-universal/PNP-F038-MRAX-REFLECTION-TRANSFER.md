## Constructive track: conditional lower-bound transfer

Fix any sound, refutation-complete CNF proof system P with a deterministic polynomial-time bit verifier. Use an explicit binary CNF encoding, including bounds on variable names/indices, and a fixed standard deterministic machine model. For a program M and unary bounds N,t, construct a CNF R(M,N,t) expressing: there exist a well-formed CNF F of encoded length <=N, a satisfying assignment for F, and a computation of M on F entering its designated REJECT state within t steps. Encode the input and witness with bounded length, verify satisfaction, and encode the bounded deterministic computation using the classical Cook-Levin circuit/tableau construction with auxiliary variables. The formula is uniformly polynomial in |M|+N+t; the machine encoding and simulation overhead must be included. Reject is distinguished from timeout and unknown. R is unsatisfiable exactly when M has no false rejection in that bounded domain. This does not decide unbounded machine soundness.

Define Q proofs of a CNF F as either an ordinary P proof, or a tuple (M,1^N,1^t,pi) where |F|<=N, pi is a P proof refuting R(M,N,t), and simulation of M on F rejects within t. Q's verifier constructs the same R, checks pi, and runs the bounded simulation. Q is sound by bounded reflection, complete by its ordinary P fallback, and polynomial-time checkable in total encoded input/proof length (N and t are unary; never charge a binary exponential clock as polynomial). The same reflection certificate can justify every rejection of that program within the same bounded domain. This is an abstract proof-system construction, not a deployed universal interpreter or a theorem that reflection proofs are short.

For each fixed, correct polynomial-time SAT decider M, choose its polynomial bound t_M(N). If its bounded reflection formulas have P proofs of size polynomial in N for every sufficiently large N, then every UNSAT formula of length N has a Q proof of polynomial length: reuse M, the bound, and a reflection proof, and simulate rejection. Finitely many small lengths can be absorbed in the polynomial by completeness. If those reflection proofs are also uniformly constructible in polynomial time from unary N, the same construction gives a uniform polynomial-time Q proof producer on UNSAT inputs. These are separate hypotheses.

**Transfer criterion.** If every correct deterministic polynomial-time SAT decider has polynomial-size P reflection certificates as above, and Q is not polynomially bounded, then P!=NP. Proof: a polynomial-time SAT decider would make Q polynomially bounded, contradicting the lower bound. It actually suffices to show Q not polynomially bounded and prove the reflection premise for at least one decider conditional on P=NP. The premise is not supplied here. A lower bound for P alone does not imply one for Q, and a lower bound for Q alone would only imply that any putative polynomial decider cannot have the stipulated short reflection certificates. Polynomial boundedness of Q implies NP=coNP, not by itself P=NP. Neither the transfer premise nor a superpolynomial bound for Q is proved here.

## Alternative track: exact finite guard reflection and proof transfer

For any normalized Boolean CNF G on n variables, define a simple clocked partial rejector M_G. Its carrier F_w is the ordered list of n unit clauses, one for each variable, fixing all bits to w. All carriers are satisfiable. Parse an input; if it is exactly a carrier, evaluate G on the encoded bits and reject iff G(w)=true. Otherwise, or when G(w)=false, return UNKNOWN. The program and runtime bound are polynomial in |G| and the input size; there is no SAT oracle. Take N large enough to include every carrier. Then bounded rejection soundness of this program is equivalent to UNSAT(G): a false rejection occurs exactly at a carrier whose w satisfies G. Thus the general bounded rejection soundness decision problem is coNP-complete, even for this explicit sublanguage of polynomial-time partial rejectors (coNP membership by a satisfiable rejected carrier, or more generally the bounded input/witness/computation). This is a many-one reduction with varying program description, not a claim that any fixed correct SAT decider is hard to certify.

A specialized, direct circuit encoding for this guard sublanguage is R_G on original w and fresh clause-evaluation bits z_i:

    z_i,  (not z_i OR C_i),  (z_i OR not l) for each literal l of C_i.

These enforce z_i iff C_i and require all z_i true. Every model of G has exactly one extension to R_G and conversely. Empty clauses are allowed. Setting all z_i=1 restricts the CNF to G after deleting satisfied clauses. For ordinary resolution, restriction of a refutation yields a refutation of the restricted CNF with no increase in line count or width: track a subclause of each unsatisfied restricted line, ignore satisfied lines; if a pivot is fixed, keep the surviving parent's subclause; if it is unfixed, resolve the tracked parents when both pivots remain, otherwise keep a parent missing its pivot. In each case the tracked clause is a subclause of the restricted resolvent. The final empty clause is retained. Conversely derive each original clause from the unit z_i and (not z_i OR C_i), then replay a G refutation. This adds at most three lines per clause and increases maximal width to at most max(2, original input width+1, original proof width). The executable producer/checker implements these transfers with exact parent indices and checks every result. Thus resolution lower bounds for G survive this explicit specialized reflection encoding, rather than relying on vague proof complexity of a circuit. This is not a claim about every Cook-Levin encoding or all proof systems.

If a fixed polynomial-time-checkable proof system supplies polynomial-size certificates for these specialized reflection statements for every sound M_G, the certificates give NP witnesses for UNSAT(G), so NP=coNP. If a uniform polynomial-time compiler supplies them for every sound M_G (known polynomial cutoff on promised inputs, validate outputs), it decides UNSAT(G) by running the compiler and verifying, hence P=NP. Conversely, under P=NP one can decide soundness in polynomial time and produce proofs in an appropriately chosen computation-trace proof system; this does not assert that arbitrary fixed P automatically admits such proofs. Formula-specific partial rejectors therefore expose a real hidden complexity risk in blanket reflection-compiler assumptions. The narrower premise for true total deciders in the transfer criterion may be much weaker; the guard result does not rule it out.
