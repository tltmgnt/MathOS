## Constructive track: exact obstruction hypergraph

Let G be the primal graph of normalized 3-CNF on n explicitly indexed variables, h>=3. For interface I, each component C of G-I has complete scope N[C] (its closed neighborhood in G), including private coordinates and all adjacent interface coordinates. Isolated unused variables are harmless. Interface-only clauses have size <=3<=h. Call I admissible if every such scope has size <=h. This is exactly the previous block_project scope test; all clauses containing a private variable of C have their scopes inside N[C], and every adjacent coordinate is present in such a clause. Supersets of an admissible interface are admissible: every remaining component lies inside a former component and its closed neighborhood is contained in the former closed neighborhood.

Define a forbidden core S to be nonempty, connected in G, |S|<=h+1 and |N[S]|>h. An interface is admissible iff it hits every forbidden core. If it misses S, S lies within a private component and that component's closed neighborhood contains N[S]. Conversely, a violating private component C either has size <=h+1 and is itself a core, or contains a connected h+1 vertex subset (grow along edges), which is a core. These witnesses are global: they must be hit even by interfaces not extending the one used to find them. A core is found in polynomial time from a violating component, and checked by connectivity, cardinality and closed neighborhood. For fixed h the entire hypergraph can be listed in n^O(h) time but is unnecessary.

Given a cardinality budget k, branch on the vertices of a discovered core; every admissible extension must include one. Recurse until the interface is admissible or the budget is exhausted. This is complete in (h+1)^k poly(L) time, including graph construction and checking, with polynomial space in a depth-first implementation (cap k by n). The executable negative result concerns existence of a size-k interface, not satisfiability. Its proof is the exhaustive branching argument; the implementation checks returned positive interfaces and tests all small budget results independently, but does not export a separate negative tree certificate.

A second algorithm repeatedly adds *all* vertices of a found core until admissible. The cores are pairwise disjoint because each is contained in the current private graph. Every admissible interface hits each of them, hence their number p is a lower bound on the optimum k*. The produced interface has size <=(h+1)p<=(h+1)k*. A certificate consists of the disjoint connected cores and their union, with the final scope bound; checking is polynomial. This is a certified (h+1)-approximation, not a claim of a tight approximation ratio or optimal polynomial discovery.

Combining exact discovery with block tables and enumeration of at most 2^k interface assignments gives a deterministic SAT decision and witness algorithm on instances admitting an interface of size <=k, with total cost poly(L)((h+1)^k + 2^h + 2^k); table membership and reconstruction are included. If no interface exists, the structural algorithm cannot decide SAT from that fact. If h is fixed and k=O(log L), or more generally k log(h+1)=O(log L) and h=O(log L), this is polynomial on the promised class. The greedy interface gives poly(L)(2^h+2^((h+1)k*)) without requiring k*. These are conditional structural bounds, not universal guarantees.

## Alternative track: automatically recover the previous large-interface family

The earlier three-copy cyclic gadget has each private variable appearing four times, while every original incidence variable appears more than four times (each incidence variable participates in at least one width>=2 full parity group and each occurrence is replicated three times). Thus selecting all variables with source occurrence count >4 recovers exactly the original incidence interface, without being given its identity. This rule is a sufficient family-specific heuristic; the algorithm checks the full scope bound and refuses invalid interfaces. Its large interface need not satisfy the logarithmic k condition. Instead, construct exact block tables at h=6, convert each missing boundary signature to the clause that forbids it, and recover complete parity groups in the projected CNF. Every projected clause is implied by all clauses of its private block, hence its original indicator support is the block's occurrence list. Union those lists for each recovered XOR row. Check block tables by replay, check extraction and guard supports, and pass the guarded rows to the existing hybrid conflict checker. The wrong root pin gives the incidence dual contradiction M^T y=0, y^T b=1 after fixing that pin. For the correct pin, solve the exact affine projection and restore original witnesses via the independently replayed tables. The full original assignment is checked. No width-three resolution closure is needed on this route. General projected constraints may be nonlinear; the implementation returns no affine-only answer if any projected clause is not in a complete parity group. Only width<=3 projected clauses are passed to the extractor.

The mathematical topology here is exact connected-component separation and gluing of private witnesses over common interface coordinates, plus the incidence cokernel obstruction. It is not a universal homology characterization of SAT.

## TECT-X adversarial barrier: optimal structural discovery is NP-complete at h=4

Even for a satisfiable positive binary CNF, deciding if an admissible interface of size <=k exists is NP-complete. Membership in NP follows from the polynomial scope test. Here is a reduction from vertex cover in subcubic graphs; for completeness its classical source hardness follows directly from 3-SAT: for a variable with t occurrences, use an alternating cycle of length 2t (a single edge for t=1), whose independent sets of size t are exactly the two alternating choices. For each clause use a triangle with one vertex per literal; connect each literal vertex to a distinct occurrence vertex of the variable cycle on the parity chosen when that literal is false. All degrees <=3. An independent set of size sum t + number of clauses exists iff a satisfying assignment exists, since reaching the upper bound forces one alternating assignment per variable and one true literal per clause. Taking complements gives vertex cover hardness.

Given subcubic G0, replace each edge uv by a length-three path u-a-b-v with two fresh vertices. The resulting core graph K is triangle-free and subcubic. Its minimum vertex cover number equals tau(G0)+|E(G0)|: extend a cover of G0 by choosing one internal vertex per path; conversely a cover of K has at least one internal vertex per path and two if neither original endpoint is selected. Add one endpoint for each such uncovered original edge to recover a cover of G0 of size at most the core cover size minus |E(G0)|.

Add private pendant leaves to every core vertex until its degree is exactly three, obtaining G*. Set h=4 and use the monotone 2-CNF AND_{uv in E(G*)}(x_u OR x_v), trivially satisfiable. If two adjacent core vertices are both private, their connected pair has closed neighborhood of size six: the endpoints each have two other distinct neighbors and no common neighbor since G* is triangle-free. Thus any admissible interface restricted to the core is a vertex cover of K. Conversely any vertex cover of K, used as interface with no pendant leaves selected, leaves each private core vertex isolated from other private core vertices, possibly accompanied by its own pendant leaves; the full scope is its closed neighborhood of size four. A pendant leaf attached to an interface core vertex has scope two. Hence the optimum interface size is exactly tau(G0)+|E(G0)|. This establishes the stated NP-completeness and a structural optimization obstruction even on easy SAT instances. It does not show that finding some useful large interface, an approximate interface or a SAT solution is NP-hard on that family. It does not constrain arbitrary alternative decompositions or preprocessing.
