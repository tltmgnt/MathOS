## Explicit CNF preprocessing

Normalize each source clause (distinct variables, no tautologies), with dense variable indices. Group width-one through width-three clauses by their unordered variable scope. A clause on a scope forbids exactly one assignment, namely the assignment that makes its negative literals true as variables and its positive literals false. If all 2^(s-1) forbidden patterns of one parity on a scope of size s are present, their conjunction is exactly the opposite parity equation on that scope. Extract that equation with the indices of its source clauses. If both parity classes are complete, extract both. Duplicate source clauses are harmless. Leave all other clauses, including empty and larger clauses, in a residual CNF B. This is a polynomial-time equivalence-preserving transformation F = A AND B, without new variables. It is deliberately not a general recognizer of all possible hidden affine consequences. The verifier checks the exact forbidden-pattern set for each extracted equation and that the source indices and residual indices partition the original clauses.

## Hybrid propagation with explicit proof provenance

Under a set of decision literals, maintain a partial assignment. Reduce the extracted affine equations after substituting the assigned variables, retaining a binary coefficient vector recording the XOR of original extracted equations for each row. Reduce to echelon and then reduced row echelon form. If a row becomes 0=1, emit its source combination as a conflict. A row with exactly one unassigned variable forces a literal; emit its source combination and that literal. All variables fixed by the current affine system are detectable by this reduced form. Repeat until no algebraic unit is available, then perform an available residual or learned-clause unit/conflict step with its database index, and repeat. Every nonconflict step assigns a new bit, so a propagation pass has at most n such steps plus a possible conflict. If no conflict and all CNF clauses are satisfied by the partial assignment, extend the affine system by setting remaining free variables to zero and back-substituting.

At a conflict, learn the negation of the decision conjunction, using this propagation trace as a certificate. Branch adaptively on an unassigned variable in an unresolved residual or learned clause (maximum occurrences, then lowest index; false first). When both children fail, their learned clauses yield complementary units under the parent decisions; hybrid propagation also detects that contradiction. Learn the parent decision clause with a fresh certificate. The checker need not trust Gaussian elimination or the search heuristic: for an algebraic step it XORs the specified source rows and verifies the claimed residual unit or contradiction under prior assignments; for a CNF step it checks the indexed clause. Each addition is sound, and the final empty learned clause certifies UNSAT. A satisfying output is checked against the original CNF. Completeness follows by exhaustive branching if necessary. This is a stronger certificate language than ordinary RUP; the earlier RUP-only lower bound does not transfer to this verifier.

## Projected affine dimension parameter

Let I be the union of variables occurring in the original residual CNF B, let J be the complement among declared variables, and suppose the affine system A is consistent. Let M be its coefficient matrix and M_J its restriction to columns J. Its model set is affine of dimension n-rank(M). The fiber over any attainable value of I has dimension |J|-rank(M_J), since varying J while I is fixed has exactly that kernel. Therefore the projected affine model space on I has dimension

r = |I| - rank(M) + rank(M_J).

This parameter is computable by two Gaussian eliminations and may be much smaller than |I|. For an inconsistent affine system use immediate algebraic rejection instead. All learned clauses involve only variables from I, by induction on the branch rule. At each branching node, the branch variable is not fixed by the affine equations plus the current partial assignment (the algebraic propagation was saturated). It belongs to I. Both affine children from that partial assignment are nonempty affine slices of projected dimension exactly one less than the current projected dimension; additional CNF propagation can only further restrict them or produce a contradiction. Along the recursive path, all previously derived units remain implied by A, the current learned database and the ancestor decision literals; since no learned clauses are deleted, propagation in a descendant preserves those implied units (monotonicity of complete affine-unit/CNF-unit closure, unless there is conflict). In particular each branching step decreases the available projected dimension by at least one along any nonconflicting descendant. Alternatively, count only affine restrictions from branch decisions: if a variable is not fixed even with all current propagated pins, it cannot be fixed under the weaker decision-only affine system, so adding its decision alone reduces that projected dimension by exactly one. This latter argument does not require a particular propagation order.

The search tree therefore has depth <=r and at most 2^(r+1)-1 nodes. Each node and each learned-clause check costs polynomial time in the explicit input length and accumulated learned database size; each certificate uses at most n+1 unit/conflict steps, with source combination masks or clause indices of polynomial bit length in input size plus log(database size). Hence overall time and certificate size are 2^O(r) poly(L), with L the explicit input size (including dense variable declarations). This gives a uniform polynomial-time solver and certificate producer on the structural domain r=O(log L). No bound on the number of affine variables, primal treewidth or residual-variable count is needed. This parameter is not claimed necessary for tractability; arbitrary 3-SAT may have r linear in n. The algorithm does not assume a polynomial bound on unrestricted r.

For a large residual interface of n variables constrained by a chain of equalities x_i=x_(i+1) and sliding positive triples (x_i OR x_(i+1) OR x_(i+2)), the extracted affine projection has r=1 even though |I|=n. Exactly three nodes and one learned clause suffice for n>=3. For the preceding split-hypercube parity family, all clauses including a branch pin are recognized as affine (r=0 when consistent); the incorrect branch is rejected in one node with one empty-clause certificate, and the correct branch has a witness in one node. This overcomes the earlier RUP proof-size obstruction by explicitly changing the certificate language, not by improving RUP itself.
