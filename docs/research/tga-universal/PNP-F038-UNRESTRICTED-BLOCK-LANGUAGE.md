## 3. Finite block languages, capacity and branching charge

Fix a complete two-state table, direction and one-, two- or three-cell block at the chosen cut. A local configuration consists of the exact block symbols, internal head and running state. To generate the next target-direction departure, start with a set of possible block patterns and entry states. Execute exact transitions within the block, including writes. If a departure is to the opposite exterior, allow any return from that exterior in the corresponding refined incoming alphabet, retaining the new block symbols; if it is in the target direction, emit the entered state and save the resulting block pattern. A halt contributes no running-state departure. Closure is finite (at most 2b*3^b internal configurations for length b<=3). Initially the block is zero and is first entered from the left; after each target departure, if there is another arrival it enters from the target exterior with a state in its allowed alphabet. This nondeterministic construction includes every actual departure word by induction on local visits and emitted symbols.

Determinize: each vertex stores a set of possible saved block patterns after the preceding emitted symbol, with a separate initial vertex. A label 0 or 1 determines the union of saved patterns of the next target departure. All finite prefixes are permitted, including the empty word. If more than 256 vertices would be required, revert to unconstrained binary counting. No missing edge is inferred from such a truncation. Try block lengths 1,2,3 until a finite capacity is certified; otherwise retain the final rate bound.

A branching vertex has two labeled outgoing edges. If no reachable branching vertex lies on a directed cycle, every cycle is unary and has no outgoing alternatives. The maximum number of prefix-incomparable words from a vertex is at most the sum of the capacities of its outgoing labels, with value 1 at a terminal or unary cycle and with the option of stopping at the vertex itself (max with 1). Compute this on the graph after recognizing unary cycles. Parallel edges with different labels count separately. If this test fails or the integer capacity would exceed 100000, no finite capacity is claimed. In particular a finite capacity C bounds every prefix-free set of actual incoming words by C, regardless of which actual input is supplied. This improves on a mere alphabet-cardinality bound.

Even if capacity is not finite, if the subgraph induced by branching vertices is acyclic then there is a longest run of branching vertices of length d-1. Any d consecutive traversed edges have at least one nonbranching source vertex. A word of length j then has at most j-floor(j/d) binary choices. If a branching-only cycle exists or the graph is truncated, use d=0 denoting no improvement. Put probability 1/2 on each edge out of a branching vertex and 1 on a unary edge; dead ends stop the process. The probability of a word's cylinder is 2^(-b(word)), where b counts its branching choices. Any prefix-free set of actual incoming words has summed probability <=1 by disjoint cylinders. Prefix-freeness follows from deterministic replay on the final output side with its initial data fixed, as in the parent theorem. This use of the opposite block is an overapproximation of possible WORDS, not a replacement of the local final-side replay by a nondeterministic program.

For each successful execution choose h retained cuts. Incoming lengths sum to at most K=floor((t+g)/2), where t is the original 2^30 two-state clock. If the final head lies on the left of EVERY retained cut, all those crossing counts are even, so K_left=floor(t/2) suffices. For d>0, sum of branching choices is <=min(K,K-floor(K/d)+h-1) by the floor-sum inequality and monotonicity in the total length. For d=0 the bound is K. Call this integer bound K_d. The discrete convexity argument from the parent gives total cylinder mass across the h cuts at least (2h-r)/2^(k+1), where K_d=kh+r. Therefore weight(K,h,d)=2^(k+1)/(2h-r) converts a per-cut mass bound into a success bound. All quantities are exact. When both directions lack a finite capacity, use the worse of the two spacing bounds (0 is worst, otherwise the larger d).
