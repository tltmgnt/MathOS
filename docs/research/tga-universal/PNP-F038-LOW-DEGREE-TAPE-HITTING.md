## An explicit efficient success predicate without large affine subspaces

Let R=2m, m>=1, and write a tape as (x,y) in GF(2)^m x GF(2)^m. Define q(x,y)=sum_i x_i y_i over GF(2). Its one-set S has cardinality (2^m-1)2^(m-1): for x=0 there are no successful y, and for each nonzero x exactly half the y succeed. Its density is (1-2^(-m))/2 >=1/4.

Suppose an affine subspace a+V is contained in S. Its direction V is totally isotropic for the polar bilinear form
 B((x,y),(u,v))=x dot v + u dot y.
Indeed q(a)+q(a+w)+q(a+z)+q(a+w+z)=B(w,z), which vanishes for all w,z in V. B is nondegenerate, hence dim V <= m. In fact dim V=m is impossible for a constant-one coset: V=V^perp, and q restricted to V is linear. There is a unique coset a+V on which q is constant, because B(a,-)|V ranges bijectively over all linear functionals on V as a ranges over the quotient. Every other coset has equally many zeros and ones. The global character sum sum_{x,y} (-1)^q(x,y)=2^m (sum over y first). Thus the constant coset must have q=0. It follows that the maximum dimension of a constant-one coset is exactly m-1: fix x=e_1 and y_1=1, with the other y bits arbitrary. Its minimum affine codimension is m+1, not O(log R).

This is an explicit polynomial-size Boolean predicate, not a probabilistic existence argument. It can arise as the success set of a genuine randomized witness algorithm even for trivial unit-CNF inputs: compute the pinned assignment, and return it iff q(tape)=1, otherwise report failure. On a valid complete unit template the witness is always correct; on invalid or inconsistent templates reject. This is a polynomial-time one-sided witness algorithm for that restricted domain with constant success probability, and its success sets have no logarithmic-codimension affine subspace for growing tapes. This does NOT refute affine richness for the specific universal witness search U_free: other simulated programs may accept independently of this gate. Nor does it imply hardness of finding unit-CNF witnesses. It shows that an affine-richness theorem cannot follow just from efficient evaluation and high success mass, even for actual witness algorithms.

## An alternative exact hitting criterion: Boolean algebraic degree

Every function f:{0,1}^R -> GF(2) has a unique multilinear algebraic normal form (ANF) f(x)=sum_{A subseteq [R]} c_A product_{i in A} x_i. Here degree means the largest |A| of a nonzero coefficient; the zero function is included in each degree class. Work with integers 0<=d<=R. Define H(R,d)={1_B: |B|<=d}. Its size is D=sum_{i=0}^d binom(R,i).

For any ANF of degree <=d, evaluation at 1_B gives f(1_B)=sum_{A subseteq B} c_A. Over GF(2), Mobius inversion gives c_A=sum_{B subseteq A} f(1_B): in the double sum every strict subset of A has even multiplicity. Hence a polynomial vanishing on H(R,d) has every coefficient zero. Enumerate subsets by size directly, in time polynomial in R and the list size (do not scan the full cube). This produces a uniform input-independent hitting list for every nonzero degree-<=d Boolean success predicate, without access to its coefficients. The list size is O((R+1)^d) for fixed d>=1, and one when d=0. It can be applied to an actual fixed-clock tape evaluator merely by running it on the list and checking returned witnesses. The quadratic gate above is hit by a weight-two tape, despite failing the preceding affine promise.

There is a matching information-theoretic lower bound for common lists on the full degree class. The space of degree-<=d ANFs has dimension D over GF(2). For any list H with fewer than D distinct tapes, evaluation on H is a linear map to a space of dimension <D, so its kernel contains a nonzero polynomial. Thus no such list hits all nonzero degree-<=d functions. This is exact for common input-independent lists; it says nothing about input-dependent algorithms reading a circuit or an adaptive algorithm with extra information. In a deterministic membership-only model even adaptive tests for nonzeroness must query at least D points on the identically-zero transcript by the same kernel argument.

Every nonzero ANF of degree <=d is one on at least 2^(R-d) inputs. Induct by writing f=g+x_R h, where deg h<=d-1. If h is nonzero, at least 2^(R-d) assignments to the first R-1 bits have h=1 by induction, and each gives exactly one accepting value of x_R. If h=0, use induction on g (or the trivial nonzero lower bound if d=R), and double the count. The base of a constant function or R=0 is immediate. The bound is attained by a single degree-d monomial. Thus the whole degree-logarithmic class has inverse-polynomial mass, yet for d=floor(log2 R) its minimum common hitting-list size is superpolynomial in R (binom(R,d)>=(R/d)^d). This does not contradict the preceding nonuniform length-N list existence: that union bound is over at most 2^N actual input predicates, not the full space of all degree-bounded polynomials.

## Consequence for the universal clock

Let R(N) be the polynomial tape length of the previous free-suffix sweep, with fixed a,k. If every sufficiently long satisfiable f has a nonzero sweep success indicator of degree at most a fixed constant d, then the explicit H(R,d) list gives P=NP. Unsatisfiable inputs have the zero indicator by verified acceptance. If R=0, just test the empty tape. A variant suffices if the actual success set contains the one-set of any nonzero degree-<=d polynomial, even if the success indicator itself has larger degree. Neither polynomial nor its coefficients must be supplied. This is a separate sufficient condition from affine richness, not a claim that universal SAT computation satisfies it. The full-class list lower bound is not a lower bound on explicit-input SAT.
