## Forward theorem: guarded affine consequence learning

For each normalized original clause C_i introduce a Boolean indicator e_i iff C_i, using the immutable base of the previous guarded learning session. Detect complete forbidden parity classes using the prior extraction and validate their source provenance. For each extracted equation (a,b,ids), retain the conditional axiom

  (AND_{i in ids} e_i) => (a dot x = b over GF(2)).

It is sound because the complete set of source clauses excludes exactly the opposite parity. No clause is deleted from the indicator base. In a conflict check under literal pins P, activate exactly the rows whose positive indicators occur in P; rows whose guards are only inferred later are deliberately not activated by this prototype. Every active equation is therefore a logical consequence of the immutable base under P. A hybrid propagation trace alternates CNF unit consequences and XOR combinations of active rows. A linear step cites a nonempty source-row XOR mask; after substituting currently known bits it must be a forced unit or the contradiction 0=1. A clause step cites a database occurrence and must be a unit or falsified clause. The existing independently checked hybrid trace verifier checks every step with the derived active-row list. Thus if the trace ends in contradiction, the clause OR_{l in P} not l is globally implied by the immutable base plus the previous globally implied learned clauses. Induction proves global soundness. The proof is guarded by the actual query AND branch decisions, not only by a claimed equation provenance.

The search keeps temporary assumptions and branches separate from the persistent base. At each node try hybrid propagation; if contradiction, add the verified negation of the pins. Otherwise try a particular Gaussian solution (free bits zero) and verify it against the entire current database and pins. If not a witness, branch on an unassigned variable in a currently unresolved clause. When both children fail, their learned clauses yield a contradiction under the parent pins (ordinary unit reasoning suffices, or the hybrid propagator may find it sooner). Learn the parent guard. This terminates on finite inputs; a matching previously learned guard can reject a later query directly. The verifier reconstructs the source indicator database and extraction, replays all added clauses under their own negations, and checks query witnesses or references to falsified learned clauses. It does not accept an XOR explanation under a disabled guard. Proof size and replay are polynomial in the actual learned and trace lengths, with O(n_total) propagation steps per conflict and polynomial Gaussian algebra per step. No polynomial bound on search or total proof length follows. This is a fixed-variable guarded clause/XOR system, not arbitrary extended resolution or unrestricted algebraic proof search.

## Mathematical topology: exact obstruction for parity gluing

For the active binary equation matrix M and charge vector b, inconsistency is equivalent to a dual obstruction y with M^T y=0 and y dot b=1. Necessity follows by pairing with any putative solution; sufficiency follows from row elimination (or orthogonal complement of the image). The certificate is an explicit row-combination mask, not merely a topological analogy. In the graph incidence example of the earlier resolution-certificate research, each edge contributes to two vertex equations, so the sum over all vertices cancels every internal edge. With a prescribed external root bit z, an incompatible total charge yields a nonzero obstruction. This is the degree-zero cohomological obstruction: over GF(2), the incidence boundary image consists of even charges on each connected component. Proof: necessity by cancellation; sufficiency by routing charges along a spanning forest, eliminating leaves. This statement concerns the graph incidence system, not arbitrary nonlinear SAT or a new invariant for all 3-CNF. Under all-positive indicator pins and wrong root bit the guarded hybrid solver needs one learned conflict clause and no search branching; under the right pin a Gaussian particular solution satisfies the source. Changing the pins leaves old guarded conflicts safe.

## Adversarial representation change and surviving lower bound

Take the same ordinary parity CNF source, with each clause of width 2 or 3, and replace each C=(l_1,...,l_k) by (l_1,...,l_(k-1),u) AND (not u,l_k), using a different private u per occurrence. This is existentially equivalent to C: if C holds, choose u equal to the truth of l_k; if both new clauses hold, either a prefix literal holds or u forces l_k. The literal substitution u -> l_k maps the new clauses to C and a tautology. Every resulting scope occurs singly (the private u distinguishes it), so no complete parity pattern is detected by the implemented extraction. All guarded XOR steps are unavailable on this encoding. With all indicators true and wrong root bit, a persistent hybrid refutation is now ordinary RUP. Restrict indicators to true, keep the original root pin as a unit axiom, and translate to resolution with weakening as in the earlier F038 analysis. Then apply the literal substitution to each resolution line. Non-tautological images of resolution steps follow by resolution or weakening: if a parent image is tautological, a non-tautological resolvent image contains the other parent image (the only surviving complementary pair in that parent must involve the substituted pivot); if the resolvent is tautological omit it. Thus the refutation projects to one of the original ordinary parity CNF with polynomial overhead. The previously established bounded-degree Tseitin resolution lower bound transfers to this specific guarded learning architecture on the split encoding, even with arbitrary query scheduling, because cumulative proof prefixes remain globally checked. This is not a lower bound for the full MathOS portfolio, which might undo the splitting or discover implied parity rows by other means. It is not a SAT runtime lower bound. The selected split-cube family has only width-two/three source clauses for d>=2. The new finite tests check the local split truth relation, absence of extracted rows, guard deactivation, wrong XOR provenance, cross-mode reuse, and root parity certificates. No claim that this architecture captures all topological or algebraic obstructions.
