## Result

Let delta(p)=M(p)/2^n, the fraction of all assignments satisfying the original selector p. For every fixed integer k>=3 there is a fixed original general tape program and a threshold n0(k) such that for every n>=n0(k),

    delta(p) >= n^(-(k-2)/10)  ==>  p not in B_k(n),

where B_k is the actual original residual set at stage s=k ceil(log2 L(n)). Thus every residual p in B_k(n) at these sizes satisfies

    log2 M(p) < n - ((k-2)/10) log2 n.

In particular the exact cubic stage eventually succeeds on ALL selectors with assignment density at least n^(-1/10). This is a uniform costed algorithm over arbitrary original selectors, not a promise about formula distribution or syntactic shape. It excludes a density region of the residual set; it does NOT prove B_3 is nonempty at unbounded n, or a uniform cutoff for all SAT. The prior balanced-entropy embedding provides no inverse-polynomial density guarantee, so these results are compatible.

Dense bounded-width CNF search is an established topic; no novelty is claimed for the elementary matching technique or polynomial-time dense-SAT search. See E. A. Hirsch, A Fast Deterministic Algorithm for Formulas That Have Many Satisfying Assignments (1998), https://academic.oup.com/jigpal/article-abstract/6/1/59/732679 . The objective here is the explicit clock charge for the unchanged F038 tape syntax, not a claim of improvement over the general SAT algorithms literature.

## 1. A density certificate from actual clause order

Scan the actual normalized selector in its fixed width/support/sign order. Greedily choose each selected ternary clause whose three distinct variables are disjoint from all variables of previously chosen clauses. Call this matching H, m=|H|, with A the union of its supports. It is maximal: every other selected ternary clause meets A, because any skipped clause met a previously chosen support. Each selected matching clause forbids exactly one of the eight assignments on its three variables. Disjointness makes the fraction satisfying all matching clauses exactly (7/8)^m, irrespective of signs. Therefore

    delta(p) <= (7/8)^m.

For fixed k define b=b_k(n) as the largest nonnegative integer with 8^(10b) <= n^(k-2) 7^(10b). If delta>=n^(-(k-2)/10) then m<=b. Compute b by repeated integer multiplication, using O_k(log(n+2)) bits. In the fixed tape algorithm stop with FAIL on attempting to add the (b+1)-st matching clause. This is not an UNSAT inference. If it completes the scan with m<=b, every selected triple is hit by A and |A|=3m=O_k(log(n+2)).

## 2. Deterministic witness algorithm

Enumerate exactly the 7^m assignments of the matched variables that satisfy their matching clauses, as a mixed list of seven local choices in increasing assignment order on each support. Each original satisfying assignment restricts to one such branch. For each branch scan the original selector anew. Drop clauses made true by assigned variables and delete false assigned literals from other clauses. If an empty clause results, reject that branch. All remaining clauses have at most two variables: every original ternary met A. Add the unit clauses fixing A to this branch's chosen values. Solve the residual 2-CNF on the original n bits, including these units. If a solution exists, it is an original satisfying assignment because every dropped clause was satisfied by the chosen bits and every remaining clause is its exact simplification. Emit that assignment and halt. If no branch succeeds, return FAIL. On a completed matching scan this is a complete SAT-search algorithm; on a cap miss it is only a partial search algorithm. The actual U verifies all output proposals as usual.

The implication matrix implementation reuses the earlier bijunctive-core method: for (a OR b) include edges not a -> b and not b -> a, with b=a for a unit. Add reflexive edges. Compute reflexive transitive closure by Warshall. Let R(l) be the row bitvector for literal l, interpreted as an integer in a fixed common column order. A contradiction exists iff R(l)=R(not l) for some variable: equality is equivalent to mutual reachability because the closure is reflexive. If no contradiction, set l true iff R(l)<R(not l). This gives complementary truth values. An edge a->b implies R(b) is a subset of R(a), and its contrapositive gives R(not a) subset R(not b); hence a true and b false would imply R(b)<=R(a)<R(not a)<=R(not b), contradiction. Thus all implications and clauses hold. This proof does not depend on arbitrary-access graph algorithms.

## 3. Charge the original tape clock

Fix k. A fixed multitape bit algorithm scans the unary header and pool by binary width/support/sign counters. Its matching list has at most b records of three O(log L)-bit indices plus signs (or at most b+1 on the aborting scan). Membership of an index in this list costs polylog L bit steps by sequential scan/rewind, since b=O_k(log L). There are O(L) selector positions. Matching, cap arithmetic and branch enumeration are O_k(L polylog L) initialization plus polylog L per branch. The branch assignment list is of length O(log^2 L) bits, so simplifying a selected clause takes polylog L bit steps without random access. The branch produces O(L) implication edge records of O(log L) bits each. Sort by endpoint pair using sequential fixed-tape merge passes (O(L polylog L)); merge into a 2n by 2n matrix in row-major order including reflexive edges, in O(L polylog L). For each Warshall round scan the matrix to extract the pivot row and column onto separate tapes, then update each row sequentially while rewinding the pivot row and reading the corresponding column bit. The total O(n^3 polylog L) bit cost fits O(L polylog L), since L=Theta(n^3). Using the ordering of paired literal vertices, compare paired closure rows sequentially with a row buffer and generate the n assignment bits; this costs O(n^2 polylog L). For an optional original-formula check, sort O(L) signed occurrence records by variable index, join with the generated assignment, then sort by clause and OR each clause's truth bits; this is another O(L polylog L), not a hidden O(nL) random access charge. No separate program-internal verifier is necessary for the mathematical algorithm, but this cost also fits. The complete multitape runtime on all valid inputs is bounded by O_k(L polylog L 7^b), including the abort and successful output.

Use the fixed polynomial-overhead simulation with quadratic time bound from the previous tape proofs: a constant number of tracks and marked heads are binary coded in constant-width blocks with blank delimiters; scans of the used interval implement each simulated step. Initialization, T steps, and conversion to the n raw output bits with final head positioned at the first bit take O((L+T)^2) transitions on the original three-symbol single-tape machine. This is an existence argument for a fixed original table of some description length ell_k, not a compiled or measured table. Consequently the one-tape bound is O_k(L^2 polylog L 49^b). The exact integer inequality 7^63 < 8^59 gives 49^2 < (8/7)^59. Using the cap definition,

    49^b <= (8/7)^(59b/2) <= n^(59(k-2)/20).

Since L=Theta(n^3), the one-tape time is O_k(L^(2+59(k-2)/60) polylog L). The exponent equals k-(k-2)/60, strictly less than k for every fixed k>=3. This slack eventually absorbs all fixed constants, polylog factors and the fixed code length ell_k. Hence for some n0(k), each successful execution fits within 2^(k ceil(log2 L)-ell_k), the actual original weighted allocation. This proves the announced implication for every such n, not just a subsequence. The machine is chosen once per k, not once per input. No numerical ell_k or n0(k) is provided.

This proof uses the complete selector length; it does not claim that the same exponent in a succinct sparse clause-list encoding follows. Nor does it replace the general U with a two-tape or random-access machine. The Python regression uses bitsets and ordinary data structures only to check semantics, not to establish the time bound.

## 4. Unrestricted implication and boundary

For fixed k>=3, eventual membership in B_k requires a greedy disjoint ternary matching of size >b_k(n), in addition to the displayed density bound. Equivalently any inverse-polynomial assignment-density promise delta>=n^(-d), d fixed, is handled eventually by every fixed k>=max(3,10d+2) (integer k with k-2>=10d); finite exceptions can be hardcoded for a polynomial-time promise solver. No promise density test is performed: the matching scan itself is the runtime guard. The ordinary polynomial-time dense-width search consequence is known in the literature; the finite-clock calibration is the project-specific result.

Under P!=NP, for each fixed k>=3 arbitrarily large residuals still exist by the earlier exact U equivalence, and necessarily have the indicated small density. By a non-effective diagonal choice of k increasing, their density can be made smaller than every fixed inverse polynomial along the resulting sequence. This is conditional and supplies no new proof of existence. The high-entropy normal form from the parent can have density as small as 2^(-h^epsilon); its guaranteed entropy deficit is much larger than O(log h). High entropy rate and polynomial assignment density are different. Combining the present upper bound with deterministic few-model isolation does not eliminate intermediate multiplicities or establish a universal algorithm. The finite cubic interval remains 52..233. Next seek unconditional unbounded B_3 or a general polynomial cutoff, not simply another equivalent hardness class. No universal obligation closes.
