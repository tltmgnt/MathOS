## 1. Result

Use the full nine-group normalized family from PNP-F038-UNRESTRICTED-DISTRIBUTED-HYPERCLIQUE.md: m digits per group, all negative cross-group clauses of widths 1..3 independently selectable, fixed one-hot/OR/pin/guard clauses, n=19m-7 and L=Theta(m^3). No equality reductions. Define a forbidden-context signature for each digit in each group as below. Let c be the minimum over the nine groups of the number of distinct inclusion-minimal signatures of live digits, and let u be the minimum number of live digits whose signature is not weakly dominated by ANY other live digit of that group (including ties).

For every fixed rational 0<delta<1, there exist two fixed original three-symbol single-tape programs with bounds

    T_general = O((m^7 + c*m^(8+delta)) polylog(m+2)),
    T_unique  = O((m^7 + u*m^(8+delta)) polylog(m+2)).

The first finds a witness for every satisfiable member of the full family, the second finds a witness on every uniquely satisfiable member and is not guaranteed on multi-model inputs. Both halt on blank if the respective branch search is exhausted; external verification is unchanged. Constants and descriptions can depend on delta, not on m, masks, pins or the chosen pivot group.

For every fixed 0<epsilon<=1, choose rational delta<epsilon/2. All satisfiable selectors with c<=m^(1-epsilon), and all uniquely satisfiable selectors with u<=m^(1-epsilon), are eventually accepted at the actual exact cubic stage, uniformly over those promised selectors. This is a conditional structural cutoff, not a general nine-group cutoff. In particular any unbounded exact-cubic unique failure sequence must have, for every fixed epsilon>0, u>m^(1-epsilon) at all sufficiently large failed sizes. The necessary condition also excludes unary-dead digits and tied minimal signatures. It does NOT establish that instances meeting that necessary condition actually fail.

## 2. Exact signature relation

For group g and digit a let F_g(a) be the Boolean vector indexed by every context H of zero, one or two distinct groups other than g and every digit selection on H. The bit is the actual selector bit of the negative clause selecting digit a in g and the given context. Use a common order (context width, remaining variable indices in ascending lex order). There are

    h(m)=1+8m+28m^2

bits per digit. The empty context is the negative unit selector. A digit is live iff that bit is zero; no satisfying tuple uses a dead digit. All signature bits are actual selected-clause bits, not membership queries or inferred model sets.

Write a <=_g b iff F_g(a) is coordinatewise <= F_g(b), i.e. each context forbidden at a is also forbidden at b. If a satisfying tuple has b in group g and a <=_g b, replacing b by a preserves the satisfying-tuple predicate: clauses not involving g are unaffected; any newly violated clause involving g would have a selected context bit for a, hence also for b, contradicting the original solution. This is a statement about tuple feasibility. The OR and fixed auxiliary assignment is reconstructed for the new tuple rather than assumed unchanged. It applies with arbitrary overlapping ternary constraints.

Among live digits define
* R_g: one representative (least digit) of each distinct inclusion-minimal signature;
* U_g: all live digits b for which there is no different live digit a with a <=_g b.

Then U_g is a subset of R_g: it consists exactly of singleton inclusion-minimal classes. Dead digits can never dominate live digits because of the empty context bit. For every live b a representative in R_g weakly dominates b by finiteness of the inclusion order. Consequently any solution can be converted coordinate by coordinate into a solution in product R_g. Dominance is defined on ALL other contexts, so substitution stays sound after previous coordinates are changed. This is a deterministic input-aware restriction preserving SAT, implemented if desired by setting negative unary selector bits for excluded digits, without changing the outer layout. It need not produce a unique solution. If every R_g is a singleton and the input is SAT, the reduced selector has exactly one full model.

If the original formula is uniquely satisfiable, every digit of its unique tuple lies in U_g: otherwise a different weak dominator would yield a second distinct satisfying tuple, hence a different full witness. Thus restricting to product U_g preserves the unique witness exactly, but can discard all witnesses on a multi-model input (e.g. two tied live digits). We never use that restriction as a general SAT equivalence.

## 3. Charged signature extraction and comparison

A fixed multitape bit algorithm reads the actual raw unary header, derives m=(n+7)/19 and enumerates the canonical clause pool width/support/sign order with binary counters. For each negative cross clause on a group subset of size 1..3, whether selected or not, emit one record for EACH of its participating digits. The record contains group g, digit a, ordered remaining context (width and up to two variable indices), and the selector bit. All fields use O(log(m+2)) bits and there are 9m*h(m)=O(m^3) records. Other clause positions are skipped. Extract the actual pin bits during this parse using the inherited positive-pin/negative-guards rule.

Use sequential external merge sorting (as in the earlier projection construction) by group, digit, context width and remaining indices. Bottom-up two-stream merge with fixed tapes, O(log L)-bit counters and comparisons, and O(log L) passes gives O(m^3 polylog L) time and space. This orders each signature and makes all contexts align, including zero bits and the empty context. There is one record for each possible context at each digit; no sorting by hash or probabilistic equality is used. Compact the records into fixed-length signature streams with group/digit delimiters.

For each group, for each digit a, copy its signature to a reusable scratch tape, then scan all m signatures b of that group sequentially, comparing against the scratch signature and rewinding scratch between b's. The comparison reads both aligned vectors and accumulates two flags for F(a)<=F(b) and F(b)<=F(a); each comparison costs O(h(m) polylog L) bit steps, including rewind. The signature stream can be rewound from its marked origin to locate a and then scan its group; even rewinding the entire O(m^3 polylog L) stream per a costs O(m^4 polylog L). Maintain two ordered arrays of flags for every digit on scratch tapes: mark b excluded from R if a is live, distinct, weakly dominates b and either strictly dominates b or ties with smaller a; mark b excluded from U if a is live, distinct and weakly dominates b. Skip dead b. Update flags in digit order during the scan; no random indexed flag access is required. Count the remaining flags per group and choose a minimum-count pivot, with a deterministic least-group tie break. Empty lists are allowed. Time O(m^4 polylog L), total visited interval O(m^3 polylog L) on each of a fixed number of tapes.

The inherited fixed-track one-tape simulation (constant-width binary blocks with all-2 blank blocks, raw input expansion, simulated head markers and a fixed number of sweeps of the used interval per simulated step) charges O(L^2) for expansion and O(m^3 polylog L) per multitape step, hence O(m^7 polylog L) original transitions for all preprocessing, including preservation of the original raw selector on a stationary track and leaving the small ordered list of candidate pivot digits. This is a finite-control existence argument in the original three-symbol alphabet, not a compiled table. No external solver, random access, semantic equivalence oracle or random bits are used.

## 4. Reduction to eight-group branches

For general SAT use the pivot group attaining c=min |R_g| and enumerate only its R_g digits. For unique SAT use the pivot attaining u=min |U_g| and enumerate only its U_g digits. If the respective list is empty, halt on a blank; no original unique instance has an empty U_g. For each listed live digit a of the pivot g build an eight-group instance of the SAME distributed family with domain size m, n8=17m-6, zero local pins and its inherited fixed clauses.

Scan the actual outer selector. For each selected negative cross clause not containing g, keep the clause; for one containing g discard it if its pivot digit differs from a, otherwise delete its pivot literal. The latter is satisfied if discarded, and after deletion the remaining context is exactly its forbidden condition for this pivot. A matching selected unit would give an empty forbidden clause, but a is live, so none occurs. Renumber the remaining groups in original order and deduplicate translated clauses. Projected clauses are still negative cross clauses of widths 1..3 and disjoint from the local fixed clauses. The local tuple solutions biject exactly with the original solutions having that pivot digit. Local pins and OR auxiliaries are not copied from the outer formula. On success reinsert the pivot digit and reconstruct the actual full outer witness, using actual pins.

The local selector can be built by a fixed multitape bit algorithm emitting O(m^3) projected records, externally sorting/deduplicating by the actual canonical width/support/sign key, and merging with the generated local pool and its fixed clause records. The latter have O(m^2) fixed clauses and can also be sorted before merging. Emit the unary local header and every bit of the local pool, zero for all omitted positions. This costs O(m^3 polylog L) multitape steps and visited span O(m^3 polylog L). The same charged sweep simulation costs O(m^6 polylog L) original steps per branch, including cleanup and arranging a contiguous raw local input on a local-machine track. The outer input and pivot list remain on separate stationary components of the same encoded physical tape. This method is charged even if all variable mask positions are selected.

The earlier recursive-tiling theorem for eight groups (PNP-F038-UNRESTRICTED-RECURSIVE-TILING.md, Section 4) supplies a fixed local original-tape solver with time O(m^(8+delta) polylog L), visited span O(m^3 polylog L), for each fixed delta>0, by taking sufficiently many FIXED tiling levels. Incorporate that finite control in the outer program. Simulate each of its original physical transitions on the local-machine product component by a constant number of physical moves per transition, as in that note: preserve outer components, follow the local head without shuttling to an outer header on every step, and mark the local visited extent for subsequent cleanup. A bounded number of fixed tracks has constant-width block encoding in 0,1,2. Initial conversion of outer input is already charged; local raw conversion is included in the local solver bound. Clear/reuse the local track after failure, return to the saved outer list marker, and advance its counter; O(m^3 polylog L) cleanup is dominated. On success read the local witness at the local halt head, recover its one-hot choices, reinsert the pivot and emit the outer raw n-bit witness in a fresh contiguous region. Position the original head at its first bit. A simple shuttle per bit costs O(m^4 polylog L), dominated by preprocessing. Local failure halts on blank, as required by the inherited subroutine. On promised inputs the subroutine is exact; no claim of accepting arbitrary nonfamily inputs without the original verifier.

Total time for k candidate digits is O((m^7+k*m^(8+delta)) polylog L), as stated. The preprocessing and local simulation use only fixed finite control depending on delta and fixed group counts, hence constant description length ell in the actual U syntax. The general solver covers the full family, though the displayed bound is not uniformly strictly subcubic. The unique-specialized solver may halt with malformed output on some SAT multi-model instances; it is used only for the unique promise.

## 5. Cubic consequence

For fixed epsilon in (0,1], choose 0<delta<epsilon/2. If the relevant k is <=m^(1-epsilon), time is O(m^(9-epsilon/2) polylog L) (since m^7 is dominated), i.e. O(L^(3-epsilon/6) polylog L). With j=ceil(log2 L), the original allocation for the fixed description is 2^(3j-ell)>=L^3/2^ell once 3j>=ell. A strictly smaller polynomial exponent dominates the description penalty and logarithmic factors eventually, uniformly on the indicated promise. This proves the two family-specific cutoff statements and the necessary condition on eventual unique misses by contraposition. The same argument gives c>m^(1-epsilon) on all sufficiently large general SAT misses. No threshold is computed and no inference is made that near-full antichains cause failure.

The result is input-sensitive: two instances of the same normalized length can have vastly different signature widths. The unique case is stronger than mere equivalence-class compression because strict subset domination also excludes a digit, and even an inclusion-minimal class with many ties cannot occur in a unique witness. This does not provide uniform deterministic isolation of arbitrary SAT inputs, and avoids the previous oracle lower bound precisely because the algorithm reads the explicit selector.

Next investigate contextual dominance after safe deletion of dead/dominated values and other deterministic pruning, or focus lower-bound research on instances with near-full singleton minimal antichains in every group.
