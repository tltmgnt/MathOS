## Competitive scheduling theorem

Fix k deterministic strategy-and-verifier pairs for the same designated residual-clause semantic translation problem. A strategy may abstain. An accepted positive answer must certify a translation preserving all bad models, and an accepted negative answer must certify absence of a translation in this class. A strategy unable to find its own special repair is NOT entitled to give a negative answer. Treat the entire production and independent verification of an answer as one computation. Let T_i(x) be the time in a fixed step-counted computational model to obtain an accepted result by strategy i on x (infinity if it never produces an accepted result). The model includes input preparation, certificate production, reading and verifying certificates, and output; a bounded run can be stopped without accepting an unfinished answer.

For budgets 1,2,4,..., run each strategy from scratch for at most the current budget, stopping only on a verified result. If T=min_i T_i is finite, the first budget at least T is less than 2T (or equals T at a power of two). The sum of all charged strategy steps through that round is at most k(2B-1)<4kT. The fixed scheduling bookkeeping can be performed with linear overhead in a step-metered RAM model, or with polynomial simulation overhead in a conventional bit-machine model. With a power-of-two cap C, if T>C, report UNKNOWN after at most k(2C-1) charged steps. A rejected certificate, a partial local strategy's failure, and a budget expiration never imply a negative result. No unbounded preprocessing or validation step is outside the per-strategy accounting. Geometric restarts are sufficient; resumable state or predictions are unnecessary for this guarantee.

For a fixed finite portfolio, if every input has at least one verified strategy finishing within a common polynomial bound, then the portfolio is polynomial on the entire domain. More generally it is competitive on the union of the individual guaranteed domains. This is an instance-wise result; the winning strategy need not be efficiently recognizable in advance. It cannot supply the missing uniform polynomial bound itself. A collection of procedures with different easy examples or different worst-case lower bounds need not cover all inputs. If an external discovery algorithm is included, its runtime and verification must count too. For the present implementation the supplied clause tree is part of the instance (or the default balanced tree is computed inside each attempt).

## Executable portfolio

The five strategies are: prior local affine repair (positive-only), explicit separator tables, affine unions, factored affine unions, and affine ROBDDs. Each prepares the original source and checks the extraction/tree inside its budget. The local positive is checked independently with the prior affine-flat preservation criterion; no direction found means abstain. The other four produce exact semantic certificates and invoke the respective source-level verifier. The portfolio accepts only a verified result, preserving positive, negative, and unresolved distinctions. It does not implement cross-representation conversion mid-message, parallel threads, or a general SAT decision portfolio. The source can still be satisfiable when a semantic translation does not exist.

The executable meter counts Python opcode trace events across production and verification and restores the prior tracing setting on exit. It demonstrates deterministic finite restart scheduling and distinguishes timeouts from accepted answers. It is NOT a hard wall-clock, memory, or bit-operation bound: Python native operations, interpreter overhead and certificate object allocation are not fully metered; no untrusted plugin code is executed. A production sandbox with interruptible bit-level or OS resource accounting is still needed before claiming actual resource isolation. The mathematical competitive bound applies to the stated fully metered model, not a wall-clock guarantee for this prototype. Unexpected exceptions propagate rather than being silently mistaken for a proof.

## Simultaneous fixed-message representation barrier

Separate hard examples for each representation do not imply that the portfolio fails on a common input. A useful common obstruction is the prior monotone square-grid CNF F_G = AND_{uv in E(G)} (x_u OR x_v), duplicated in two halves of a supplied tree. The half boundary contains all n=k^2 coordinate directions. Its exact message is F_G. No complete parity group is present in this source representation.

1. Explicit boundary rows: one grid checkerboard color class is independent of size at least n/2. Set the other class to one and independently assign the first. Hence at least 2^floor(n/2) rows.
2. Affine-union lower bound: the whole grid has 2k(k-1) edges and degree at most four. Greedily select an edge, discarding all edges incident to its endpoints or their neighbors. At most 40 edges are discarded per step, so there is an induced matching of q>=|E|/40=Omega(n) edges. Fix all unmatched variables to one. The restricted relation is the product of q three-point OR relations on pairs. Every affine flat contained in it has at most 2^q points, since each local projection is an affine set with at most two points. Intersecting any covering flat with the restriction gives a flat or the empty set, so at least ceil((3/2)^q) flats are required even before restriction.
3. Prior factored-group implementation: within one half every boundary is the full span of its incident coordinates because the duplicate half is outside. Its coordinate-scope factorization has one group per connected component of the processed edges: a leaf has one nonuniversal factor with its two coordinate directions; joining groups merges precisely those with intersecting coordinate scopes, and the combined conjunction remains nonuniversal. Induction gives one factor on all n coordinates at the completed connected grid half. Therefore that factor's union also needs at least ceil((3/2)^q) flats. This is a claim about the implemented grouping rule on this tree, not arbitrary linear factorizations.
4. ROBDDs: the preceding all-orders grid bound gives 2^Omega(sqrt(n)) nodes in the original coordinates for this same message.

Thus all four exact explicit/symbolic message engines can face superpolynomial representation requirements on a single supplied decomposition. This is NOT a lower bound for the five-strategy repair portfolio, since the local positive-only strategy can delete the monotone clauses, or a different tree, order of simplification, encoding, or representation might be effective. It is not a SAT runtime lower bound. It demonstrates why portfolio selection alone does not eliminate the need for logical preprocessing and stronger structural guarantees. The local repair approach is deliberately included to expose this distinction.
