## Encoding and uniform sweep

Choose explicitly a padding-closed CNF encoding for this theorem (the preceding universal-machine theorem allowed a choice of encoding). A raw valid CNF bit string r of length l has representation 1^l 0 r 0^j for arbitrary j>=0. Decoding is polynomial time; validity includes checking the raw syntax and the zero suffix. The raw variable ordering and assignment verifier do not change with j. Every valid encoded input f of length N can be padded to any integer length m>=N simply by appending m-N zeros. The canonical encoding overhead is linear, so SAT in this representation is NP-complete. Fix a universal witness-search machine U for this representation, sound and terminating on satisfiable inputs as in the preceding note. The result does not assume arbitrary preexisting encodings have exact-length padding.

Fix integers a>=1 and k>=1. On valid f of length N, sweep all integer m in [N,N^a]. For each padded formula pad_m(f), run U for at most (m+1)^k actual U steps. Verify and decode any returned assignment against the original f; accept with witness at the first success, reject if the sweep ends. Invalid inputs are rejected immediately. There are at most N^a trials, each with size at most N^a and simulation deadline O(N^(ak)). Padding, simulation, output checks and bookkeeping have a fixed polynomial cost for fixed a,k. For example a fixed polynomial-overhead simulator gives an overall polynomial bound in N+N^a+N^(ak) multiplied by N^a. The algorithm is uniform; it neither knows nor needs to identify which lengths are good. All acceptances are sound.

## Common-witness hard windows

Call a valid satisfiable f of length N jointly missed if for every m in [N,N^a], U fails to accept pad_m(f) within (m+1)^k steps. Then the following equivalences hold:
- P=NP iff some fixed a,k have no jointly missed f at all sufficiently large N.
- Equivalently, P=NP iff for some fixed a,k every sufficiently large window [N,N^a] contains at least one length m at which ALL satisfiable inputs of length m meet the U deadline (m+1)^k.

The first reverse implication is the uniform sweep, with finitely many smaller inputs handled by exhaustive search. The second reverse implication follows because a single globally good length solves every padded input from length N, regardless of where that length occurs in the window. Both forward implications follow from the universal polynomial-clock theorem: P=NP implies a single eventual polynomial deadline at all lengths. The window property is a sufficient condition even if a different padding length works for each input, and does not require a globally good length in that window. The two eventual existential conditions are equivalent through P=NP, not pointwise equivalent for a particular k,N.

Consequently if P!=NP, for EVERY fixed a,k and arbitrarily large N there exists ONE satisfiable formula f at length N whose padded versions miss the clock at EVERY length in [N,N^a]. In particular the set of lengths at which some satisfiable input misses the fixed clock contains arbitrarily large polynomial windows. The stronger conclusion is the shared raw formula throughout each window; taking a separate adversarial formula at each length would not prove this. The proof is by contradiction using the explicit uniform sweep, and does not rely on a computable hard-instance generator. This establishes a conditional density/propagation statement across lengths, not an unconditional lower bound.

A pointwise quantitative transfer also holds: if any padding of a particular f succeeds in the window, the fixed sweep program produces a witness in a polynomial time bound depending only on a,k and the simulation model. By universal search's constant-description overhead, U on the original f then accepts by C(N+1)^c for constants C,c depending on a,k, not on f or the successful padding length. Thus an input exceeding this larger clock propagates its failure to every padding at the smaller specified clock. There is no claim that identical exponents are preserved; the sweep and universal overhead must be paid.

## Exact joint counterexample compiler

Use the preceding bounded counterexample compiler with shared f,w variables. Conjoin validity and satisfying-witness checks on f with NOT AcceptBy(U,pad_m(f),(m+1)^k) for every integer m in the window. Each pad is a deterministic circuit transformation or direct wiring of zeros, and each simulation has independent extension variables. The resulting circuit has polynomial size in N for fixed a,k, since there are polynomially many simulations of polynomially bounded lengths and times. Width-three gate encoding preserves the projected f,w relation exactly. The CNF J_U(N,a,k) is satisfiable iff one jointly missed f exists; a witness gives the raw input and satisfying assignment shared across the whole window. UNSAT certifies that the sweep suffices at length N. For a=1 it reduces to the preceding single-length clock compiler. This is a uniform construction, not an algorithm to decide its UNSAT status efficiently.

The same proof works for any explicitly enumerable polynomial-size list of allowed padding lengths bounded polynomially in N and containing only lengths >=N; a nonempty list is required. No oracle for recognizing good lengths is assumed.
