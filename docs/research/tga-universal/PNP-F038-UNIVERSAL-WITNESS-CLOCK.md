## A single unrestricted witness-search procedure

Fix a binary encoding of deterministic Turing machines and a universal interpreter with polynomial simulation overhead. Invalid descriptions are skipped; machine outputs are untrusted. For a CNF input F of bit length N, accept a proposed complete assignment only after checking its length, format and every clause. This verifier is uniform polynomial time. Empty formulas and empty clauses use their usual semantics.

Define stage s>=0: enumerate every binary description p of length l<=s and simulate p on F from its initial configuration for at most 2^(s-l) simulated steps. If p halts within budget, verify its proposed assignment; return the first accepted witness. After an unsuccessful stage advance to the next. Restarting rather than maintaining all simulations simplifies resource accounting. The number of allotted simulated steps in a complete stage is sum_l 2^l 2^(s-l)=(s+1)2^s. Enumeration, decoding, bounded simulation, output handling and verification cost at most poly(N+s+2^s), with one fixed polynomial independent of the simulated program. The cumulative cost through stage s has the same type of bound. A program of length l producing a valid witness in T>=1 steps is included with sufficient budget by stage s=l+ceil(log2 T). Thus the search cost is at most poly(N+l+2^l T) with a fixed polynomial. A fixed exhaustive assignment-search program ensures termination on every satisfiable input. No candidate can cause a false SAT acceptance, regardless of its correctness on other inputs.

This is an unrestricted explicit-input witness search, not a membership-query procedure or a restricted proof system. The overhead includes verifying every candidate, and the exponential description-length factor is charged. The procedure is partial: it need not halt on unsatisfiable inputs. One may run a complete exhaustive solver alongside it to obtain a total solver, but that does not establish a polynomial UNSAT bound.

## Exact uniform-clock equivalence

Let U be the fixed search procedure above and let t_U(F) be its actual running time on a satisfiable input in a fixed machine model, including simulation and verification. The following are equivalent:
1. P=NP.
2. There are constants C,k such that every satisfiable F is accepted by U within C(N+1)^k steps.
3. There is an integer k such that, for all sufficiently large N, every satisfiable F of length N is accepted within (N+1)^k steps.

If P=NP, SAT self-reduction constructs a witness in polynomial time using a polynomial-time SAT decision procedure on successively pinned formulas. This is one fixed program of constant description length, so the universal-search overhead is polynomial. Conversely a known fixed clock can be built into a decision algorithm: simulate U for the clock budget and accept only verified witnesses; reject if time expires. A machine implementing that fixed clock is polynomial time; its simulation overhead is charged. Under (3), finitely many shorter inputs may be decided by exhaustive search (or a finite table). Constants in (2) can be absorbed by increasing k. This is an existential equivalence, not a method for finding the clock.

Consequently, if P!=NP, for every integer k there are satisfiable formulas of arbitrarily large encoded length on which U has not accepted by (N+1)^k steps. Otherwise a finite-exception clock would decide SAT in polynomial time. The conclusion does not exhibit a hard formula family or establish P!=NP. If P=NP, some single fixed clock suffices eventually. A finite successful replay, a short certificate on each input without a common resource bound, or an input-dependent program length without charging it cannot discharge this obligation.

## No uniform automatic polynomial exponent extractor

There is a separate unconditional computability limitation on certifying arbitrary submitted programs. Work even on the simple infinite domain of satisfiable unit-only CNFs with unbounded input lengths. A fixed polynomial-time witness algorithm A exists there (assign the pinned variables; choose arbitrary values for the others). For each machine M form a program P_M which first simulates M on empty input for N steps, where N is its CNF input bit length. If M has not halted, run A. If it halted after t steps, insert a delay of at least (N+1)^t elementary steps and then run A. This is a uniform effective construction. Use an explicit t-digit nested counter in base N+1 to implement the delay, with polynomial overhead per increment for fixed t; handle immediate halting by t=0. If M never halts, the program has polynomial overhead for the bounded simulation. If M halts at fixed t, the program is also polynomial-time, with an exponent depending on t. Every constructed program is a correct polynomial-time witness solver on this domain.

Suppose a computable extractor, promised a correct polynomial-time solver on this domain, always halts and returns an integer k such that its runtime is O((N+1)^k) on the domain (the multiplicative constant may be arbitrary). Apply it to P_M. If M halts after t steps, the delay for all sufficiently large N implies t<=k. Simulating M for k steps therefore decides whether M ever halts (check the initial state as well). Contradiction to undecidability of the halting problem. The result holds even for an extractor partial outside the promised domain. In particular no computable bound in terms of program description length alone can upper-bound a valid polynomial exponent for all such programs. It does not prohibit a proof of a polynomial exponent for one particular fixed program U; that remains precisely the target above.
