## 2. TGA Recovery Engine: ideal order is not discovery cost

Let X=product_(i=1..n) D_i, n>=1, F subset X, and for 1<=k<=n define

    R_k(F)=intersection_(|S|=k) pi_S^(-1)(pi_S(F)),

with inverse images relative to X. The inclusions F subset R_(k+1) subset R_k subset X follow by extending any k-subset to a (k+1)-subset and projecting its witness. R_n=F. These are set identities, not an implementation of the projections. For F empty, every R_k is empty. If F is defined by a conjunction of predicates of scope size at most w<=n, then R_w=F: for any tuple violating a predicate on S, extend S to a w-set T. Its restriction to T cannot occur in pi_T(F), because it already violates that original predicate. Thus k*<=w, including the normalized latent nine-group original relation whose selected cross supports have width at most three. This observation does not necessarily apply to a projected relation after eliminating latent digits or to an arbitrary expanded correction relation. It also does not imply any fast algorithm for computing pi_S(F).

Projection order can increase under elimination. For d>=2 visible bits, introduce one hidden variable whose domain consists of all even-parity d-bit strings (size 2^(d-1)). Impose the d binary predicates that each visible bit equals its corresponding hidden coordinate. The full augmented relation is binary, so its ideal recovery order is <=2. After eliminating the hidden variable, the visible relation is exactly even parity. Every proper coordinate projection is the full Boolean cube, because the missing parity can be chosen freely. Therefore its visible k*=d. The large hidden domain is explicit in this example; no complexity compression is claimed. This gives an exact structural separation, not a distance-to-proof metric.

For any nonempty coordinate subset S, an oracle returning the exact pi_S(F) determines whether F is empty just by checking if its output is empty. Repeated exact unary-projection calls on the original constraints with previously chosen unary restrictions can reconstruct a witness: pick an allowed value for the next coordinate, restrict to it, repeat; nonemptiness persists inductively. Thus ideal exact projections cannot be treated as free preprocessing. This is a circularity warning, not a hardness claim for the fixed nine-group family (which is finite-dimensional and polynomially enumerable). Solving a proper induced subproblem at a fixed key is NOT the same as querying a projection of the global F. The first discards constraints involving omitted coordinates; the second demands a completion satisfying all of them. Sections 5-6 separate these notions even for small scopes.

## 3. Audit of the supplied feasible-source multiplicity formula

Let A(c) now denote a set of feasible source digits for fixed context c (not the coordinate set A below). Suppose all nonself directed rows Z(a,b) have the same cardinality D, self rows zero, as in the finite-field construction. For any actual map p_c, the source-filtered RAW correction count is exactly

    R_feas = D * sum_c ( |A(c)| - #{a in A(c): p_c(a)=a} ).

In the special singleton-map case p_c(a)=f(c), the subtraction is the indicator of f(c) in A(c), not always 1. Hence the supplied formula D*sum_c(|A(c)|-1) requires f(c) in A(c) for every counted context (or sum only over nonempty contexts with this property). If a context has no feasible source, it contributes zero, not -D. If the target is infeasible, every feasible source is nonself and the subtraction is zero. These are identities for counts of free-coordinate corrections before pointwise original compatibility. They are not equalities for the number of full original satisfying corrections. In particular even exact global source feasibility does not imply that every free pair in its raw directed row can extend to a full original model.

For m sources, exactly two feasible sources, and one feasible singleton target, the raw fraction retained is 1/(m-1); reduction (m-2)/(m-1). This verifies the algebra of the supplied m=4,8,16,32,64 percentages under those assumptions, not their underlying experimental provenance or runtime implications. Discovery of A(c) remains an obligation. We next compute a sound overapproximation using a distinct global consistency mechanism.

## 4. Constructive recovery: conditioned parity graph

Use the inherited normalized nine-group family n=19m-7 Boolean encoding bits as its variable count, L=Theta(m^3) raw input length, real latent digit domain [0,m). To avoid overloading n, the nine latent groups are the coordinates of this section. All selected original negative cross supports have arity <=3; original one-hot, OR, pin and guard extension restored as usual.

Choose four actual key coordinates A (source g and three context groups if desired), leaving five private coordinates V. Fix low-bit coloring chi(a)=a mod 2 on real digits, both colors nonempty for m>=2. For every original binary support S={u,v} with u,v in V, and every ternary support S={h,u,v} with h in A, u,v in V, compute the exact allowed parity mask M_S(d) subset {0,1}; d is the actual h digit for ternary and absent for binary. A parity r is included iff there exists an allowed real pair with chi(u) XOR chi(v)=r for that support and conditioned digit. Multiple original supports on the same private edge may remain separate constraints. Ignore all other supports in this relaxation, not in final original acceptance.

Compute masks by counting forbidden records, not solving a global subproblem. Normalize support order and deduplicate records; use real digits only. Let N_r be the exact size of the full real parity-r pair class (N_0=ceil(m/2)^2+floor(m/2)^2, N_1=2ceil(m/2)floor(m/2)). Count forbidden pairs f_(S,d,r) in each slice. Then r in M iff f_(S,d,r)<N_r. Empty mask is immediate contradiction, mask {0,1} unconstrained, singleton mask enforces the corresponding binary XOR. Counted pairs are distinct because of deduplication. This is safe even if allowed pairs with different supports cannot be combined.

For a key z in A, evaluate the five-vertex parity graph with those actual conditioned masks. Define W(z)=1 iff a Boolean assignment to the five private colors satisfies every edge mask. This can be evaluated by 32 assignments (fixed family), or parity propagation on singleton edges. If an original model extends z, its own private low bits witness W(z). Thus pi_A(F) subset W. The converse is not claimed in general.

This is not a global projection oracle: mask discovery uses only original width<=3 records and condition on ONE actual key digit. Build a type signature for each digit of each A coordinate from all masks whose conditioned coordinate is that coordinate. There are fixed many supports (at most ten private pairs per coordinate), hence a constant number of possible signatures independent of m. For a tuple of four signatures W is fixed, as unconditional pair masks are fixed. Compute exact cardinality R=|W| by summing products of the four actual signature class sizes over allowed signature tuples. No need to store a global width-four table. The number of signature tuples can be large as an absolute constant; this is an asymptotic fixed-family result, not a claim of practical speed.

Define mu=R/m^4, equivalently average allowed-source fraction under this computable overapproximation. Choose the least exact mu among the fixed many four-group choices if desired. No assumed relation to average substitution loss, no need for representative maps in this worker. If mu=0, no original model exists in the normalized family. If mu>0, use W as an auxiliary width-four necessary guard, retaining all original constraints. This is a direct witness search, not an E-only recovery branch. It can return any original model. Unlike pointwise cylinder projection, it recovers joint information from a parity cycle before search.

## 5. Separation: two globally feasible sources, all proper private checks pass

Let m=2^d, m>=8, A={g,c1,c2,c3}, V={v0,...,v4}. Take original binary supports on consecutive path edges (v0,v1),(v1,v2),(v2,v3),(v3,v4), each forbidding equal low bits. Add original ternary support {g,v0,v4} forbidding equal low bits at its private endpoints only for source digits a>=2. For a=0,1 this support is vacuous. No constraints on contexts. For a>=2 the required alternating colors around the five-cycle are inconsistent. For a=0,1 the path admits both alternating patterns, so endpoints have equal colors. Every proper private subset is a subgraph of a cycle with at least one vertex removed, hence has a consistent color assignment for EVERY source a. In particular, at any fixed key, every induced original subproblem retaining A plus at most four private vertices admits a completion. The actual full global source set is {0,1}, independent of context.

Add one genuine wide original support {g,v0,v2}, using F(a,x,y)=1{a*u+v in J} over GF(m), with (u,v)=P(x,y) a common permutation of the m^2 free columns, |J|/m=zeta<1/4. For m power of two each fixed parity rectangle has m^2/4 cells. Each raw row has zeta*m^2 ones, strictly smaller than every rectangle, so each of the four rectangles contains an allowed pair, for every a. Thus the field support is always parity-unconstrained and does not destroy the proper-subproblem completions or the two full feasible sources. For each consistent parity pattern with both field vertices present, choose an allowed pair in their parity rectangle, then arbitrary real digits of required colors for other retained vertices; if either field vertex absent that support is not present. The proof does not require randomness or the previous all-submatrix uniqueness event. All original supports remain width<=3.

For distinct a,b the affine field pair map is bijective, so directed field loss D=|J|(m-|J|) independent of P. The conditioned closing-edge support has zero directed loss into a good target b=0 or 1 from every source (its forbidden row is zero). Into a bad target b>=2 it contributes m^2/2 from each good source and zero from other sources. Thus total wide incoming loss to either good candidate is (m-1)D, strictly less than for any bad candidate. Narrow loss zero (all g-dependent supports here are wide for the designated context). With numeric ascending first-facility tie rule, actual first facility is 0; with another fixed tie between good facilities the same proof and counts apply to its chosen good digit. After that, adding any candidate can improve only its own source by at most D<m^2, because all other nonself field losses stay D and closing-edge loss cannot improve below zero. Subsequent marginal gains nonincreasing, so the best facility-penalized positive round is singleton with self ties. The map p_c(a)=0 is actual under the stated tie rule, beta=1/m, delta_n=0, delta_w=(1-1/m)zeta(1-zeta). Choose zeta=Theta(1/log(d+2)) below 1/4 eventually for slow loss if desired; no need for this rate in the parity theorem.

The exact source-filtered field count is D*m^3 instead of D*(m-1)*m^3, realizing the supplied two-source reduction with actual generated singleton maps. The original pointwise-compatible field corrections additionally require x,y same parity (path length two); their projected count is m^3 times the number of such directed ones from source 1 into 0. This may be strictly smaller than D*m^3; full model occurrences also depend on the three other private digits, each of which has m/2 choices for fixed x,y of compatible colors. The conditioned closing-edge guard contributes no directed corrections into the good target. Both globally feasible sources admit original models, irrespective of whether a particular directed row has compatible corrections.

The parity certificate recovers EXACTLY W={a<2} times all contexts, mu=2/m, while every one of the five maximal proper induced subproblem tests passes at every key. Exact ideal global projections would recover the same set, but this certificate obtains it by counting and a five-bit contradiction. It is an explicit structural recovery mechanism distinct from row deletion or cylinder enlargement. This is an easy family, not hardness or separation from all previous workers: graph parity or other structural propagation can solve it, and previous proper-join or other methods may also exploit other features. The result separates these specific local feasibility tests from the conditioned parity test at the same key.

## 6. TECT-X adversary: even arbitrary binary colorings may be insufficient

Use m divisible by four and four nonempty digit classes (a mod 4). On the five private vertices take every edge of K5 except {v0,v4}, with original binary supports requiring distinct digit classes. Add ternary support {g,v0,v4} requiring distinct classes only for a>=2. Contexts free. Good sources a<2 give K5 minus an edge, 4-colorable by assigning the same class to the two nonadjacent vertices and different classes to the other three; bad sources require 4-coloring K5, impossible by pigeonhole. Every proper private subset is 4-colorable for every source. Again exact feasible source fraction is 2/m.

For low-bit parity, distinct classes permit both parity differences on each active edge, so W is all keys, mu=1. This failure is not repaired merely by choosing a clever binary coloring, even with distinct arbitrary maps chi_u:[0,m)->{0,1} per private vertex and conditioned key. For any active edge its allowed bipartite graph between actual digits on its two sides contains all pairs of different classes. It is connected: two left vertices have a common right neighbor from a class distinct from both, likewise for right vertices, and at least one cross edge connects the sides. If chi_u(x) XOR chi_v(y) is constant on every allowed pair, connectivity forces each coloring constant on its entire side (along each two-edge path the same-side color must agree). If it is not constant, both parities are allowed. For a vacuous edge the full bipartite graph is also connected. Thus every inferred singleton edge joins two constant-colored vertices and has the XOR of their constants. All such equations are simultaneously consistent by assigning those constants; every other edge allows both parities. No empty support mask arises. This proof applies to arbitrary per-vertex binary color choices, not just low bits; repeating independent choices or imposing these per-edge equations on multiple color components cannot reveal a contradiction here. It does not rule out joint multi-color relations, combining constraints before abstraction, or other algebraic inference.

Therefore small true feasible-source multiplicity does NOT imply small conditioned parity envelope even allowing arbitrary binary color selection in this per-edge scheme. The adversary has no added wide field relation; it refutes sufficiency of parity recovery for discovering global feasibility, not a new simultaneous certificate-overflow or low-loss runtime lower bound. The family is deliberately easy. Do not escalate to an unbounded search of colorings on the strength of the positive cycle alone. A distinct invariant (e.g. multi-color consistency, separator tractability) and cost audit would be required to reopen this route.
