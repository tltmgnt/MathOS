## 1. Main result

Use the full nine-group distributed family, n=19m-7, L=n+1+2n^2+8 binom(n,3)=Theta(m^3), arbitrary negative cross-group clauses of widths 1..3, and inherited one-hot/OR/pin/guard clauses. Suppose its primal support graph has a partition into S,A,B, with |S|<=5, A and B nonempty, and no edge from A to B. Thus all selected cross supports lie in G_A=S union A or G_B=S union B. Each bag contains at most eight groups.

There is a fixed deterministic original three-symbol single-tape program that recognizes this promise and finds a valid witness on every SAT selector satisfying it, with charged time

    O(m^(62/7) polylog(m+2)) = O(L^(62/21) polylog(L+2)).

The exponent in L is 62/21 = 2.952380... <3, with slack 1/21. Its visited span is O(m^3 polylog m). The full five-coordinate message can contain m^5 records, but the program NEVER materializes either full separator message at outer scale m. It only keeps a single common block of both messages in memory. This extends the preceding four-coordinate separator cutoff to five-coordinate vertex separators, including the unbalanced split 3+1 after five groups are removed. It is not a theorem for arbitrary five-adhesion multi-bag decompositions or for arbitrary nine-group inputs.

## 2. Exact blockwise separator semantics

Choose a domain block width b, 2<=b<=m. Partition [0,m) into consecutive intervals [jb,min((j+1)b,m)). Process all block-index vectors on the separator S; for the current vector, restrict the separator digits to those intervals. Assign each selected support's forbidden list to exactly one of the bags containing it, e.g. the first. This avoids any unsupported assumption that constraints on S are absent. For each side independently, enumerate all block-index vectors on its private groups. For the resulting bag tile, translate every retained forbidden tuple by its coordinate offsets and add negative unary restrictions on any padded digits outside the original domain. All relations remain width at most three, and there are a fixed number of them. Duplicates may be removed by a sequential sort, or simply kept in separate bounded lists. With local uniform domain [0,b), satisfying tuples correspond exactly to original bag tuples in the tile.

Compute a local existential message: for each extendible key on S in that tile retain one full bag tuple agreeing with it. Translate keys and representatives back to outer digits. Keep a stationary accumulator, unioning the tile messages on keys (any representative suffices). Because S-block indices are held fixed, the accumulator contains at most b^|S|<=b^5 records. It is precisely the side's set of extendible separator keys within that block; every qualifying bag assignment belongs to exactly one private-coordinate tile, and every stored representative is valid. Do this for both sides on the SAME separator block, then intersect their two key sets. A common key gives a valid global tuple by joining the two stored representatives on S. All selected clauses are owned by one side, and the private groups are disjoint. Conversely any global satisfying tuple gives a common key in its block. On success stop; otherwise discard both accumulators and advance to the next common block. No global message list or witness oracle is required. This is exact for arbitrary SAT or UNSAT within the promise, not merely uniquely satisfiable inputs.

For analysis and finite testing one may continue across all blocks to check every intersecting key, but the actual witness algorithm need not retain them or count all models. The number of tiles across both sides is O((m/b)^8): for a side of size a the exact count is ceil(m/b)^a; both a<=8. The number of separator blocks is at most ceil(m/b)^5.

## 3. The local message subroutine: time O(t^10 polylog t)

We require a fixed three-symbol local routine for arbitrary width<=3 forbidden lists on at most eight groups with uniform domain [0,t), returning the COMPLETE message on at most five designated groups, in a contiguous raw self-delimiting stream of key/representative records. This local routine may have a t^5-record output; the outer program will call it only at scale b. Input lists contain O(t^3) records, and output O(t^5); record lengths are O(log(t+2)) bits. The local format is internal and does not modify the original universal interpreter.

Base routine: enumerate all t^a bag tuples (a<=8) on a fixed multitape bit machine in buffers of C=t^5 records. For each forbidden list sort the chunk's projection/ID queries and merge with the sorted forbidden list, flag matching IDs, OR-merge flags and surviving tuples, and accumulate one representative per output key by sorted union. Each chunk costs O(C polylog t), including a short last chunk; input relations are smaller than C. Total bit time O((t^5+t^a) polylog t) and visited span O(t^5 polylog t) on a fixed number of tapes. The inherited fixed-track three-symbol simulation costs O(t^5 polylog t) physical moves per simulated step. Raw conversion and final raw output shuttles cost at most O(t^10 polylog t). Hence the base physical bound is O(t^13 polylog t) time and O(t^5 polylog t) span.

Improve this base by ONE fixed tiling level, with inner block width d=Theta(t^(3/10)), chosen by the least integer d>=2 with d^10>=t^3, capped at t. At this level the message is materialized at scale t, so its O(t^5) records are appended to a stationary output stream. Tile ordering is as in Section 2, fixing all designated output blocks first. The per-block accumulator of at most d^5 records is stationed at a fixed work anchor near the input's first cell, rather than moved with the input scanning head. This is the critical difference from the previous recursive separator note, where the mobile workspace included the accumulator.

For each tile, only the counters and restricted width<=3 input records are mobile; their total size is O(d^3 polylog t). The stationary input has O(t^3 polylog t) bits. In constant-width binary-coded product tracks, use the inherited one-block carry shift of the mobile component aligned with the stationary input head, preserving all other components. A shift costs O(d^3 polylog t), including head return; counters and record insertion can use sequential scans with at most that cost times polylog. Read every input record and retain only translated matching tuples, adding O(d) padding records per group. Scan and return to the fixed work anchor in O(t^3 d^3 polylog t) physical moves. Do not scan the already-produced output or carry the d^5 accumulator along this scan. A fixed marker delimits input and locates the work anchor; separate product components permit overlaps in physical positions without altering stationary data.

Near that work anchor, copy the tile records into the raw local format, and call the base routine at scale d on a separate local-machine track, following its physical head at constant overhead per local transition (mark visited extent for cleanup). Its time O(d^13 polylog t) includes local output conversion. Its span O(d^5 polylog t) is no larger than O(t^3 polylog t) for the chosen d. Merge the returned records into the stationary accumulator, e.g. compare each new key to all existing keys, with counters and temporary record copies charged O(d^10 polylog t). Translate only at the work anchor. No shuttle over the whole stationary outer input is needed for each key comparison. Clear the local-machine component over its marked interval. The base call dominates this merge and cleanup.

After all tiles for one designated-output block, append its accumulator to the stationary output stream at its marked end. There are at most O((t/d)^5) blocks, each with O(d^5 polylog t) bits, and the total span including output is O(t^5 polylog t). Even a separate shuttle from anchor to append marker per output bit costs O(t^5 d^5 polylog t) per block, hence O(t^10 polylog t) total. Then clear the accumulator. The blocks have disjoint keys; no global deduplication is required. Finally copy the encoded output into a fresh contiguous raw self-delimiting stream in O(t^10 polylog t) moves, including the empty-list header and placing the halt head at the first bit. Thus the new subroutine has the same complete-message interface and span O(t^5 polylog t).

Including all tile preparation, base calls, accumulations, appending and raw conversions, its time is

    O((t^10 + (t/d)^8 * (t^3 d^3 + d^13)) polylog t)
      = O((t^10 + t^11/d^5 + t^8 d^5) polylog t).

At d=Theta(t^(3/10)), the last two terms have exponent 19/2=9.5, so the total is O(t^10 polylog t). The constants may be large; no statement of practical speed or O(t^10) without logarithms is made. This uses one fixed inner tiling level, not a recursion depth dependent on t. All three-symbol product-track alphabets have constant block width, with all-2 blank blocks and finite control. The local routine's raw output may be large relative to its own input but never exceeds its stated span.

## 4. Outer physical algorithm and exact clock

Parse the actual normalized unary header and canonical selector positions, derive m, extract selected cross records and actual pins, and accumulate the 9-vertex support graph. Enumerate all partitions of the nine groups into S,A,B, with the cardinality and nonedge conditions of Section 1; this is a fixed finite computation with no advice. Fix a deterministic tie break. If no partition exists, the program may halt on blank. Assign each selected support to one bag, generate sorted width<=3 forbidden lists and retain the original raw input on stationary tracks. Sequential bit preprocessing costs O(m^3 polylog m); the inherited sweep simulation and initial raw block expansion cost O(m^6 polylog m) physical moves. The original selector and extracted lists have total span O(m^3 polylog m).

Set b=Theta(m^(3/7)) by the least integer b>=2 with b^7>=m^3, capped at m. Both stationary accumulators (each O(b^5 polylog m)) and the local message routine's entire visited interval O(b^5 polylog m) fit within O(m^3 polylog m), since b^5=O(m^(15/7)). Keep them at a fixed work anchor on separate product components. For each outer tile, mobilize ONLY the translated width<=3 input lists and counters, O(b^3 polylog m), and scan the original selected records (or owning bag's lists) and return to the anchor in O(m^3 b^3 polylog m) moves, exactly as in the inner routine. In particular the five-coordinate accumulators do not move with the input scan; otherwise the bound would be different. At the anchor call the O(b^10 polylog m) complete-message subroutine from Section 3, simulated with constant overhead per local physical transition on its own component. The accumulator merge, translating records, local input/output copies and cleanup cost O(b^10 polylog m) or less, even using pairwise scans of O(b^5) records. This keeps the original and the other side's accumulator unchanged. On completion of both sides' current block, check matching keys by pairwise comparisons, O(b^10 polylog m), reconstruct the joined tuple if any, or clear both accumulators. Charge this intersection once per separator block, which is no more than the total tile count. All workspace is reused; no m^5 record global message is emitted, and no per-block t^10 raw copy at outer scale m is required.

The original full witness uses the inherited one-hot variables, OR auxiliary bits, actual pins and zero guards. Emit the n-bit witness contiguously in a fresh raw region, ending at its first bit as required by the original tape_run. Shuttling per output bit costs O(n m^3 polylog m), dominated by preprocessing. On exhaustion without a common key halt on blank. Fixed number of tracks and fixed control, including the local subroutine, imply one finite original description of length ell independent of m, masks, separator or pins.

Total physical time is

    O((m^6 + (m/b)^8*(m^3 b^3 + b^10)) polylog m)
       = O((m^6 + m^11/b^5 + m^8 b^2) polylog m).

The two tile terms balance at b=Theta(m^(3/7)), giving exponent 62/7. The total visited span is O(m^3 polylog m), including the stationary input and all inner subroutine tracks. At s=3 ceil(log2 L), the allocated clock for this fixed description is 2^(s-ell)>=L^3/2^ell once eligible. Since 62/21<3, this eventually dominates the time bound uniformly on the promise. No numerical cutoff, explicit compiled transition table, or full original stage run is supplied.

## 5. A strict separation from the four-coordinate cutoff

Use the previous dense unique control, with bags G={0,...,7} and H={3,...,8} instead of the earlier H={4,...,8}. For every pair in either bag select the negative binary clause forbidding (1,1). Within groups 0..3 use all four triples, and within groups 4..8 use the five cyclic consecutive triples. On each such triple allow exactly even parity of nonzero indicator bits, requiring the two nonzero digits to be distinct if present. Implement by selecting the forbidden negative ternaries. No other cross clauses.

For m>=3 the parity equations force every type bit zero: on the first four groups summing the four equations gives total parity zero and each missing bit zero; on the remaining five groups subtracting consecutive equations gives period three, which with period five forces a constant bit and then zero. The unique global tuple is therefore all zero, allowed by the pair clauses. Each constrained triple still permits all zero and any two distinct nonzero digits with the third zero; the binary restrictions are redundant on such triples. Other local tables permit all but the (1,1) restrictions, so each digit has local support by setting other digits zero. On a parity triple containing a given group, distinct nonzero digits a,b are distinguished in both directions by contexts (a,0),(b,0); zero and a nonzero are distinguished by (0,0) and (b,0) for a different nonzero b. Hence raw and contextual signatures are incomparable in every group, and both general and unique pruning modes retain full width m. Every direction's maximum fanout is >=m-2: on a parity triple fix a nonzero and a zero parent; for every other local table use all-zero parents. Thus minimum global fanout W>=(m-2)^9.

The graph is K8 plus a vertex with exactly five neighbors, giving 33 edges and minimum vertex separator size exactly five. Removing fewer than five vertices leaves the clique connected and the extra vertex either deleted or still adjacent to it. Removing all five neighbors disconnects the extra vertex. Any tree decomposition with bag size<=8 has, after contracting contained adjacent bags, at least two bags. Every remaining tree edge separates nonempty groups on both sides after deleting its bag intersection, by running intersection. Thus no such decomposition has adhesion<=4. This control strictly separates the prior graph cutoff and pruning/fanout tests from the new one; it is not a hardness example (its all-zero witness is particularly simple). All pin choices are permitted by the construction.

At m=2,3,4, 18 fixtures were compared against independently enumerated untiled side messages and full nine-group solutions. ## 7. Disposition

Any unbounded sequence of original exact-cubic SAT misses in this nine-group family must now eventually have no vertex separator of size <=5 into two nonempty parts, as well as resisting earlier independent sufficient conditions. The new bound does not cover six- or seven-coordinate separators or complete support graphs. Simply replacing five by six in the displayed implementation gives no strict cubic saving: full local raw message conversion alone was charged O(b^12), which balances with the same eight-group tile scan bound at exponent 28/3 in m, above nine. This is a limitation of that implementation, not a lower bound. Next investigate asymmetric separator processing, alternative compressed local output interfaces and highly connected cases. General nine-group cubic coverage, unbounded B_3 and P versus NP resolution remain OPEN. Promotion NONE.
