## Correctness argument

For any normalized state S and any assignment y on the remaining variables, split factors into untouched U and bucket B containing the eliminated variable a. The original relation at y with an extension a is U(y) AND B(y,a). Enumerating the Cartesian product of the bucket scope including a and attaching factor membership by sorted projected key merges computes B on the same full row identity. Conjunction precedes projection. Thus the outgoing relation equals {q : there exists a in D_a for which every bucket factor accepts (q,a)}. When the bucket is empty, its conjunction is true but the eliminated domain is still enumerated; an empty domain therefore yields false. Nullary true is the one empty row, nullary false is no rows. Deduplicating projections changes no Boolean truth value. Untouched factors are normalized in the next coordinate order, preserving their evaluation. The resulting relation at y is U(y) AND exists a B(y,a), exactly exists a [U(y) AND B(y,a)], also for an empty D_a. If the remaining assignment domain is empty the relation itself has no rows. The proof holds for every finite well-formed normalized state, including an empty variable set. Whole-candidate batching preserves the conjunction, and union of projected positive rows over chunks is exactly the same existential relation. Summed trace counts are exact because each candidate is enumerated once. Induction on the finite elimination sequence proves composition; eliminating all variables produces a true/false nullary relation. Termination follows by one fewer active variable per stage and finite iteration inside each stage. This is a mathematical semantic argument, not an actual U-stage theorem, Lean proof or universal polynomial-time result.
