## Input and output contract
There are n>=1 vertices on a path, with nonempty rank domains {0,...,d_i-1}, independently sized d_i>=1. Unary membership mask U_i and binary edge mask E_i(a,b) for consecutive vertices; both may be all zero. Raw contiguous bit input at head zero, blank elsewhere. Tokens 00/01 represent data bits, 10 ends a column, 11 ends a vertex stage. Initial stage consists of d_0 unary bits then 11. Each following stage consists of d_i columns (one per destination value): unary bit U_i(b), then exactly d_(i-1) edge bits E_i(0,b),...,E_i(d_(i-1)-1,b), then 10; stage ends with 11. No dimensions are supplied separately. Each column must be nonempty and its edge length is checked by pairing with previous message entries. Each stage must contain at least one column. Zero-sized rank domains and arbitrary integer labels are outside this physical grammar. An explicit all-zero unary mask represents infeasibility, not a zero-sized domain.

N=2*(d_0+1+sum_(i=1..n-1)[d_i(d_(i-1)+2)+1]) raw bits. Success output is concatenated one-hot vectors, one per vertex in original order, length H=sum_i d_i. The least feasible final rank is chosen, then least feasible predecessors; this is the reverse-coordinate lexicographic minimum satisfying assignment. Valid infeasible and malformed inputs halt on blank, not distinguished by output alone. Rejection need not clean residual data. Output is not the original normalized F038 witness format; decoding one-hot ranks and original raw selector parsing remain separate.

## Physical mechanism and proof
Use the REX block compiler, 29 logical symbols, five-cell codes over physical alphabet {0,1,blank}. Parser tags data and separators, installs left L and right R, one active boundary A. All other stage separators are S. Initial unary data are T(u,u); later columns initially U(u) and E(e). First token cell Z is retained. Parser rejects incomplete or inappropriate tokens and missing final boundary.

At each stage, A identifies the start of the destination stage (end of source). Source message entries are T(u,m), stored on the tape, not in finite control. For each destination column mark its unary Q(u), first edge cursor K, and first source message cursor C. Find each cursor by a bounded sweep from L. For each aligned pair, compute hit = u AND m AND edge AND NOT already_found. A first hit changes E1 to P (an edge provenance tag); all other edge bits are restored. Advance the edge and source cursors in lockstep. Simultaneous termination at column delimiter D and active boundary A is required; if either ends early reject on blank. Thus every column is checked against exactly the previous domain cardinality, even after an earlier prefix becomes infeasible. Complete column writes T(u,found), preserving original unary bit. Move A to next boundary on stage completion. Only unary and found flags, not rank or dimension, occupy finite control. Empty factor masks handled without early semantic rejection.

Invariant: before processing a column, previous stage entries T record exact prefix feasibility M_(i-1)(a); the marked source and edge cursors denote the same rank a. After the scan, T records M_i(b)=U_i(b) AND OR_a [M_(i-1)(a) AND E_i(a,b)]. P is at the least compatible predecessor rank iff M_i(b)=1. All earlier original data and history remain. This proves by induction exact feasibility for arbitrary finite nonempty ranks and all valid rectangular masks.

At final boundary select first T11 in final group or reject. Mark its unary W (retaining the implied raw unary and message bits 1). Move A to the start of that group and pair source entries with selected column edges until P is found; the corresponding T11 is the selected predecessor. Restore transient cursor tags, move active boundary left, mark predecessor W and repeat. At the initial group select/mark W and remove L. Exactly one W in each group; T for all others. All original edge bits remain recoverable (P means 1) and W retains original unary=1 and message=1. Following stored feasible predecessors proves full assignment validity and reverse-lex minimality. Serializer projects W to 1, all T to 0, all other tags to no output, erases input and scratch, and halts at contiguous witness. No host reset or supplied flags/ranks between these steps. Every sweep on valid input is bounded by the finite marked region, every forward iteration advances edge/column/stage, every backward iteration advances edge or reduces stage; hence termination. Syntax and dimension mismatches reject during finite parsing or bounded pairing. This is path dynamic programming with physically stored variable-domain messages, not a novel unrestricted SAT algorithm.

## Charged resource bound
Forward processing visits each edge entry once in cursor-pair iterations, each with a constant number of O(N)-length scans. Column and boundary overhead is O(N) per column/stage, and there are O(N) of each. Backward visits at most the selected column edge entries, plus O(N) scans per stage; there are at most N edge entries and stages. Parser and final cleanup O(N). Logical work O(N^2), fixed compiler moving/stay transition costs 13/9. Preparation P(N)=6N^2+15N+3 for nonempty input; hence already Theta(N^2) lower bound for this implementation. Serializer on success costs exactly 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, w=5, e_i=1 at unary-data output positions, c_i=sum_(j>i)e_j. O(N^2) since H<=N. Physical total Theta(N^2) on valid nonempty paths, including UNSAT preparation. Logical scans within L/source/R only, no expanding scratch region; compiler preparation/serialization adds linear span, so O(N) visited cells. For fixed path length and common rank size m, N=Theta(m^2) if at least one edge, physical O(m^4). For n>=2 and uniform m, O(n^2 m^4). This is a restricted compact mask bound, not an F038 full normalized input bound, and not a universal lower bound against other implementations. Actual original U stage admission is not established.
