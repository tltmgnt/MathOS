## Constructive tree-interface theorem

Given explicit CNF F(x,y) and a supplied rooted tree decomposition of its variable scopes, let b be the maximum bag size and L the explicit input/decomposition length. Every clause is assigned to a bag containing its scope. Bags containing any given variable form a connected subtree. For a node v write B_v for its bag, V_v for the union of bags in its subtree, and F_v for the conjunction of clauses assigned in that subtree.

For a fixed assignment x to the parameter variables, define T_v(x) to be the set of assignments to B_v extendible to a model of F_v with parameter bits in V_v pinned by x. A leaf table follows by enumerating its bag assignments and testing its clauses and pins. For each child c, project its table onto the separator B_c intersect B_v. Intersect the parent's local table with the inverse images of all such projections. Running intersection ensures that child subtrees have no common variables outside the parent bag, so independently chosen extensions agreeing with the parent can be glued. Induction proves the table invariant. The root table is nonempty iff the pinned formula is satisfiable. To construct a full witness, select any root row, then descend choosing child rows agreeing on separators. This is uniform time and space 2^O(b) poly(L), with no enumeration of global assignments. Supplied decomposition validity is checkable in polynomial time. A family of disjoint NAE triples from the preceding obstruction has bags of size three, so this factored representation is linear in the number of triples despite its exponential explicit common-oriented Horn cover. This does not require Horn orientation at all.

## Exact universal totality via sets of possible messages

For universal certification, keep at each node the set of pairs (a,T), where a is a parameter assignment on B_v and T=T_v(x) is the table induced by some assignment to all parameters in V_v extending a. Keep the tag even for an empty table. For a fixed tag a, initialize the local bag table with clauses and pins; combine children one at a time. For each possible child pair (a_c,T_c) whose tag agrees with a on shared parameter variables, project T_c to the separator, lift to the parent bag, intersect with the current table, and deduplicate identical parent tables for this tag. These combinations are realizable independently since child parameter domains overlap only in the parent bag. Conversely every actual subtree parameter assignment generates one such combination. Induction proves equality with the set of all attainable messages, not merely an overapproximation. The root contains an empty table iff some universal assignment has no witness. Optional predecessor pointers recover such a parameter assignment. A constructive per-input repair is obtained by the preceding fixed-input evaluator; a Boolean witness circuit can be compiled from its bounded uniform execution when b is fixed.

A bag has at most 2^b rows and 2^b parameter tags; thus at most 2^b * 2^(2^b) messages, each of length O(2^b poly(L)). Pairwise combination and projection give time and space bounded by 2^(2^O(b)) poly(L) (time can use dictionary or sorting deduplication; neither is an uncharged oracle). In particular universal totality is polynomial for fixed b. This bound differs from the singly exponential fixed-input solver and does not imply polynomial time for b=O(log L). The exact message construction is self-contained; it is a standard-style tree-decomposition dynamic program, not a claim of novelty in quantified CSP algorithms.

## Double-exponential state diversity is unavoidable for exact context-independent summaries

Let k>=1, with k existential boundary bits p. For each s in {0,1}^k introduce a universal data bit x_s and a private implication (p=s) implies x_s, i.e. the clause consisting of the k address-mismatch literals and x_s. With all x pinned, the feasible boundary table is exactly {s:x_s=1}. Every subset of the 2^k boundary assignments is therefore realizable, including the empty subset. The family has O(k 2^k) literal occurrences and can be converted to width-three CNF by private existential clause-splitting chains, preserving the feasible boundary tables. A decomposition of width at most k+2 has central bag containing p, with one branch per clause consisting of bags containing p, x_s and up to two consecutive chain auxiliaries; the running intersection and clause containment properties are immediate. Here width is maximum bag size minus one.

Any exact deterministic reusable interface summary of this pinned subproblem that must support arbitrary external constraints on p, without rereading the original data, needs at least 2^(2^k) distinct states. Indeed if two different boundary tables share a summary, choose s in their symmetric difference and attach unit constraints p=s. Feasibility of the two completed formulas differs, a contradiction. Thus the summary needs at least 2^k bits in the worst case, counting all retained information. The full set of possible messages in the universal dynamic program for this family contains 2^(2^k) distinct tables for a single (empty) parameter tag at the central bag.

This is a state-cardinality bound for exact reusable summaries, not a double-exponential bit-space or time lower bound. Symbolic sets of tables, special-purpose algorithms, query-dependent representations and access to original data may avoid explicit enumeration. In fact this example has a simple direct pinned solver (look for a one in the data) and its projection is not total because the all-zero data vector has no witness. The family separates explicit message enumeration from per-input feasibility, not P from NP.
