## Low-zero obstruction for a union of meet-closed projections

Let R_1,...,R_k be meet-closed subsets of {0,1}^m, k>=1, possibly empty. Meet means coordinatewise AND, closure under nonempty finite meets. Claim: their union is the entire cube iff it contains every vector with at most k zero coordinates (cap k at m).

Proof: suppose x is outside the union. For each i consider Q_i={r in R_i:r>=x} under coordinatewise order. If Q_i is empty, every vector above x is outside R_i. Otherwise its meet u_i is in R_i, is >=x, and cannot equal x. Choose a coordinate j_i with x_j=0 and (u_i)_j=1. Every vector above x with bit j_i=0 is outside R_i, since every member of Q_i has that bit 1. Let x' have zeros at the selected coordinates j_i only, and ones elsewhere. Then x'>=x, has at most k zeros and is outside every R_i. The other direction is immediate. This proof uses neither model counts nor an explicitly enumerated projection. The k-zero threshold is sharp for m>=k: take R_i={x:x_i=1}, for which the union misses exactly those inputs whose first k bits are all zero.

A common coordinate sign orientation is sufficient: complement the same subset of parameter coordinates for all R_i before applying the lemma. The common orientation matters. With different signs the low-zero test in an arbitrary fixed orientation need not be correct (even R={x:x_1 OR x_2} is join-closed and contains both coatoms and the top while missing 00).

## Algorithm for explicit Horn alternatives

Suppose H_i(x,y_i) are explicit Horn CNFs in a common orientation of x (the private witness variables may be oriented separately). Their projections R_i={x:exists y_i H_i(x,y_i)} are meet-closed: combine satisfying extensions by AND. Test all sum_{j=0}^{min(k,m)} binom(m,j) near-top parameter vectors using at most k pinned Horn satisfiability calls per vector. Horn satisfiability and model construction use forward chaining, starting all variables false and repeatedly enforcing a positive head whenever every body variable is true; a headless clause with true body proves infeasibility. Units implement pins. Return a concrete uncovered vector if any probe fails. If all pass, the lemma proves universal coverage.

For every input x a uniform evaluator finds the first satisfiable H_i(x,.) and constructs its least model, giving both an alternative index and a witness. Common sign flips are undone on output. For fixed k, both global certification and construction are polynomial time; with variable k the evaluator costs polynomial in the explicit list size, but the certification bound is not uniform polynomial in k. A polynomial-size witness circuit follows by compiling the bounded forward-chaining evaluator; one may pad and tag different private witness universes. No assertion that each individual alternative is total is needed.

If k is unrestricted, explicit Horn-cover totality is coNP-complete. Membership: an uncovered x can be checked by running Horn SAT on each listed alternative. Hardness: for a CNF D(x), take one alternative per clause, a conjunction of unit literals forcing that clause false. Such alternatives are Horn and have no witness variables; their union is total iff D is unsatisfiable. Thus the fixed-k result cannot simply be upgraded to a polynomial-time totality algorithm for arbitrary explicit lists unless P=NP.

## Mixed-block structural compatibility via existential backdoor

Let F(x,b,y) be normalized CNF, and B the supplied b existential control variables (no universal variables in B). Suppose one sign orientation of all remaining variables makes each clause after deleting B literals Horn. Every one of the 2^b assignments to B yields a Horn residual in this common orientation, since satisfying clauses disappear and falsified B literals are deleted. Therefore existential projection of F is the union of k=2^b Horn projections. Certification uses at most k*sum_{j=0}^{min(k,m)} binom(m,j) Horn calls, each polynomial in the explicit input length L. For fixed b this is uniform polynomial time in L; the parameter dependence is XP, not a fixed-parameter tractability claim. Per-input witness synthesis tests at most 2^b Horn residuals. With b=O(log L), that per-input cost is polynomial, but the global certification bound need not be.

A supplied B can be tested for a common sign orientation using 2-SAT: for each clause with B literals removed and each pair of remaining literals l,l', forbid both becoming positive. A flip bit t_v is true when variable v is complemented. A positive literal becomes nonpositive iff t_v=true and a negative literal becomes nonpositive iff t_v=false, so the constraint is a binary clause (sign(l)*t_v OR sign(l')*t_v'). Solving these pair clauses yields a common orientation if one exists. This assumes normalized clauses without tautologies or repeated variables; normalize first. If B is not supplied, for any fixed size bound b one can enumerate all subsets of at most b existential variables and run the 2-SAT test, at additional polynomial cost for fixed b. This is a sufficient structural domain, not a promise that all 3-CNF admits such a bounded backdoor. For the earlier guarded-selector construction, a synthesized model of F(x,b,y) yields a zero-branch repair by deterministic guard auxiliaries whenever totality holds.

This result identifies a tractable common-orientation structural compatibility class. It neither proves universal coverage by bounded backdoors nor gives a general polynomial-time selector.
