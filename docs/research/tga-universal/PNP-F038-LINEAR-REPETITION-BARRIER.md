## Shared prefix circuit

Use the pseudoexpander path CNFs of Lachish and Razgon, arXiv:1604.01560v2, Definition 9, Corollary 1 and Theorem 4 (https://arxiv.org/html/1604.01560v2). A binary-tree-based graph H is a union of rooted trees, sharing only leaves, each leaf belonging to exactly two trees, and each pair of trees sharing at most one leaf. A source bit x_v is assigned to every vertex v. The source formula phi_H is the conjunction, over shared leaves, of the OR of x_v along the two root-to-leaf paths meeting at that leaf.

Let n be the vertex count, L the number of shared leaves, and r the number of trees. The sum of tree vertex counts is n+L, so the sum of tree edge counts is E=n+L-r. Assume L>=1. Within each tree T, define p(T,root)=x_root; along each parent-child edge define p(T,v)=p(T,parent) OR x_v. This reuses path prefixes rather than duplicating long clauses. For each shared leaf l use one OR gate joining the two tree prefixes. Conjoin the resulting L bits using L-1 binary AND gates. Induction along tree edges shows each prefix equals the OR of its root path. Hence the final output equals phi_H exactly, even though x_l occurs twice in the two prefixes. Gate count g=E+2L-1=n+3L-r-1<=4n. This is linear even when the source CNF has logarithmic clause widths.

Encode each gate using three width-at-most-three clauses enforcing its equivalence. Pin the n input variables with one signed unit clause each, and equate the final gate output with selector z using two binary clauses. There are n+g+1 variables and n+3g+2 clauses (each at most three literals), hence Theta(n) clauses and variables. Each pinned input has exactly one satisfying extension, with z=phi_H(x); SAT(F_x|z=b) iff phi_H(x)=b. Every instance has exactly one satisfiable branch. A public template has all gate/output clauses fixed and two signed unit slots per source bit, occupied complementarily. The local projection maps each variable slot to one source bit or its complement; other slots are constant. The full presence-vector length M=2n+3g+2 is Theta(n). A serialized DIMACS bit length may add a logarithmic factor.

## Bounded-repetition adaptive nonmonotone lower bound

Theorem 4 of Lachish and Razgon states that for sufficiently large pseudoexpanders and d<=log(n)/10^5, a syntactic nondeterministic read-d branching program computing phi_H has at least alpha^(n^beta) vertices for constants alpha>1 and 0<beta<1. Corollary 1 ensures unbounded such families. The lower bound is stretched exponential, not necessarily 2^Omega(n).

Take an exact deterministic selector program on the public presence vector. It may adaptively choose any coordinate, and may use arbitrary nonmonotone logic in its transitions, but every directed source-to-terminal path must test each coordinate at most k times, including inconsistent paths. Replace tests by their source-bit labels (swap successors for negative pins), contract constant tests, and remove rejecting paths for output 1. This is a syntactic read-2k nondeterministic branching program (a deterministic program is a special case). Its size is at most the selector size up to a constant convention factor. The factor 2 is essential: the two pin coordinates may both be queried. Every source input is promised, so the projected program computes phi_H exactly. Consequently for k<=log(n)/(2*10^5), selector size >= 2^Omega(n^beta)=2^Omega(M^beta) along the family. The argument is for exact deterministic selectors; it also applies to a syntactic nondeterministic recognizer of the branch-one predicate, but not to an arbitrary ambiguous nondeterministic selector. The theorem does not establish a bounded-error randomized bound, or a semantic read bound, or cover unrestricted repetitions. For any fixed k the asymptotic condition eventually holds.
