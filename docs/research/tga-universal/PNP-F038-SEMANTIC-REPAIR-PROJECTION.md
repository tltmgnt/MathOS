## Exact semantic repair compilation

Let A be an explicitly tagged affine system, B a normalized CNF, C a designated clause of B, and H=B-C (remove one occurrence). In original coordinates define the bad-model set M={x:A(x), H(x), not C(x)}. A candidate translation delta must lie in the homogeneous kernel of A. For x satisfying A and H, do nothing if C is true; otherwise replace x by x XOR delta. Call delta valid if the output satisfies A and B for every such x. This is conjunction-aware: unlike the preceding local rule it need only preserve the conjunction on its actual models, not individual clauses at all points falsifying C. If M is empty, zero is a valid repair.

For each clause D of H, let I_D be its variable scope and f_D its unique falsifying assignment on that scope. Compute the exact projected set P_D={x|I_D : x in M}. For every p in P_D, forbid the restriction delta|I_D=p XOR f_D. Also, when M is nonempty, forbid the all-zero restriction of delta to I_C, because all x in M falsify C and flipping at least one of its variables is exactly what is needed to make C true. Empty clauses and empty scopes follow the same rule. Each forbidden pattern is represented by a single clause of the same width as its scope. Include the homogeneous affine equations on delta. The resulting formula Q is satisfiable iff there exists a valid semantic translation; indeed for every D, the translated model falsifies D iff one of exactly these observed projections matches f_D after translation. For C the bad input projection is fixed. Conversely every valid translation avoids every forbidden pattern. Thus the models of Q are exactly the valid kernel translations, with the convention that only homogeneous constraints remain if M is empty.

Each projection membership query is a satisfiability test on A AND H AND not C AND pins(I_D,p). For bounded clause width w, one initial emptiness query and at most sum_D 2^|I_D| further queries suffice. All projection queries can be asked nonadaptively (even if M is empty); the executable omits them when empty. Final decision is one SAT query on Q. If A is given in extracted width-three parity groups, homogeneous equations can be encoded by width-three parity clauses as before; general explicit linear rows can use private XOR gates. All construction costs apart from the oracle are 2^O(w) poly(L). For 3-CNF and polynomial explicit affine input, this gives P^NP decision with two rounds of oracle queries, not an unconditional polynomial algorithm. Witness synthesis by SAT self-reduction takes polynomially many additional queries. The general existential/universal description alone would give a weaker Sigma_2^P upper bound. This compiler reduces the number of distinct universal conditions by exploiting bounded clause scopes; no equality with a smaller complexity class is claimed.

For a supplied direction, validity is in coNP: check the kernel condition and search for an x satisfying A,H,not C but falsifying some translated clause. A positive answer to a projection query has a model certificate. A negative answer needs a checked UNSAT certificate (or a tractable exact decision procedure); simply trusting an unverified list of projections is insufficient. For fixed direction, one can instead verify UNSAT of each violating-pattern query. These checks compose with prior reverse-order witness repairs. They do not guarantee polynomial-size general UNSAT certificates.

## Polynomial 2-CNF specialization

When A is absent and B has width at most two, all projection queries and the final translation formula are 2-CNF, with unit pins allowed. Thus exact semantic repair discovery and direction verification are polynomial-time by 2-SAT. Repeated greedy deletions cost polynomial time, and reverse conditional translations reconstruct source models. The implementation supplies a 2-SAT decision procedure using mutual implication reachability and self-reduction for witnesses. This is also valid if explicit affine equations have width at most two, since each is equivalent to a conjunction of binary or unit clauses; the executable general tagged-affine adapter is not implemented here. The implemented compiler operates on ordinary explicit CNFs (A absent). A clause with rank two in an arbitrary affine parameterization need not have two coordinate variables; general rank-two affine predicates are NOT claimed tractable by this argument.

A strict-existence example is C=(a), H={(not a),(a OR b),(not b)}: M is empty, so semantic deletion is valid, but the clause (not a) prevents every local repair flipping a. This example has UNSAT H. A nonvacuous strict-direction example is C=(a), H={(a OR b),(not a OR b)}: flipping a alone works on M (which forces b=1), but the pairwise test fails at a=b=0. These examples do not claim novelty over semantic clause-elimination literature.

## Hardness of unrestricted semantic translation

Reduce UNSAT of a normalized exact-width-three CNF D(x) to validity of a supplied direction and to existence of any semantic translation, even with H and B both guaranteed satisfiable. Add fresh z,w,r and one u_j per source clause. Take C=(z OR w). Put (not w) in H. For each source clause (l1 OR l2 OR l3), include (z OR l1 OR u_j) AND (not u_j OR l2 OR l3) in H. For every variable q other than z,w (including x,r,all u_j), put (not z OR not q) in H. When z=1, H has exactly one model, all other variables zero. When z=0, H projects onto D(x), with r free and w=0. Hence if D is UNSAT, M is empty and every direction is valid, including the supplied flip of z. If D is SAT, M has at least two distinct models, but B=H AND C has exactly one model. An XOR translation is injective, so no semantic translation can map M into B. This proves coNP-hardness of existence and coNP-completeness of supplied-direction validity; the reduction already has ordinary 3-CNF and no affine equations. It is not vacuous due to an UNSAT source H: both H and B always have a known model. The hardness concerns discovery/verification of this repair class, not SAT on the constructed instances.

Existence is also NP-hard in general: take C=(z OR w), H contains (not w), enforce every other variable zero when z=0 by (z OR not q), and guard D with not z instead of z (split each guarded 4-clause using private u_j; the initial pins u_j=0 satisfy the second clause and the first is guarded true). The unique bad model is all zero, and any satisfying good model is obtainable from it by a translation. Existence iff D is SAT. Here H is always satisfiable, but B need not be. No completeness result for existence beyond these lower bounds and the P^NP upper bound is asserted.
