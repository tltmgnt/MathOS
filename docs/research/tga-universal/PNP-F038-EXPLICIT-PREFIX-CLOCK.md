## Explicit-input complete search, not a toy interpreter

Fix an ordering of n variables, and interpret an n-bit assignment as an integer, most significant bit first. Start at cursor 0. At each event, test each prefix of the cursor, from empty to full, for contradiction by unit propagation (UP) on the original explicit CNF with that prefix pinned. If no prefix contradicts, the full assignment satisfies the CNF; return it after verification. Otherwise let k be the shortest contradictory prefix. Set the last n-k bits of the cursor to one and increment. If this overflows n bits, reject UNSAT; otherwise repeat. Every skipped assignment extends the contradictory prefix. Hence no model is skipped, and the increasing cursor ensures completeness. This is lexicographic prefix pruning, not general DPLL/CDCL; it uses UP as a contradiction test, not as a forced-value shortcut. An event is a full prefix-testing and cursor-update iteration, not a Turing machine step. Each event costs polynomial time in the explicit CNF length and n. The number of events is at most 2^n for n>=0. With dense variable indexing (or prior renaming), polynomial event bounds would imply polynomial running time.

## Real bounded circuit compiler

For an explicit clause template with L literal occurrences and n variables, let presence bits select the clauses, and add n source-witness bits. Build a gate DAG of bounded prefix search for T events. A state consists of n cursor bits, an active bit and an absorbing acceptance bit. For each prefix k and each variable i, initialize two bits P_i,N_i for pinned true and false. Synchronous UP updates for each round OR into the respective sign bit every enabled unit implication. For each literal l of a present clause, if all other literals have their opposite assignment bit set, add l; the empty clause has no updates but immediately conflicts. If any clause has all literals false or any variable has both sign bits set, contradiction holds. The sign bits are monotone. In the absence of a conflict, each nonstationary round assigns at least one new variable; hence after n rounds there is either a contradiction or closure. If all n variables become assigned on the last round, any further inconsistent implication would already have an all-false clause. Once detected, a conflict persists. This is equivalent to standard UP contradiction, regardless of order. Clauses are normalized (no repeated literals, tautological clauses may be dropped); the implementation also handles empty clauses.

Select the shortest contradictory prefix with a priority mask. Compute the cursor successor for each possible prefix by a binary increment of that prefix with zero suffix; detect overflow. Multiplex the successors and update the two state flags. If active and no contradiction exists, latch acceptance. If a contradiction is found and increment overflows, become inactive without acceptance. Inactive states cannot newly accept. Repeat T times, starting from cursor zero, active=true, acceptance=false. The result is exactly whether this complete explicit-input solver accepts within T events.

Conjoin source satisfiability on the witness bits with negated acceptance. Every AND gate gets the three standard Tseitin equivalence clauses; NOT is a signed literal and OR uses De Morgan. A true-constant unit and an asserted output complete the CNF. All gate extensions are uniquely determined by the presence and witness inputs. The resulting width-three CNF is satisfiable on given presence bits iff the selected formula is satisfiable but missed by the deadline. Every satisfying extension carries the source witness. Construction is uniform and polynomial in n+L+T (T in unary); a straightforward implementation uses O(T(n+1)(n+1)(L^2+n+number_of_clauses)+T(n+1)^2) gates before simplification, allowing naive per-literal conjunctions. This is an actual gate-level bounded compiler, rather than the earlier hardcoded candidate-set exclusion formula. It is for this specific complete algorithm, not the universal interpreter U or actual machine-step timing. No claim that deciding the compiler output is efficient.

## Explicit clock obstruction for this algorithm

Let m>=1 and order variables z,a_1,b_1,...,a_m,b_m,u,v. Use independent binary constraints (a_i OR b_i) AND (not a_i OR not b_i), and four guarded clauses (z OR l_u OR l_v), with all four sign combinations of u,v. The formula has 2m+3 variables and 2m+4 clauses of width at most three. It is satisfiable exactly with z=1 and each pair opposite (u,v arbitrary). The initial wrong z=0 branch is unsatisfiable, but its four binary clauses have no unit until u or v is pinned. Every consistent complete assignment to the m pairs defines a disjoint prefix block under z=0, and no prefix up to the end of those pair variables along such a block has a UP contradiction: pair constraints are consistent and the four guarded clauses remain nonunit. Therefore any conflict jump skipping a leaf of such a block must use a strictly longer prefix, and cannot skip a leaf in another pair block. The algorithm visits at least 2^m distinct conflict events before it can return a witness in z=1. This is an unconditional exponential event lower bound on satisfiable explicit inputs for the exact algorithm implemented here (also superpolynomial in ordinary encoded bit length). It is not a general SAT lower bound: e.g. solve the guarded gadget separately or branch on u early. The example needs no proof-complexity theorem.
