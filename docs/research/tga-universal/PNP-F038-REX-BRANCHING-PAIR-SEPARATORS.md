## Bounded mission

Require one fixed three-symbol descriptor, actual physical dimensions, joint tuple conjunction, private factor conjunction before projection, full physical checkpoints, direct predicate and independent-code reference agreement, and a charged resource argument. Stop after the bounded regression. This is a restricted width-two star decomposition, not arbitrary branching with changing overlaps or an unrestricted SAT algorithm. ## Contract
Variables b,c have positive rank cardinalities B,C. There are g>=0 private variables a_j of independent positive rank sizes d_j. Root pair mask Q(b,c); child j unary U_j(a), two ternary masks R_j(a,b,c), S_j(a,b,c). No private variable occurs outside its own child. All tables explicit. Input contiguous raw binary from head zero, blank elsewhere. Three-bit tokens 000/001 are data, 010 group open, 011 pair open, 100 pair end, 101 group end, 110 stage end, 111 private-header end. Root: C groups in c order, each 010 then B bits in b order then 101; 110. Each child: nonempty unary vector, 111; C groups, each 010 then B pairs, each 011 then exactly d_j pairs of data tokens R,S in private rank order then 100; group 101; child 110. No dimensions supplied separately. Root rectangularity, group and pair count, private candidate count and syntax are validated by fixed tape rules. Empty domains, arbitrary integer labels without encoding, changing separator identities, arbitrary additional factor scopes and original F038 raw grammar outside scope.

Successful output is BC joint one-hot bits in c-major b-minor order, then one-hot vectors for every private variable in input order. With dimensions, this uniquely determines an assignment. Root selection prioritizes c then b; each private rank is chosen least feasible. Valid infeasible and malformed input halt on blank, not distinguished by output alone. Rejection need not clean residual scratch.

## Proof and fixed machine
For each child define
 L_j(b,c)=OR_a [U_j(a) AND R_j(a,b,c) AND S_j(a,b,c)].
After k children let Q_k=Q AND AND_(j<k) L_j.
Invariant: Q_k(b,c) exactly represents feasibility of all processed private variables with the SAME fixed pair (b,c). Base k=0 is the root mask. For induction, child k shares no other variable with processed children. Thus a new extension exists iff the previous extension exists AND there is one private rank satisfying all three child factors. Both directions follow by restriction or combining assignments on disjoint private variables. The conjunction is at the full joint key, never independently on its marginals. The local predecessor p_j(b,c) is the least private rank with all three child factors true, or absent if none. At a positive final root tuple every child's predecessor exists; choosing these independently gives a full satisfying assignment. Conversely no positive root tuple implies no satisfying assignment. This proves semantic correctness and the stated deterministic tie-breaking for all finite valid instances of the contract.

Reuse REX-015 six-cell block compiler. The parser installs L,R and stationary root boundary A, tags initial cells T(raw,feasibility), private unary U, factor bits F/E and group/pair boundaries. Initial adjacent root group comparisons use unique cursors and reject unequal lengths; all original bits preserved. Each child header H becomes active B, root group BI and child group U align in c order; root QT and child Q pair align in b order; private CU and candidate K align in a order. A constant number of whole-region sentinel sweeps per candidate read U, R, S and accumulate hit, tagging first compatible E1 as EP. The pair header becomes P0/P1 recording the local message. On completing a pair, root QT becomes T(raw,old AND hit). Root and destination group and pair delimiters must be reached simultaneously; private end B and pair end V must be reached simultaneously. Restore all transient tags. Every child scanned even after Q_k is identically zero. Child boundary D restored before moving to next. The stationary root grid and all child masks remain on tape.

At final root scan choose first T11 as W or reject. In the second pass repeat physical alignment against each child using the selected root W. Only that pair's EP can mark its corresponding private unary entry UW, which preserves the implied original positive unary bit. Other pairs and all feasibility/provenance tags restored unchanged. All selected private ranks remain on tape concurrently; no host handoff or re-encoding. Cleanup removes L and invokes serializer projecting W/UW to 1 and T/U0/U1 to 0, all other symbols skipped. Ready head at first aligned block; original raw and history erased by serializer. Full forward/backward snapshots check these precise contracts. Valid loops progress through bounded token, child, group, pair or private cursors; each sentinel sweep is finite. Dimension corruption rejects at the first unmatched boundary, including a late malformed child after an infeasible earlier prefix.

## Resource ledger
N=3*[C(B+2)+1+sum_j(d_j+2+C(2+B(2+2d_j)))]; output H=BC+sum_j d_j. All input token counts explicit. Initial rectangular check visits O(N) entries, each costing O(N) bounded scans. Each forward candidate, pair, group and child incurs constant-many O(N) sweeps. Second pass repeats these operations at most once per item; extra predecessor selection scans also constant-many per pair. Thus logical work O(N^2); fixed six-cell compilation charges 16 transitions per move, 11 per stay. Preparation P=7N^2+17N+3 for nonempty valid input. Serializer exact clock 2wN+2w+2+sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, w=6, e_i marks each root membership or private unary cell, c_i=sum_(j>i)e_j. O(N^2) as H<=N. Successful final head -6N-H-2. Valid physical time Theta(N^2) including UNSAT (preparation supplies this implementation's lower bound); visited span O(N), no external counters or growing separate scratch. For g>=1 and all domains m, N=Theta((g+1)m^3), time O((g+1)^2 m^6). This is explicit mask input, NOT construction from original normalized SAT input, general width, universal time lower bound or original U-stage admission. For fixed nine-group uniform m and a fixed common pair with distinct private variables, accounted compact-mask machine contribution is O(m^6), but source normalization, factor assignment, encoding and witness translation remain separate obligations.
