## Constructive track: project to fractional coordinates

For source affine rows (a,b) over GF(2), let W be their augmented row span, retaining source combination provenance. At a rational point z with common positive denominator D, let F be coordinates strictly between 0 and 1, P be the mask of integral-one coordinates, and I the complement of F. A forbidden-pattern inequality is violated iff its distance numerator is strictly less than D. Any mismatch to an integral coordinate in its support contributes D by itself. Thus every violated cut matches all integral coordinates in its support. Project W by the linear map

  (a,b) -> (a restricted to F, b XOR parity(a & P)).

Let W_F be its image of rank rho. For any image row (u,c), optimize a forbidden pattern on fractional support u using the nearest-bit plus minimum-cost parity-changing flip from the prior attempt. Extend that pattern by matching the integral bits of a provenance lift (a,b). The result is an original forbidden pattern, with exactly the same distance. Conversely every violated original cut projects to such a candidate. This proves equality of the minimum distances clipped at D, even for inconsistent affine systems. Gaussian elimination on the projected augmented rows yields a basis with original source provenance, so exact violated-cut discovery costs 2^rho poly(L), with rho <= min(rank(W), |F|+1). It need not enumerate the original row span. This is a new parameter relative to the preceding rank bound, not a general polynomial claim.

At half-integral points z_i in {0,1/2,1}, a matching forbidden pattern on u has distance |u|/2. Hence violation is possible only for u=0 or a unit vector. Test membership of (0,1) and (e_j,c) for every j in F and c in {0,1} by Gaussian elimination in the projected span. If the pinned affine system is inconsistent, (0,1) belongs to W_F and gives distance zero. Otherwise an equation with unit support is present iff that fractional variable is forced by all affine extensions of the pins (a linear functional constant on the solution affine space is in the row span). Its forbidden assignment yields distance 1/2. If no forced coordinate exists, there is no violated redundant parity cut at that half-integral point. Thus at most 2|F|+1 membership tests give a polynomial exact oracle for these points, even with unbounded original and projected rank. This is exactly affine contradiction/forced-bit propagation, not complete propagation of the nonlinear constraints.

## Alternative track: a graph-cycle exact separation oracle

Suppose the row space on edge coordinates is the cycle space of an explicit undirected simple graph G, with RHS parity given by a supplied edge label c. A fundamental cycle basis with RHS equal to its edge-label sum gives a consistent affine system; x=c satisfies it. Conversely this input representation makes the RHS well-defined on every cycle combination. Construct the two-sheet graph with vertices (v,p), p in {0,1}. For each original edge e=uv and chosen forbidden bit f in {0,1}, add an undirected edge from (u,p) to (v,p XOR f XOR c_e) of nonnegative weight D*z_e if f=0, D*(1-z_e) if f=1. Keep edge IDs and f. Find shortest paths from (v,0) to (v,1) for each vertex by ordinary nonnegative shortest-path algorithms.

A violated cut corresponds to an Eulerian edge subset with odd total f XOR c, and weight <D. Decompose it into edge-disjoint simple cycles: some cycle has odd label and weight <D, and lifts to a path between the two sheets. Conversely a shortest path of weight <D projects to an odd closed walk. Split at repeated vertices into elementary closed walks. One has odd label and weight <D. A two-edge backtrack using the same original edge has odd label only if it uses both bit choices, in which case its weight is exactly D. Since the graph is simple and there are no loops, the selected odd elementary walk of weight <D must be a simple cycle. Its selected bits give a forbidden pattern with exactly that weight. Convert the cycle to source-basis provenance by Gaussian membership, and replay the ordinary cut checker. This proves exact separation below the threshold D, not necessarily the exact untruncated minimum if no violation exists. Time polynomial in explicit graph and rational bit lengths; the implementation uses Dijkstra with a heap, then walks and basis provenance. This is a sufficient structured oracle with unrestricted rational points and unrestricted cycle rank. It does not solve arbitrary binary row spaces. Related odd-cycle and graphic-code separation techniques are established; no novelty claim is made.

## TECT-X barrier: even all parity cuts need not suffice

Take the previous pigeonhole family p=m+1, m>=2, in original x coordinates: odd row parity and pair exclusions. Put x_ij=1/m for every bit. Every pair inequality is satisfied since 2/m<=1. The affine rows have disjoint supports. A nonempty combination of k rows has support km and RHS k mod 2. Every forbidden-pattern distance is at least km*(1/m)=k>=1 since 1/m<=1/2. Thus no redundant parity cut is violated, including with the exact oracle, despite integer infeasibility. Boolean bounds hold. This is a feasible point of the full parity-cut-plus-source-clause LP relaxation, not an integer witness. The previous counting refutation derives the missing global inequality. So even complete separation of this cut family is not by itself a sufficient universal decision mechanism. Neither the half-integral nor graphic oracle proves polynomial hybrid proof discovery; the graphic promise is not satisfied by every general affine system. Exact separation of a restricted domain does not contradict the prior uniform-point hardness.

Topology: the integral-coordinate projection is exact restriction of affine consequences; in the graphic route, cycle decomposition and the two-sheet graph encode the parity obstruction. The pigeonhole example retains a fractional feasible point but no global integer section. No universal topological SAT characterization.
