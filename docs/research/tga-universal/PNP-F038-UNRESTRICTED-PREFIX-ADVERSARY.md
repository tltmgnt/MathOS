## Constructive track: a common prefix carrying an arbitrary SAT problem

Take n a multiple of four, n>=8, h=n/4-1. The universal normalized pool order is the actual pool(n) order: increasing width, then lexicographic variable supports, then signs. The last 8 binom(n/2,3) clauses are exactly all signed ternary clauses with variables in the last n/2 positions. Let N=|U_n|, L=n+1+N, B=L-8 binom(n/2,3), R=B-n. The first B input tape cells of every selector supported in this suffix are identical: n unary ones, the delimiter, and zero selector bits. R=Theta(L), and R>=L/2 for n>=8, by the displayed binomial formula (the suffix is at most one eighth of the ternary pool).

Partition the last half of the source variables into h original slots, h independent pin slots, and two fresh guard variables u,v. Embed any normalized 3CNF G on at most h original variables in the original slots. Lift each unit literal l into the four clauses (l OR +/-u OR +/-v) over every guard sign pattern. Lift each binary clause C into the two clauses (C OR u),(C OR not u). Keep ternary clauses unchanged. All clauses now lie in the suffix. Conjunction of each lifted block is equivalent to the original clause for EVERY guard valuation, because one extension has all guard literals false. To force a pattern a in {0,1}^h on the pin slots, apply the same four-clause lift to its signed unit literals. Thus the encoded p(G,a) has SAT iff G has SAT, and every satisfying source assignment has pin pattern a. Conversely any satisfying assignment of G extends with pattern a, arbitrary guards and arbitrary unused bits. Empty clauses in a source reduction can be handled separately by replacing G with a contradictory pair of units. This is an ordinary decision-preserving encoding, not a parity task.

## Universal-stage elimination theorem

Use the SAME scheduler as before: a binary description of length ell receives t=2^(s-ell) steps at stage s. In the actual general tape interpreter, the head starts at zero and moves at most one cell per step. If t<=R, every tape access is within the shared prefix or on its identical blank left side. Even the final read of n output bits from the halt head has maximum index t+n-1<=B-1. Induction on time proves the entire execution and the emitted assignment (including malformed/timeout cases) are identical to execution on selector p=0. Hence for each such valid general description collect its output's projection onto the h pin slots, if it emits a well-formed assignment. No SAT verification on p=0 is needed. This avoids assuming the algorithm is syntactically blind to the formula when it actually has the full input; it is a proved consequence of the SAME charged clock and tape encoding.

For the short built-ins of U, the null program emits nothing, constant proposals and p mod 4 all project to the all-zero pin pattern because the first two selector bits are zero and the pin slots lie beyond the first two source bits. The deliberately invalid proposal 2^n is rejected. The exhaustive built-in is inactive if 2^(s-3)<2^n (or s<3). Include zero in the forbidden set. Under this condition all built-ins are eliminated by a nonzero pattern. There are fewer than 2^(s+1) binary descriptions and at most one projection per description, including the reserved all-zero projection (the constant-zero description exists when s>=1; s=0 can be treated with the single reserved zero). Therefore whenever 2^h>2^(s+1), a missing pin pattern can be found deterministically by sorting the forbidden patterns or scanning the first |forbidden|+1 integers. No search for a satisfying assignment of G is involved.

Every description with t<=R is now defeated on every satisfiable p(G,a); the built-ins are defeated independently of t. The only descriptions not eliminated are general tape programs with t>R. The number of ALL binary strings in this remaining length range is exactly

    2^max(0,s-floor(log2 R))-1.

At s=s_k(n)=k ceil(log2 L) this is O(L^(k-1)) for fixed k. Invalid codes and built-ins only reduce this bound. The pattern construction can enumerate all descriptions and run the prefix-blind ones within their allotted clocks, using the previous polynomial overhead bound in L+2^s. Encoding and output projection are polynomial per launch. Therefore for each FIXED k this is a deterministic polynomial-time many-one embedding of arbitrary 3SAT into a family in which all but that explicitly counted class of competitors are eliminated. Choose n sufficiently large and a multiple of four with h>=source variable count, 2^h>2^(s+1) and the exhaustive built-in inactive. For fixed k these inequalities hold for all sufficiently large n; one can double n until they hold, and n is polynomial in original input size (indeed linear beyond a k-dependent constant). The constructor does not solve SAT. The image family retains NP-hard ordinary SAT decision by the exact projection; this is NOT a claim that membership in Bad is NP-hard or that remaining competitors fail.

### Actual bad witnesses for k=1

For s=ceil(log2 L), R>=L/2 implies s-floor(log2 R)<=2. Thus the remaining description strings have length at most one. No valid general tape description of the actual U is shorter than 20 bits (one state: three-bit prefix, unary count and delimiter, three five-bit transitions). The built-ins were already eliminated. Consequently taking G empty and any missing pin pattern produces a satisfiable selector p with S_s(p)=0 for every sufficiently large n divisible by four. The witness is explicit: pin pattern a, every other source bit zero. This proves

    H_(n,s_1(n)) is SAT for all sufficiently large n divisible by four.

The same argument works for any fixed additive stage offset j for which s_1(n)+j-floor(log2 R)<=20 (e.g. j<=18); this changes only a constant factor of budget. This is an unconditional lower bound for the actual unrestricted universal scheduler at a particular exponent, not a superpolynomial runtime lower bound for SAT. It attacks the precise predicate from the preceding cycle instead of introducing a new restricted computational model. The elimination theorem remains valid for arbitrary programs at any stage, but only for the ones whose allotted steps actually prevent reaching the suffix.

## Alternative/adversarial track: why this does not settle higher exponents

The input-prefix construction cannot defeat an arbitrary program with t>R. In particular when G is empty, a single fixed polynomial-time algorithm can read the selected lifted clauses, recover the pinned pattern, and emit a satisfying witness. Such an algorithm can be encoded in the general tape family, with polynomial total time on all these empty-G instances. For some fixed exponent K the universal machine succeeds on all of them by s_K(n). The chosen pin pattern is encoded in the suffix, not cryptographically hidden. Thus even an adversarially chosen missing pattern from the blind executions cannot certify all-exponent hardness. For arbitrary G the remaining programs may solve the embedded 3SAT problem. Their count is bounded but their algorithms are unrestricted; a finite or polynomial-size set of programs can include a universally polynomial-time SAT algorithm if one exists. Defeating them is the exact outstanding obligation.

A proposed next step must reason about these programs after they have read and processed the whole input, at the SAME stage and length. Merely moving information further into an explicit input cannot provide a superlinear read horizon. Increasing n to grow the suffix also increases the stage polynomial budget. Encoding the missing pattern in a larger formula or simulating all long competitors to choose a contradictory witness does not automatically preserve satisfiability or beat their clocks. No unrestricted lower bound is claimed for k>=2. The direct resolution target remains the previous all-k infinitely-many-n condition.
