## 1. Semantic classification of the actual ternary blocks

For each triple I=(i,j,k) the actual selector has an eight-bit block of signed clauses. Let R_I subset {0,1}^3 be its allowed local assignments, i.e. assignments satisfying every selected clause on that support. The block-to-relation map is a bijection between the 256 masks and the 256 local relations, since each signed clause forbids exactly one assignment.

Form G_I as the conjunction of all 12 signed binary clauses on pairs of distinct variables of I which are true on every member of R_I. If R_I is empty, every binary clause is entailed, and G_I is contradictory. Always R_I subset models(G_I). Call the block reducible if equality holds; otherwise call it irreducible. Reducible blocks are replaced by G_I without adding variables, guessing assignments or changing the model set. Empty and full relations are reducible. Every complete seven-of-eight block is reducible as well, but the property is not restricted to complete blocks.

Equivalently R_I is reducible iff it is closed under coordinatewise majority of three allowed assignments. Each binary clause is majority-closed: if the majority falsifies both literals, at least two inputs falsify each literal, so at least one input falsifies both. Conversely if w satisfies every entailed pair clause, each of its three pair projections occurs in some member of R_I; otherwise the missing pair would give an entailed clause falsified by w. The majority of three such members (one for each pair) is exactly w. Thus closure implies w belongs to R_I. This proof includes empty R_I because its pair closure is empty. This is an elementary arity-three instance of the classical bijunctive relation characterization.

The exact mask census by finite enumeration is 166 reducible masks and 90 irreducible masks. The classification is constant-size and can be implemented as a fixed lookup or finite truth-table test. It is not a claim about global 2-CNF equivalence of the full formula; locally irreducible blocks may be rendered redundant by other supports.

## 2. Hitting the irreducible supports

Let E(p) be the family of triples whose blocks are irreducible. Define tau(p) as the minimum number of source variables hitting every member of E(p), with tau=0 for the empty family. Set b=floor(log_3 n), equivalently the greatest integer with 3^b<=n.

On the actual input, parse all unit and binary clauses, replace reducible triple blocks by their entailed pairs, and retain selected clauses of irreducible blocks separately. This is an exact equivalence. Discover a hitting set A of size at most b by the following bounded branching: starting with the empty set, find any uncovered triple; branch on adding each of its three distinct variables. If none uncovered, return the chosen set; if depth b is reached while a triple remains uncovered, return failure on that branch. A cover of size at most b exists iff this search succeeds: any cover extending the current choices must contain a member of the next uncovered triple. There are at most (3^(b+1)-1)/2 nodes. Stop if no cover exists; this does not assert UNSAT.

If A exists, enumerate its 2^|A| assignments. Keep all earlier binary clauses and add a unit for each chosen value. Simplify every retained irreducible triple clause by this assignment: delete it if satisfied; otherwise remove fixed false literals. Since A hits its support, the remaining clause has width at most two. An empty remaining clause rejects just that assignment. Thus each branch is an ordinary 2-CNF with the same original variables, no auxiliary variables. Any model satisfies the original selected formula and vice versa for its own branch assignment. Find a model of the first satisfiable branch, verify against the original selector, and emit the n output bits with the original halt-head convention. Failure is not a general UNSAT inference. The algorithm solves every satisfiable selector with tau<=b, regardless of its total number of clauses, model count or global structure.

## 3. Explicit bounded-clock 2-CNF witness search

For a 2-CNF on n variables, make the 2n implication vertices, one per literal, with edges not a -> b and not b -> a for each clause (a OR b); a unit is treated as a repeated literal. Add reflexive edges. Compute the Boolean transitive closure by the usual Warshall recurrence. Let R(l) be the resulting row bitvector, interpreted as a nonnegative integer in a common vertex order. If R(l)=R(not l), then reflexivity gives mutual reachability and the implication constraints force contradiction. If no such equality exists, set each literal l true exactly when R(l)<R(not l). This assigns exactly one sign per variable.

For any implication a -> b, inclusion gives R(b)<=R(a), and the contrapositive edge gives R(not a)<=R(not b). If a is true and b false, then R(b)<=R(a)<R(not a)<=R(not b)<R(b), contradiction. Hence every implication and every original binary or unit clause is satisfied. This row-order proof constructs a model directly without a separate SCC sorting or uncharged SAT call.

## 4. Full bit-cost bound in the original stage

The original input length L=n+1+2n+4 binom(n,2)+8 binom(n,3)=Theta(n^3). Use a fixed multitape bit machine with a fixed number of tapes, then the same ordinary quadratic one-tape simulation used in the preceding cycle. A careful implementation uses no free random access:

- Sequentially parse the unary header and the actual selector bits, using binary support counters. Generate at most O(L) explicit clause/support records, each O(log(n+2)) bits. The block lookup is constant-size, and the 12 output clauses are constant per block.
- At each cover-search node scan the support records against an O(log n)-entry list of chosen variables, using sequential tape comparisons and resets. Store the depth-first branch stack of O(log n) records and return the first cover. Each node takes O(L polylog L) bit steps. With 3^b<=n the total is O(n L polylog L).
- For each of at most 2^b<=n assignments, scan the records against the short chosen-variable list, simplify retained clauses and add units. Generate directed implication-edge records (O(L) records, O(log n) bits each). Bottom-up merge sort on a fixed number of sequential tapes sorts them in O(L polylog L) bit steps: each pass merges ordered runs by record comparison and copying, using binary run counters; O(log L) passes suffice. Scan the sorted edge stream and emit the full 2n by 2n adjacency bit matrix, including reflexive entries; missing edges become zeros and duplicate edges coalesce.
- The Warshall computation costs O(n^3 polylog L) on a fixed number of sequential tapes, not O(n^5) via repeated random tape indexing. In each of 2n rounds extract the chosen row and column by a sequential scan of the old matrix into two work tapes. Scan the old matrix again row by row, holding the column entry for the current row and rewinding the extracted row tape once per output row, to compute each new bit by the Boolean recurrence. Swap old/new matrix tape roles, and rewind the tapes. Each round costs O(n^2 polylog L) including counters and rewinds. At completion compare adjacent complementary rows lexicographically in their common bit order (the significance order may be reversed if desired, as long as common). Output the truth sign with the smaller row, or mark contradiction on equality. All bit comparisons and scans are charged. This is O(L polylog L) per branch since n^3=O(L).
- Verify one successful completed assignment against the original full selector, using at most O(n) sequential assignment-bit scan operations per clause, with logarithmic counter overhead. This costs O(n L polylog L) once, not for every unsuccessful branch. Mathematical correctness of the binary solver ensures any reported branch model satisfies the input; the explicit final verifier is retained. Write the verified output or return a malformed proposal.

Overall multitape bit time is O(n L polylog L). Initial input conversion, fixed-track block encoding, head-marker simulation and final output positioning on the actual three-symbol one-tape machine take O((L+T)^2) steps: at each simulated step the used tape is O(L+T), and a constant number of sweeps of its coded region suffice. This gives a fixed valid general description d of U, with length ell independent of n, and time bound

    O(n^2 L^2 polylog L) = O(L^(8/3) polylog L).

As 8/3<3, for all sufficiently large n this time is <=2^(3 ceil(log2 L)-ell), with ell fixed. The general algorithm can be realized by fixed finite control and a fixed tape alphabet; the three-symbol implementation and its description length are mathematical existence claims, not a compiled artifact. No numerical threshold n0 is supplied. The same bound holds for failure runs. No generic program or clock in U is modified.

Therefore there exists n0 such that for every n>=n0,

    p in B_3(n)  implies  tau(p) >= floor(log_3 n)+1.

This is an unconditional structural necessary condition on arbitrary cubic-stage residual selectors. In particular E(p) must have more than b supports, and a maximal disjoint-support matching of size m covers E by its 3m vertices, so every such matching satisfies 3m>=tau(p)>b. Neither condition is sufficient for failure. This does not subsume the previous complete-support recovery criterion; the two are complementary. It excludes every 2-CNF selector and every selector with only reducible triple blocks, as well as selectors with logarithmically small hitting sets of irreducible supports, including some containing genuine ternary clauses.
