This test certifies nonhalting when the reachable running states are closed under all three read symbols and all these transitions are defined and nonhalting.

An exact local or checkpoint recurrence requires the same running state, head position and entire tape. A rolling hash is only a trigger; every cell changed since the earlier configuration is compared to its exact original value, using the earliest recorded prior value. Untouched cells coincide. A fresh exterior frontier is a head position strictly beyond the original input and all previously visited positions in that direction. All cells strictly outward are therefore blank. ## 3. Exact hierarchical block replay

Implement a second, independently structured execution engine to avoid repeatedly traversing million-cell stretches. Represent a tape segment of length 2^ell by a binary tree with canonical interned child pairs; three leaf IDs denote the three symbols. Equality of node IDs means equality of entire segments by induction on level. The hash table compares exact key pairs; it does not equate hash collisions. A root segment contains the full input, both possible clock-bounded head excursions and every possible final output cell.

Define a macro on a segment, relative head, state, and partial transition table. The result contains elapsed original transitions and either exit from the segment, halt, first undefined transition, proven nonhalting loop, or exhaustion of the macro's original-step cap. For a leaf, execute actual transitions until one of these events, detecting exact state/symbol recurrence if the head stays. For a parent, call the child containing the head; on a child exit update the persistent tree and enter the next child or exit the parent. On halt or undefined transition return the exact tree and head position. On a proven loop return nonhalting. At any parent boundary where an identical canonical node ID, head and state recur after nonhalting steps, the same execution recurs forever. A macro that exceeds the remaining original-step budget is counted as a timeout only up to that budget; it cannot hide an earlier halt or undefined transition because every macro stops at the first such event. At an exact-clock halt, the output is still read. At an undefined transition exactly at the clock boundary no transition is executed. Thus induction on segment level and on child events proves the same exact original semantics for all completions of the current partial table.

Memoize the macro by exact node identity, head offset, running state and full partial-table code (base 9(q+1)+1, zero digit undefined). The level is implicit in node identity. A hit is an exact identical local computation, never a probabilistic approximation or a free step in the machine's original clock. Persistent child updates avoid copying unchanged tape. The macro cap and actual root clock are fixed for an audit; cache clearing affects performance only. At a root undefined event branch on all possible transitions, partitioning the full table space as in the scalar audit. The engine has an opt-in full two-state clock mode. It has not completed a full-clock run; no asymptotic acceleration guarantee is asserted.
