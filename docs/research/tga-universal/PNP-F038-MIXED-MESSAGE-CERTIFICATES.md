## A representation-independent message contract

A message is a Boolean cylinder on an explicitly specified independent direction basis S: membership depends only on the signature of the ambient parameter t on S. Use three interchangeable encodings: a sorted set of allowed signatures (explicit table), a direct-sum conjunction of affine unions (including a single affine union as a special case), or an ordered binary decision diagram (OBDD) in the fixed ambient order. The leaf and root initialization are explicit tables. Every operation has a mathematical specification: given input cylinders R_j and a target space T, return the cylinder Pi_T(intersection_j R_j). The exact upward and downward recurrences and the translation predicates from the earlier semantic repair theorem depend only on this contract, not on a representation.

Conversions are exact and resource-accounted:
* Any input to a table: enumerate signatures on its own boundary S, lift each to any ambient representative, and test membership. This is valid because the input is a cylinder. This can cost exponentially in dim S.
* A table to factored affine form: encode each allowed point as its full set of signature equations, compress by the previously proved exact affine-union rules and wrap as one factor. An OBDD can take this route via a table; no polynomial conversion guarantee is made.
* A table or factored affine form to an OBDD: disjoin points or flats, each flat a conjunction of parity equations, and conjoin factors. Each parity equation admits a linear-size OBDD, but successive apply operations can grow exponentially. A native OBDD is copied by importing its reduced reachable DAG. The manager-independent serialization is deterministic postorder with terminals 0 and 1; it does not copy unrelated temporary nodes.

The table backend enumerates compatible tuples of input signatures and output signatures via linear consistency. The factored backend calls the exact dependent-group projection routine. The OBDD backend builds the conjunction and saturates by a basis of T-perp. These all implement precisely the contract even if T is not contained in the sum of the input scopes (free directions in T remain free). At each upward join, downward join, local projection feasibility test, and final translation join choose a backend independently. Conversion need not materialize any other engine's intermediate results. In particular the factored-to-OBDD route does not expand the product of independent factors. A chosen backend may still be expensive.

## Certified local switching

Record the output message and its representation tag for each operation, in deterministic dependency order. A verifier derives the clause tree, leaf predicates and operation dependencies from the original formula and designated residual occurrence. It recomputes each operation using the recorded tag and already checked predecessor messages, compares the exact deterministic encoding, and checks the induced local projections and translation predicates. Equality of these deterministic outputs is sufficient; no general equivalence test for arbitrary heterogeneous representations is assumed. Induction over the operation DAG proves that every accepted message is the exact specified cylinder. The translation root at the empty boundary is true iff some valid constant translation exists. The positive witness is checked on every translation predicate; the producer reconstructs it using local OBDD intersections and parity pins, with all conversions counted. A negative result certifies no translation, not that the source is UNSAT. A malformed or incomplete transcript is not accepted.

For a fixed executed sequence of local operations, let t_j be the least fully metered cost among the available backends on the actual accepted input messages to operation j, including conversion, output and verification. The previous geometric scheduler gives charged work <4k sum_j t_j for k choices, plus explicitly accounted initialization, final verification and reconstruction costs. This is a conditional path-wise bound, NOT a competitive guarantee against the globally optimal representation schedule: locally inexpensive representations can incur costly conversions later. For example an abstract two-stage cost table can give a first choice of cost 1 followed by conversion cost 2^n, versus an alternative first choice of cost 2 followed by cost 1. Local greedy competition alone cannot imply the globally best path bound. The prototype implements a deterministic mixed policy and separately exposes a bounded local join with verified fallback. It does not claim global boundedness of the default full run. The bounded join uses the previous Python opcode meter, not a hard CPU/memory or bit-operation sandbox; a cap expiration yields UNKNOWN, never false.

## Universal coverage is a resolution-level obligation

A general constant-translation existence algorithm for designated residual clauses of normalized 3-CNFs would decide SAT in polynomial time if its complete execution, including discovery and verification, were polynomial on every instance. This follows even when a valid affine extraction is mandatory: use the previous semantic-repair NP-hardness reduction with C=(z OR w), w forced zero, a unique bad model in the z=0 branch, and the z=1 branch projecting onto the arbitrary source 3-CNF. C is the only clause on its scope and is not extracted by the specified parity extraction. Both any bad model and any good model satisfy the extracted affine system; the XOR of these models belongs to its homogeneous kernel, and every kernel vector is obtainable by a free-parameter translation. Thus extraction does not alter existence of the required repair. A total polynomial bound on a fixed finite portfolio's verified best strategy would imply P=NP by the scheduling theorem. Conversely if P=NP the general projection compiler and final SAT self-reduction give some polynomial algorithm, but do not imply a bound on these particular representations or the greedy switching policy.

This supplies a direct coverage barrier, not a lower bound for an individual strategy. The earlier grid common-message example remains removable by local logical repair; we have not proved a shared representation obstruction that survives every available preprocessing strategy. Do not infer one from this equivalence.
