## Objective and outcome

The earlier exact symbolic compiler encodes the same U failure predicate by unrolling a rectangular tape tableau for each program, with bound poly(L+s) 4^s. This cycle replaces the tableau with sparse execution records and shared lookup tables. The mathematical construction and executable circuit builder yield an existential width-three counterexample CNF of size O((L+2^s) poly(s+log(L+2))) bits. This is a substantial improvement to the exact higher-exponent counterexample search target, not a proof that it is satisfiable. No change to the machine, verifier, selector encoding or stage clocks. Classical near-linear reductions from machine computation to SAT by memory-order sorting are established techniques, not a novelty claim. See van Melkebeek, A Survey of Lower Bounds for Satisfiability and Related Problems, https://pages.cs.wisc.edu/~dieter/Papers/sat-lb-survey-fttcs.pdf ; and From RAM to SAT, https://www.ccs.neu.edu/~viola/papers/ram2sat.pdf . We specialize the technique to simultaneous rejection rather than to a single accepted run, with shared original input and clause tables and at most four terminal tape reads per program. Seven MRA-X roles are authored local records, not independent agents.

## 1. Exact sparse trace semantics

Let the original source size be n, pool size N and explicit encoding length L=n+1+N. For every eligible valid general description d with length ell<=s, retain its EXACT allotted clock t_d=2^(s-ell). Invalid binary strings never emit a proposal and can be omitted from the encoding. For a fixed d,t introduce two guessed bits for the read symbol and two guessed bits for the original initial symbol at each of t time steps. Compute the next state, write symbol and head position from the guessed read and the actual decoded transition, starting at state/head zero. The halt state is absorbing with head stationary and identity writes. This freezes the first halting tape through the end of the allocated clock. The read alphabet is restricted to 0,1,blank. One-hot state and bounded binary address arithmetic are Boolean circuits of polynomial size in s+log(L+2) per step. The head range is [-t,t]; shifted addresses use a common offset max_d t_d and enough bits to include all terminal reads and the original input, so no modular wrap occurs on a consistent trace.

Each access generates a record (program ID, address, time, read, write, claimed initial symbol). Sort all such records together by (program ID,address,time), using a fixed bitonic compare-exchange network. The record payload travels with its key. For each first access to a program/cell require read=claimed initial symbol. For every later access to that same program/cell require read=the preceding write. Compare only adjacent sorted records. Programs never share writable memory: program ID is part of the memory key. To authenticate the claimed initial symbol of every access, use a SECOND batched sorting lookup with one common table of the original input bits (unary header, delimiter, selectors), and a blank sentinel for addresses outside it. Sort table rows and requests by (address,table-before-query). Each query must match its predecessor's address and payload; inductively it matches the unique table row. Requests outside the input use the sentinel key. This avoids a separate copy of L input cells per program and a separate L-way multiplexer per read.

Time consistency plus authenticated memory consistency determines the actual deterministic execution: induction on time, the sorted-order condition forces the symbol from the last prior write or the true initial tape, so the next event is exactly the original transition. Conversely the actual trace satisfies every constraint. Absorbing halt reads/writes are valid identity operations. Sorting cannot change the multiset of records. Padding uses an additional high key bit so every dummy sorts after all real records, including ties. The arithmetic and comparator circuits are explicit and constrain all auxiliary gates in both directions.

## 2. Reject without copying the entire output window for each program

At the end of each trace guess a valid output offset j in [0,n-1] and a clause-pool index i. Retrieve the selected bit and the (up to three) literal offsets and falsifying bits of that clause by a THIRD shared batched lookup. Short clauses repeat their last literal. The table has one row per original pool clause, with selected bit from the original symbolic p and constant literal metadata. Each program has exactly four additional read-only tape records at distinct successive times: one for final head+j, three for the chosen clause's literal offsets from the final head. Authenticate these in the same two memory checks. These records have write=read and do not affect the tape. Even when the program timed out, the dummy requests are well-defined and may use an arbitrary valid index and offset.

Require the disjunction of:
1. state is not halt at the final time;
2. the chosen output cell is blank;
3. the chosen clause is selected and each of its literal output cells contains its falsifying binary bit.

These are exact certificates of failure. In case 2 the original output is malformed. In case 3, even if there is another blank elsewhere, either the output is malformed or the selected clause is false. Conversely every failed program is a timeout, has at least one blank output cell, or has a well-formed assignment falsifying at least one selected clause. In particular no successful verified proposal admits a rejecting certificate, regardless of which clause or offset is guessed. Crucially we do NOT need n terminal cells per program, a full witness verifier per program, or a unique rejection certificate. The actual execution is unique, but several failure reasons may be possible. The existential trace CNF is therefore not asserted to have a unique extension for a fixed p,x.

The actual short built-ins are checked using their original bounded semantics from the earlier symbolic compiler. If the exhaustive built-in is active (s>=n+3), a verified source witness implies stage success; the counterexample CNF is immediately contradictory. Otherwise all other built-ins are saturated by stage 4, and evaluating their success via the earlier compiler at min(s,19) includes no general descriptions and leaves exhaustive inactive. Require no built-in success. Finally independently verify x against all selected source clauses. This costs O(L) gates once. Thus

    exists trace/certificate/gate assignment satisfying J_(n,s)(p,x)
      iff x satisfies F_p and S_s(p)=0.

This preserves the exact prior H predicate including the arbitrary higher stages. If there are no generic descriptions, only the short built-in and original witness checks are needed.

## 3. Quasilinear size and exact clock accounting

The total number of time-step records is at most

    sum_(ell=0)^s 2^ell * 2^(s-ell) = (s+1)2^s.

There are at most 2^(s+1)-1 eligible descriptions and at most four extra reads, one clause request and O(1) certificate words per valid general description. Add the shared input and clause tables of O(L) rows. Thus the total number of rows across all three networks is O(L+(s+1)2^s). Each record uses O(s+log(L+2)) bits, including addresses, time, program IDs, clause offsets, symbols and payload. The local transition checker uses at most O(poly(s+log L)) gates per step (q<=s). A bitonic sorting network on R rows padded to a power of two has O(R log^2(R+2)) compare-exchanges, each with O(record width) bounded-fan-in gates. The Boolean gates convert by exact Tseitin equivalences into at most three width-three clauses per AND and unit constraints. Encoded clause indices add only O(log(R+2)+log(s+log L)) bits each. The result is an explicit width-three formula of encoded bit size

    O((L+2^s) poly(s+log(L+2))).

A uniform constructor enumerates valid descriptions, builds the local circuits and generates the fixed sorting wiring and CNF in time polynomial in L+2^s. The size estimate is independent of memoization. An append-only circuit implementation with standard indexed data structures can generate the wiring with polynomial-log overhead per gate in a bit-cost random-access construction model; no such quasilinear running-time guarantee is claimed for the Python dictionary implementation or a single-tape constructor. The bound is on the ordinary explicit clause-list CNF, not on the complete selector tape required if that CNF itself is fed back to U. At s=k ceil(log2 L) its size is O(L^k polylog L) for fixed k>=1. In particular the actual cubic counterexample search can now be represented with cubic-times-polylog explicit CNF size rather than a quadratic-in-stage-budget tableau. This does not run a SAT solver for free.

## 4. Exact remaining obstruction

This compilation cannot produce a same-clock contradiction merely by running U on the compiled formula: even the compact CNF may have polynomially more variables and clauses than the original p, the complete normalized selector encoding can further enlarge it cubically in its variable count, and the stage clock of the enlarged instance is different. A model of the compiled CNF certifies a counterexample only if the formula is SAT. No theorem here forces a model at arbitrarily large n. The new representation also does not evade the previous self-description discovery bounds. It supplies a more economical explicit search target for actual unrestricted stage failures, not a decision lower bound.
