## Objective and result

Directly audit whether the earlier exact quadratic-stage lower-bound family (PNP-F038-UNRESTRICTED-QUADRATIC-STAGE.md) can extend to the cubic stage by improving its crossing-transcript proof. It cannot. We construct a single fixed witness algorithm for the ENTIRE original family, with arbitrary forbidden sets and pin pattern. Its compiled running time is O(L^2 polylog L) in the actual general three-symbol one-tape model. Consequently there exist constants a,b such that the original universal stage succeeds on every satisfiable member of this family by

    2 ceil(log2 L) + a ceil(log2(ceil(log2 L)+1)) + b.

In particular, for every fixed epsilon>0, the family has no residual failures at stage ceil((2+epsilon) log2 L) for all sufficiently large m. The exact stage-two lower bound derived earlier is therefore sharp in leading exponent for this family. This is a no-go theorem for extending that adversary, not an unrestricted upper bound on SAT. U, its description encoding, input, verifier and weighted clocks are unchanged. Seven MRA-X role records are locally authored, not independent agents.

## 1. Exact family from the previous proof

Use m>=3, n=11m, M=m^3. The original X groups are X_k=( (k+1)m+1,...,(k+2)m ) for k=0,1,2. The copy groups Z_k=X_k+6m. The prefix-OR auxiliary groups Y_k=(4m+k(m-1)+1,...,4m+(k+1)(m-1)). Retain exactly the preceding onehot, equality-copy and guarded-pin clauses C, including the m-2 pins at 10m+1,...,11m-2 with final two variables as guards. For each index j=(j0,j1,j2) in [0,m)^3, the Alice clause A_j is the negative triple of the corresponding X variables; the Bob clause B_j is the negative triple of the corresponding Z variables. Select arbitrary subsets of these two sets of clauses, with indicator strings a,b of length M. No further clauses are included. The pin pattern is arbitrary, not necessarily the particular pattern used by the crossing argument.

Any model has exactly one variable true in each X group, by the pairwise negative clauses and the defined prefix-OR chain forced true at its end. The copies equal those variables. The selected triple-negative clauses therefore rule out precisely the indices with a_j=1 or b_j=1. The pins are forced by the four guard-sign combinations. Thus the formula is SAT iff at least one j has a_j=b_j=0. Given such j, set X_k[j_k] and Z_k[j_k] true, Y_k[i] true iff j_k<=i+1, and the pinned variables to their pin bits. Set all other bits, including the two guards, to zero. This is exactly the prior reconstructed witness W[j]. Conversely every model yields a surviving index; free unused variables do not create an alternative to this condition.

## 2. Streaming extraction from the actual full selector

The solver receives only the original tape 1^n 0 followed by the N selector bits. It is not supplied a,b, the pins or a promised index as extra input. Recover n from the unary header and test n=11m with m>=3. Parse the full normalized clause pool sequentially using binary width, support and sign counters, with no random access to the input.

For each ternary clause in the actual lexicographic support/sign enumeration:
- if the three literals are negative and their variables lie respectively in X_0,X_1,X_2, append that selector bit to a first work tape;
- if they lie respectively in Z_0,Z_1,Z_2 with all three negative, append the bit to a second work tape;
- if the first literal is positive on a data pin and the other two are negative on the final guards, append its selector bit to a third work tape.

Because the groups are ordered disjoint intervals, each triple tape contains the M bits in identical lexicographic index order, without an index sort or an M-way random access. There is exactly one chosen positive/negative-guard clause per pin; its selector bit is one exactly when that pin is one. Those clauses occur in increasing pin-variable order. Other fixed clauses never collide with these extracted positions. The streams are correct on every promised family input, including all-zero masks, full masks, arbitrary pins and unsatisfiable complementary masks.

Rewind the two mask tapes and scan in lockstep, maintaining an index with three base-m digits, until the first pair of zero bits is found or the streams end. On success generate the n witness bits sequentially using the group formulas above, consuming the pin tape in order. On exhaustion return FAIL. The algorithm does not need to determine whether an arbitrary input belongs to the family; its runtime is bounded for arbitrary correctly encoded selectors and its output, even on an input outside the family, is verified by the existing U verifier. It never makes an UNSAT claim on a general input. If desired an implementation may reject malformed input lengths; this costs only sequential counting. A separate full in-program verification is not required for this family theorem because the witness is proved correct on the promised family and U performs its own actual verification. We do not omit the verifier from the universal stage.

## 3. Full bit cost and exact weighted clock

Use a fixed multitape bit machine with a fixed number of tapes: input, mask streams, pin stream, binary counters, and output. All counters and interval endpoints have O(log L) bits. Each successor of a support/sign counter, group test, comparison, small fixed-integer arithmetic operation and stream append costs polylog L bit steps; there are O(L) iterations. The unary header and input length can be checked using binary counters in O(L polylog L). The lockstep scan costs O(M polylog L), the witness generation O(n polylog L). All tapes used have total length O(L polylog L). Hence total multitape time is O(L (log(L+2))^c) for a fixed c, on every promised input, without using random-access operations or hidden witness search.

Simulate this fixed machine by a fixed general one-tape program in the original syntax. One standard direct construction stores the constant number of simulated tracks and head markers in constant-width binary blocks, with blank delimiters; each simulated step scans and updates the used coded interval and extends it as necessary. The interval has length O(L+T), so initialization (including raw input conversion), T simulated steps and final copying/positioning of the n output bits can be performed in O((L+T)^2) transitions. The three-symbol alphabet is sufficient because the fixed block alphabet is binary coded. The fixed finite control has a constant number of states independent of n, a constant description length ell, and halts with its head at the first output bit, as required by the actual interpreter. Thus the general program has time at most C L^2 (log2(L+2))^d on family inputs, for fixed C,d. This is a mathematical machine-existence proof, not an implemented source-to-U compiler or measured tape runtime. No exact code length or numerical threshold is claimed.

For any such successful run the original U includes the program whenever s>=ell+ceil(log2 t). Absorb C, ell, rounding and the log(L+2) versus ceil(log L) comparison into fixed nonnegative integer constants a,b. The displayed stage cutoff in the objective follows. For any fixed epsilon>0, a log log L + b = o(log L), hence ceil((2+epsilon)log2 L) eventually dominates that cutoff, including the exact cubic stage. This uses the actual length-weighted allocation 2^(s-ell), not the aggregate stage runtime or a change in the machine. The cost of checking the witness belongs to the existing U stage implementation; it is not a free operation added to the program's tape clock.

## 4. Consequence for the direct unrestricted investigation

The previous mathematical derivation established failure at s=2 ceil(log2 L) along an unbounded sequence for members of precisely this family. This upper bound is compatible with that theorem: the O(log log L) additive stage slack and constant description length may matter at the exact quadratic stage. Taken together (subject to review of both derivations), the family is asymptotically sharp in its leading stage exponent, and cannot establish even a fixed positive improvement beyond two. In particular better crossing-transcript compression for this same disjointness-and-pins construction cannot prove unbounded B_3 existence. The finite cubic examples in a different pin family at n=52..92 remain unaffected.

The new result is a direct obstruction to the prior lower-bound strategy, not a restriction of the universal competitors. A next adversary must have more than two explicitly ordered forbidden-index streams with a direct surviving-index witness reconstruction, or otherwise prevent such cheap reconstruction. Merely counting more clauses or crossing records without changing that mathematical search structure cannot work. The original target remains B_3(n) nonempty at arbitrarily large n, and ultimately every exponent, or a uniform polynomial cutoff for unrestricted SAT. No universal obligation closes.
