## Constructive track: affine boundary cosets

Let C_j be explicit Boolean clauses on n>=1 variables, A_j their binary syndrome columns, and b the target syndrome. Use the preceding characterization: for each variable i, V_i^v is the span of columns of clauses containing the literal true at value v. Define W_i=V_i^0+V_i^1. For a set I of variables let W_I=sum_{i in I} W_i, and let D_I be the set of XOR sums of one vector from V_i^(x_i) for every i in I, with one truth value per variable. D_empty={0}. The prior theorem gives feasibility iff b is in D_all. Ambient syndrome dimension is explicit; dependent equations and empty/tautological clauses are permitted. Empty clauses never contribute; inconsistent systems cannot have a witness. Zero columns may be removed for this existential task by fixing their selectors to zero.

Let a supplied rooted full binary tree have exactly one leaf per variable. For each node use its leaf set I and complement J. Define

    lambda(I)=dim(W_I intersect W_J)=dim W_I+dim W_J-dim W_all.
    K_I=W_I intersect (b+W_J).
    k=max over tree nodes lambda(I).

K_I is empty if b is outside W_all; otherwise it is an affine coset of W_I intersect W_J, of exactly 2^lambda(I) points. It includes every contribution on side I that could possibly participate in a solution, even if its complement is not actually attainable. Crucially this bound does not charge the dimension of W_I itself. Construct K_I in polynomial preprocessing plus 2^lambda(I) poly(L) enumeration: concatenate independent bases of W_I and W_J, solve the linear combination equal to b by elimination, obtain a particular solution and a basis for its nullspace. Project each coefficient vector to its left summand in W_I. Since the individual bases are independent, projection of the kernel is bijective onto the intersection. This constructs the exact affine coset with no enumeration of either full subspace. Compute all W_I and complementary bases by polynomial-time elimination on explicit column lists. A supplied tree and its width can be checked in polynomial time.

Define table T_I = D_I intersect K_I. At a leaf, enumerate K_I and test membership in each V_i^v by elimination; store one valid value and a column-mask certificate for each retained syndrome. In particular one need not enumerate V_i^v even if its dimension is huge. At an internal node with child sets P,Q, enumerate pairs a in T_P, c in T_Q and retain a+c exactly when it lies in K_I. Store a witness pair per retained entry. This is exact: the forward inclusion follows from disjoint choices. Conversely if s in D_I intersect K_I, split a+c=s with a in D_P and c in D_Q. Since b+s in W_J, b+a=c+(b+s) belongs to W_Q+W_J, so a in K_P, and similarly c in K_Q. Thus both child contributions were retained. At the root K_all is {b} if consistent (otherwise empty); accepting iff T_all is nonempty is exact. Backtrack through stored pairs and leaf masks, XOR all masks, and assemble the leaf truth values. The selected clauses are satisfied by this one assignment; duplicate column uses cancel. Replay against the original equations and clauses.

With supplied width k the resulting time is O(n 4^k poly(L)) and space O(n 2^k poly(L)), including bit operations on syndromes, bases, backpointers and selector masks. L is complete explicit input length, including tree, n, matrix, clauses. These are upper bounds, not minimal costs. At k=0, every interface has at most one point: the theorem can solve instances with arbitrarily large global rank without enumerating any large local span. Example: n independent positive unit columns e_i with target all ones, global rank n, width zero for every tree. Local rank, not global rank, controls this particular algorithm. No claim that all NP instances have such a decomposition.

## Discovery is separately charged

For fixed explicit source subspaces, calculate lambda(I) for every subset by basis elimination. For each nonempty set I define opt(I) as the smallest possible maximum lambda over nodes of a rooted binary tree on I, with every complement measured against the original full variable set. For a singleton opt(I)=lambda(I). Otherwise

    opt(I)=max(lambda(I), min_{nonempty P proper subset I} max(opt(P),opt(I minus P))).

This follows by splitting at the root of a subtree; disjoint child choices have no additional constraints. Store the minimizing split and reconstruct an optimal tree. Time O(3^n poly(L)) and space O(2^n poly(L)); symmetric splits may be considered once. This is an explicit exact exponential discovery method, not an FPT discovery claim in k. It is used only for small fixtures. The supplied-tree algorithm itself remains fixed-parameter tractable in its verified width. A polynomial-time procedure returning logarithmic-width trees for all instances in a polynomial-size equivalent representation would imply P=NP by the preceding reduction and this theorem. Existence of good layouts without uniform discovery does not give that procedure.

## Alternative track: disjoint-row reduction has hypergraph cut rank

Use the previous 3SAT reduction verbatim: for clause C_j introduce fresh guard g_j; one equation forces selection of unit not g_j, a second requires odd selection among the tagged clauses (literal OR g_j). Row coordinates are distinct, one guard coordinate and one clause coordinate per source clause. All unused columns are zero. W_i spans exactly the clause coordinates for clauses containing original variable i; W_gj spans precisely the two coordinates of its own clause. Thus for every split I,J, lambda(I) equals the number of hyperedges H_j={g_j} union vars(C_j) meeting both sides. The guard coordinate itself belongs to only one leaf and never contributes to the intersection. Distinct clauses contribute independent clause coordinates, even if two clauses have the same variable support. This proves an exact cut-rank identity, not merely a bound from row overlap.

For a counterexample to any universal small-width guarantee on this unchanged encoding, take m=binom(a,2) positive binary clauses (x_i OR x_j) on a>=2 original variables and m fresh guards. All these source clauses are satisfiable by the all-ones assignment. In any rooted binary tree on the originals and guards, some subtree contains between a/3 and 2a/3 original variables: start at the root and descend through a child containing >2a/3 originals until none does, then take the larger-original-count child. Its original count is >a/3 and <=2a/3. At that cut every pair of originals split across sides gives a distinct hyperedge meeting both sides, independent of guard placement. Therefore

    k >= ceil(2 a^2 / 9).

The trivial upper bound k<=m gives Theta(a^2) for this family. Its global rank is 2m. The number of universal selector coordinates and explicit matrix encoding size are polynomial in a, so this is much larger than log L. The same lower bound applies even to optimal layout discovery on the fixed subspaces. It is not a lower bound on actual DP entries (many states can be absent), on execution time of every solver, or on the best equivalent encoding. In fact these positive formulas are easy; their width can be a property of the representation, not intrinsic SAT hardness. No universal P!=NP result follows. The hypergraph identity also allows a direct supplied-layout width calculation for these tagged systems without generic subspace elimination.

Topology: local witness subspaces glue by equal global syndrome, with only complementary affine cosets retained at tree interfaces. Exact union of compatible local choices is essential: replacing V_i^0 union V_i^1 by W_i for actual leaf feasibility is unsound. The complete-pair counterexample separates graph layout geometry from intrinsic decision hardness. No SAT homology invariant is claimed.
