## 1. Result

On the full nine-group distributed family, n=19m-7 and L=Theta(m^3), form the primal graph on the nine groups by connecting groups co-occurring in a selected cross clause. If it has a tree decomposition with bag size at most five and adhesion at most three (intersection size of adjacent bags), there is a fixed deterministic original three-symbol single-tape witness program running in

    O(m^8 polylog(m+2)) = O(L^(8/3) polylog(L+2)).

The program recognizes the promised support-graph condition from the actual normalized selector; the decomposition is not supplied as advice. All SAT selectors satisfying the promise eventually fit the exact original cubic stage uniformly over clauses and pins. The promise allows cyclic overlapping constraints within each bag and does not require a unique solution.

More generally, for a chosen decomposition of the nine groups with adhesion <=3, even with larger bags, a conditional message fanout bound is O((m^6 + m^3 sum_B W_B) polylog m), where W_B is the parent functional-plan product computed on the bag's original owned relations AND its child messages, as defined below. Empty local relations are handled without enumeration. The first bound is the special case W_B<=m^5. The second is input-sensitive, not a universal nine-group cutoff.

An explicit connected family has a unique model, full static and contextual domains in both modes, and minimum global fanout W >= (m-2)^9, yet falls within the first new cutoff for every m>=3. Thus this is a genuine separation from the preceding width and global-fanout sufficient conditions, not merely another example of low fanout. No hardness follows from failure of these sufficient conditions.

## 2. Exact ownership, decomposition and messages

Use the full inherited layout of nine one-hot digit groups, OR auxiliaries, pins and guards. A selected negative cross clause forbids exactly the tuples selecting all its specified digits. Only variable cross clauses enter the support graph; inherited fixed clauses give a unique full extension to each surviving tuple for the actual pins, and are not constraints between latent digit groups.

A tree decomposition consists of bags of groups, whose union covers all groups, such that every graph edge belongs to a bag and the bags containing any particular group induce a connected subtree. In particular every selected cross support of size <=3 is contained in some bag: the three occurrence subtrees of a triangle have pairwise intersections and hence a common vertex (the Helly property for subtrees of a tree, proved by rooting and choosing the deepest among their topmost vertices; every intersecting subtree whose top is shallower contains that vertex). Unary supports are covered as well. Alternatively the search below explicitly checks support coverage. Assign every selected support, and all its clauses, to exactly one containing bag by a fixed tie break.

A suitable decomposition, if one exists, can be found by finite enumeration independent of m: remove empty redundant bags and contract every edge on which one bag is contained in the other, keeping the larger bag. This preserves coverage and running intersection; for a neighbor of the removed smaller bag, its intersection with the larger bag equals its intersection with the smaller bag by running intersection. Thus the adhesion bound is preserved. Root the resulting tree at any nonempty bag. Every nonroot bag introduces at least one group absent from its parent. For any given group only its topmost occurrence can introduce it, by running intersection. Hence there are at most nine bags. Enumerate all rooted trees of at most nine nodes with bags subsets of the nine groups, check bag and adhesion bounds, union, coverage and running intersection. This finite search may have a huge constant but no input-dependent exponent or advice. The support mask can be accumulated during raw input parsing. If the first promise fails, the fixed program can halt on blank. No claim is made that every graph of treewidth four has a decomposition of adhesion three.

For a rooted tree, let S_B=B intersect parent(B), empty for the root. A message M_B is a list of distinct assignments to S_B that extend to satisfying assignments of all clauses owned by bags in the subtree of B. Alongside each allowed separator assignment retain one representative assignment on B that gives such an extension. There are at most m^|S_B|<=m^3 records (one record at the root). For each bag, a bag assignment passes iff it satisfies all clauses owned by B and its restriction to each child separator occurs in the corresponding child message. Retain one passing bag assignment per separator key. This computes M_B exactly by induction: extensions in different child subtrees can intersect only in groups of B, by running intersection; they agree there because the separator keys agree with the bag assignment. Thus they can be combined. Conversely any satisfying subtree assignment projects to a passing assignment. Root message nonempty iff the original formula is SAT.

On success read the root representative, then for each child look up its key using the already chosen parent values and read its stored representative. Recursion yields consistent digits on all nine groups, reconstruct the original full witness using actual pins and inherited auxiliary bits, not local zero pins. Each child needs only its own message and the key, not a whole stored subtree witness. The number of bags is constant. The process returns one valid original witness, not all models. For unique instances it necessarily returns the unique one.

## 3. Sequential bit algorithm with charged storage

Parse the actual normalized unary header and selector pool with counters, preserve actual pins and the support graph. Emit each selected cross clause record to its owning bag (or sort after tree selection). The total cross data is O(m^3) records. A fixed number of sequential tapes suffices. All tuple records, keys, clause support and local identifiers have O(log(m+2)) bits.

Process bags bottom-up. For a bag of size a<=5 enumerate its m^a assignments using counters and reusable chunks of C=m^3 records. For each chunk assign local identifiers. For every owned support H (width <=3), generate (projection,ID) records, sort by projection, and sequentially merge with the sorted forbidden relation for H; mark matching IDs as rejected. For every child separator, do the same against its allowed message keys, rejecting missing keys. Empty separator messages are tested as constant Boolean relations. Sort flags by ID and OR-merge back into the chunk to find the passing records. A support relation or child message contains O(C) records and the number of tests per bag is fixed. External merge sorting, key comparisons, sequential scans and rewinds therefore take O(C polylog m) bit steps per chunk. No random-access query is assumed.

Sort passing records by the parent separator key, keep one per key, and merge with the accumulated sorted message, keeping one representative per equal key. This incremental union costs O(C polylog m) per chunk and cannot grow beyond m^3 records; the root key is empty. Distinct messages are kept on separate sequential tapes (constant count) for subsequent parent computation and reconstruction. No m^5-sized bag table is ever written. The last short chunk can be charged a full C-record scan. The per-bag time is O((m^3+m^a) polylog m), since there are ceil(m^a/C) chunks. Total time O(m^5 polylog m), visited interval O(m^3 polylog m) on a fixed number of tapes, including input, all messages and scratch. The final reconstruction reads at most a constant number of messages sequentially, costing O(m^3 polylog m) additional bit steps.

The inherited fixed-track simulation into the original three-symbol tape charges O(L^2) for raw block conversion and O(m^3 polylog m) physical moves per simulated bit step, using a constant-width binary-coded product alphabet with head markers and all-2 unoccupied blocks. Space is bounded by reusable chunks and messages, not by the total number of enumerated assignments. Reconstruct and copy the raw n-bit output contiguously and position the halt head on its first bit; O(n m^3 polylog m) moves suffice, dominated by the bound. On no root key halt on a blank. All control is fixed, including the finite decomposition enumeration. Hence there is a fixed actual description of length ell, independent of m and the input. At s=3 ceil(log2 L) its allocated time is >=L^3/2^ell once eligible; strictly subcubic O(L^(8/3) polylog L) eventually fits uniformly. No practical threshold is asserted.

## 4. Message-aware fanout generalization

If larger bags are permitted while adhesion is still <=3, treat each child message as a new allowed relation on at most three groups in its parent bag. These relations are internal bit tables, not modifications to U, and representative payloads are ignored when testing keys. For each support of width <=3 inside the bag build the closed local allowed table from the conjunction of original owned forbidden relations and child allowed relations of support contained in it. Intersect all constraints of equal support. This can be done by emitting forbidden completions of each rejected local tuple (including missing child keys from a sequential enumeration/merge of all keys of that separator), sorting/OR-merging, and complementing, as in the preceding fanout note. There are O(m^3) records because all relation widths are <=3. If a child empty-key message rejects or any local table is empty, emit an empty message for the bag without any candidate generation.

Otherwise apply the previous bounded-fanout plan DP to the bag's groups using its closed local tables. Write W_B for the minimum product of maximum fanouts in this bag, computed AFTER incorporating the child messages. The previous persistent-buffer joins generate at most W_B final candidates, with O((m^3+W_B) polylog m) multitape bit time and O(m^3 polylog m) visited span. At each final chunk perform the exact global-in-bag relation checks and incremental separator-key union of Section 3 rather than halting on the first surviving tuple. The same total chunk bound holds, since each final chunk costs O(m^3 polylog m) and only one short final chunk occurs. A root message may short-circuit on its first witness but is not required to. Define W_B=0 in the immediate-empty case.

For a fixed decomposition choice (e.g. the first valid tree in a finite support-graph enumeration with adhesion <=3 and any bag size <=9), this gives original tape time O((m^6 + m^3 sum_B W_B) polylog m). If sum_B W_B<=m^(6-epsilon) for a fixed 0<epsilon<=3, the exact cubic cutoff follows as in the preceding fanout note. A bound for one chosen tree does not require efficient minimization over all possible data-dependent plans/decompositions. For existence of any good tree, one may run the finitely many tree algorithms as separate fixed descriptions with a fixed finite tie policy for each possible support graph; at least one appropriate fixed description then has the required asymptotic slack, uniformly over that finite list. This is optional and not necessary for the bag-size-five theorem.

## 5. Connected high-fanout unique family missed by earlier sufficient conditions

Split the nine groups into A={0,1,2,3} and B={4,5,6,7,8}. For m>=3 define t(a)=0 if a=0 and t(a)=1 otherwise. Within A choose all four triples; within B choose the five distinct cyclic consecutive triples (indices modulo 5). On each such triple permit exactly those digit triples with even sum of type bits, and, when two digits are nonzero, require those two nonzero digits to be distinct. Implement this by selecting exactly the forbidden negative ternaries. Additionally select the single negative binary clause forbidding digit pair (1,1) on groups 3,4; it connects the two parts. No other variable cross clauses. These are actual allowed normalized positions and disjoint from the inherited fixed clauses.

The type equations on A are invertible over GF(2): sum all four equations to get sum of all four bits zero, then each equation forces its omitted bit zero. In B the equations t_i+t_(i+1)+t_(i+2)=0 imply period three by subtracting consecutive equations. Period five and period three imply all bits equal, and the equations force that common bit zero. Thus the only possible global digit tuple is all zero; it satisfies every clause, including the bridge. Fixed extension gives exactly one full model for any actual pins.

Every digit has local support in every table A_H: a constrained triple supports zero by all zeros, and a nonzero digit a by pairing it with another nonzero digit b!=a and a zero, possible for m>=3. Other supports are unconstrained except possibly the bridge binary; for a bridge value one choose the opposite bridge coordinate zero. No constrained triple contains the bridge. Every pair of different digits in a group has incomparable signatures already on one constrained triple: for distinct nonzero a,b, a context with other digits (a,0) forbids a and allows b; context (b,0) does the reverse. For zero versus a nonzero, context (0,0) allows zero and forbids a, while context (b,0) for nonzero b!=a allows a and forbids zero. These contexts prove incomparability for both raw and closed signatures (there are no selected smaller supports within these triples). Hence the static and contextual pruning in both modes retain all m digits of every group and stop unchanged.

For each direction within a constrained triple, a parent key with one nonzero and one zero allows m-2 possible appended digits. Any other table is fully allowed or only checks the bridge pair; its maximum extension count is at least m-1, in fact at least m-2 suffices. This includes singleton and pair directions. Thus every direction has maximum fanout >=m-2, and the global fanout product W is >=(m-2)^9, regardless of group order and chosen parent sets. It is <=m^9. For large m this violates the previous W<=m^(6-epsilon) sufficient cutoff for every fixed epsilon>0; both prior width conditions also fail. No assumption about actual failure at cubic is made.

The graph is connected and has the three bags A, {3,4}, B arranged as a path, with adhesions one and maximum bag size five. The new theorem therefore solves it in O(L^(8/3) polylog L) or less, uniformly over m and pins. The special family also has the trivial all-zero digit solver, so its purpose is separation of structural tests, not computational hardness. It has no hidden-label or fixed-point hardness implication.

## 6. Executed finite reference checks

Independent JavaScript checked 14 fixtures (m=2,3,4), with prescribed valid decomposition paths. The generic controls used three size-five bags with consecutive adhesion three, testing empty/full, unary-fixed, equality, dense patterned ternaries and unique planted ternaries. The connected high-fanout control was tested at m=3,4 with its three-bag path. The reference assigned clauses to bags, enumerated allowed bag tuples and passed representative messages bottom-up, reconstructed witnesses and compared the root SAT predicate to direct original tuple enumeration. Independently it compared EVERY separator message key to direct enumeration of its entire subtree's assigned constraints. Totals: 14 fixtures, 1,803 selected cross clauses counting fixture occurrences, 20,222 original satisfying tuples, 1,648 locally allowed bag assignments tested, 1,595 passing bag assignments, 338 exact message keys, 162 ordered antichain comparisons for the high-fanout controls, zero discrepancies. The high-fanout controls had one solution each, all local supports and minimum directional fanouts 1 and 2 respectively, as the m-2 bound predicts. These are indexed high-level reference tests, not tape timing measurements, and the tested decomposition was supplied rather than found by the finite search. ## 7. Disposition

Separator messages extend the structural cubic cutoff to a connected full-width, high-global-fanout family. Future work should target larger adhesion or dense graphs with no such decomposition, and improve the physical costs of message construction without materializing large intermediate tensors. The general nine-group cutoff, unbounded B_3, P vs NP resolution remain open. Finite cubic interval 52..233 and reported Lean census unchanged, not recounted. Promotion NONE.
