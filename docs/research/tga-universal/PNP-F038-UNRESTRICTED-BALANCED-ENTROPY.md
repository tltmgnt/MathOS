## 1. Motivation and result

The previous deterministic isolation theorem gave a guarantee only for polynomially many models. Does high model multiplicity itself make arbitrary SAT easier, even after excluding free variables and biased bits? Here construct an injective polynomial-size reduction from arbitrary original selector SAT to an unusually high-entropy, globally complement-symmetric class. The reduction is unconditional; hardness on the image is conditional on source hardness. This is a barrier to using model count or one-coordinate marginals alone, not a proof of a new lower-bound exponent.

For every rational epsilon>0 there is a fixed polynomial-time transformation of original selectors at size n to original selectors at size h(n), increasing unboundedly, such that every satisfiable source maps to a satisfiable target with all the following properties for sufficiently large n:

* At least 2^(h-h^epsilon) models (equivalently log2 of the model count >=h-h^epsilon).
* The uniform distribution on the model set has exactly balanced marginal on every variable.
* Every target variable is semantically essential: there exists a satisfying assignment whose flip of that one bit falsifies the formula.
* The syntactic variable co-occurrence graph is connected.
* Every target model projects efficiently to a satisfying assignment of the source; unsatisfiable sources stay unsatisfiable.

The target is a full normalized width-at-most-three selector, not an implicit or compressed instance. Syntactic connectivity does not imply an irreducible connected core, and our construction deliberately includes redundant connection clauses. Marginal balance does not imply independence. The entropy rate tends to one, but the guaranteed model density may still be subexponentially small, not inverse polynomial. The model count here is not the count of hard formulas.

For each fixed k>=1 and fixed epsilon>0, some fixed K>=k and n0 give an injection from B_K(n) into B_k(h(n)) intersect the above class for every n>=n0. In particular P!=NP is equivalent to the existence, for every fixed stage exponent, of unbounded residuals even within this high-entropy class (for any fixed positive rational epsilon). This is an exact reformulation of the original all-exponent question, not an unconditional assertion of such residuals.

## 2. Complement-symmetric encoding of arbitrary SAT

Use source variables represented by target bits y_i (1<=i<=n) and one reference bit z at index n+1. Interpret the source assignment as x_i=y_i XOR z. Negation of a represented literal corresponds to negation of y_i. Write NAE(l_1,...,l_j) for the relation that the truth values of the listed literals are not all equal. For j=2 or 3, implement it by the two clauses (l_1 OR ... OR l_j) and (not l_1 OR ... OR not l_j). This is globally invariant under simultaneous complement of every variable.

Allocate one fresh auxiliary u_c for EVERY possible source ternary clause c, even if not selected, in the original pool order. Thus the base variable count is b=n+1+8 binom(n,3). For each selected source clause use:
* unit l: NAE(l,z);
* binary (l_1 OR l_2): NAE(l_1,l_2,z);
* ternary (l_1 OR l_2 OR l_3): NAE(l_1,l_2,u_c) AND NAE(not u_c,l_3,z).

For the first two cases the condition says that some literal differs from z. For the third, the two ternary NAE constraints have an extension in u_c exactly when the four literal truth values l_1,l_2,l_3,z are not all equal. Indeed if l_1=l_2=a, the first forces u_c=1-a and the second becomes NAE(a,l_3,z). If l_1!=l_2 the first is always true and some u_c makes the second true. Thus the result is equivalent under projection to the original clause. In orientation z=0, the represented truth values are exactly the source literal values. In orientation z=1, they are all complements of those source values; the NAE condition is invariant. Each satisfying source assignment has at least one base extension in each orientation. The base formula is invariant under global complement and has a model iff the source does. Its model count M_base(p) satisfies M_base(p)>=2M(p); it need not equal 2M(p) because the split NAE constraints and unused auxiliaries can have multiple extensions. This is not a parsimonious reduction.

For fixed n, the selected source clause bits are recoverable from distinct marker clauses: for a unit or binary, use the first NAE clause (the sign of z there is positive); for each ternary use the first clause of its first NAE, containing its dedicated positive auxiliary u_c. Distinct source clauses have disjoint groups of encoded clause positions. The first and second ternary supports differ since only the second includes z. Normalize literal order by absolute variable index; all variables within each clause are distinct.

## 3. Make every bit essential and give a large connected entropy reservoir

For every base bit v allocate a distinct copy bit v' at index b+v. Include equality v=v' by two binary clauses. For each base v!=z add NAE(z,v,not v'), which is automatically true under the equality. These explicitly redundant clauses connect the base copy pairs to z in the syntactic co-occurrence graph without changing their extensions. The z pair is connected by its equality. The copies extend every base model uniquely, and flipping any single base or copy bit in any model violates its equality. In particular even a base auxiliary associated with an unselected source clause is not an unconstrained target variable.

Introduce a control bit t at index 2b+1 and R>=1 new bits s_1,...,s_R. For each j select NAE(z,t,s_j). If t differs from z, all R bits may be assigned arbitrarily; if t equals z, every s_j must differ from z. This gives exactly 2^R+1 assignments to the reservoir including t for each base assignment. All reservoir variables appear in actual nontrivial constraints. Given any base model, choose t=z and all s_j=1-z; flipping any s_j violates its NAE. To show t is essential, choose t=1-z and s_1=z, then flipping t violates the first NAE. All reservoir variables are adjacent to z syntactically. Together with the copy pairs, every target variable is semantically essential in the stated sense; this does not say every bit is essential on every model.

The final variable count is h=2b+1+R, the exact model count is M_target(p)=M_base(p)(2^R+1), and any model projects by x_i=y_i XOR z. The entire selected clause set is closed under literalwise sign reversal, so global complement acts as a fixed-point-free involution on the model set. This gives equal counts of zero and one for each coordinate, independent of the source. Every copy, connection and reservoir clause uses a new variable and therefore cannot collide with the base marker clauses. The entire mapping p->target is injective at fixed n,R by reading those markers, and polynomial-time invertible on its image. Source satisfaction is not tested by the constructor.

## 4. Exact entropy and stage transfer

Take a fixed integer a>=4 with a*epsilon>3 and R=(n+2)^a. Then b=O(n^3), h is strictly increasing, h=Theta_a(n^a), and for every satisfiable source M_target>=2(2^R+1)>2^(R+1)=2^(h-2b). Since h^epsilon >=(n+2)^(a epsilon), eventually 2b<=h^epsilon. Consequently M_target>=2^(h-h^epsilon) for all sufficiently large n. For the uniform distribution over models both Shannon entropy and min-entropy equal log2 M_target. The density in the full assignment cube is at least 2^(-2b), hence at least 2^(-h^epsilon); this lower bound does NOT imply efficient uniform sampling hits a model. It is important not to confuse entropy rate 1-o(1) with inverse-polynomial density.

The constructor emits the entire target tape 1^h 0 plus all width-one through width-three selector bits. With L(n)=Theta(n^3), L(h)=O_a(L(n)^a) and O(L(n)+R) selected clauses, constructing the full tape is polynomial for fixed a. For example enumerate source clauses and generate selected base records, copy and reservoir records; sort by normalized pool order and merge against the target pool. Binary counters and indices, output length, and sequential tape work all have polynomial bit cost.

For fixed k,a, a single fixed deterministic source algorithm constructs that target on any valid p, runs the actual U stage k ceil(log2 L(h)), projects any verified witness and verifies the projected source assignment. If no target witness is returned, it returns FAIL, not an UNSAT conclusion. The fixed stage cost is polynomial in L(h) by the established same-U simulation bound; the entire source wrapper is polynomial in L(n). A fixed general three-symbol tape description implements it with polynomial overhead and final n-bit output positioning. Thus some fixed K>=k absorbs its runtime and description length into the exact original stage K ceil(log2 L(n)), enlarging K for small sizes. If p belongs to B_K(n) the target cannot be solved by its own stage k, since then the wrapper produces a verified source witness. Injection gives the stated cardinality transfer. Neither K=k nor a concrete compiled description is claimed.

By the earlier all-exponent equivalence, P!=NP implies unbounded B_K(n) for every fixed K, so the image has unbounded stage-k failures for every fixed k and fixed epsilon. Conversely such failures for every k imply P!=NP because they are failures on a subset of the original domain. The same proof says a uniform polynomial solver on the promised class of satisfiable targets alone (returning verified witnesses or failure on unsatisfiable inputs, with a uniform polynomial clock) would solve arbitrary SAT in polynomial time. This promise does not require computing model counts or checking entropy at runtime: construct the target, run the solver with its polynomial clock, project and verify. Finite exceptions can be handled separately.

## 5. What this does and does not show

The deterministic few-model isolation theorem and this high-entropy transfer concern different directions. The former reduces few-model hardness to unique hardness. The latter embeds unrestricted hardness in models with almost maximal normalized entropy, balanced one-bit marginals, connected syntactic structure and no single completely irrelevant bit. It does not show arbitrary naturally arising high-density instances are hard, nor does it remove the padding structure or make every variable mutually independent. The construction's reservoir is intentionally easy to fill, so the search difficulty is in the source projection. This demonstrates why entropy/marginal arguments alone cannot resolve unrestricted SAT, not a lower bound beyond the existing finite 52..233 cubic interval. No unbounded cubic-stage failure or P vs NP separation is proved.
