## Bounded mission
Test whether a fixed physical descriptor can preserve changing joint separator identities in a nested width-two bag tree, and recover all original introduced variables without host handoffs. Isolate overlap and topology by fixing Boolean domains and one explicit local mask per bag. Acceptance: all three parent-pair maps exercised, intrinsic running intersection, full tape checkpoints, individual direct global-assignment oracle agreement, separately implemented Python relational replay, exact charged phase checks, malformed and conflict controls. Stop after finite audit. This is standard tree decomposition dynamic programming implemented with fixed tape rules; no independent agents or formal certification claimed.

## Contract and running intersection
Root has ordered scope (x0,x1,x2). Every nonroot bag retains an ordered pair of its parent's three variables and introduces exactly one globally fresh Boolean variable as its last coordinate. Pair codes 0,1,2 select parent coordinate positions (0,1),(0,2),(1,2), respectively; code 3 is root only. The nested grammar assigns fresh variable identities by introduction order, not by externally supplied IDs. Thus for any variable x, bags containing x form a connected subtree: x is introduced once, and can occur in a descendant only if every intervening bag retains x. Distinct child subtrees share no variables outside their parent scope. This proves running intersection by construction, not validation of arbitrary user-provided tree decompositions. Repeated labels, alternative pair orderings, bags of other sizes, larger rank domains and original F038 input are outside this grammar.

Each node is token 10, two code bits as tokens 00/01, eight local mask bits as tokens 00/01 in binary triple-index order, zero or more recursively encoded children, then 11. Exactly one root. Root code must be 3; every child code must be 0..2. Raw binary contiguous from head zero, blank elsewhere. N=24q for q>=1 bags; number of distinct variables n=q+2. Each mask is one complete local predicate, not supplied projected feasibility; multiple factors in one bag would require explicit conjunction into its mask by a separate producer. Success emits the three root bits, then each introduced variable bit in preorder, contiguous at halt head. Valid infeasible and malformed input halt on blank, not distinguished by output; rejection need not clear scratch.

## Invariant and correctness
Let B_v(t) be the local triple predicate. For each child c, let pi_c(t) be the pair selected by its edge code. Define
 F_v(t)=B_v(t) AND AND_c [OR_(a in {0,1}) F_c(pi_c(t),a)].
By induction on completed subtrees F_v(t) represents exactly the existence of an assignment in the subtree consistent with the full tuple t. For the inductive step restrict any satisfying assignment to each child, and conversely combine compatible child assignments conditional on t. Running intersection ensures no remaining shared variables can conflict. The root is satisfiable iff F_root has a positive entry. Choose least feasible root tuple, then for each child choose least feasible last bit conditional on the selected pair of its parent. This yields a satisfying assignment by induction downward, and the lexicographically least assignment in introduction order because child subtrees have disjoint introduced variables conditional on the parent.

## Physical mechanism
Reuse six-cell REX compiler. The parser writes active A(code) openings, preserves code bits, stores each local bit in T(raw,feasibility) initially equal, and uses X for pending close. On closing a child, nearest active opening is marked H(code). For each of eight parent tuple ranks j, finite control maps code and j to the corresponding two consecutive child T entries (last bit 0,1). Reads their feasibility OR, scans left through H to nearest active parent opening, locates its j-th T entry and conjoins the OR into it while preserving the raw bit. Return to unique H; repeat for all eight ranks, then mark F(code) and restore close C. Parent retains only the conjunction of precisely its processed children. Root close installs R after requiring end of raw input; all T entries now represent exact conditional subtree feasibility. This is a fixed finite-control table of three pair projections, not arbitrary supplied compatibility tables or independent unary marginals.

Backward pass reads least positive root T, marks root opening V(rank), writes three output tags O(raw,feasibility,bit) into the first three T cells, preserving both existing tracks. At each child opening F, temporarily mark H(code), scan left to nearest V parent, map its selected rank to the same child pair as forward phase, select first feasible child entry with that pair. Mark child V(rank), put its introduced bit in first T as O, and descend. On close C mark Y, pop nearest V to G, restore C and continue. All selected ancestors reside on tape; no host supplies ranks or topology. Cleanup removes L, serializer projects only O bits and clears all scratch. All valid loops progress by a node, one of finitely many local ranks or a bounded scan. Root/child code errors, extra roots, truncation and illegal data tokens rejected in designated controls. Sparse default rejecting rules may halt at a partial block; exact aligned phase clocks asserted only on valid inputs, not malformed. Full arbitrary parser formal verification remains open.

## Charged resources
Each close performs eight parent-tuple updates, each involving a constant number of O(N) scans. Each backward open/close likewise uses constant-many O(N) scans. Parsing and cleanup O(N); thus logical work O(N^2), with fixed moving/staying costs 16/11. Preparation P=7N^2+17N+3 on nonempty input. Serializer exact
 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+n+3,
 w=6, e_i marks output position (first three local entries at root, first local entry elsewhere), c_i=sum_(j>i)e_j.
Output head -6N-n-2. Since n<=N, serializer O(N^2). Preparation supplies quadratic lower bound for this implementation. Overall valid physical time Theta(N^2), visited span O(N), including UNSAT preparation. No dependence on tree depth in descriptor; time bound is for explicit Boolean triple grammar and not unrestricted SAT, variable-size tensors, or original U-stage admission.

## TECT-X adversaries
Three children sharing different parent pairs require x0=x1, x0=x2 and x1!=x2, respectively (masks 195,195,60). Each alone is satisfiable and has both unary marginals full. All three jointly impossible. Actual physical run rejects; this demonstrates the necessity of consistent complete parent tuples across changed separators, not a universal complexity lower bound. Separate mixed-depth tree: root 101, child retaining (0,2) introduces 0, its child retaining (1,2) introduces 1, root's second child retaining (0,1) introduces 1. Actual output 101011. This exercises all three maps, a change of coordinate identities along a path, and sibling branching.
