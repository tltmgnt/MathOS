## 1. Parameterized original raw selector grammar
For k>=1 rank coordinates and common m>=2, use k*m one-hot X bits, k*(m-1) cumulative OR bits Y, m pin bits P and two guards. Hence n=(2k+1)m-k+2. The original unary-header and complete signed distinct-variable clause pool are retained, in exactly the same order (arity, increasing variable tuple, sign tuple). Raw length is exactly L=n+1+2n^2+8*C(n,3). The host decoder receives k,m explicitly, checks their derived header and raw length, every mandatory clause and all four lifted clauses per pin, and accepts only additional negative clauses on one to three distinct X groups. It rejects extra positive clauses, same-group optional clauses, incomplete pins, missing mandatory clauses, and malformed length/header. The binary-domain reduction below fixes m=2, so k=(n-4)/3 is uniquely recoverable from the header; no external dimension hint is necessary for that subfamily. For general m,k the API parameters are not automatically inferred. The original D6X machine still assumes k=9 and n=19m-7.

For each group enforce pairwise at-most-one X, equivalences Y_0=(X_0 OR X_1), Y_j=(Y_(j-1) OR X_(j+1)), and final Y=1. Three CNF clauses per OR equivalence suffice. Thus exactly one rank is chosen, and its cumulative Y bits are unique. Force the two guard variables false. Each four-clause lift of a pin literal over all guard sign combinations forces the pin literal, so pins are unique. For any rank tuple z and specified pins the original-format Boolean witness W(z) is uniquely defined: X one-hot, Y_j=[z_g<=j+1], pins specified, guards false. Conversely every satisfying assignment of the mandatory clauses equals one such W(z). An optional negative clause on X ranks forbids precisely the indicated rank tuple. This proves a bijection between satisfying rank assignments and original raw-formula models. Fixed-nine backward compatibility follows by substituting k=9 in the indexing and clauses, independently regression-tested below.

## 2. Polynomial, model-bijective reduction from 3-CNF
Given a width-at-most-three CNF, renumber its distinct occurring variable identifiers to 1..k (arbitrary-length signed decimal identifiers supported; never allocate by largest identifier). If no variables occur, introduce one dummy forced false, retaining exactly one extension of the empty assignment when the source is satisfiable. Remove duplicate literals within a clause and discard tautological clauses; an empty clause becomes two unary forbiddances on group zero. Fix m=2, pins zero. For a nontautological nonempty source clause with literal x_i or NOT x_i, choose its falsifying rank r_i=0 or 1 respectively, and emit the optional clause consisting of the negative X_(i,r_i) literals. Every such target clause is legal with distinct groups. Under W, it is false exactly when every source literal is false. Therefore F(z) iff the target raw formula is satisfied by W(z). The mandatory constraints give the converse and uniqueness, including the forced dummy case. Decode by reading the selected rank in each group, then restore source labels; projection alone is not a verifier and assumes a satisfying target witness. Unused variables not occurring in the formula are outside the model-count convention of the sparse API (explicit indexed lift includes all declared k variables).

At m=2, n=3k+4 and L=Theta(k^3). Each occurring identifier consumes at least one input symbol; the sorted renumbering, O(k) mandatory selected clauses, at most one optional clause per nonempty non-tautological source clause (two for empty), and writing the full O(k^3) pool are polynomial in the source description length. In an ordinary bit-cost model include polynomial identifier sorting/lookup overhead; no unit-cost unbounded integer assumption is needed. The inverse witness map is polynomial as well. The representation is in NP by directly checking its raw clause pool and structural header. Since width-three CNF SAT is NP-complete, the variable-k, m=2 normalized raw selector subfamily is NP-complete under polynomial reductions. This is a representation result, not a polynomial decision algorithm, not a reduction into the old fixed-nine family, and not P=NP. The executable JavaScript reference is limited by host memory and array sizes; the proof is about the mathematical uniform construction.

## 3. Variable-coordinate separator reference and boundary
The host reference computes the primal clique graph of active factors, independent components, and enumerates at most two separator vertices per component. No bitmask of k vertices or fixed nine-element array. For each candidate separator S it partitions the residual graph into blocks B_j. For each fixed separator rank assignment all non-separator-only factors belong to exactly one block, so independent feasible extensions combine; separator-only factors are checked once per assignment. Enumerating separator assignments and retaining the lexicographically least full component assignment (not the first feasible separator assignment) preserves global lexicographic minimality. A component with no beneficial separator uses full lexicographic tuple enumeration. The checked candidate ceiling is min(m^|C|, m^|S|*(1+sum_j m^|B_j|)) over admitted plans, summed over independent components. Planner tests O(k^2) candidate subsets per component; graph scans and factor checks are polynomial in explicit raw input length. If each chosen separator has size<=h and residual block size<=b (take b=component size for no-separator plans), summed enumeration ceiling is O(k*m^(h+b)). For fixed h,b this yields a polynomial HOST algorithm on that structural subfamily; it supplies no uniform physical clock bound.

## 4. Explicit infinite obstruction to this enumeration policy
For every k>=4,m>=2, impose equality on EVERY pair of rank variables, and forbid ALL diagonal tuples (a,a,a) on the first three variables. These are legal optional clauses (all unequal pair tuples forbidden, all m diagonal triples forbidden). Full GAC retains all m values: equality has equal-value supports; ternary disequality-from-diagonal has supports by choosing another coordinate unequal. It terminates after one pass with zero deletions. Equality implies every globally satisfying tuple is diagonal; ternary factor forbids it, so UNSAT. The primal graph is K_k; deleting at most two vertices leaves a connected nonempty graph. There is no admitted split. The implemented full-tuple fallback therefore tests exactly m^k assignments before exhaustion. For m=2 this is 2^k=2^Theta(L^(1/3)); with variable k no fixed-degree polynomial candidate bound survives for this policy. This does not lower-bound arbitrary SAT solvers, other enumeration methods, or a variable-k physical implementation. In particular equality substitution immediately refutes this particular family, and the current D6X direct-extension worker is not the measured host enumeration. The obstruction only falsifies extension of the capped-separator/full-tuple ceiling into a universal polynomial guarantee.
