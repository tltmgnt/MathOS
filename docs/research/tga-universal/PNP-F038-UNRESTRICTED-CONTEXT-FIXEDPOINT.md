## 1. Result

On the full nine-group family (n=19m-7, L=Theta(m^3), arbitrary selected negative cross clauses of widths 1..3, inherited fixed one-hot/OR/pin/guard clauses), define a deterministic iterative reduction using local support consistency and contextual signature dominance. It has a general SAT version and a unique-promise version. Let k be the minimum remaining group size at the respective fixed point (zero on early empty-domain termination). For every fixed rational 0<delta<1, the preprocessing and eight-group branch search can be implemented by a fixed original three-symbol single-tape program with time

    O((m^8 + k*m^(8+delta)) polylog(m+2)).

The general version preserves satisfiability, the unique version preserves the unique tuple on the unique-SAT promise. For any fixed 0<epsilon<=1, k<=m^(1-epsilon) implies eventual exact cubic-stage success on the corresponding SAT promise. The preprocessing is charged even if a linear number of rounds is needed. This extends the previous raw-signature cutoff: there are unique inputs with all raw minimal frontiers of size m but reduced domain sizes exactly one. On the other hand, an explicit family of unique SAT selectors with every domain size m survives the entire new reduction unchanged, for arbitrarily large m=2^b. Those instances have a cheap direct algebraic solver, so a full-width fixed point is not a hardness certificate.

## 2. Local tables and domain semantics

For every nonempty subset H of at most three distinct groups and every tuple z of digits on H, define A_H(z)=1 iff no selected negative cross clause supported on a subset of H is violated by z. In particular this closes higher-width tables under all inherited unary and binary cross constraints. These tables use actual normalized selector bits and not the inherited auxiliary clauses, whose extension is unique for each surviving full tuple. All global solutions are locally allowed on every H; conversely a full tuple locally allowed on every H satisfies all selected cross clauses. The total number of table entries is O(m^3) because the group count is fixed. No new clauses or variables are required.

Start domains D_g=[0,m). At each round first use a snapshot of the current domains to compute support sets for each H: retain a digit in group g in H only if some locally allowed tuple on H contains that digit and all its coordinates lie in the snapshot domains. Intersect all such support sets for a group with its old domain, simultaneously for all groups. This includes the singleton tables, so unary-dead digits are removed automatically. Every globally satisfying tuple in the old product survives this support step exactly: its projections are certificates of support. An empty domain certifies UNSAT in this step, relative to the input to that step.

Next, using the post-support domains as a fixed snapshot, form contextual signatures F^D_g(a) for each surviving digit a. For every H containing g, list the complement of A_H on every context of digits from the other groups of H restricted to their snapshot domains. Order H by size and lex order, contexts lexicographically. Signatures are aligned within a group. Define a <=_D b iff F^D_g(a) is coordinatewise <= F^D_g(b). If a satisfying full tuple within the snapshot uses b, replacing b by a keeps every local projection allowed: for supports containing g, the corresponding bit for b was zero and so the bit for a is zero; other supports are unchanged. This proves the substitution property directly with arbitrary overlapping original ternary constraints.

In general mode retain the least digit of each distinct inclusion-minimal signature class in each group. Every deleted digit has some retained weak dominator. To preserve SAT under simultaneous replacement, substitute the chosen representatives one coordinate at a time in a solution of the old snapshot. Each intermediate tuple remains in that snapshot; dominance is defined over ALL contexts in that snapshot, not just the initial tuple. The final tuple lies in the new product. Conversely the new product is a subset of the old, so no new satisfying tuple appears.

In unique mode retain only digits having no distinct weak dominator, including ties. If the current solution set has exactly one tuple, each of its digits must survive, since a distinct dominator within the old product would give a distinct solution. Inductively the unique original tuple survives every round. This version may discard all solutions on a multi-model input; its empty-domain outcome is NOT a certificate that the original instance is UNSAT outside the unique promise. General mode never makes that mistake.

Repeat support and dominance until a domain is empty or an entire round changes no domain. All domains only shrink; any changing nonterminal round deletes at least one of the initial 9m digits. At most 9m+1 rounds are needed including the final unchanged round. The fixed point here is for this specified synchronous rule and tie break, not a claim of confluence for arbitrary deletion orders. Its domains are deterministic functions of the original selector. Restricting the original selector by negative unary bits for removed digits implements exactly this domain product without changing normalized length. The unique model, when promised, retains its original full witness.

## 3. Charged implementation and exact cubic consequence

Use a fixed number of sequential multitape bit tapes. Parse the actual normalized selector and extract cross records with binary counters as in the parent, retaining the original raw input and actual pin pattern. Construct all A_H without indexed RAM lookups: for every support H, emit an initial record for every H tuple and, for each selected clause on a subset of H, a forbidden record for each completion to H. Each selected clause of width w<=|H| generates m^(|H|-w) records; summing over all possible clauses and the constant number of H yields O(m^3) records, even in a dense selector. Sort by H and tuple and OR the forbidden flags, then complement. Sequential external merge sorting costs O(m^3 polylog L) bit steps and visited span. This precomputation is done once.

Per round:
1. Scan the table entries, checking current domain bits for at most three digits. Even sequentially rewinding and scanning the O(m polylog L) domain array per entry costs O(m^4 polylog L) bit steps. Mark supported digits per H using a sequential flag array of O(m polylog L) bits, charging the same scan cost per update. Intersect supports by sequential scans of these arrays. Keep the snapshot separate from the output flags.
2. With the new snapshot, emit at most three records per table entry (one per participating digit), retaining entries whose other digits lie in the snapshot and whose distinguished digit survives. Again domain checks cost at most O(m^4 polylog L) total. Sort by group, distinguished digit, H and context and compact aligned signature vectors. Each group has at most m signatures, each O(m^2) bits. For each distinguished digit copy its vector and scan all other vectors of the same group, using scratch rewind and two comparison flags. Updating exclusions in order as in the parent costs O(m^4 polylog L) total, including whole-stream rewinds for O(m) distinguished digits. Produce simultaneous deletion flags, compare with the old domains and reuse scratch. Empty lists halt without any extra round.
3. All scratch and tables occupy O(m^3 polylog L) visited span on a fixed number of tapes. Use the inherited fixed-track three-symbol simulation: raw input expansion O(L^2), sweeps of O(m^3 polylog L) encoded blocks per multitape bit step. O(m^4 polylog L) work per round becomes O(m^7 polylog L) original transitions; at most O(m) rounds yield O(m^8 polylog L), including precomputation. This explicitly charges membership, flags and repeated context rebuilding; no constant-time RAM access is used. A fixed finite number of tracks and finite control suffice regardless of the number of iterations. No increasing recursion depth or program description length is needed.

If no domain is empty, choose the least group of minimum final size k. Enumerate those k digits. For each, construct an eight-group instance as in the parent signature-dominance note: restrict the remaining domains by existing negative units, keep original cross clauses not involving the pivot, discard clauses whose pivot literal does not match, project away matching pivot literals, renumber groups, sort/deduplicate, generate full local normalized selector with fixed local zero pins. The pivot is live, so a matching unary forbidden clause cannot occur. The local solutions biject to original solutions with this pivot and the retained domain restrictions. Sorting/merging and sweep simulation cost O(m^6 polylog L) original steps per branch. The fixed eight-group solver from recursive tiling at a sufficiently large FIXED depth takes O(m^(8+delta) polylog L) original steps with visited span O(m^3 polylog L). Run on its own encoded local-machine track with constant overhead per local transition, preserve the outer selector/domain markers, reuse local workspace on failure. On success recover its digits, reinsert pivot, reconstruct original OR bits and actual pins and emit the raw contiguous witness at the original halt head. The one-time output cost O(m^4 polylog L) is dominated.

The total bound is O((m^8 + k*m^(8+delta)) polylog L). At k<=m^(1-epsilon) choose fixed rational delta<epsilon/2; this is O(L^(3-epsilon/6) polylog L) since epsilon<=1 and L=Theta(m^3). The fixed description length ell is independent of m; the exact cubic clock 2^(3 ceil(log2 L)-ell)>=L^3/2^ell eventually dominates the bound. Thus on any unbounded sequence of actual cubic unique-SAT misses the unique-mode fixed point must have k>m^(1-epsilon) eventually for every fixed epsilon>0 (analogous general-mode condition for SAT misses). This necessary condition is strictly stronger as a pruning test on some families, not an assertion of sufficient hardness. No numerical threshold or compiled transition table is supplied.

## 4. Strict improvement and a cascading control

For every m>=2, impose binary constraints between consecutive groups g,g+1 allowing only (0,0), and within each of the three disjoint consecutive group triples select exactly the m forbidden triples (a,(a+1) mod m,a). The unique solution is all zero (the selected ternaries never forbid all zero). Every raw signature is live and distinct digits have incomparable raw signatures in every group: on its disjoint triple, each digit has exactly one forbidden context specific to that digit, and these contexts differ for different digits. Hence the previous raw-signature frontier has width m for both modes. The support step on the new tables removes every nonzero digit in all groups, leaving the unique solution. Both versions reach width one and then stabilize. This shows a strict separation for unbounded m, though other cheap algorithms also solve these instances.

For a separate propagation control, force group 0 to digit zero by unary clauses, and enforce equality of each consecutive group pair (all unequal binary tuples forbidden). With closure only on supports of size <=3, support information can propagate at most two positions along the chain per support round; the contextual signatures on the remaining equality-constrained live groups are incomparable whenever both domains still equal [0,m), and no additional values are deleted by dominance before their support disappears. More generally we need only the finite cascading control, which at m=2,3 takes five rounds including the final unchanged round in the specified algorithm. No asymptotic lower bound on round count is claimed.

## 5. Algebraic full-width residual: unique and easy

Let m=2^b with b>=1, identify digits with b-bit vectors under XOR, and take the nine distinct cyclic triple supports H_i={i,i+1,i+3} modulo 9. On each H_i forbid exactly the triples not satisfying

    x_i XOR x_(i+1) XOR x_(i+3) = rhs_i,

where each rhs_i is an arbitrary b-bit vector; no unary/binary cross clauses or other ternary clauses are selected. The nine linear equations have a unique solution for every RHS. To see nonsingularity, a homogeneous solution obeys x_(i+3)=x_i XOR x_(i+1). Successively expanding gives x_(i+7)=x_i for every i. With cyclic period 9, gcd(7,9)=1 forces a constant sequence, and the equation on three identical values forces that constant zero. The linear map on the finite vector space is injective and therefore bijective. This holds independently on every bit.

Every digit has local support in every table: for constrained triples choose either other digit arbitrarily and solve for the third, while all other tables are unconstrained (no smaller forbidden supports). All domains therefore remain full after support pruning. For any two distinct digits in a group, on a cyclic triple containing that group choose a context allowed for the first digit; it is forbidden for the second because XOR determines a unique missing digit. Reverse the roles for an opposing comparison. Thus every pair of different signatures is incomparable, both raw and contextual. The reduction stops in its first unchanged round in both modes, k=m, despite the unique solution.

This family has a fixed direct original solver: scan canonical triple positions and find one allowed triple for each cyclic support, recovering its RHS by XOR (each such table has m^2 allowed entries); solve the fixed nine-by-nine invertible binary system on the O(log m)-bit digit words by fixed elimination/XOR, then reconstruct the original pins and witness. Sequential multitape O(L polylog L), charged original sweep simulation O(L^2 polylog L), fixed description. It eventually fits cubic uniformly over RHS and pins. Consequently even a full-width contextual fixed point with a unique model is not a witness-generation lower bound. A next residual analysis must address global dependencies, not merely add another small local signature test.
