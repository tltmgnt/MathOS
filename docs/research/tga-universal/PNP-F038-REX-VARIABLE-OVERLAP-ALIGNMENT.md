## Bounded hypothesis and acceptance

The variable-size alignment problem in REX-017 is decomposed into one physically executed parent-child edge with any of its three ordered pair maps. Hypothesis: a fixed transition descriptor can read original variable-length tuple labels, compare the complete retained pair with child rows, update each parent row, and recover one compatible child without a host producing projected keys or a compatibility tensor. Acceptance: raw syntax validation, exact row flags and selected support, full physical checkpoints, malformed and correlation controls, exact phase clocks and a charged resource ledger. Stop after this finite audit. This is deliberately not the full nested variable-domain worker. The MRA-X roles are used within the research cycle, not independently deployed agents.

## Contract

Input begins with two raw bits selecting parent coordinates (0,1), (0,2), or (1,2), coded 00,01,10. Then zero or more parent rows, token 110, then zero or more child rows. A row is token 011, three nonempty bit strings (each digit a 000/001 token and each field terminated by 010), then local Boolean mask token 100/101. No other tokens accepted. Input contiguous from head zero, blank elsewhere. Labels are opaque nonempty bit strings; leading zeros are significant (0 and 00 are distinct labels). This supports arbitrary finite represented label sets, not dense tensors with declared domain cardinalities. Canonical integer encoding would require a separate producer or grammar change. Missing rows denote absent assignments. Duplicate rows allowed, each with separate input identity and mask. Child coordinate 2 is fresh; only child coordinates 0,1 are matched. Empty tables valid. No external projected keys, rank counters, membership flags beyond original local predicate bits, or matching pairs supplied.

Output consists of one bit per parent row in input order, followed by one bit per child row in input order. First vector is exact rowwise semijoin; second vector marks the first compatible positive child for the first positive surviving parent, or is all zero if none. The parent selected is implicit as first positive flag. Selection is input-order, not numeric rank order unless input is appropriately sorted. Output is a local certificate/index, not an assembled original SAT assignment. Valid negative instances produce zero flags, rather than halt rejection. Empty tables produce empty output if both are empty. Malformed raw input halts on blank; rejection need not clear all scratch. Output alone may not distinguish empty valid output from rejection.

## Semantics and physical invariant

Let p_i be a parent triple, u_i its local mask, c_j a child triple, v_j its local mask, and pi_k the selected parent pair. The exact flag is
 f_i = u_i AND OR_j [v_j AND pi_k(p_i)=(c_j[0],c_j[1])].
The output child flag at j is 1 iff j is the first supporting child of the first i with f_i=1. An OR over an empty child list is false. This is the semijoin/projection needed at one edge of the REX-017 recurrence, and preserves duplicate parent identities. For each positive parent row the existence of a compatible child extension is exactly the existential quantification of the fresh child label.

Reuse the six-cell REX compiler. Parser physically chooses field tags A/B for the two retained parent positions, X for the discarded parent position, C/E for the first two child positions, X for the fresh child position. Every original digit is preserved. Each row has its own header P/H and local mask M/N. Parser installs L/R and validates exactly three nonempty fields and one flag per row, one separator, and code range. During forward phase mark current parent Q and current child K. For each chosen parent field, find first unprocessed digit inside Q's row, mark it UA/UB and hold its bit in finite control; find first unprocessed corresponding child digit inside K's row, compare and mark UC/UE. Simultaneous exhaustion required. Thus a successful comparison means equal lengths and equal digits, not just a common prefix. Field A is compared to C and B to E independently but in the SAME two rows. Unprocessed/used tags progress monotonically for each comparison; searches stop at row mask. If either field mismatch, restore used tags on both rows and advance child. A child with local mask 0 is skipped; disabled parent becomes T00 without comparing. For a positive parent with a compatible positive child write T11; after exhausting children without support write T10. All other rows, local bits, tuple labels and delimiters preserved. This proves f_i exactly by induction over child attempts and parent rows.

After forward completion, select first T11 (if any), re-run alignment on that parent, mark first positive matching child's N1 as O1. Restore both row headers and temporary cursors. Thus output witness corresponds to actual positive row identity; no host handoff. Full forward and backward snapshots check every tag, including all original digit and mask tracks (O1 implies raw N1). Serializer projects T tags to computed flag, N tags to 0, O1 to 1, skips all other tags, removes input/history and returns contiguous flags. All valid scans stay in a bounded region, each comparison consumes a digit or finishes, each failed comparison advances a child, each forward iteration advances a parent. Repeated backward comparison occurs only once for selected parent. Therefore termination. Syntax and explicit-row label matching checked, not dense tensor completeness or arbitrary tree-decomposition validation.

## Charged resources — new cost obstruction

Let N be raw bit length, P and C row counts, l_i/r_j the encoded lengths of individual rows. For each pair of rows, comparison and restoration costs O(N*(1+min(l_i,r_j))) by constant-many sentinel scans per compared digit, plus O(N) row setup/restoration; conservatively O(N*(1+l_i+r_j)). Sum over all pairs gives O(N*[PC+C*sum_i l_i+P*sum_j r_j]) = O(N^3). Backward adds at most one parent scan. Parsing O(N). Physical moves/stays cost 16/11; preparation exactly 7N^2+17N+3 for valid nonempty input; sparse serializer with w=6 costs 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, H=P+C, e_i output indicator, c_i=sum_(j>i)e_j. Output head -6N-H-2, including empty output. Thus physical time O(N^3), Omega(N^2) from preparation, visited tape span O(N). No claim of tight cubic lower bound. For fixed row counts and growing label widths, comparison bound and preparation are O(N^2); scaling below tests this narrower regime. If dense triple tables contain Theta(m^3) rows with O(log m) bit labels, N=Theta(m^3 log m); conservative time O(m^9 log^3 m). This does not establish original F038 cubic-stage admission (original L=Theta(m^3), descriptor-dependent clocks matter). Merely matching explicit rows by repeated global sweeps is not enough to preserve the desirable quadratic explicit-mask resource bound of prior restricted workers. Need a more efficient physical join or rank-indexed traversal, plus nested stack integration and original input producer. This is a resource shortfall of the implemented analysis, not a universal lower bound.
