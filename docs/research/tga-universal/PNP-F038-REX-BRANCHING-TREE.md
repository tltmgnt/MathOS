## Contract
Every vertex has Boolean domain {0,1}, a two-bit unary allowed-value mask U and four edge bits E(a,b) in order 00,01,10,11, where a is the child value and b the parent value. Root edge bits are present but ignored. A node is encoded by token 10 (open), six data tokens 00/01 carrying the unary and edge masks, zero or more recursively encoded ordered children, and token 11 (close). Exactly one root, arbitrary finite depth and degree. Raw binary input is contiguous from head zero, blank elsewhere. N=16n bits for n>=1 nodes. Valid output is the lexicographically least satisfying Boolean assignment in preorder, emitted contiguously at halt head. Valid infeasible and malformed streams halt on blank; rejection need not clear scratch. Empty input is invalid. The grammar does not describe cycles, arbitrary factor scopes, non-Boolean domains or original normalized F038 selector inputs. Input has no supplied feasibility messages, stack, topology index or witness flags.

## Fixed physical construction
Use the REX block compiler over {0,1,blank}, five-cell blocks, 21 logical symbols. The parser and forward pass are integrated. At open, tag the opening A (active), preserve unary bits as T(u,u) and edge bits E(e), then scan child tokens. At close, mark temporary X, scan left to nearest A. This is the matching opening: previous completed descendants have opening F, never A. Read the two accumulated feasibility bits and four edge bits in fixed control, compute outgoing two-bit message for parent. Return left to A, set F (finished), continue left to nearest active ancestor A, or L if this was root. Conjoin the outgoing message into that parent's two T(u,m) cells, preserving unary bits; scan right to the unique X, restore it as C and resume parsing. Thus A openings encode an unbounded active stack on the tape without an externally supplied depth counter. On root close require immediate end of raw region, install R. No extra roots, unmatched closes, incomplete headers or missing closes accepted. All finite scans are bounded by sentinels or a grammar-checked unique cursor; raw malformed tokens or premature blank reject. The compiler performs raw preparation before this phase.

Define F_v(a)=U_v(a) AND AND_{c child of v} M_{c->v}(a), and M_{v->p}(b)=OR_{a in {0,1}} [F_v(a) AND E_v(a,b)]. At entry to a node, T records U. Each processed child updates the same two T entries by conjunction with its outgoing message, not by a projection that loses the shared parent rank. The active-stack invariant associates each active node with the conjunction of precisely its already completed children. When a node closes, every child is complete. By induction on completed subtrees, F_v(a) exactly indicates a satisfying assignment to that subtree with v=a. The induction uses disjoint child subtrees conditional on v, so compatible extensions can be combined. Hence root is satisfiable iff at least one root T message bit is 1. The full physical forward checkpoint preserves original factor bits, topology, and exact feasibility vectors for every node, including UNSAT inputs.

Backtracking begins at root opening F. Read its retained feasibility bits and choose least feasible root rank; if none reject. Change opening to active selected tag V0/V1. At a child opening F mark H; find nearest V parent to left, read selected parent rank, return to H, use child's retained F_v and original edge mask to choose least feasible compatible child rank. Mark V and descend. On close mark Y, find nearest V to left, finalize it as W0/W1, return to Y and restore C. This is a second tape-resident stack with the selected ancestor values. Every choice extends the already fixed parent and has a valid subtree extension; independent siblings can be joined. Choosing least feasible at every node yields the least preorder assignment (induction by subtree independence). The backward checkpoint preserves all masks and completed F_v values while opening tags record the selected bits. The sparse serializer emits W bits in original preorder and erases all other symbols, including history. Unlike REX-011, no separate predecessor edge tags are necessary: the two exact feasibility bits and the four retained edge bits suffice to reconstruct the local choice at constant logical work once read. No host transfer, reset, externally provided flags or parent pointer is used during physical computation.

## Resource ledger
The parser makes O(N) token/header steps. Each node closes once; the constant number of scans to find current A, parent A and X are each O(N), including on a high-degree or deep tree. Backtracking visits each open/close once, with O(N) scans for H, V, Y. The remaining cleanup is O(N). Thus logical time O(N^2); compilation uses 13 physical transitions per moving logical transition and 9 per staying transition. The inherited preparation is exactly P=6N^2+15N+3 for nonempty input; it already gives a quadratic lower bound for this specific implementation. Success serialization is exactly 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+n+3, w=5, e_i=1 at node-opening second token positions, c_i=sum_(j>i)e_j. Thus O(N^2); the output positions may vary by shape even at fixed n. Work region includes only L, source, R, with linear compiler input/output span. Overall valid physical time Theta(N^2) and visited tape span O(N). Unsat has no serialization; preparation still quadratic. This is a bound for explicit Boolean tree mask input, not unrestricted SAT, arbitrary tree domain sizes, arbitrary treewidth or original selector stage admission.
