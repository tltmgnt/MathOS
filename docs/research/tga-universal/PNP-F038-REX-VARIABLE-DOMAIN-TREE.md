Success requires arbitrary finite positive rank cardinalities, arbitrary finite rooted ordered topology under the specified grammar, actual physical rectangular checks, shared-parent conjunction, same-tape witness reconstruction, full tape checkpoints, direct predicate and Python reference agreement, and charged resources. ## Input and output
A node begins with token 10, then a nonempty sequence of data tokens 00 or 01 representing unary membership by rank, followed by 11. Next, for each parent rank b in order, a column of data bits E_v(a,b) in child rank order, terminated by 10. The entire edge section ends with 11. Root has zero columns; each nonroot must have exactly d_parent columns, each of length d_v. After the edge section come recursively encoded children in order, then token 11 closing the node. Exactly one root. Positive finite rank domains d_v>=1, no predeclared dimensions, topology pointers, messages, candidate flags or witnesses. N=2*(sum_v(d_v+4)+sum_nonroot d_parent*(d_v+1)) raw bits; H=sum_v d_v. Input contiguous from head zero, blank elsewhere. Success emits H bits (one-hot per vertex in preorder), lexicographically least feasible assignment by ranks. Valid infeasible and malformed streams halt on blank (not distinguished by output alone); rejection need not clear scratch. Empty domains, arbitrary labels without encoding, cycles, higher-arity factors and original F038 selector grammar outside scope.

## Construction and invariant
Reuse REX block compiler, 38 logical symbols, six-cell codes. Parser tags unary data T(u,u), edge bits E0/E1 and delimiters, opening A, close X. The nearest active A to the left of X is the closing node (completed nodes F); change it to H. Nearest earlier active A is its parent, change to B. For root, require empty edge section and immediate raw end after its closing delimiter, then install R. No depth counter in finite control.

For each nonroot v, the parent rank cursor Q and edge column are traversed in lockstep. In a column pair every child unary message entry (C cursor) with exactly one edge bit (K cursor). Read via sentinel-bounded scans from L; finite control holds only feasibility and hit bits. Advance both; require simultaneous end at unary delimiter D and column delimiter J. Mark the least feasible compatible edge entry P (its original bit is 1); restore all other edge bits. At end of column update the current parent T(u,m) to T(u,m AND hit). Require parent rank and column sequence end simultaneously at D and S. Restore parent B to A and child H to F, close X to C and resume parsing. A missing column, nonrectangular length, missing header/delimiter, incomplete close or extra root rejects. No early UNSAT exits before dimensions are checked.

For each active node v the T message bits equal U_v(a) AND the conjunction of outgoing messages of already completed children at the same rank a. The child message is OR over a of F_v(a) AND E_v(a,b). Pair alignment computes it exactly for each b; P records its least compatible child rank. When v closes all children are complete, so by induction F_v(a) is exact feasibility of its subtree conditional on a. Child subtrees are disjoint given parent rank, so compatible extensions can be joined. At root choose least positive T11, or reject. This proves correctness of the forward phase for every valid finite tree in the grammar.

Backtracking uses opening V for selected active nodes and G for popped nodes. Root marks its chosen unary value W; W implies original unary and feasibility bits both 1. On child F mark H; find nearest V parent, temporarily B. Repeat rectangle alignment with QW for selected parent rank, C/CW for child values, KP for predecessor edge. On selected column's P mark the corresponding feasible child unary W, restoring P and all other bits. Other columns cannot select a witness. Require a hit in the selected column; restore parent V and child V, descend, and on closing C mark Y, pop nearest V to G, restore C and continue. Induction gives exactly one selected feasible rank per node, satisfying each original edge and unary factor. Least local choice conditional on fixed parent gives least preorder assignment, by subtree independence. Original mask bits, nested topology, F messages and predecessor P marks remain recoverable until serialization. Cleanup removes L and projects W to 1, T to 0, all other tags to no output. No host handoffs or externally provided ranks. Valid loops progress by token, edge entry, column or node, and scans bounded by region; thus termination. Malformed controls test rejection, not a complete independent parser certification.

## Resource ledger
Each forward edge entry is visited in a constant number of cursor-pair operations, each with O(N) sentinel scans; each parent rank corresponds to an explicit column so total per-column overhead O(N^2). Each node close uses O(N) scans; parser O(N). Backward repeats alignment once per edge rectangle and uses O(N) scans per node, so O(N^2) logical work. Physical moving/staying costs 16/11, respectively. Exact preparation P(N)=7N^2+17N+3. Successful serializer costs 2wN+2w+2 + sum_(i=0..N-1)[2w(i+1)+2c_i+2e_i+4]+H+3, w=6, e_i=1 at unary value positions, c_i=sum_(j>i)e_j. O(N^2) since H<=N. Successful output head -6N-H-2. Preparation provides Theta(N^2) lower bound for this implementation even on valid UNSAT. Thus valid physical time Theta(N^2), visited span O(N), no growing batch workspace. For uniform m and n>=2, N=Theta(n m^2) and time O(n^2 m^4). This covers tree-structured unary/binary tables, not arbitrary treewidth or original selector input. The standard reference reverse-preorder elimination enumerates d_v*d_parent candidates per nonroot and d_root at root. No actual original U-stage admission or unrestricted polynomial SAT follows.
