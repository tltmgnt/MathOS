## 2. Constructive discovery: bounded joint theorem

Pad to M least power of two >=m; B largest dyadic B^3<=m^2. On a projected aligned cube D of side t<=B and a real key z=(a,c), define X_D(z) as all real x in current x interval for which every original support contained in A union {x} is allowed at z,x. Define Y_D similarly. Check all A-only supports; padding excluded. These are the exact independent extension masks of the parent, not globally feasible digit sets. For each original support S containing both x,y and contained in P, define G_S(z) as its forbidden pairs inside X_D times Y_D. Because supports have width <=3, each such S contains at most one coordinate of A. Let N=|X_D|*|Y_D|.

For a fixed dyadic capacity C, 1<=C<=m^(1/32), keep the key iff all the following hold:
(a) A-compatible, X_D and Y_D nonempty.
(b) For every S containing both free coordinates, |G_S(z)|<N. That is, no INDIVIDUAL support forbids the whole rectangle.
(c) If min(|X_D|,|Y_D|)<=C, there exists a pair in X_D times Y_D avoiding the UNION of every G_S(z). Otherwise do not claim exact joint feasibility; pass condition (c) without a test.

Call this Boolean W_(D,C)(z). The exact test in (c) checks all original supports contained in P at fixed z; no private-coordinate completion is attempted. The number of candidate pairs when invoked is <=C*t, and can always be clipped to t^2. W is a necessary condition for original satisfiability, and for min mask size <=C it is equivalent to P-contained feasibility. The supportwise test can reject even when both masks exceed C. It is not a test that the union covers a rectangle in that regime.

For any original satisfying tuple in D, its actual x,y survive both masks, avoid every G_S, and witness the exact test when invoked. Hence no original satisfying tuple is removed. For child D' subset D, both masks only shrink at a common key. A pair avoiding a support in the smaller rectangle avoids it in the larger. If parent invokes the exact test, then the smaller nonempty masks also trigger it; a surviving child exact pair witnesses the parent. Therefore W_(D',C)<=W_(D,C) on common keys. At fixed D, larger C can only strengthen W (more exact tests); no rejected key can become accepted as C increases. These implications include empty masks and padded keys.

Use W instead of V in the parent's three local representation workers. Delete references only, leave the actual E strings for retained keys unchanged. At children clip the free quadrants, restrict actual keys, apply W and re-intern rows / compact reachable DAG nodes. Nesting ensures no deleted reference must be regenerated. The represented local predicate is exactly E on D AND W_(D,C). If representation capacity overflows, abandon only the guard and search all original constraints in that full tile. The projected first-overflow census and full traversal agree, since W uses no private coordinates.

For fixed C let R_(B,C) be the exact mass of E filtered by W at B-roots, rho_(B,C)=R_(B,C)/m^6. This mass now DEPENDS on C, so it must be recomputed for each capacity or obtained by an exact equivalent batch; do not reuse the parent's single mass. Let omega_rep^W(C) be sum of t^6 over disjoint first-overflow projected cubes divided by m^6. Define

    J_rep^W(E)=min_C [C^13*rho_(B,C)+omega_rep^W(C)].
    Q_W=beta+delta_n+sum_H min_rep J_rep^W(Z_H).

The representations remain exactly dense (cap C*t per source), canonical run (C*t^4) and shared DAG (C*t^4). Enumerate inherited fixed map policy/coordinate choices and dyadic capacities. For each fixed C, the filtered root mass and first-overflow union are subsets of the parent's V-filtered ones: W implies V and the intrinsic capacity statistic is nonincreasing under deleting row references. An overflowing child under W either lies in a prior V-overflow ancestor or itself exceeds the V cap. Hence J_rep^W<=J_rep^V for identical candidates.
