## 1. Result

Use the full inherited nine-group normalized family with n=19m-7, L=n+1+2n^2+8 binom(n,3)=Theta(m^3), arbitrary negative cross-group clauses of width 1..3, fixed one-hot/OR/guard clauses and actual pins. For each ordered pair of distinct groups (u,v), define a graph on the m digits of u from the actual pair-dependent clause slices. Its deterministic greedy coloring in ascending digit order has K(u,v) colors. Define K=min over the 72 ordered pairs.

There is a fixed original three-symbol single-tape witness program with time

    O((m^7 + K*m^(62/7)) polylog(m+2))

and visited span O(m^3 polylog m), using the parent aligned-separator solver. For every fixed epsilon in (0,1/7], all SAT members with K<=m^(1/7-epsilon) are eventually covered at the original exact cubic stage, uniformly over masks and pins. This includes complete primal support graphs, even ones with full contextual domains and high global fanout. No assumption of uniqueness is needed. The algorithm remains correct beyond this promise, but the displayed bound there need not be subcubic. K is the computed greedy count, not the minimum chromatic number or a semantic hardness invariant.

## 2. Exact pair-context slices

Fix distinct u,v. Use contexts e=empty (pair support), or e=(g,c) for each g outside {u,v} and c in [0,m). Define the m-by-m Boolean matrix M_e(a,b) to equal one iff the negative cross clause on precisely u=a, v=b, and, if nonempty, g=c is ABSENT. No other clause supports enter these matrices; in particular this is not the closed local allowed table used in the contextual pruning note. The empty context is always tested, and for a complete tuple exactly one context per third group is active. All clauses containing both u,v are satisfied exactly when the empty-context bit and every active third-group-context bit are one.

Write R_e(a)={b:M_e(a,b)=1}. Make an undirected conflict edge between distinct digits a,a' of u if for at least one context both R_e(a), R_e(a') are nonempty and unequal. Empty rows do NOT conflict with other rows. An independent set A of digits therefore has, in every context separately, a common nonempty row B_e shared by all its nonempty rows, if any exist. If no such row exists take B_e=empty. Set A_e={a in A:R_e(a) nonempty}. Then on A x [0,m),

    M_e(a,b)=1 iff a in A_e and b in B_e.

This is an exact rectangle factorization of the allowed relation, including the empty rectangle. Conversely, if a context slice restricted to A x [0,m) is a rectangle, all nonempty rows are equal. Thus a partition of the u domain into sets each having rectangular slices in every context is exactly a proper coloring of this conflict graph. This equivalence concerns this particular factoring method, not every possible transformation of the SAT instance. It can merge rows with different full signatures whenever their differences arise only from empty rows in different contexts.

## 3. Deterministic edge removal by disjoint branch union

Color the conflict graph greedily in ascending digit order, using the least available nonnegative color. Each color class A is independent and nonempty. For this branch:
* Keep all selected original clauses not containing both u,v, including inherited fixed clauses and pins.
* Add negative unary clauses forbidding u digits outside A.
* Remove every selected negative cross clause containing both u,v.
* For each context e and each a in A outside A_e, forbid u=a when that context is active; for each b outside B_e, forbid v=b when that context is active.

In the empty context the last clauses are negative unary clauses. In context (g,c) they are negative binary clauses on u,g or v,g. They are actual positions in the original normalized pool; all other clauses stay unchanged. Repeated selections are OR-deduplicated, never toggled. Even when all rows are empty, the resulting clauses reject precisely all pairs in that context. No clause containing both u,v remains. Every transformed formula has the SAME n,L and actual pins, and is a member of the original distributed family.

For a tuple with u digit in A, its truth on all removed clauses is exactly the truth on the new context clauses, by the rectangle identity for every active context. For a tuple outside A, the new units reject it. The branch solution set is therefore exactly the original solution set intersected with u in A, with the same full witness assignment. The branch sets are disjoint and cover the original solution set. In particular a uniquely satisfiable input has exactly one SAT branch with the same unique witness; no new hashing or guessing is involved. A branch with no solution cannot yield an original witness. The transformation is satisfiability-preserving only as a union over all classes; a single arbitrary class is not claimed to preserve SAT.

## 4. Sequential resource accounting

Extract the actual canonical selector, fixed pins and the width<=3 cross records using the previous parsing routines. For each ordered pair build all 1+7m matrices, including absent-clause bits, as a stream of records (row digit, context, column digit, allowed bit). The O(m^3) records can be generated by enumerating the canonical supports and sorting by these keys with fixed sequential multitape bit tapes. Every record has O(log m) bits. Store a row as its O(m^2) bits in context/column order. For each distinguished row copy it to scratch and scan all other rows, rewinding scratch and maintaining per-context flags (first row nonempty, second row nonempty, rows differ) and an accumulated conflict flag. This takes O(m^4 polylog m) total bit steps including whole-stream rewinds for m distinguished rows; adjacency records are emitted in row order. Use a symmetric adjacency matrix, including a zero diagonal. Its size O(m^2) is smaller than the matrix streams. There is no indexed membership oracle. To greedily color, scan the adjacency row for a against the sequential previous-color array; mark unavailable colors in an O(m polylog m) flag array, even charging O(m polylog m) per marked color by scan. This costs at most O(m^3 polylog m) bit time. Retain the minimum greedy count and the corresponding ordered pair/classes, breaking ties by a fixed order. Only constantly many pairs are tested. Preprocessing time O(m^4 polylog m), span O(m^3 polylog m) on a fixed number of tapes.

For each selected color class generate the reduced selector from actual stored cross records, the row slices, and class labels. In context-major row order scan the rows belonging to the class, mark the empty ones, copy the first nonempty row as the common mask (or use zero if none) and emit the replacement unary/binary records. Checking class labels by sequential scans of O(m polylog m) bits per entry, even without efficient row buffering, costs at most O(m^4 polylog m) bit steps across the O(m^3) entries per class. Extract/copy the unaffected original selected clause records and add all new records; sort and OR-deduplicate by canonical pool key. Generate the full normalized selector by sequential merge against the actual canonical pool, with the original unary header. Fixed clauses may simply be retained from the original selector; no change of pins or auxiliaries is needed. The output has O(m^3) bits. All this uses O(m^3 polylog m) visited span per tape. The inherited constant-width binary-coded finite-product sweep simulation of fixed multitape bit tapes on the original three-symbol tape has overhead O(m^3 polylog m) per simulated step, including physical head movement; raw input expansion costs O(L^2 polylog L). Hence preprocessing and each selector construction cost O(m^7 polylog m) physical transitions. This loose bound includes restoring saved arrays, copying a raw local selector to a simulated machine component, and eventual cleanup. There is no requirement to compile a separate program for each class.

Run the parent fixed aligned-separator solver on each resulting raw local selector (now missing edge u,v), preserving outer data on separate stationary product components. Simulate each of its physical transitions on its local component with constant overhead, following its simulated head, marking visited extent. Its time O(m^(62/7) polylog m) and span O(m^3 polylog m) dominate per-class construction. It either halts on blank or returns a valid raw n-bit witness on its promised family. Read its halt output, and on success emit it unchanged to a fresh raw contiguous region of the outer actual tape and position the physical head at the first bit; per-bit shuttles O(n m^3 polylog m) suffice. On failure erase only its used local components, return to the class-list marker, and continue. On exhaustion halt on blank. A fixed finite number of tracks and fixed control suffice for the entire loop (not K distinct programs); all block operations are over actual 0,1,2 with constant block width. The result is a machine-existence argument, using the parent theorem and its local solver contract, not a transition-table compilation.

Total time O((m^7+K*m^(62/7)) polylog m), span O(m^3 polylog m). Under K<=m^(1/7-epsilon) the exponent is at most 9-epsilon, since epsilon<=1/7. With j=ceil(log2 L), the fixed description of length ell has budget 2^(3j-ell)>=L^3/2^ell once eligible. Strict polynomial slack in L (epsilon/3) eventually dominates log factors and fixed constants uniformly on the promise. Therefore any unbounded exact cubic SAT miss sequence must eventually have K>m^(1/7-epsilon) for every fixed epsilon in (0,1/7]. This is a necessary condition only. In particular all selectors with a constant bound on K eventually fit, including when their primal graph is complete.

## 5. Complete-graph separation and empty-row control

For m>=3 take the previous dense parity family, now forbid (1,1) on EVERY pair of groups, including the previous missing edge (0,8). On the four triples in groups 0..3 and five cyclic consecutive triples in groups 4..8 allow even parity of nonzero indicators, with distinct nonzero digits if there are two. No other cross clauses. The primal graph is K9. As in the previous control, the parity systems force all indicator bits zero; the all-zero tuple satisfies all pair clauses, so the unique full witness uses that tuple. The (1,1) pair restrictions are redundant on the parity triples. Every digit has local support in every closed table (use the allowed two distinct nonzero digits and one zero on a parity triple, otherwise all other digits zero). Contextual signatures of each pair of distinct digits are incomparable using the parity contexts, so both pruning modes retain all m digits. Every directional maximum fanout is at least m-2 (nonzero and zero parents on parity triples, all-zero parents elsewhere); W>=(m-2)^9. These are the earlier full-width high-fanout controls with the graph condition now removed.

For u=0,v=8 only the empty-context matrix is nontrivial: its row a=1 excludes column 1, and every other row is full. All seven third-group context families have full rows. The conflict graph is a star with center digit 1, and the specified greedy coloring has exactly two classes. The new algorithm therefore covers this entire complete-graph family in O(m^(62/7) polylog m). It is an easy control, not a lower-bound candidate; no claim that two-color instances in general have trivial witnesses.

For a separate rectangular-slice control, select for one fixed third group g all ternaries with u digit unequal to g digit, regardless of v. The active matrix for g=c has exactly one nonempty row (u=c), full across v. The full row signatures distinguish all m digits but there are no conflicts: one color suffices. The transformation recovers the binary equality restriction between u and g, deleting the u,v edge without branching. This illustrates why equality of entire context signatures is unnecessarily restrictive.

## 7. Disposition

The frontier now includes complete graphs with polynomially small context-conflict color count. Future work: improve the branch exponent by coalescing color classes during aligned separator processing, use two-sided rectangle partitions, or find dense controls resisting those refinements.
