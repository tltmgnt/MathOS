## Structural coverage theorem

For a normalized relation instance with nine finite rank variables, build the primal graph G with an edge for each pair in any factor scope (arity at most three). The REX-020 introduction-tree grammar has root triple and each child shares exactly two ordered parent coordinates and introduces one fresh variable. Any scope placement in such a tree provides a width-two tree decomposition by running intersection. Hence a necessary condition for direct scope placement is tw(G)<=2. Conversely, for n>=3 every graph of treewidth at most two admits this representation by the following constructive completion.

While more than three vertices remain, remove any vertex of degree at most two, inserting the edge between its two neighbors if necessary. For degree zero or one, deletion preserves tw<=2; for degree two, removal plus fill is a minor (contract one incident edge), hence preserves tw<=2. A width-two graph has a vertex of degree at most two (e.g. first vertex of a width-two elimination order), so this algorithm cannot become stuck on such a graph. Conversely a successful trace has induced width at most two, including last three vertices, and implies tw<=2. Complete the last three vertices to the root triangle. Reinsert eliminated vertices in reverse order, attaching a triple to any existing bag covering the recorded later neighbors. Two neighbors form a filled edge and occur together in a bag; one neighbor occurs in some bag; for zero neighbors choose any bag. Select a pair in that bag containing all later neighbors and order it by parent positions. Add the eliminated vertex as fresh third coordinate. By induction all graph edges are covered; each original ternary clique is covered because its first eliminated vertex has both remaining vertices as later neighbors (or all three in root). Unary scopes covered by vertex coverage. Added edges impose no new predicate. For nine variables there are exactly seven bags. All original variables have connected occurrence subtrees. This is a direct scope-placement theorem for the syntactic primal graph, not a necessary condition for all possible semantic rewrites or alternative algorithms. No arbitrary source decomposition is accepted without construction.

The implemented planner uses mutable adjacency sets; the audit uses a separately implemented immutable bit-mask recursion over all legal low-degree choices as a reference. Both rely on the elimination characterization; not an external theorem prover. Every admitted plan is checked for original edge coverage, pair maps, fresh-variable introduction and bag count.

## Host producer and witness bridge

Reuse strict original normalization decoder (raw 1^n0 header, selector pool in original width/support/sign order, n=19m-7, m>=2; one-hot groups, OR-chain auxiliaries, guards and lifted pins). Decoder yields rank factor tables. Place each factor in every bag containing its scope (duplicated conjunction has identical truth value). Enumerate all m^3 triples per bag; include row with flag 1 precisely when all assigned local factors hold. Encode each rank with fixed ceil(log2 m) binary digits, consistent across bags. These are explicit local predicates, not precomputed subtree feasibility. The REX-020 fixed machine receives this prepared grammar, computes exact subtree feasibility and returns a row-selection certificate on SAT. Host decoder reads one selected row per bag, checks rank bounds and equality of every repeated variable, recovers all nine ranks, invokes inherited normalized witness translation and verifies all selected original clauses. Structural refusal is OUTSIDE_WIDTH_TWO, not UNSAT; malformed/outside family is OUTSIDE_NORMALIZED. Explicit cutoff is TIMEOUT, never interpreted as UNSAT. SAT returns original Boolean bit string. CLI --solve reads raw stdin exactly, --physical uses the fixed descriptor simulation for the prepared worker, not the host producer. Default clock is a finite simulation control, not the original U clock.

## Charged resource relevance

Original raw length L=n+1+2n^2+8 binom(n,3)=Theta(m^3). Nine fixed groups, at most 9+36+84=129 factor scopes, seven bags. Host candidate enumeration <=7m^3, membership checks <=7*129*m^3. This counts abstract Set lookups, not tape steps. Prepared length N<=77+7m^3(15+9ceil(log2 m))=O(m^3 log m)=O(L log L). REX-020 worker valid-input physical bound Theta(N^2) gives O(L^2 log^2 L)=o(L^3) for this portion. The full original input algorithm still lacks a fixed physical parser/producer, storage and access cost for local predicate generation, same-tape handoff to worker, physical original Boolean witness translation, and rejection policy. A naive simulation of host random access is not a charged resource proof. If a SINGLE fixed descriptor of length ell implements all phases in o(L^3), then eventually it is admitted by original cubic stage s=3 ceil(log2 L), because its clock 2^(s-ell)>=L^3/2^ell. This is conditional. Existing worker alone cannot run on original raw grammar. Its enormous descriptor also does not fit tested stage indices, and finite bridge tests are not actual original-stage admission. No claim for arbitrary normalized graphs or unrestricted SAT.
