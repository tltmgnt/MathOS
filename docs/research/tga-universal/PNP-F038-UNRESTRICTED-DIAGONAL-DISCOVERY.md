## 1. Clocked discovery equivalence

For a valid general binary description d in the original U decoder, integer c>=1 in binary, and integer e>=1 in binary, define A_(d,c,e)(p) by running d on the actual unary-n selector input of length L for at most c(L+1)^e transitions. If it halts, read exactly n consecutive output cells from the final head as in U. Return its optional well-formed proposal, or FAIL on timeout/malformed output. A counterexample is an explicitly encoded valid selector p together with an n-bit witness x such that x satisfies F_p but A's proposal is absent or fails the original verifier. A proposal is not required to equal x if it is a different valid model. This makes the target independent of witness multiplicity.

Let G be a deterministic algorithm which, on every valid triple (d,c,e), halts with such a counterexample. Use a decodable binary tuple encoding with length |d|+|bin(c)|+|bin(e)|+O(log(|d|+|bin(c)|+|bin(e)|+2)); for example, prefix each component by a self-delimiting length. The formula output is its COMPLETE original selector encoding (not a compressed formula) and a full witness. All runtime statements count bit computation and output length.

Then a total computable G exists iff P!=NP. If P!=NP no clocked algorithm can find verified models on all satisfiable inputs: otherwise verify its proposal to decide the original NP-complete selector SAT in deterministic polynomial time. Enumerate the valid selectors by size, enumerate their assignments, and simulate the given clocked program on each satisfiable selector; this effective search terminates on every valid triple and returns a counterexample and witness. It is not a polynomial search claim. Conversely if P=NP, SAT self-reducibility gives a polynomial witness algorithm, which has a general tape implementation in U with polynomial overhead. One fixed (d,c,e) covers its entire runtime, including small inputs and the output convention. No counterexample exists for that triple, contradicting total correct G.

For the restricted input domain e=1, a total computable G_1 exists UNCONDITIONALLY, using the earlier exact quadratic-stage adversary for U. For each fixed d,c, at all sufficiently large lengths the original U stage s_2=2 ceil(log2 L) allocates d at least c(L+1) transitions. At the unbounded sequence of verified-model failures of that stage, the individual linear-clock program must fail as well. Enumerating selectors and witnesses therefore terminates for this domain. This conclusion uses the earlier mathematical quadratic derivation, not a claim that every polynomial algorithm has a linear clock.

## 2. Self-description construction with charged overhead

We require only an elementary effective programming construction, stated here explicitly. Fix a binary program language for deterministic multitape bit machines with a universal interpreter. A source program Q takes a constant string z and an input p. There is a compiler C(Q,z) into the original three-symbol one-tape general descriptions of U: append/write a literal copy of (Q,z) using a finite-state data loader, followed by a fixed universal interpreter. A loader of b bits uses O(b+1) states (a chain of states writing the literal bits); the fixed interpreter can use block-coded tracks over the three tape symbols and keep the input and constant on separate simulated tapes. Initial input copying/block encoding, simulation of each multitape step by scans of the used tape region, and final copying of the output bits to consecutive cells with the required final head position are polynomial overhead. The original general-machine syntax stores the state count in unary and each of three transitions per state in O(log q) bits; thus the output length is O((b+1) log(b+2)). The explicit transition table for the loader and fixed interpreter is computable in polynomial time in b. This construction does not require an efficient solution of SAT or evaluation of Q at compilation time. Only polynomial overhead is needed; no linear-time simulation claim. The compiler C itself is a fixed effective bit algorithm, so it can also be invoked in the source language. The generic compiler is a mathematical construction, NOT an implemented source-to-U compiler in this cycle.

Fix any candidate total correct G_1 for the linear-clock domain. For a positive integer h, define a source program Q(z,p) with z=(s,h), where s is a literal source program string and h is in binary. Q performs the following operations:
1. Reconstruct d=C(s,(s,h)) using the public compiler.
2. Construct the binary integer c=2^h (one followed by h zeros).
3. Run G_1(d,c,1) to obtain an explicit selector p' and witness x'.
4. Return x' (optionally compare p to p' first). The comparison is unnecessary for the contradiction; it is permissible to return an irrelevant proposal on other inputs.

Now set d_h=C(Q,(Q,h)). The string Q is fixed, includes the fixed G_1 and compiler invocation, and is passed literally as data. Therefore step 1 reconstructs exactly d_h: there is no need to solve a fixed-point equation on finite formula strings. Its description length is O(log(h+2) log log(h+3)); the combined encoded clocked descriptor has length h+O(log(h+2) log log(h+3)). The external clock remains exactly c(L+1) on an input of length L. The simulator and data loader can be implemented to return the output convention of U on the target input, including n consecutive bits and halt head positioning. This is an explicit parameterized program self-description, not self-reference of a CNF instance.

Let T_h be the actual runtime of G_1 on (d_h,2^h,1). Correctness gives an explicit counterexample p_h,x_h; hence its length L_h<=T_h up to a fixed output coding factor. Computing the self-description, creating c, running G_1, reading its output and compiling its execution to the actual tape model costs at most C0(h+T_h+L_h+1)^a transitions on p_h for fixed constants C0,a>=1 independent of h. This bound is justified by the fixed source program and polynomial interpreter simulation above; it includes input copying and output writing. If T_h<=2^(h/(2a)) for arbitrarily large h, the bound is <2^h for all sufficiently large such h. But on p_h the actual d_h then emits the verified model x_h before its external clock c(L_h+1) expires. That contradicts the claimed counterexample.

We conclude that every total correct G_1 has a sequence of explicit clocked descriptors of lengths m_h=h+o(h) on which

    T_h > 2^(h/(2a)) = 2^Omega(m_h)

for all sufficiently large h. The hidden constant depends on G_1 and the chosen fixed interpreter. This is a NONVACUOUS exponential worst-case lower bound for witness-producing counterexample discovery, because the linear-clock generator exists by section 1. In particular there is no polynomial-time such generator in the binary description and clock length, even for the e=1 domain. For a total generator of arbitrary polynomial-clock counterexamples, the same lower bound holds on its linear-clock restriction (if such a total generator exists at all). The result is not a lower bound on the length of the counterexample itself, nor on discovering an unwitnessed formula. If c were encoded in unary, exponential-in-binary-clock-length would not imply exponential in the new input length; the encoding is essential.

## 3. Two direct consequences for the same universal-stage research

Unclocked domain: no algorithm that is total on every valid general code d can output a counterexample with a witness for EVERY polynomial-time general witness program d (even if it need not be correct on other codes). Indeed form Q(z,p) as above with z=s, reconstruct d=C(s,s), run the proposed total G(d), and return its witness. Set d=C(Q,Q). Since G is total, its computation on this fixed code terminates after a fixed constant number of steps, independent of p. The compiled program has polynomial total runtime in input length, including setup/output. On the claimed counterexample it emits the supplied verified witness, contradiction. Totality on all valid codes is essential; this argument does not rule out partial procedures with weaker domain guarantees. It explains why deleting explicit clocks from the direct adversarial target is not innocuous.

Same-U stage generator: suppose a fixed deterministic polynomial-time algorithm, given unary n, outputs a polynomial-size list of explicit encoded selectors on n variables and verified witnesses, together with a proposed stage exponent k(n) tending to infinity along an unbounded sequence of sizes. A single fixed program in U can recover n from its input, compute that list, compare the input selector to the listed selectors, verify the corresponding witness, and output it. Its time is polynomial in the actual L and its description length is fixed, so the original scheduler includes its successful execution by some fixed integer stage exponent K at all sizes. For every n on the sequence with k(n)>=K, NONE of the correctly witnessed listed selectors can belong to B_(k(n))(n). This does not exclude a generator of formulas without witnesses, a nonuniform construction, an expensive search, or a proof of existence that need not recover witnesses efficiently. It does forbid a tempting uniformly efficient witnessed diagonal family at arbitrarily growing exponents. The polynomial degree must be independent of n and k(n); a separate algorithm with time degree increasing in k is not excluded.

This is a genuine resource-preservation constraint for the unbounded cubic/all-exponent investigation. It does not prove B_3 infinite, P!=NP, or the correctness of any purported universal polynomial cutoff. The earlier one-state and quadratic derivations are not promoted to stronger exponents. Future constructive work should target a hard formula without cheaply regenerable witness, or a proof that some witnesses exist even when the proof does not compute them within the adversary clock. For k=3 alone an efficient generator whose runtime is larger than that stage can still be useful. No universal obligation closes.
