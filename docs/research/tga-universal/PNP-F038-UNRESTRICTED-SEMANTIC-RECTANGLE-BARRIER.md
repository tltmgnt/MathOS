## 1. Family-specific cubic success

Use the exact unique-quadratic layout n=101u, m=10u, v=u-2, u>=3, M=m^3, L=n+1+2n^2+8 binom(n,3). Fix any pin pattern. The allowed masks S,T subset [0,m)^3 select negative X and Z triples precisely for indices NOT in S and T. The other clauses are those in the unique-model note, including the negative units on unused variables and both guards. A model exists exactly when S intersect T is nonempty, and each index in the intersection gives exactly one model.

There exists a single fixed original three-symbol tape program P, independent of u, the pins, S and T, that emits a valid witness on every satisfiable member in O(L^2 (log(L+2))^d) original transitions, for some fixed d. It halts with malformed output on disjoint pairs. This is an existence construction, not a concrete transition-table compilation.

Read the actual unary header and compute u=n/101, m=10u, v=u-2 with binary counters; reject other sizes or malformed encodings. Enumerate the actual pool in order of width, lexicographic support and lexicographic signs (-1,+1), consuming one selector bit per clause. For all-negative ternary clauses with one variable in each of X_0,X_1,X_2, append its forbidden bit to stream A; for Z_0,Z_1,Z_2 append to stream B. Both streams have identical lexicographic index order. For a positive pin variable i in [10m+1,n-2] and both negative guard literals, append its selector bit to stream C. On the promised family this bit is exactly the pin value; the guard pair is fixed and the pin clauses occur in increasing pin order. No fixed clause occupies either forbidden-stream position. Every stream is extracted from the original raw selector, not given as auxiliary input.

Rewind A,B and scan in lockstep, maintaining three base-m digits, until a pair of zero bits is found. On exhaustion return malformed output (halt on a blank). Otherwise for the found index j set X_k[j_k] and Z_k[j_k] to one, each Y_k[i] to one iff j_k<=i+1 (zero-based), and each pin according to C. All remaining bits, including guards, are zero. Write these n bits in increasing variable order and halt at the first one (first output cell, even if its value is zero). This satisfies the fixed one-hot, equality, OR and pin clauses and the new unused-variable units. The original verifier accepts exactly because it is a satisfying assignment. No claim is made that the algorithm decides arbitrary selectors.

A fixed multitape bit machine implements the input scan, group tests, counters, stream appends and sequential output in T=O(L (log(L+2))^c) transitions for some fixed c: O(L) clause events, each involving a bounded number of comparisons and arithmetic operations on O(log L)-bit counters; the mask and output scans cost O(M polylog L) and O(n polylog L). A standard direct fixed-machine simulation uses constant-width binary codes for the combined finite track symbols and head markers, with all-2 blank blocks. Convert the raw input into these blocks by right-to-left shifts as in the copier (a constant expansion factor); this costs O(L^2). Each simulated step takes O(L+T) sweeps/steps in total, using a fixed number of scans of the used interval to collect scanned symbols, update the marked cells, relocate the head markers and extend boundaries. The interval length is O(L+T). At termination copy the n output bits from marked output blocks to a fresh raw contiguous region beyond the coded interval, with a blank separator; mark each processed block and use at most O(L+T+n) physical steps per bit. Position the head at the first raw bit by moving left from its right delimiter to the left blank separator and then right one cell. On failure halt on a fresh blank. All codes, scans and marker updates are finite-control macros, so the three physical symbols suffice. Total time O((L+T)^2), and the finite control and original description length ell are constants. This justifies the existence of P in the exact original syntax without supplying its table or numerical ell.

Let j=ceil(log2 L). Its exact cubic allocation is 2^(3j-ell)>=L^3/2^ell for 3j>=ell. The ratio of the running-time upper bound to this lower bound tends to zero since every fixed power of log L is o(L). The inclusion is uniform in the pin pattern and masks. In fact the earlier O(log log L) stage slack above 2j applies to this layout too. Thus for all sufficiently large u no SAT member of this particular family belongs to B_3, unique or otherwise. This is consistent with the exact quadratic lower census and says nothing about other families or the finite cubic interval.

## 2. Exact semantic rectangle-cover obstruction

At any of the separated cuts in the unique-quadratic note, let D={(S,T): S intersect T is empty}. At sufficiently large u the combined exact cubic-stage rejection relation on this fixed-pin family is EXACTLY D: unsatisfiable pairs cannot pass the verifier, and P accepts every other pair.

Consider any rejection label r on disjoint inputs, including a label obtained by semantic compression, certified pruning of always-rejecting programs, or an arbitrary noncomputable choice. The soundness requirement of the old rectangle strategy is: if two pairs have the same label, then BOTH crossed pairs are rejected at the original clock. Equivalently the Cartesian product of the left and right projections of each label class lies inside D. A cover by overlapping certificates is also allowed provided each certificate rectangle lies inside D.

Claim: the minimum number of rectangles covering D and contained in D is exactly 2^M.

Lower bound: use the 2^M complementary pairs (S, U\S), U=[0,m)^3. For distinct S,S', at least one of S\S' and S'\S is nonempty. The corresponding crossed pair has nonempty intersection and is accepted by P. Therefore no rejection rectangle can contain two complementary pairs. This is a fooling set of size 2^M. It is also an obstruction to equal-label splicing directly: the label must be injective on the complementary pairs. For fixed-width binary labels at least M bits are needed in the worst case; for variable-width finite binary labels without a prefix requirement at least one label must have length >=M, since there are only 2^M-1 strings shorter than M.

Upper bound: for every K subset U use R_K={S:S subset K} x {T:T subset U\K}. It lies in D. Any disjoint pair lies in R_S. Hence 2^M rectangles suffice. This upper bound is an abstract semantic certificate, not an efficient algorithm for producing original-machine crossing records.

In particular dropping the always-rejecting copier is sound but cannot restore the old quadratic rectangle counting argument on this unique family. The barrier holds even if labels need not reconstruct any operational transcript. It relies on preserving combined rejection on both crossed inputs, and does not exclude approaches that change the family, use different inference rules or target only a subset of inputs. If the goal were merely to rule out singleton intersections in rectangles rather than preserve rejection, the complementary fooling-set proof would not apply as stated; the prior singleton-free rectangle bound is a separate result.

## 3. Finite reference checks

A separate JavaScript enumeration checked all 87381 mask pairs for universe sizes M=0..8, including 9841 disjoint pairs covered by R_S, and 43435 distinct unordered pairs of complementary inputs for the fooling-set property. Separate stream-order checks at reduced layouts m=2,3, n=10m+3, one pin, tested 32 synthetic streams with both pin values, and 700 index predicate checks on reconstructed witnesses. These stream checks enumerate pool positions but do not validate all fixed selector clauses. The Python regression supplied with this note additionally reconstructs the actual fixed clauses, verifies outputs against the original verifier predicate, and tests the rectangle identities. Neither test compiles the new solver into an original-U transition table or proves the asymptotic theorem by enumeration.

## 4. Research disposition

The raw copier and the semantic rectangle barrier are distinct: the former works on all binary inputs but is removable as always rejecting; the latter uses a witness-producing program and applies only to the specific separated unique family. Both require eventual stage inclusion; no practical threshold is asserted. Stop seeking cubic failures inside this direct ordered-index intersection family. Next target a different encoding whose witness recovery cannot simply scan two aligned masks, and audit its extraction complexity and the soundness of any reduced rejection certificates before attempting counting. No universal obligation closes, no unbounded B_3 is proved, and no unrestricted SAT cutoff is proved. Finite cubic interval and Lean census are not changed or recounted.
