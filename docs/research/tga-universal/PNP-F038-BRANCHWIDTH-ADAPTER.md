## Exact connectivity-function reduction

Use the earlier affine extraction and parametrization. The ground set E consists of indexed residual clause occurrences, including duplicate scopes as distinct occurrences. For X subset E let r(X) be the dimension of the span W(X) of all direction rows of clauses in X. Then r(empty)=0, r is monotone, and r(X)+r(Y)>=r(X union Y)+r(X intersect Y): W(X union Y)=W(X)+W(Y) and W(X intersect Y) is contained in W(X) intersect W(Y). The dimension identity proves the inequality. Define

lambda(X)=r(X)+r(E-X)-r(E).

This is nonnegative integral, normalized, and symmetric. Applying the rank inequality separately to X,Y and to their complements proves submodularity of lambda. It is therefore a connectivity function in the standard branch-width sense, with a polynomial-time exact rank oracle. The oracle does not enumerate the affine model space. Its cost gamma is polynomial in explicit length L, including preprocessing of the direction rows. The branch-width of this connectivity function equals the minimum separator width previously defined: root a subcubic branch-decomposition by subdividing any edge, or suppress the degree-two root of a rooted full binary leaf tree. Every nonroot subtree cut corresponds to an edge cut, and the added root cut has rank zero. Handle empty and singleton instances directly; two leaves can be joined by a single edge. The proof concerns clause-occurrence subspace arrangements, not merely the primal graph.

- T. Korhonen, S. Oum, Branch-width of connectivity functions is fixed-parameter tractable, https://arxiv.org/abs/2601.04756 (2026; author publication page https://sangil.dimag.kr/papers/ lists FOCS 2026). The reported oracle algorithm runs in 2^O(k^2) gamma m^6 log m for m ground elements, deciding width <=k and constructing a decomposition if available. The reduction above verifies its input hypotheses. The prior 3^m exact subset DP is a small-instance reference, not the best theoretical parameterized discovery baseline.
- F. Fomin, T. Korhonen, Fast FPT-Approximation of Branchwidth, SIAM Journal on Computing (2024), https://doi.org/10.1137/22M153937X, https://arxiv.org/abs/2111.03492. Its reported single-exponential factor-two approximation for ordinary graph branchwidth does not by itself establish that bound for the present arbitrary subspace-arrangement oracle.
- M. Choi, T. Korhonen, S. Oum, Branch-width of represented matroids in matrix multiplication time, https://arxiv.org/abs/2605.14428 (2026). Its reported bound O_{k,F}(m^2)+O(m^omega) for square represented matroids hides computable parameter dependence. An explicit transfer preserving occurrence groups would be needed before asserting this bound for general clause arrangements. In particular arbitrary column decompositions need not keep all vectors of a clause together.

These are literature dependencies, not newly proved external theorems or implementations. For width-three residuals and supplied width b, the exact message solver has cost 2^O(b) poly(L). Invoking the reported 2026 connectivity oracle theorem and then checking the returned tree and running the message solver gives total theoretical cost 2^O(k^2) poly(L) on width <=k. If k is unknown, try integer budgets starting at zero until successful; on width b this adds at most b+1 trials and preserves the asymptotic bound. A reported rejection of a width budget means this structural representation exceeds the budget, not that the formula is UNSAT. Independent certificates of optimality for arbitrary instances are not furnished by this adapter. Tree feasibility and actual SAT/UNSAT results have separate checkers.

Thus b=O(sqrt(log L)) is a polynomial-time domain even when the decomposition is not supplied, by the cited theorem. b=O(log L) has a quasipolynomial upper bound via that theorem, not a proved lower bound. A single-exponential constant-factor approximation for these arrangements would suffice to restore the logarithmic-width polynomial domain, but this note neither asserts its novelty nor proves it. Large width remains possible even on trivially satisfiable formulas, as shown by the previous complete-graph family.

## Executable interface

The adapter exposes an exact rank oracle, validates an arbitrary rooted full binary tree (leaf bitmasks identify occurrence indices), measures its width, and builds exact message nodes from the leaf sets rather than contiguous intervals. A malformed tree is rejected before any message enumeration. An optional rank budget rejects a valid but too-wide tree before enumeration. For an accepted tree the earlier gluing construction yields exact tables and representatives; a successful root is reconstructed and checked against the source. An empty root is independently checked by recomputing table recurrences using child boundary rows alone. Inconsistent affine extraction uses source XOR provenance instead. Neither a malformed-tree rejection nor a budget rejection is a SAT/UNSAT result. The code does not implement the Korhonen-Oum algorithm or call it as an external backend; it implements its input/output contract and includes small exact optimization and specialized cycle discovery as existing possible producers.
