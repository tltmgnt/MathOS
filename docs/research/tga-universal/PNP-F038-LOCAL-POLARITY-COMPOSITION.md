## Existential-component factorization

Let F(x,y) be normalized CNF with universal parameter variables x and existential witness variables y. Form the graph on declared existential variables: two vertices are adjacent if they occur together in a clause. Each connected component E_i gives a block F_i containing exactly those clauses with existential variables in E_i. Treat each parameter-only clause as its own block with empty existential scope. Isolated unused existential variables may be kept as empty blocks. This partition is computable in polynomial time by union-find. Denote by X_i the parameter variables occurring in block i. The X_i need not be disjoint and may have conflicting polarities across blocks. The existential scopes are disjoint.

For each fixed x, independently combine satisfying assignments on the E_i:
exists y F(x,y) iff AND_i exists y_i F_i(x|X_i,y_i).
Universal quantification distributes over this conjunction. Thus totality holds iff each block is total on its own parameter scope. Any local counterexample extends arbitrarily to a global counterexample. This is an exact equivalence, not a sufficient-only certificate based on matching local witnesses.

Within block i let H_i be the parameters occurring both positively and negatively and h_i=|H_i|. Enumerate assignments a to H_i. Set all positive-only parameters of the block to zero and all negative-only parameters to one. A satisfying witness at this worst point remains a satisfying witness for every extension of a (every changed literal can only improve). Therefore 2^h_i pinned local queries certify totality of the block and provide witness constants indexed by H_i. Parameter-only blocks and empty blocks obey the same argument. There is no requirement of a common orientation between different blocks.

With supplied local tree decompositions of maximum bag sizes b_i, the prior fixed-input interface DP gives total time sum_i 2^O(b_i+h_i) poly(L_i), where L_i includes the corresponding explicit formula/decomposition and declared variables. Add polynomial cost for partition and validating local decompositions. A supplied global decomposition can be restricted to each block's variables; this preserves clause containment and running intersection, but can give looser width bounds than separately supplied decompositions. The evaluator selects local stored witnesses and concatenates the disjoint existential outputs. Total witness circuit size is O(sum_i (|E_i|+h_i+1)2^h_i) plus polynomial routing/output overhead. In particular max_i(b_i+h_i)=O(log L) gives a uniform polynomial-time algorithm for this structural domain, with no bound on the sum of mixed counts. There are no hidden SAT calls beyond the specified local model queries.

For example, for every pair of m universal variables introduce two fresh private existential bits and blocks (x_i OR x_j OR y_ij), (not x_i OR not x_j OR z_ij). Each block has b_i=3 and h_i=0, hence just one seed; all blocks are total. Globally every parameter (m>=2) has both signs, and the primal graph contains a clique on all m universal variables. Thus neither a global logarithmic bag bound nor a global logarithmic mixed-polarity bound is necessary for this factored approach. The example is easy to solve, not a runtime lower bound.

## Opposite-orientation union obstruction

The conjunction argument does not generalize to the union of even two independently oriented unate projected relations. Given an arbitrary normalized 3-CNF D(v) on n variables, introduce universal bits x_i and z_i, representing the positive and negative literals of v_i respectively. Replace every literal in D with its positive representative and conjoin (x_i OR z_i) for each i, giving a positive-only CNF P. Let N be the negative-only CNF consisting of (not x_i OR not z_i) for each i. The conjunction P AND N forces exactly one bit of each pair to be true; it is satisfiable iff D is satisfiable. Empty clauses and empty formulas are allowed.

Apply the already verified clause-address construction separately to P and N. For a matrix Q, introduce existential address bits and private width-three clause-splitting variables to express that some indexed clause is false, with invalid indices forbidden. Its projection is not Q. The visible literals are all negative for P's encoding and all positive for N's encoding; existential splitting does not change the signs of any original literal. Each supplied decomposition has maximum bag size O(log L) as in the verified symbolic-interface derivation. Each projected relation thus has zero syntactic mixed-polarity parameters. Each can be evaluated and its totality tested in polynomial time (a single worst point plus bounded-width model query).

The union of the two projections is total iff not P OR not N is identically true, iff P AND N is unsatisfiable, iff D is unsatisfiable. This establishes coNP-hardness of deciding totality of a union of two explicit syntactically unate projected 3-CNFs with opposite orientations and supplied logarithmic-width decompositions. Membership in coNP follows because an uncovered assignment is checked by two polynomial-time fixed-input DP calls, on the promised structural domain. This gives coNP-completeness (under that promise). A common orientation, by contrast, permits a single common worst-point test. This is a conditional obstruction to generic polynomial-time union certification unless P=NP, not a proof that evaluating the union or finding a witness at fixed x is hard. A single existential switch can choose between the two alternatives, so the difficulty arises from the existential choice, even without complicated switch networks.

## Consequence for structural transformations

A polynomial-time transformation from arbitrary logarithmic-width universal certification instances (or the two-alternative union above) to the existentially disjoint block domain with max_i(b_i+h_i)=O(log L') and polynomial output length L', preserving totality, would imply P=NP by the reduction and constructive algorithm. This is a conditional obligation, not an unconditional impossibility of useful restricted transformations. It is distinct from a reduction that preserves only satisfiability at one fixed input. The algorithm supplies no unrestricted SAT solver.
