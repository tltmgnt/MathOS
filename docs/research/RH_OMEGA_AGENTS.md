# RH-Ω agent role contracts

The RH-Ω architecture document proposes ten agents. This first working
implementation produces **ten deterministic, non-AI role records**:
it does not call a model, invent independent expert consensus, execute
untrusted code, or claim to generate formal RH proofs.

| Role | Traceable responsibility |
|---|---|
| Analytic | Source-map zeta/xi properties and reflection sample limits |
| Zero | Separate N(T) estimates from verified zero locations |
| Prime | Track Euler-product convergence domains and truncated prime sums |
| Spectral | Challenge noncircularity and fixed self-adjointness claims |
| Positivity | Separate finite Li/Weil checks from universal statements |
| Conjecture | Keep proposed Li lemmas clearly unproved |
| Counterexample | Carry finite-prefix and lower-semicontinuity countermodels |
| Formal verification | Reference bounded Lean/Coq logical theorems |
| Evidence | Link source fingerprints and canonical proof obligations |
| Consensus | Refuse to treat these records as expert consensus |

Each role record declares its exact source checks, deterministic mode,
absence of external expert consensus and absence of proof claims.

A future optional model-backed implementation must enforce structured,
untrusted outputs with exact assumptions and quantifiers, a sandbox,
resource budgets, independent falsification, explicit human review
and trusted proof-kernel replay for real formal subclaims. Neither a
model majority vote nor a matching digest can upgrade global proof status.

The proposed research sequence is reconstruct, decompose, generate,
test, falsify, formalize and verify. The present reconstruction is a
source index with bounded experiments, not a new derivation of the
classical analytic theorems.
