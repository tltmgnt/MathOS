# Exact tractability boundary for isolated two-block AND overlap

**Status:** internal candidate proof; novelty not established; independent review not performed; no Millennium promotion. This is an extension of [PNP-B006](../breakthrough/PNP-B006.md).

## Model
A component has distinct Boolean inputs x,a,b, arbitrary explicit local domains D,E subsets of {0,1}² and outputs u=x AND a, v=x AND b. Require (x,a) in D and (x,b) in E. Components have disjoint input variables. Arbitrary explicit affine GF(2) equations may couple outputs, including unary constants. Let c be the number of components and m the number of equations.

## Theorem A: exact local classification
If x=0 is feasible, its output is 00. For x=1 the possible outputs form a Cartesian rectangle A×B of the permitted private input values. Thus every projected relation is either a rectangle or the union of a rectangle with {00}; the empty rectangle is allowed. A size-three rectangle is impossible. A size-three union must have a two-element rectangle not containing 00: either {10,11} or {01,11}. Hence the only non-affine projected relations are the two implications, {00,10,11} and {00,01,11}. Empty relations are inconsistent; every subset of the two-bit cube of size 1, 2 or 4 is affine (a singleton, a line, or the full space). Exhaustive domain-pair counts are 49,100,73,18,16 for cardinalities 0 through 4, with nine of each triple orientation; the analytical proof is independent of enumeration. Output integer encoding is u+2v.

## Theorem B: tractability and hardness
If all components project to affine relations or empty sets, solve using Gaussian elimination after substituting their constant-size affine descriptions. Lifting succeeds independently in each component by stored local witnesses. Empty components immediately refute feasibility.

If arbitrary repetitions of either implication component are permitted along with unrestricted affine coupling, the decision problem is NP-complete. Membership in NP follows from direct input and row checking. For hardness, reduce 3-SAT with one component per literal occurrence. Fix a=1 and leave b free, yielding u=x, v=x AND b, exactly v implies u. (For the opposite orientation swap the block labels.) Treat u as the literal truth and v as a selector. For each clause require XOR of its three selectors =1. If a clause is false, every selector must be zero; if true, select exactly one true literal. For occurrences i,j of the same original variable enforce u_i XOR u_j = neg_i XOR neg_j, where neg=1 for a negated literal. Tie each occurrence to one representative; this ensures one consistent truth value per original variable. Forward, a SAT assignment supplies all literal truths and a selector per clause, then each component lifts by choosing x=u,a=1,b=v. Reverse, a component solution determines consistent original truth values and at least one true literal per clause. The construction uses three components per clause and at most one consistency row per occurrence plus one parity row per clause. Even dense explicit output row encoding has polynomial size. No input variable occurs in more than two blocks and every block overlaps with at most one other block.

## Theorem C: parameterized recovery
Let k be the number of components having a size-three projected relation. Partition each such relation into its two slices by fixing u=0 or u=1. Both slices are nonempty affine subsets of the two-bit cube. Enumerate one slice per non-affine component, add its affine equations and solve the resulting system. The union of branches is exactly the original relation; successful witnesses lift independently. At most 2^k branches are needed. With explicit dense rows and bit-operation Gaussian elimination, time is O(2^k (1+c+m)^3), including projection, branching, back-substitution and lifting, and working storage is polynomial (branches streamed, not materialized). This bound is not claimed tight. UNSAT is reported only after all branches fail; no compact independently checkable UNSAT certificate is implemented.

## Theorem D: rank-sensitive branching (stronger scoped candidate)
Let A z = b be the affine relaxation containing all coupling rows and the exact affine descriptions of the non-triple components. Empty local relations and inconsistent relaxation are immediate UNSAT. In the consistent case, let P select the u coordinate of each of the k triple components and let d = rank([A;P]) - rank(A), with all ranks over GF(2). Exactly 2^d distinct split patterns Pz occur among solutions of the relaxation. This is a count of feasible patterns before imposing the nonlinear local restrictions, not a count of solutions of the original problem.

Proof: write the affine relaxation as z0 + ker A. The image under P is the affine translate Pz0 + P(ker A). The kernel of P restricted to ker A is ker([A;P]). Rank-nullity gives dim P(ker A) = (2c-rank A) - (2c-rank([A;P])) = d. Thus its image has 2^d points. Alternatively choose a subset Q of coordinate rows greedily independent modulo the row space of A. Its size is d, every assignment to Q is consistent with A z=b (the appended coefficient rows are independent modulo A), and every omitted row of P is a linear combination of rows of A and Q. Consequently each Q assignment determines exactly one P pattern. The correspondence is bijective.

Algorithm: preprocess row space and choose Q, enumerate assignments to Q, solve the affine relaxation with these fixed coordinates, read the determined P pattern from any representative, and add the corresponding local affine slices. Solve again and lift any witness. Every original solution lies in one enumerated slice, and every lifted solution is valid. Using dense bit accounting, time O(2^d (1+c+m)^3), polynomial working space. Since d≤k, this never increases the worst-case branch count relative to Theorem C; it does not imply a universal polynomial bound. Exact pattern count is not a lower bound on all solvers. No claim of optimal choice of split coordinates.

Structured control: k=21 implication components, all u coordinates tied equal, v0=1 in one orientation and v1=0 in the reverse orientation. The relaxation admits exactly two split patterns but both contradict an implication. Ranked solver visits two leaves, versus 2^21 candidate patterns in unfiltered enumeration; this is a branch-count comparison, not measured speedup, not the MRA-X 21-bit target, and not a general benchmark. The implementation reports d, feasible pattern count and visited count separately. Theorem D follows from classical linear algebra and is a candidate refinement, not established literature novelty.

## Theorem E: optimal coordinate selection is NP-complete and fixed-parameter tractable
For each non-affine component i allow either coordinate row e_(2i) or e_(2i+1) as its split. Let d* be the minimum rank increase over selections of exactly one coordinate per component, relative to the affine relaxation coefficient row space W= row(A). Either coordinate partitions a three-point relation into affine slices, so Theorem D extends to every such selection. This optimization excludes arbitrary linear forms (including u XOR v), adaptive branching and other solver strategies.

Decision version: given A, the coordinate pairs, and a nonnegative integer t, is d*≤t? A selection is a polynomially checkable witness, using GF(2) rank. For NP-hardness, reduce Vertex Cover on a loop-free undirected graph: one triple component per edge, its two output occurrences labeled by the endpoints. Add homogeneous affine equalities connecting all occurrences of each vertex to a representative. Use only the implication triple domain in each component. The quotient by W has one independent coordinate class per non-isolated vertex: indeed the linear map sending an occurrence basis vector to its vertex unit vector is surjective onto these classes, and its kernel is exactly the span of the equality rows (each even-parity occurrence vector within one vertex group is a sum of representative differences). Thus the rank increase equals the number of distinct vertex classes selected. Choosing one endpoint per edge produces a vertex cover, and every vertex cover permits such choices with rank no greater than its size. Hence d* equals the minimum vertex cover number. The reduction has polynomial explicit encoding, and the affine relaxation is always consistent. This proves NP-completeness of the coordinate-selection decision problem, not a lower bound on SAT solving.

Exact fixed-parameter algorithm: maintain a subspace S containing W with extra dimension at most t. If every pair has an endpoint in S, choose such endpoints, whose span modulo W has dimension ≤t. Otherwise choose an uncovered pair. Any feasible extension of S must contain one of its two endpoints; branch on adjoining either one. Each branch raises the dimension by exactly one. If an optimal covering span exists containing S, at least one child remains inside it; starting at W, this gives completeness. A depth-t binary tree has at most 2^(t+1)-1 nodes; each node performs polynomial GF(2) membership work. Iterate t=0,1,... until success, so total nodes < 2^(d*+2), and the first successful budget is optimal. Depth-first storage is polynomial. Composing this search with Theorem D yields end-to-end O(2^d* poly(L)) bit time and polynomial space, including optimizer cost; L is the explicit input bit length. No polynomial-time claim when d* grows linearly. The algorithm optimizes only the declared coordinate-splitting strategy. There is no succinct optimality or UNSAT certificate implemented.

Structured control: 21 edges of a star, leaf coordinate first and shared center coordinate second. Fixed first-coordinate selection has d=21; optimum has d*=1 (choose center at every edge; no endpoint is in W so rank zero is impossible). Thus feasible split-pattern counts are 2,097,152 versus 2. Both algorithms can stop at their first SAT witness; this control does not establish a measured speedup or a reduction in actual visited leaves. It does not evaluate the original MRA-X 21-bit identifier.

Relation to prior art: this is a rank-cost vertex-cover problem, a special case of submodular vertex cover, and the search is a rank analogue of bounded search trees. The scope-specific reduction and implementation are presented for verification and comparison, not as established literature novelty.

## Theorem F: generalized local linear forms, exact gap and complexity
Allow one of u_i, v_i, u_i XOR v_i for each triple component. Denote the minimum added rank by delta*. Any nonzero linear form on GF(2)^2 has two fibers of two points each; removing one point leaves fibers of sizes one and two, both affine. Thus the Theorem D projection and lifting algorithm works with any such choice. In particular 0 <= delta* <= d* <= k. The choice optimization has no claim to cover adaptive branching, unrestricted global forms or general SAT.

Decision complexity remains NP-complete. NP membership follows by providing one form per component and checking rank. Use Theorem E's graph embedding, with quotient basis indexed by non-isolated vertices. For edge {a,b} the alternatives are e_a, e_b, e_a+e_b. To show that XOR choices do not reduce the graph optimum below vertex cover number, take any selection and form a graph H on all non-isolated original vertices using only edges for which the XOR vector was selected. Mark vertices whose unit vectors were selected. In each connected component C of H, the chosen edge sums span the even-parity subspace of dimension |C|-1: path sums yield the difference from a fixed root to each other vertex, and all edge sums have even parity. With a marked vertex the span is the full coordinate space of dimension |C|. Different components have disjoint supports. Take all vertices in marked components, and all but one vertex in every unmarked component (including singleton components). The resulting vertex set has size exactly the selection rank. It covers every XOR-selected edge because at most one vertex of its component is omitted, and every unit-selected edge because its marked endpoint is included. Thus tau(G) <= rank for every selection. Conversely choose endpoints from a minimum vertex cover, obtaining rank <= tau(G). Therefore delta*=tau(G) on this family, proving NP-hardness even for homogeneous coupling and one fixed triple type.

Exact FPT optimizer: repeat Theorem E's subspace-extension search, now with at most three residual vectors per uncovered group. Each residual is nonzero, so every child increases rank by one. Equal residuals induce the same extension and may be deduplicated. Completeness follows because any feasible covering span must contain some original form of the uncovered group. Iterative deepening until delta* visits fewer than (3^(delta*+2))/4 nodes: each depth-t tree has at most (3^(t+1)-1)/2 nodes, and summing t=0..delta* gives the stated strict upper bound. Each node performs polynomial bit work; depth-first space is polynomial. End-to-end solve time including exact optimization is O(3^delta* poly(L)), not O(2^delta* poly(L)); the subsequent SAT search visits at most 2^delta* patterns. This is not necessarily faster than the coordinate optimizer on every instance.

Exact exponential pattern separation: for arbitrary k>=1, take k implication triples and impose homogeneous equalities u_i XOR v_i = u_0 XOR v_0 for i=1..k-1. Let t denote the common parity class modulo the coefficient row space W. The quotient has independent basis u_0,...,u_(k-1),t, since the k-1 displayed relations are independent and every v_i equals u_i+t in the quotient. Any coordinate-only choice selects one vector u_i or u_i+t per i, and these k vectors are linearly independent by their distinct u_i coefficients. Thus d*=k. Selecting the parity form in every block gives rank one, and rank zero is impossible since every available form is nonzero in the quotient. Hence delta*=1. The exact ratio of feasible affine split-pattern counts is 2^(k-1), unbounded as k grows. This is a gap between restricted optimization strategies, not a lower bound on actual solver runtime or on unrestricted SAT. The family is satisfiable; an early witness can avoid exploring most patterns. For k=21 the coordinate count is 2,097,152 analytically and the generalized count is 2; small coordinate optima and the generalized large control are executable tests. This does not evaluate the original MRA-X state identifier.

Formal boundary: the two new Lean identities check the parity-slice behavior for both implication orientations. They do not verify the quotient-space proof, graph reduction, rank optimizer or bit bounds. Prior art on bounded-rank subspace transversals and linear SAT branching must be compared before claiming novelty.

## Theorem G: proof-carrying optimal local linear decomposition
For the declared model, an exact optimizer and decision procedure can emit a separately checkable proof of its optimum and either a SAT witness or a complete UNSAT certificate. The checker reconstructs the two-bit relations directly from local domains, validates all selected forms and rank claims with independent low-column elimination, and does not call the optimizer or solver.

Optimality upper bound: selected forms belong to their respective groups. A supplied basis is a subset of those forms, adds exactly d independent dimensions modulo W, and spans all selected forms modulo W. Thus d is attainable. Lower bound: if d>0, refute budget d-1 with a finite preorder tree. Every node names a group with no member in the current span. At depth below budget the tree must contain one child for every form in that group, in the specified order, adjoining that form to the span; at budget depth the uncovered group proves failure. The verifier checks every membership condition and exact tree exhaustion. By induction on remaining budget, no feasible covering span of extra dimension <= d-1 can extend the root: any such span must contain an alternative in every uncovered group, and the corresponding child remains inside it. Rank zero needs no lower tree. This proves optimality in the local-form selection model only, not global solver optimality.

SAT certificate: directly validate original input-domain membership and every original affine row on the reconstructed outputs. Early empty-domain UNSAT is checked against the input. Early affine UNSAT is checked by XORing indexed relaxation rows to obtain (zero coefficients, RHS one); these early UNSAT cases make no rank-optimality claim. For a ranked UNSAT proof, the verifier checks exactly 2^d leaves, in lexicographic basis-bit order. Each leaf provides a representative satisfying the relaxation and that assignment. By the basis-span property the representative determines all selected split values throughout that branch. The checker independently reconstructs the local affine slices, and validates an explicit XOR of distinct indexed branch rows giving 0=1. Since all basis assignments are covered and each slice is equivalent to the original local relation within its branch, every original solution would contradict a checked leaf. Conversely an UNSAT instance admits these row certificates by Gaussian elimination, and an optimal rank admits the complete budget-refutation tree. A SAT instance admits a witness and the same optimum proof. This is a soundness/completeness argument for the certificate format, not a kernel-checked theorem.

Cost: the lower tree has at most (3^d-1)/2 nodes for d>0, the UNSAT tree has exactly 2^d affine leaves, and each node or leaf requires polynomial bit operations and polynomial-size data in explicit input length L. Hence production and checking take O(3^d poly(L)) bit time, and materialized proof length and storage are O(3^d poly(L)) bits; no polynomial certificate-size claim, no polynomial-space claim for the materialized proof implementation. The base decision procedure from F still uses polynomial working space without emitting materialized proof. Counts and actual compact JSON byte sizes for structured controls are recorded by the CLI; they are not a general timing or memory benchmark.

Controls: the 21-component common-parity family admits d=1 and a one-node optimality lower proof. A separate four-component homogeneous-coordinate pattern with affine translations imposes all four shifts of one implication and excludes every common output pair, yielding d=1, one lower node and two contradiction leaves. Mutations include missing, duplicate or reordered leaves, invalid rank/basis/forms, missing or extra lower nodes, corrupted witnesses and contradictory row references. See mathos/research/pnp_overlap_certificates.py and tests/test_pnp_overlap_certificates.py. The separate checker is software independence from the solver, not independent scientific review.

## Theorem H: adaptive affine closure with rank-bounded search

At each node, retain all original affine rows plus exact affine descriptions of already resolved components. For a remaining triple R_i, calculate the locally reachable allowed points S_i = {v in R_i : the current affine system has a solution with output pair i fixed to v}. Each point check is an affine consistency test. If S_i is empty, the node is impossible. If its size is one or two, it is affine, so add its exact description and retire that component. This preserves precisely the original feasible set in the node: any feasible solution must belong to S_i and conversely S_i is a subset of R_i. Repeat to a fixed point. If all components are retired, any affine witness lifts independently. Otherwise choose an optimal generalized form selection for the remaining triples, and branch on the first selected form with RHS zero or one. At a closure fixed point each remaining triple has three reachable points, so no nonzero local form is constant on the current affine space; every selected form adds one coefficient rank. Both children partition the node and the branched component resolves by closure.

Let d be the static optimum at the root before closure (consistent relaxation assumed). Closure only adds rows and removes groups, so cannot increase the residual optimum. At a split, take the chosen optimal selection of dimension t. Adding its first form to the coefficient space reduces its remaining rank increase to t-1; after closure the residual optimum is at most t-1. Inductively depth <= d and nodes <= 2^(d+1)-1, even if the optimizer is recomputed at each node. A node at depth j has optimum <= d-j, so total optimizer work is bounded by poly(L) times sum_{j=0}^d 2^j 3^(d-j) <= 3^(d+1) poly(L). Closure performs at most one successful retirement per component and polynomially many affine tests per node. Thus end-to-end bit time is O(3^d poly(L)); depth-first working storage is polynomial excluding explicit proof output. No optimal adaptive strategy or general runtime improvement is claimed.

Proof format: a SAT result is a directly checked original witness. An UNSAT result contains a preorder tree with a list of retired components at each node. The checker reconstructs each allowed reachable set by augmented-matrix rank (rather than invoking the optimizer or solver), accepts a retirement only for a nonempty affine subset of size <=2, and then appends its equations. Leaves are either explicit XOR row-sum contradictions or a checked empty reachable local relation. Internal nodes specify a nonconstant local form and require both RHS children. Exact tree consumption rejects missing or extra nodes. This establishes soundness and completeness of the scoped proof format by induction, conditional on the described elementary rank tests; not a full Lean formalization. Certificates do not prove adaptive optimality. Materialized proof size can be O(2^d poly(L)); no polynomial-size UNSAT claim.

Separation against the specific static full-leaf certificate format G: take k>=2 implication components v_i implies u_i with v_0=1, u_(k-1)=0, and v_(i+1)=u_i. Forward propagation forces every u_i=1, contradiction. The initial affine relaxation is consistent. In its coefficient quotient, the two endpoint forms fixed by unary rows are zero, and the k-1 free classes u_0,...,u_(k-2) are independent. Internal groups correspond to edges of a path on these k-1 vertices; end groups can select a zero class. By the graph argument of F, the static generalized optimum is the minimum vertex cover of that path, floor((k-1)/2), attained by alternating vertices and lower bounded by disjoint edges. G requires all 2^floor((k-1)/2) leaves on this UNSAT family. H retires implications forward until an empty reachable local set is detected, without a single split. For k=43, this compares 2,097,152 required static leaves analytically to one adaptive terminal node (with a nonconstant-size propagation trace). This is a proof-format and branch-count separation, not a measured runtime comparison or a lower bound on all static solvers: conventional preprocessing/unit propagation can already solve this chain. The static large proof is not materialized. Small rank values are checked by the existing exact optimizer.

Reproduce with python -m unittest discover -s tests -p 'test_pnp_overlap_adaptive.py' -v and python -m mathos.research.pnp_overlap_adaptive. The proof checker and generator share elementary helpers but checker does not call solver or optimizer. Full theorem formalization, prior-art comparison (especially unit propagation, Gaussian elimination, dynamic backdoors and proof logging), and independent human review remain open. No original 21-bit state identifier or general SAT claim.

## Theorem I: irreducible rank, ordered-search obstruction, and factorized recovery

I.1 (rank obstruction). With k independent implication triples and no coupling rows, every local form selection has disjoint nonzero supports and rank k. No triple is retired at the root by H. Every local-form binary split resolves exactly its own component, leaving all other triples fully reachable, and both children are feasible. Hence any complete local-form affine decomposition tree with this retirement rule has exactly 2^k leaves. This is NOT a lower bound for SAT decision: a single branch suffices for a witness. Even allowing arbitrary affine sets as cover pieces, any affine subset of the product projects to an affine subset of each triple, of size at most two, so each piece contains at most 2^k points. At least ceil(3^k/2^k) pieces are necessary to cover the product. This last bound is not asserted tight.

I.2 (connected obstruction). For k>=2 impose one homogeneous row XOR_i u_i=0 on k implication triples v_i implies u_i. Every allowed local point extends to a solution of the relaxation by choosing the first coordinate of some other block appropriately. Thus H cannot retire a triple at the root. The explicit row-support graph is connected. Any selection of one nonzero form per block has ordinary rank k because supports are disjoint. Quotienting by the one-dimensional row space can decrease rank by at most one. Selecting every u_i attains k-1 since their span contains the coupling row. Therefore the exact initial generalized rank is k-1. At k=21 this is 20, even after root closure. The family is SAT and no decision-time lower bound follows. Tests check the optimum at small sizes and full local reachability at size 21.

I.3 (actual exponential ordered search). Put k independent, unconstrained implication triples before G's four-translate UNSAT core. Core outputs are fixed translates of a common pair; every local triple has all three points reachable under the affine relaxation, yet the four excluded points cover the entire common pair. Its optimal rank is one (all corresponding first coordinates equal modulo row space and no local form has zero class). Any local split in the core restricts the common pair to two points, neither globally feasible, and closure refutes each side without another split: the four translates forbid both points, and any triple whose excluded point lies on this line reduces to a singleton, after which another triple has empty reachable set. For the exact H implementation (first selected form in first remaining triple, no factorization or memoization), the first k splits along every path must resolve the independent distractors: both children remain locally feasible and no other component changes. The core remains untouched until then. Hence the UNSAT certificate tree is a full binary tree of depth k+1 with 2^(k+2)-1 nodes and 2^(k+1) contradiction leaves. This is a lower bound for that fixed ordered implementation, not for all branching orders, adaptive proof systems or SAT solvers. In particular selecting the core first removes the obstruction.

I.4 (factorized recovery). Construct the explicit row-support graph on components, joining every pair of blocks appearing in one nonconstant affine row. Local domains and constraints never cross blocks. A constant contradictory row is checked separately. Each nonconstant row belongs entirely to one connected factor, so the full feasible set is the Cartesian product of factor feasible sets. Solve each factor with H; combine satisfying witnesses or emit one factor's UNSAT proof and its original component indices. The checker reconstructs the subset's rows directly from the original masks and independently checks the H proof; even a non-maximal subset refutation is sound because those constraints are part of the original input. No need to trust graph construction. For consistent affine relaxation and nonempty local domains, the coefficient row space and all allowed form groups decompose across factors, so the minimum added rank of the full static model is exactly the sum of factor optima d_j. H's end-to-end bound applied independently is O(poly(L) sum_j 3^d_j), also O(3^max_j d_j poly(L)), and the working space remains polynomial excluding materialized certificates. The factor proof contains at most one failing factor's explicit tree; SAT proofs use the original global witness. This optimizes explicit support decomposition, not finest semantic decomposition. For I.3 the implementation processes k one-block SAT factors (two visited H nodes each: a split then a SAT child), and the core (three nodes), totaling 2k+3 nodes. The comparison is actual node counts on the specified ordering, not a measured runtime ratio.

Evidence: run python -m unittest discover -s tests -p 'test_pnp_overlap_obstructions.py' -v and python -m mathos.research.pnp_overlap_obstructions. The k=5 control predicts 127 monolithic nodes versus 13 factored nodes; both emit checkable UNSAT certificates. For k=21 the formulas predict 8,388,607 versus 45 nodes; the large monolithic run is not executed. Connected-component solving and component caching are established SAT/CSP techniques (Bayardo and Pehoushek, AAAI 2000; Decomposing SAT Problems into Connected Components, AAAI 2006). The scoped rank formulas and exact ordering pathology are candidates for comparison, not a claim of original discovery. ## Theorem J: canonical affine dependency recovery

Let A z=b be the original coupling system, assumed consistent, with coordinates grouped into two-bit blocks. Row reduction to coefficient RREF carries RHS and original-row XOR provenance; a zero-coefficient row with RHS one certifies inconsistency. For a partition of the blocks, the affine solution set factors as a Cartesian product across the partition iff the coefficient row space W is the direct sum of its subspaces supported in the partition parts. Indeed, translating by a solution reduces the claim to the kernel K of A, and orthogonal complementation takes a direct sum across disjoint coordinate supports to the direct sum of the corresponding orthogonal complements. Thus K factors iff W factors.

If W decomposes across a partition, the union of RREF bases for the supported subspaces, sorted by pivot coordinate in the fixed global column order, is itself in RREF (disjoint supports cannot interfere with pivot columns). By uniqueness it is the global coefficient RREF. Conversely if every RREF row is supported inside a part, its row span decomposes over the parts. Therefore the connected components of the RREF row-support graph form the unique finest block partition factoring the affine solution set: every valid partition must contain each connected component, and the component partition itself is valid. Isolated blocks are retained. For a consistent system the RHS on each coefficient row is uniquely determined by any solution, so the resulting affine factors are independent of the original row basis and RHS representation.

Intersecting each factor with its original block-local domains preserves this product. The partition is canonical for the affine relaxation, not necessarily finest for the nonlinear feasible set (which may factor further or be empty). Rank additivity and the factor complexity bound of I apply with these recovered factors. Dense RREF with provenance is polynomial in explicit input length; including this preprocessing the bit time is O(3^max_j d_j poly(L)), where d_j is the optimum of each recovered factor. Materialized proof output may be exponential; no general polynomial-time SAT claim.

Certificates: the generator carries original-row indices through every row operation. A SAT result is verified directly on the original constraints. For an inconsistent affine system, XOR the supplied original rows to verify 0=1. Otherwise an UNSAT certificate supplies original block indices, derived rows with XOR provenance and a checked adaptive refutation on those blocks. The checker verifies each derived row as an original consequence, checks support containment, remaps the coordinates and checks the adaptive proof. Soundness does not require trusting the RREF, factor graph, rank optimizer, or completeness of the derived row set. The proof format certifies the result, not the fineness of the partition; fineness follows from the separate analytical argument.

Hidden-factor control: start with k independent two-block SAT factors, each equating its two first coordinates, and the four-translate UNSAT core of G. XOR the same nonzero core row into every SAT-factor equality while retaining all core rows. The explicit support graph becomes connected, but the row space is unchanged and RREF recovers k+1 factors. Each SAT factor has optimum one; the core has optimum one. The ordered H algorithm must split the distractor factors first: any optimal selection on a two-block equality must use the common first-coordinate class, and both branches resolve that factor without affecting the others. Thus the monolithic H tree has 2^(k+2)-1 nodes, while the recovered factor solver visits 2k+3. For k=5 both are executed (127 versus 13 predicted nodes); for k=21 only the recovered solver is executed (45 predicted nodes), while the monolithic count 8,388,607 is analytical. The example has 2k+4 blocks, not k blocks. This is a comparison to the specified ordered implementation, not a lower bound on general SAT or measured runtime speedup.

RREF, linear-code decomposability and component solving are classical. The scope-specific integration and row-mixing control require prior-art comparison; no novelty or full Lean verification is asserted. Reproduce with python -m unittest discover -s tests -p 'test_pnp_overlap_semantic.py' -v and python -m mathos.research.pnp_overlap_semantic.

## Theorem K: nonlinear joint affine recovery and a strict bounded-order hierarchy

Define the order-r closure of a consistent affine relaxation C by considering each nonempty subset J of at most r blocks. Enumerate the allowed local tuples on J and retain exactly those extendible to C using affine consistency with pinned coordinates. Call the retained set S_J. An empty S_J proves UNSAT. Otherwise add every affine equation on J valid on S_J, keeping the original nonlinear constraints. The implementation adds one coefficient-independent equation at a time and rescans to a fixed point. Each addition is valid on every original solution, since its local tuple belongs to S_J. Every original solution remains feasible and no new solution is introduced when the nonlinear constraints are retained. If the relaxation was consistent and S_J is nonempty, a dependent coefficient row valid on S_J must have the already implied RHS. Thus the independent-row rule discards only redundant equations. Each addition raises rank, so at most 2c additions occur. This is stronger than single-block closure H, but it is not an exact projection of the global nonlinear feasible set in general.

For each subset of size s, at most 4^s tuples require polynomial affine checks, and testing all nonzero forms against all retained tuples uses at most 16^s polynomial work. With c blocks the implementation has bit time O(poly(L) sum_{s=1}^{min(r,c)} binom(c,s) 16^s), polynomial for fixed r. It stores a local table of at most 4^r tuples and a polynomial-size trace (at most 2c equations). For arbitrary r this is not a uniform polynomial-time bound. If recovery stops without contradiction, solve the strengthened instance using J. The complete solver adds the corresponding factorized search cost; closure alone is not a decision procedure for fixed r.

Strict hierarchy for every integer r>=1. Use Boolean implications along two paths of length r+1: x -> a_1 -> ... -> a_r -> not x and not x -> b_1 -> ... -> b_r -> x, with distinct private variables. One block per implication uses the fixed triple v implies u; its antecedent and consequent truth values are linked to signed variable occurrences via affine equality/inequality rows. The affine relaxation is isomorphic to the unconstrained space of 2r+1 original variables. The full constraints are inconsistent: the first path implies x=0, the second x=1.

Any at-most-r subset of implication edges is a forest on the original variables, counting parallel edges as a length-two cycle when r=1: the underlying graph consists of two cycles of length r+1 meeting only at x. A forest of signed implications, with one forbidden assignment per edge, has a nonempty solution set with full affine hull on its vertex variables. Proof by leaf removal: any prescribed value of one vertex extends to a satisfying assignment by rooting its tree there and choosing an allowed child value along each edge. For a leaf, choose the neighbor value for which both leaf values are allowed and extend to the remaining tree; any affine equation valid on the forest's solutions must therefore have zero leaf coefficient. The projection on the remaining variables is the entire solution set of the smaller forest, since every remaining assignment extends to the leaf. Induction forces all coefficients zero and RHS zero, including isolated variables. Thus every subset of at most r implications has full affine hull in original variable space, and after affine occurrence substitution its projected hull equals the projection of C. Order r cannot add any independent row or detect contradiction, even after repeated scans.

At order r+1 the first entire path is considered. Its satisfying assignments force x=0 (and exist), so the corresponding unary occurrence equation is a valid consequence. Likewise the second path forces x=1. In any putative noncontradictory fixed point, both paths have nonempty reachable sets and all their affine consequences are imposed, which is impossible. Since rank increases finitely, order r+1 must detect contradiction, possibly after earlier deductions. Hence the hierarchy is strict at every level for this restricted affine-consequence operator. The example is merely a signed 2-SAT contradiction and is easy for standard implication-graph algorithms. It is not a lower bound on ordinary k-consistency, 2-SAT, unrestricted SAT, or arbitrary proof systems.

The certificate lists each derived row and its block subset, followed by an empty reachable subset or a checked J refutation. The checker independently reconstructs reachable tuples with augmented-matrix rank and checks every row against every retained tuple, then checks the terminal proof. A SAT witness is checked on the original constraints. Checking does not require trusting the optimizer, the closure fixed-point claim, or the alleged minimal recovery order. The proof of the hierarchy and complexity bound is analytical, not fully Lean verified. Evidence executes r=1,2,3 and mutation controls. These are established techniques; the exact signed-implication separation for this narrowly defined affine operator is a candidate for comparison, not established novelty.

## Theorem L: minimum structural recovery order and complexity bounds

Define r*=0 if the original affine system is inconsistent; otherwise r* is the smallest positive order whose K closure detects contradiction, or infinity (JSON null) if no order does. Order zero performs only the initial affine consistency check. For c blocks, order c considers all local domains simultaneously, so if the affine system is initially consistent, it detects contradiction iff the original instance is UNSAT. Hence r* is finite exactly for UNSAT instances, and lies in [0,c].

Canonical closure: for an affine set C, each subset J imposes the lifted affine hull of the allowed tuples reachable in C. If C' is contained in C, its reachable sets and hulls are contained in the corresponding sets/hulls for C; thus this shrinking operation is monotone under inclusion. Empty reachable sets are treated as contradiction. A closed affine subset D of the original relaxation remains contained in every intermediate relaxation at that order, by induction. Any nonempty terminating fixed point is therefore the largest closed affine subset of the initial relaxation, independent of scan and independent-row order. Increasing the recovery order imposes more subset conditions and cannot enlarge the fixed point. Detection is monotone in order. Exponential probing followed by binary search finds the exact finite threshold with O(log(1+r*)) probes, each of order at most min(c,2r*) for positive finite r*; SAT needs O(log(1+c)) probes up to c. A full-order non-detection yields an actual allowed tuple and lifted witness.

Fast hull algorithm: on each subset J of s blocks, enumerate reachable points, store the first point a and a Gaussian basis for differences p+a. The affine hull is a+span(differences). Its direction dimension is at most the dimension of the affine projection of C on J, namely rank([A;P_J])-rank(A), with P_J selecting the 2s coordinates. Equality permits early termination of enumeration because a contained nonempty affine set of the same dimension equals the projection. Otherwise compute a basis for the orthogonal complement of the difference span by setting one free column at a time; each form f gives the valid equation f.p=f.a. Add one coefficient-independent equation and repeat. If the hull is strictly smaller than the current projection, at least one such form is not already implied. This produces the same canonical closure as K, with at most 4^s local tuple checks and polynomial additional work per tuple, rather than the previous bound of 16^s from testing every form against every tuple. Total bit time per probe O(poly(L) sum_{s=1}^{min(r,c)} binom(c,s) 4^s), and polynomial working space: stream tuples, store at most 2s basis rows and at most 2c derived rows. A logarithmic number of cached probe traces remains polynomial space. For a finite positive threshold this is an XP bound in r* (the maximum tested order is at most twice r*), not fixed-parameter tractability or a general polynomial-time SAT algorithm.

Complexity classification: define THRESHOLD={(instance,t): r*<=t}, with 0<=t<=c. For fixed t the algorithm is polynomial-time. With t part of the input it is coNP-hard under polynomial many-one reductions: use B's polynomial reduction of 3-SAT to the overlap model and set t=c; THRESHOLD then answers 3-UNSAT. The full-order slice t=c is coNP-complete by the same equivalence and NP membership of feasibility. For unrestricted t, THRESHOLD is in Sigma_2^P: existentially guess a sequence of at most 2c independent derived equations and a terminal empty subset (or an initial affine contradiction). Each step names at most t blocks, a supported row, and a reachable tuple demonstrating nonemptiness; universally quantify over all local tuples to check that every reachable tuple satisfies the derived equation and that no reachable tuple exists at the terminal subset. Reachability given a tuple is polynomial affine consistency. All guesses are polynomial-size, and monotonicity guarantees any such derivation is accepted by the canonical closure; the implemented closure supplies such a derivation when it detects contradiction. The exact classification between coNP-hardness and the Sigma_2^P upper bound remains open here. No Sigma_2^P-hardness claim.

Minimum certificates: positive r uses a K contradiction derivation at r plus a nonempty affine subspace D contained in the original relaxation and closed at order r-1. The verifier checks consistency and original equation entailment by augmented rank. For every subset of at most r-1 blocks it independently enumerates reachable tuples and checks that their difference span has exactly the dimension of the affine projection of D. This proves D is closed and nonempty, so no smaller order detects contradiction. D need not be the exact fixed point for soundness; the generator supplies the fixed point. Rank zero uses an original-row XOR contradiction, and infinity uses a directly verified original witness. Proof objects have polynomial encoding size (including the explicit original/derived rows), but checking can be exponential in variable order. In particular this is not a polynomial-time verifier for general UNSAT and does not prove NP=coNP.

The K path family has exact r*=r+1 by the preceding hierarchy argument; new controls compare the fast and original closures on small systems, check minimum certificates and adversarial mutations, and use the 3-SAT reduction. This is a scoped complexity and implementation result; monotone fixed points and affine hull algorithms are classical, and exact novelty needs prior-art comparison. ## Theorem M: graph-predictable recovery-order bounds for signed implication networks

Scope: one triple block for each implication a -> b between signed literals of distinct original Boolean variables. Occurrence consistency uses only affine equalities of the appropriate sign, exactly as K. No additional affine coupling or fixed variable values are allowed in this theorem. The affine relaxation is isomorphic to the free original-variable cube. The implementation accepts an explicit implication list and constructs this model; it does not infer such a representation for arbitrary instances.

Let G be the undirected occurrence multigraph, one edge per implication with signs erased, and g its girth (parallel edges form a cycle of length two). Let D be the ordinary directed implication graph with edges a -> b and not b -> not a for each constraint. The standard 2-SAT criterion says the instance is UNSAT iff some literal x and its complement are mutually reachable. For a pair of such directed paths P,Q, let s(P) be the number of distinct original constraint indices used on P, and similarly for Q. Then for an UNSAT instance,
g <= r* <= max(s(P),s(Q)).
The upper bound holds for every contradictory pair. The implementation searches shortest-edge paths in both directions for each variable and chooses the smallest resulting maximum distinct-index count; this is a polynomial upper bound, not a claim to minimize distinct-index paths globally.

Lower bound: every subset of fewer than g edges is a forest. The forest full-affine-hull lemma of K applies to arbitrary signed implications on distinct variables, including disconnected forests. Such a subset is nonempty and imposes no independent affine equation on the initial relaxation. Thus all orders below g stall at the initial relaxation, proving r* >= g. Upper bound: a path from x to not x forces x=false, and a reverse path forces x=true. The involved constraint subsets are each of size at most the displayed bound. At a nonempty closed affine fixed point at that order, neither subset may have an empty reachable set, and its forced unary equation must hold on the fixed point. The two opposite unary equations cannot both hold. Monotonic termination therefore yields contradiction. This proof uses exact local reachability, not a claim that the paths directly appear in K's trace. For SAT, r*=infinity by L.

Computing girth by removing each edge and finding a shortest path between its endpoints handles parallel edges without ambiguity. BFS from each literal to its complement computes paths in D. With n occurring variables and c constraints, adjacency construction and both calculations use O((n+c)^2) graph operations, with polynomial explicit bit complexity (sparse signed IDs are not expanded to their numeric maximum). The checker recomputes girth and validates all path steps against the original signed implications and their contrapositives, counting distinct constraint indices; SAT claims are checked by mutual reachability. It does not invoke the recovery hierarchy. When the bounds coincide, the exact threshold is predicted in polynomial time on that instance, even when a direct hierarchy computation is infeasible.

Exact family: the two cycles of K with equal length ell>=2 have girth ell and two contradictory paths using ell constraints each, hence r*=ell. The underlying simple graph has treewidth at most two (a pair of cycles meeting at a vertex; for ell=2, two edges after ignoring multiplicity). Thus recovery order is unbounded even at constant original-variable graph treewidth two; no bound depending only on that treewidth exists. This is not a statement about treewidth of arbitrary affine representations, nor a lower bound on 2-SAT solving. The new predictor establishes r*=21 for 42 implication blocks using coincident graph bounds, without running the exponential hierarchy at order 21. Smaller balanced and unbalanced examples are compared to the existing exact minimum-order engine. A noncoincident interval is explicitly not claimed exact. No general prediction theorem for unrestricted overlap instances is asserted.

A separate general structural identity follows from J and L: if a consistent initial affine relaxation factors across blocks, the full threshold is the minimum of the factor thresholds (including infinity for SAT factors). For proof, if any factor detects at order r, its subset steps are valid globally until contradiction. Conversely, if every factor has a nonempty closed affine subset at order r, their product is nonempty and closed: any subset of at most r blocks has reachable set equal to the product of the factor reachable sets on its parts, and the affine hull of a product of nonempty sets is the product of their affine hulls (fix anchors, then vary one factor at a time). By L no global detection is possible. This identity is analytical in this cycle; no new generic factor-threshold optimizer is implemented.

## Theorem N: algebraic obstructions and affine-dimension certificates in the full overlap model

Let C be the original consistent affine relaxation, h=dim C=2c-rank(A), and W=row(A). Let D be the minimum nonzero block support size of a word in W (infinity if W=0). If every block relation has full affine hull (size three or four), then for every subset of fewer than D blocks, the projection of C is the full local cube: otherwise a nonzero supported linear equation would lie in W. Its allowed tuples form a product of full-hull relations and also have full affine hull. Thus all orders below D stall immediately. On UNSAT instances r*>=D. This is a sufficient algebraic lower bound, not a claim to compute minimum code distance efficiently. The more general implemented lower test checks whether the initial relaxation itself is closed at a chosen order by streaming affine points, without requiring full projections.

For any UNSAT instance and consistent C, every affine point violates at least one block. Choosing one violated block per point yields a contradictory subset of size at most min(c,2^h); hence r*<=min(c,2^h). Deleting redundant blocks gives a deletion-minimal inconsistent core, not necessarily a minimum one. At full dimension enumeration, feasibility itself is decidable in O(2^h poly(L)) bit time. This is useful only when h is small; rank alone does not establish a general polynomial-time solver.

The implementation computes an affine anchor and basis, streams all 2^h points by Gray code, collects a core, and tests initial closure up to a user-supplied order cap. It returns SAT witnesses, original affine contradictions, or an interval for r*. The checker verifies anchor satisfaction, basis membership in ker(A), independence and exact dimension by separate elimination, then enumerates the entire certified affine space using binary assignments. It verifies the core excludes every point and independently checks the full reachable hull dimension for every subset below the lower bound. Thus the interval is sound. With lower-order cap t, the total bit cost is O(2^h poly(L)(1+sum_{s=1}^t binom(c,s))); working storage polynomial by streaming. The default dimension budget is 16, and larger instances are rejected unless the caller raises the explicit budget. No claim of optimal bounds or minimum-order calculation in general. The NP-complete model of B is supported, including its 3-SAT encoding, but high-dimensional instances may exceed the budget.

Exact algebraic control: work over GF(4)=GF(2)[alpha]/(alpha^2+alpha+1), take z in GF(4)^3, and one block for each of the 21 one-dimensional projective directions v. Its two-bit output is v.z+2, where 2 is the field element represented by binary 10. Use the fixed implication domain that excludes binary 10, so the local constraint is v.z != 0. The affine map has rank six over GF(2) because the directions include the coordinate unit vectors. Any z has some nonzero orthogonal v, so the instance is UNSAT. Its affine space contains exactly 64 points. Distinct projective directions yield full pair projections, giving D>=3. A stronger argument gives exact r*=4.

For any at most three distinct directions, the excluded sets are distinct GF(4) hyperplanes in GF(4)^3. Each has size 16 and intersects the first in four points, so their union has size at most 16+2(16-4)=40. At least 24 points survive, more than the size 16 of a proper GF(4)-linear subspace. The survivor set is invariant under multiplication by every nonzero field scalar. Its GF(2)-affine hull contains zero, since each nonzero scalar orbit consists of three points summing to zero; the hull is therefore linear and scalar invariant, hence GF(4)-linear. It must equal the entire space. Consequently every subset of at most three blocks has full reachable affine hull relative to its projection, so order three stalls. In the two-dimensional pencil spanned by the first two coordinate directions, there are five projective directions. Requiring nonzero evaluation on four forces zero evaluation on the fifth: the five distinct one-dimensional kernels partition the nonzero two-coordinate vectors, and the zero vector is excluded by all four. The fifth evaluation is an affine linear combination of the first four output forms, so its two forced coordinate equations can be obtained by order-four hull recovery on those four blocks (one independent equation at a time). The remaining fifth block becomes impossible. This proves r*=4. The argument also applies to GF(4)^2 (five blocks), with hyperplane sizes four and intersections one. The implementation generates a four-block deduction trace and verifies it using K, and verifies the lower bound by exhaustive enumeration of the small affine space and subsets of at most three blocks. It does not run the complete order hierarchy for the 21-block case.

This is a concrete algebraic obstruction inside the general overlap model, not a hard instance of unrestricted SAT: h=6 makes the control easy by enumeration. Classical coding theory, affine-space enumeration, finite-field geometry and unsatisfiable cores underpin the results. Full proof formalization, literature comparison and independent expert review remain open. ## Theorem O: linear recovery-order obstructions by the probabilistic method

For every positive integer n there exists an UNSAT overlap instance of c=64n identical implication triples with a consistent affine relaxation of dimension h=16n such that every projection onto at most n blocks is surjective. Consequently the initial relaxation is closed for every order <= n and r* >= n+1 > c/64 by N. The construction has positive affine rate h/(2c)=1/8, unlike the fixed-dimension finite-field example of N. This is a nonconstructive existence theorem with a high-probability random generator, not a deterministic explicit family with efficiently certified distance.

Proof: let G be a uniformly random binary h-by-2c generator matrix and a an independent uniform binary anchor of length 2c. The affine relaxation is the image a+{xG:x in GF(2)^h}. Use the fixed local relation R={00,01,11} on every block (integer values 0,1,3; first coordinate is low bit). Three bad events suffice.

(1) A nonzero coefficient vector w supported on at most n blocks satisfies Gw=0. For fixed nonzero w the probability is 2^-h by independence and uniformity of the rows. The count at support size s is binom(c,s)3^s. For lambda=1/64, the sum for s=1..n is at most lambda^-n(1+3lambda)^c since lambda^s >= lambda^n for s<=n. Thus the bad probability is at most 2^-16n * 64^n * (67/64)^(64n) < 2^-5n, using the exact integer inequality 67^64 < 32*64^64. Absence of such a word means every projection onto at most n blocks has full rank and is surjective; otherwise an annihilator of the projected image lifts to a forbidden low-block-support word.

(2) Some x yields a+xG in R^c. Conditional on G and x, the independent anchor makes a+xG uniform on the whole output cube, so its probability is (3/4)^c. The union bound over the 2^h choices is 2^16n*(3/4)^64n < 2^-8n using (3/4)^8 < 1/8. No independence between different x events is needed.

(3) G lacks full row rank. For every nonzero x in GF(2)^h, xG is uniform on the 2c-bit cube, hence the probability of a nontrivial kernel vector is <= (2^h-1)2^-2c < 2^-112n.

The sum of the three bounds is strictly less than one for all n>=1. Therefore there are choices avoiding all three events. The resulting relaxation has exactly 2^h points and can be encoded in polynomial-size affine equations by taking a basis of ker(G) with RHS determined by a. Every block triple has full affine hull, so full local projections imply that no new independent equation or contradiction can arise at any order <= n. Event (2) failing gives UNSAT. This proves the assertion. In fact the uniform random procedure succeeds with probability greater than 1-2^-5n-2^-8n-2^-112n. No efficient test of success at unbounded n is asserted.

Consequence for the implemented exhaustive subset-scanning recovery routine L: at order n the relaxation never changes and no subset is empty. The routine must therefore inspect every n-subset, at least binom(64n,n) >= 64^n (choose one block from each of n disjoint groups of 64). This is exponential in the block count c, not necessarily in the dense explicit input bit length, and is a lower bound only for this specified implementation at that order. It is not a lower bound on other algorithms computing the same closure, proof systems, or general SAT decision. The already-known M cycle family also has linear recovery order; O adds a positive-rate algebraic construction with all small projections surjective.

Finite controls: sample a full-rank affine frame using a deterministic Python PRNG seed and a bounded trial count; verify projection ranks on all t-subsets and UNSAT by enumeration of the affine space. The checker separately validates frame completeness against the supplied original equations, full-hull local relations, each projection rank, and all binary coefficient assignments. It does not invoke the sampler or the recovery engine. The finite 64-block, 16-dimensional control aims to certify t=2 (stronger than the existence guarantee at n=1), hence r*>=3, not an exact threshold. Its 2,016 pair projections and 65,536 affine points are within the explicit finite budgets. The 24-block control checks that order-one recovery stalls. The finite samples are not proof of the asymptotic result, and their seed search may fail for different parameters. Verification is bounded to 128 blocks, dimension 16 and 10,000 subsets; it is not a polynomial-time asymptotic distance or UNSAT certificate. The analytic existence argument uses the standard Gilbert-Varshamov random-code union-bound technique plus a first-moment exclusion argument; originality of this application remains unestablished.
