# Delayed unit propagation under nonadjacent odd-cycle traversal

**MathOS Millennium milestone PNP-002 · 2026-11-24 · Unreviewed bounded technical note**

## Abstract

Does a fixed edge permutation that delays the initially incident edges increase the literal-read cost? ## 2. Mathematical argument and method

Use the odd inequality cycle and the same two clauses, two branch assignments, positive-first clause ordering, immediate unit propagation and two-literal-read metric of PNP-001. For n odd, visit edge indices 1,3,…,n−2; then 2,4,…,n−3; finally 0,n−1. Repeat the full scan until contradiction. The first scan cannot propagate until the last two edges, because neither earlier endpoint is initially assigned. The procedure records reads and scans over both branches and rejects stalls. This is a fixed-order algorithm experiment rather than a complexity lower bound.
