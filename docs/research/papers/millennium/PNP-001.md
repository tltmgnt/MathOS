# Direction invariance of literal-read cost for two traversal orders on odd parity cycles

**MathOS Millennium milestone PNP-001 · 2026-11-24 · Unreviewed bounded technical note**

## Abstract

Does reversing the edge visit order increase repeated scans under the fixed unit-propagation policy? For n=3,5,7,9,11 both directions use 22,38,54,70,86 literal reads respectively, and two total scans. The hypothesized late-unit slowdown does not occur under simple reversal. ## 2. Mathematical argument and method

Use odd cycles of length n with constraints x_i≠x_{i+1}, each represented by clauses (x_i∨x_j) and (¬x_i∨¬x_j). Fix x0 in turn to 0 and 1. For each edge visit the positive clause first and count two literal reads per clause even if already satisfied. Propagate immediately; stop on contradiction. Both forward and reversed edge lists start adjacent to x0 and propagate around the cycle, so the first n−1 edges cost four reads per branch. The last edge costs two reads on the all-false endpoint branch and four on the all-true endpoint branch. Thus total cost is 8(n−1)+6=8n−2, with one scan per branch in either direction.
