## 2. Mathematical argument and method

Let p≥5 be prime and a an integer Hasse trace with |a|≤2sqrt(p). Define s_0=2,s_1=a and s_r=a s_(r−1)−p s_(r−2). Then s_2=a²−2p fixes |a|. For any odd r≥1, s_r(−a)=−s_r(a) by induction. Also s_r≡a^r mod p for r≥1, by recurrence. Since 2sqrt(p)<p for p≥5, any nonzero Hasse trace has nonzero residue modulo p, so s_r cannot vanish. Thus s_2 and any odd s_r determine a uniquely: if a=0 there is no ambiguity; otherwise exactly one of ±|a| has the observed odd trace. The local inverse Euler polynomial 1−aT+pT² follows. The extension point counts give traces via s_r=p^r+1−#E(F_(p^r)). Conversely all even traces are unchanged under a→−a. This is a statement about local trace information, not the existence of an elliptic curve with each candidate trace.
