# Milestone research papers

For each materially new and verified MathOS research milestone, publish a numbered technical paper here alongside its evidence. Routine maintenance, repeated runs of an identical result, and merely proposed hypotheses are not new discoveries. Mathematical or literature novelty requires a separate prior-art review; do not infer it from project novelty.

Each paper must include the question, specific contribution, mathematical statement or hypothesis, assumptions, methods, observed results (including failures), reproducibility commands, source commit and run links, limitations, and appropriately scoped conclusions. Label drafts and unreviewed technical notes explicitly. Never mark an unexecuted experiment as passed, imply independent review without evidence, or replace a prior result silently. Use versioned corrections. Peer-reviewed publication requires an actual submission and review process.
