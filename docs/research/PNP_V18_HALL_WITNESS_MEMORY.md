## Mathematical conditional transfer

Let a valid Hall witness consist of variable-disjoint required clauses and a partition of their literals into fewer pairwise incompatible buckets. Extract exactly the required clauses and every binary incompatibility premise as the guard set A. The same witness is a refutation of A. Dense variable relabeling preserves this statement. For any signed injection e of the dense variables into the target, extend e to signed literals by e(-x)=-e(x). If the target contains every clause e(C) for C in A, a target satisfying assignment would induce a satisfying assignment of A by pulling back its truth values along e. This contradicts the Hall witness. Alternatively the transformed groups and buckets themselves form a direct Hall certificate. Extra target clauses cannot invalidate it. This is sound conditional transfer, not an assertion that an embedding can always be efficiently found. An explicit embedding can be checked in polynomial time in the guard and target sizes; automatic embedding discovery and retrieval indexing are separate unresolved obligations. This is not a new unrestricted complexity result.

The new module independently checks a source witness, abstracts it to dense variable labels, checks its exact guard-only proof, and on each query revalidates the untrusted record, checks a supplied signed injection, tests guard containment, and verifies the resulting certificate directly against the target. Exhaustion or guard miss earns no positive result. No automatic matching, persistent shared cache, SAT credit, or modification of production routes. Source embedding is a convenience label map, not authenticated provenance; soundness rests on rechecking actual premises. Admission and mapping acquisition costs are not charged to the reported transfer-versus-cold sums.
