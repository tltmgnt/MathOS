# Phase XII — dependency-indexed incremental repair

Run `python tools/mra_x_indexed.py --output indexed-evidence.json` with Python 3.11+. Fixed domains and elimination order, up to 128 variables of domain size at most four, 1024 active factors. Direct edits map factor IDs to replacement tables/scopes or deletion (None). The snapshot adapter matches factor contents and multiplicities. There is no requirement to know future edits. No adaptive order changes, variable-set changes or runtime-trained online dispatcher.

Each original factor is routed to its earliest variable, or the terminal accumulator for a constant. Each projection is identified by the step that produced it, and routed similarly. Edits mark old and new destinations dirty. A minimum-rank queue processes only dirty buckets. If a projected scope or table changes, old and new consumers are marked; if only witness rows change, update those rows without invalidating the downstream numerical message. With fixed domains and order, all dependencies point forward. By induction over rank, unchanged buckets have the same inputs as the fresh reference; changed buckets are recomputed before their consumers. This gives the same projection and deterministic tie-broken trace as a fresh solve. Copy-on-write buckets and locally staged state allow validation and enumeration-budget failures to leave the previous state intact. This is an informal correctness argument, not a mechanized proof. Output construction, snapshot diff, and bookkeeping still incur global work; the budget is not a wall-time or memory limit.

## Local evidence
27 new-seed batches of ten solves (8,32,64 variables; chain/cycle/overlapping ternary factors; repeated, value and structural edits). 270 inputs, 810 comparative solution results per campaign; all agreed, including 252 feasible and 18 infeasible inputs. All indexed traces matched fresh fixed-order execution and the Phase VI checker; 90 inputs also checked by brute force. Eight controls passed: witness-only change, budget rollback, three boundary cases, two invalid edits, returned-trace mutation. Two runs reproduced all deterministic evidence and both report digests verified.

Indexed and same-order flat incremental both enumerated 25,412 assignments; full fixed-order recomputation 94,488; compiled meta (different order permitted) 21,960. Indexed recomputed 2,308 buckets and skipped 7,052, with 2,219 changed messages. This isolates scheduling overhead rather than claiming an enumeration improvement over the same-order cache.

Five randomized-order timing repetitions per strategy per batch (405 timed batch runs per campaign). Includes snapshot diff, setup, planning and complete outputs, excludes verification. Geometric-mean indexed/baseline median-time ratios: fixed incremental min-fill 0.6821 and 0.6896; compiled meta 0.7924 and 0.8073. Worst per-batch ratios respectively 0.9404/0.9458 and 1.0206/1.0685. Both campaigns met the predeclared review gate (at least 10% geometric-mean improvement against both baselines, no more than 20% slowdown on any workload). REVIEW_CANDIDATE only; no deployment. These are repeated local synthetic experiments, not independent or held-out-after-selection benchmarks. No native memory measurements or external solver comparisons. Direct-ID edit performance was not separately timed.

Original curriculum acceptance remains unchanged. Original RE-X integration, Lean certification, independent replication, remote CI, broader performance benchmarks and online learned dispatch remain outstanding.
