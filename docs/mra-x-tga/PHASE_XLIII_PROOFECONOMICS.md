# Phase XLIII — predictive proof economics and verification strategy

Opt-in mra_x_proofeconomics uses a frozen empirical cost model, not a learned mathematical checker. Seven features (log variable count, log factor rows, log elimination visits, largest component log assignment space, maximum arity, infeasibility flag and normalized gap from independent factor minima) are range-scaled with a floor of .25. Five nearest training examples estimate first-acceptance and subsequent replay costs normalized to direct elimination replay. The maximum predicted total cost ratio among the five neighbors is used; it is not a statistical confidence bound. For demand R, compare (first+(R-1)*replay)/R times a calibrated margin to .85. Single-read, disabled-model and fewer-than-64-elimination-visits requests bypass prediction. Calibration chooses a margin from 1, 1.15, 1.35, 1.6 or disabled to minimize demand-weighted observed cost proxy subject to worst observed ratio <=1.2. This proxy excludes feature/prediction overhead, which is included in the held-out timing. The original Phase XLII bounded search/size policy and both unchanged proof checkers enforce acceptance, including checked elimination fallback; no model can approve an unchecked result. Supply an independently trusted expected digest string; direct replay inherits kernel.check's optional-anchor behavior and does not enforce non-None at this facade. Model is trusted local configuration, not an adversarial model parser. No online retraining or timing guarantee.

Run python3 tools/mra_x_proofeconomics_audit.py --model fresh-model.json --directory fresh-audit (new directory), then reuse the same model file with a different directory. Training and calibration use separate seeds (72 training states, 36 calibration states), five timing repetitions for each observed direct check, attempted generation/first acceptance and replay. Local calibrated margin 1.0: 27 of 180 calibration scenarios attempted, predicted aggregate observed-cost proxy .875990, worst 1.165429. Initial 72-problem test timed out; both completed campaigns use every even-indexed test case across six families (36 held-out problems, 28 feasible, eight infeasible, 8–14 binary variables; unary, blocks, sparse, chain, cycle, frustrated overlapping ternary factors). No completed results from the interrupted attempt are included. All five read demands 1/2/4/8/16 retained, giving 180 scenarios per campaign. Three randomized-order timing repetitions of direct elimination, Phase XLII heuristic and predictive, 1620 timed method batches and 540 method/scenario results per campaign. Independent original-factor exhaustive oracle from Phase XL and standalone elimination checker agree with every result. Seven controls per campaign: single read, disabled policy, Boolean demand, wrong digest, false optimum, injected exhausted-search fallback, checked partition. Non-timing evidence identical across two runs using the same frozen model, both report digests verified. This is not independent retraining or external replication.
