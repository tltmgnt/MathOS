# Phase XLI — independently replayable original-factor partition proofs

A second proof format for the exact finite-domain min-sum problem, not an elimination trace. A feasible certificate supplies original factors, a complete witness, its claimed integer optimum, and a partition proof for each connected component independently derived by the checker. For a partial assignment P, each original factor's minimum compatible table cost is a lower bound on its contribution under any feasible extension. Sum these minima to bound the component. A dead leaf requires at least one factor with no compatible row; a bound leaf requires the recomputed sum to be at least the component cost of the supplied witness. A split must name an unassigned component variable and contain exactly one child for every domain value, in value order. By induction on the finite tree, every feasible extension belongs to a checked child and costs at least the target; dead branches have no feasible extension. Component costs and constant factors add. A checked complete witness attains the claimed optimum, hence proves optimality. Infeasibility instead requires a forbidden constant or a complete dead-only partition of one original connected component. No solver trace, projections, elimination order or imported solver scorer needed by the new standalone checker.

mra_x_boundproof.py uses the standard library only. CLI python3 -I -S tools/mra_x_boundproof.py PROOF.json --expect-problem SHA256. Retain expected problem fingerprint independently. mra_x_boundproof_generate.py searches for trees using degree-first/domain-size tie breaking and factor minima; checker does not trust search decisions. It shares parsing/bound routines with the checker; the checker is independent of elimination, not a separately authored verifier of the generator. Budgets: 128 variables, domain sizes 1–4, 1024 factors, bounded integer magnitude, 250000 tree nodes, 10000000 leaf table-row examinations, 8 MB file input and generated proof limits. These are selected work/size bounds, not a complete memory, runtime or adversarial-process sandbox. Search can be exponential and fail within budgets; no universal efficiency improvement claimed. The new format validates optimum and witness, not the elimination trace or canonical tie-breaking witness. It is an opt-in companion certificate, not a replacement for transaction verification.
