# Phase XLIV — deterministic proof economics and mandatory problem binding

Opt-in mra_x_proofguard.select requires an exact lowercase 64-character hexadecimal expected problem SHA-256; the caller must retain it independently. All paths first run the full elimination checker, including its checked visit count and lookups. This prevents admission based on forged solver telemetry and rejects corrupted elimination traces even if a different proof could validate the same optimum. No timing-trained model is needed for this selector. Existing interfaces and default transaction gate are unchanged; the Phase XLIII model is used only as a benchmark comparator. Trusted sequential local callers; returned proof objects can share input references and must be checked on every subsequent read.

Let B = original domain count + factor count + original table rows + 1 + checked elimination visits + lookups + message rows + trace rows. Let C denote the common original problem count (first four terms), and partition replay units P = C + checked partition nodes + leaf table-row examinations. These are heterogeneous deterministic accounting units, NOT comparable CPU instructions or wall-clock bounds. Only consider conversion for R >=4 reads, >=64 checked elimination visits and sufficient budget. Set budget min(300000, floor(R*B/8)); reserve explicit proxy charges for root screening, structural screening, generation and replay preflight. Root-only producer uses independent factor minima attaining the witness per component, or a forbidden constant/empty factor proving infeasibility. Otherwise reject if a conservative complete-tree bound exceeds remaining proxy budget. At each depth the nodes describe disjoint subsets of complete assignments; (component size+1)*product(domain sizes) bounds total nodes. Multiply by factor queries plus possible row scans per node for a conservative search counter bound. Use existing adaptive search with capped nodes, work and cache entries. The complete-tree screen is intentionally pessimistic. Count search counters even on refusal. Replay preflight bounds leaf row scans by each leaf's component's total original table rows. Accept conversion only if B + extra charged units + (R-1)*preflight bound <= .9*R*B and the new proof fits 8 MB. Independently check the new proof and compare optimum to the first receipt; an unexpected checker refusal fails closed. Conversion counts as two total checks (elimination then partition); remaining reads replay the chosen proof. Refused conversion uses the already checked elimination certificate. For normal returned decisions, charged speculative proxy units <= floor(R*B/8), selected partition projected units <= .9*R*B, fallback projected units <= 1.125*R*B. This is an accounting bound, not a total computational complexity or latency theorem: sorting, parsing, Python operations, hashing, graph construction, serialization, allocation and actual time are not fully counted. No hostile-code isolation, mechanized program correctness, independent replication or physical RE-X equivalence claimed.
