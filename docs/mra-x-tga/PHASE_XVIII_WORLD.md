# Phase XVIII — predictive edit-event world model

Run python tools/mra_x_world.py --output world-evidence.json --model world-model.json. The engine learns a five-class first-order categorical transition model (add, remove, resize, factor, idle) with Laplace smoothing. It estimates three-transaction relative enumeration effects from paired interventions, changing only the first action then following Phase XV, with identical external edits in both trajectories. The eight-feature nearest-neighbor estimator conditions on baseline action, alternate action and current event; weights observed next-event groups by predicted probabilities. Unsupported mass is assigned zero gain and counted separately. Positive-gain frequency and support thresholds are heuristics, not calibrated statistical confidence intervals. The model forecasts edit categories, not complete future states or general causality.

18 training streams (370 transactions), 12 separate validation streams (238 transactions), 18 held-out streams (350 transactions), new seeds, randomized synthetic edit motifs, three graph families. Training generates 170 paired rollouts (35 beneficial, 114 harmful, 21 ties). Validation evaluates fallback and gain thresholds 0.05, 0.15, 0.30 with fixed positive-frequency >=0.7 and support >=0.75; all tie at 15,719 evaluations with no departures, so validation selects fallback before holdout. Model saved to fingerprinted JSON and reloaded. No test tuning. Inference sees current/past edits only.

Per campaign 3,984 verified transitions (including paired rollouts and repeated validation), four basic checks, zero mathematical disagreements. Identical model and non-timing evidence across two runs; report digests checked. Held-out next-event forecasts 159/332 top-class correct (47.89%), multiclass Brier 0.591604 vs unconditional 0.781033 (24.25% lower). Post-hoc paired interventions on held-out baseline trajectories: 157, of which 46 improve, 98 regress, 13 tie; 26 improve despite higher immediate enumeration. 150 estimates available, 109 correct positive-vs-nonpositive classifications (72.67%) versus 105/150 (70%) for always nonpositive. Mean absolute relative-gain error 0.511705. No estimate satisfied both positive-frequency and support gates. These diagnostics are not policy selection data. Held-out actual work 47,251 each; 325 feasible and 25 infeasible inputs. No promotion. Three randomized-order timing repeats per policy on 18 streams; ratios 0.995311 and 1.003287, worst 1.038950 and 1.067681. Since validation disabled learning, these compare identical fallback code paths, not learned inference overhead. No measured speedup claim. Timings exclude training, verification, disk I/O and model loading.

The policy is intentionally conservative and did not demonstrate decision utility. Shared scripted motifs limit generalization. No persistent live learner, independent replication, real-world causality, original RE-X integration or Lean proof. Model fingerprints are not authentication. No default policy change.
