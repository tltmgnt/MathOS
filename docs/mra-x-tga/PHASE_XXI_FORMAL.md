# Phase XXI — mechanized mathematical obligations

Run `python3 tools/mra_x_formal.py --output formal-evidence.json` on a system with the Z3 shared library (tested with Z3 4.13.3.0, Linux). The Python ctypes adapter uses a fresh solver context and a five-second solver timeout for each query. Only explicit SAT or UNSAT is accepted; UNKNOWN/errors fail the audit. No floating-point optimization is used.

## Mathematical scope

The projection theorem is encoded using arbitrary separator and eliminated-variable sorts, a feasible integer-cost relation C(s,x,c), a projected relation P(s,p), and an unaffected feasible cost tail(s). Assume attainment (each projected cost has an original witness) and dominance (each original feasible cost has a projected cost no larger at the same separator). SMT checks both directions of minimum equivalence by separately checking attainment and the global lower-bound property, both directions of feasibility equivalence, and witness lift. The original combined quantified query returned UNKNOWN in the initial experiment; splitting it into the constituent implications allowed all final obligations to discharge.

Additional checks cover the minimum/earliest-index fold invariant (four obligations), equality of argmin relations under equal input cost relations, unchanged consumer contribution under the abstract old/new route invalidation rule, and the inductive arithmetic step for a lower-bound order potential. Together these are 14 UNSAT obligations, plus three SAT countermodels after dropping attainment, dominance or the clean-consumer premise. These are symbolic lemmas over the encoded mathematical abstractions, not a machine-checked refinement from Python or a complete proof of the dirty-queue algorithm, migration signature, termination, persistence, or witness recovery. Induction and composition of the local obligations into program-level correctness remain to be formalized. Z3 is trusted; there are no exported independently checked proof objects and Lean remains unavailable.

## Independent concrete optimum verification

For each finite input the encoder directly declares integer variables with domain constraints and one extensional table disjunction per factor, including empty and constant factors. The total is the sum of factor costs; absence of a row is forbidden. For a feasible claimed result with integer objective m, ask SAT with the exact witness and total=m, and UNSAT for total<m without fixing the witness. For an infeasible claim, ask UNSAT for the original constraints. No elimination order or computed message is used in these queries. The encoder shares input validation with the reference implementation, so this is an alternative solving formulation, not fully independent software or independent replication.

44 generated networks across 11 existing topology families; four checked states per network (indexed initialization, domain expansion with reordered migration, insert a forbidden unary at the last variable, remove it), plus three boundary cases. 179 outputs: 101 feasible, 78 infeasible; 280 direct SMT queries (101 SAT witness queries and 179 UNSAT optimality/infeasibility queries). Every checked indexed/migrated trace matches the fresh same-order reference; each migration actual work is within its predicted bound. Five deliberately invalid result claims rejected, including a feasible but suboptimal solution, an impossible better objective, false infeasibility, mismatched witness and Boolean witness masquerading as integer. Two local complete reports were byte-identical, with the report digest verified. Counts refer to one campaign unless specified.

No new performance claim or default-policy promotion. This phase does not close original RE-X physical-logical equivalence, Lean certification or independent benchmarking.
