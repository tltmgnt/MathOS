# Phase XXXII — compact persistent mathematical memory

Run python3 tools/mra_x_dense_audit.py --directory dense-audit (new directory). Opt-in Store uses integer primary keys for objects, a binary SHA-256 unique index, compressed canonical version manifests (zlib level 1), and no separate reference table. Exact content comparisons accompany hash matches. On expiry, parse the retained manifests and delete unreferenced objects atomically. Store and Compressed use separate databases; no format migration or mixed-format API. Compressed is a stronger new baseline storing one compressed self-contained snapshot plus the nonduplicated result fields per version. Both inherit the independently routed mathematical checking approach and rebuild the verified engine on reopen. Full factor/trace scans, serialization, and independent recovery checks remain. Manifest and payload digests are integrity checks, not authentication or rollback protection. Decompression rejects trailing or incomplete compressed streams and expansion past 8 MB; database reads and the garbage-collection scan do not constitute hostile-input memory limits. No new program-level proof, original RE-X integration, arbitrary concurrency, or power-loss guarantee.
