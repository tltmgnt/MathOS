# Phase XIX — bounded model-based scenario planning

Run from repository root: python tools/mra_x_scenario.py --output scenario-evidence.json --model scenario-model.json.

Learn Laplace-smoothed categorical transitions on 12 training streams (110 transactions, 8/12 initial variables). Generate concrete hypothetical edits using hand-written domain-aware templates: add a variable and factor, remove a previously added variable and its incident factors, resize and filter invalid rows on contraction, modify a factor, or idle. The proposal uses only the current simulated state, the original variable set and seeded randomness. It does not read future test edits. Templates are not learned full-state transitions and scenario accuracy was not validated against actual future edit sequences.

When Phase XV's alternative order differs and is admissible, execute both initial actions, then evaluate three sampled two-edit continuations with common external edits, continuing with Phase XV. Choose the alternative if mean relative enumeration gain is at least 10% and it wins at least two of three scenarios. Reuse the selected initial execution; count the unselected initial execution and all future shadow visits as planning overhead. Verification separately replays every tested transition. The gate compares total kernel visits including planning, not only committed work; no statistical confidence claim. Each decision evaluates at most 14 kernel executions (two initial, twelve future), with the existing per-state full enumeration budget. No separate global search time or memory limit. A hypothetical budget failure can raise rather than gracefully abstain; this was not exercised.

Six validation streams (57 transactions, 10 variables): fallback 2,118 evaluations; active actual 2,084 plus 6,734 simulation overhead = 8,818. Validation selects fallback. Twelve new-seed test streams (108 transactions, 16/24 initial variables, up to 25), compare the frozen fallback with the predeclared active diagnostic policy. All objectives and checked traces agreed with the reference and Phase VI checker. Per campaign 1,324 verified transitions including training, repeated validation and paired simulations. Active diagnostic planned 48 times, departed nine times, five workloads saved committed work, five tied, two regressed. Baseline 8,141; active committed work 7,484 (-8.07%), overhead 28,912, total 36,396 (4.47x baseline). Two randomized-order timing repetitions per policy per test stream (48 timed stream executions per campaign). Active/baseline geometric mean median-time ratios 6.2253 and 6.4954; worst 9.7047 and 10.6465. Both NO_PROMOTION. Runtime includes scenario planning and in-memory execution, excludes training, verification and SQLite. Two reports reproduced all non-timing evidence and identical model; digests verified. The larger initial audit attempt timed out and the corpus and repetition counts were reduced before completed campaigns. No external or independent replication.

The implementation is opt-in and does not replace Phase XV, integrate with durable state, certify general causal effects, provide mechanized proof, or integrate original RE-X. Future direction: cheap structural surrogates, explicit planning budgets and abstention, calibration of scenario quality, independent benchmarks. No default policy change.
