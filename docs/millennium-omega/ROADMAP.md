# Roadmap

**Stage 0 (implemented in this branch):** Seven explicit engine adapters,
six deterministic offline agent stages, input fingerprints, hard proof-state
nonpromotion rules, a TECT packet auditor, adversarial Python tests,
a bounded benchmark and independently checked small Lean/Coq policy lemmas.

**Stage 1 (future):** Model-specific formal definitions aligned by
mathematician-reviewed specifications, exact source theorem references,
and proof-dependency traceability. Every proposed bridge must document
quantifiers, hypotheses, and counterexample criteria.

**Stage 2 (future):** A sandboxed optional model-backed discovery/conjecture
component that produces untrusted candidates. Add schema constraints,
cost quotas, reproducibility records, adversarial critique and explicit
human approval. Reuse MathOS's existing agentic research harness.

**Stage 3 (future):** Formally reconstruct tightly scoped published results
in Lean/Coq (with trusted kernel transcripts, declared axioms, exact theorem
statements and independent specialist review), never conflating those
subresults with Millennium claims.

**Stage 4 (future):** Preregistered evaluation against comparison workflows
and held-out tasks; external reproduction and negative-result reporting.

No stage automatically unlocks theorem certification. Any proposal to promote
a global theorem requires separate, externally reviewed mathematical evidence.
